## 2. 建造四块 · 技术路径拆解

每块给出：**物理链** → **建议 golden（闭式物理律）** → **建议 candidate（方法学独立数值）** → **复用接口** → **已知坑**。

### 2.1 纠缠分发（Entanglement Distribution）

**物理链**：NV 自旋 ↔ 腔 ↔ 飞行光子 → 光纤（损耗 η_fiber）→ 远端。分发后得到 Bell 对角态 ρ(F)。

- **建议锚 1（主）· 分发保真度**：
  - golden = **偏振编码 Bell 态经损耗 + 退极化的解析保真度**（Werner 族闭式：分发后 `F = (1+3p)/4`，p 为信道保留相干度，由 η 与偏振漂移解析给出）。
  - candidate = **密度矩阵 Kraus 序列数值传播**（含部分迹 ⇒ 复用 `partial_trace_mode2`）。
  - 与 B10/B30/B453/B502/B503 **保真度族**的分歧：①被测标量（**两体纠缠态保真度** vs 单比特门/读出/相干态损耗/门预算保真）②物理构型（**含信道传输的两体态** vs 本地单比特信道）③数值格式（**两体 Kraus + 部分迹** vs 4×4 PTM / erfc 链 / 一维求积）。
- **建议锚 2（辅）· 纠缠度**：concurrence `C = max(0, 2F−1)`（Werner）——但**纯代数** ⇒ 残差沉地板，**不可单独立锚**（同 S1–S6 纪律），须与积分/ODE 结构绑定或降为 smoke。
- **建议锚 3（备选）· CHSH 参数**：`S = 2√2(2F−1)` ⇒ 违反 Bell 不等式阈值 F>1/√2 的**物理判据**；同样是代数式，宜作判据而非锚。
- **🔴 已知坑**：① 分发保真度**易与 B454/B455（TMSS 预报条件态）撞车**——两者都用 TMSS 源，必须把被测标量锁在"**两体**纠缠度/保真度"而非"**单模**约化纯度/g²(0)"（见 §3.1）；② 熵/纠缠度类量在纯信道下可能**解析可积** ⇒ 残差沉地板，锚形须含非平凡数值结构（如时间/距离积分）。

### 2.2 量子中继（Quantum Repeater）

**物理链**：链路分 n 段 → 每段建立纠缠 → **纠缠交换**（Bell 基测量）串接 → （可选）纠缠纯化 → 端到端。

- **建议锚 1（主）· 纠缠交换后的保真度递推**：
  - golden = **两级 Werner 态纠缠交换的解析递推** `F' = f(F₁, F₂)`（Bell 对角态在交换下封闭，有教科书闭式）。
  - candidate = **完整密度矩阵的 Bell 基投影 + 部分迹数值模拟**（16×16 或截断 Fock）。
  - 与 B453/B454/B455 分歧：①被测标量（**交换后两体纠缠保真** vs 单模纯度/g²）②物理构型（**双源交换测量** vs 单源预报）③数值格式（**Bell 投影算符链** vs Kraus 求和）。
- **建议锚 2（辅）· 中继增益**（用户点名锚）：
  - 定义 `G = P_repeater(L) / P_direct(L)`，其中 `P_direct = e^{−L/L_att}`（指数），`P_repeater = p₀^{L/L₀}`（分段乘积）。
  - **物理本质**：对数域 `ln G = L·(1/L_att − ln(1/p₀)/L₀)` ⇒ **线性于 L** —— 这就是"中继把指数衰减变成线性衰减"的复利本体。
  - 🔴 **风险**：纯幂次的 `p₀^{n}` 是**代数式**，残差必沉机器地板 ⇒ **不可直接立锚**。**建议改靶**：把锚落在**含存储退相干的吞吐率** `R = (1/T_gen)·P_succ`，其中 `P_succ` 含对存储窗口 `∫ e^{−t/T_mem} dt` 的积分 ⇒ 有真实数值残差与收敛阶（复用 J4 M3 的 `∫率 dt` 经验，但**必须与 B502/B503/B504 的 `exp(−∫率)` 原子族避开**——本条积分在**分母的时间窗**而非指数的率，须逐项核验分歧）。
- **复用接口**：`partial_trace_mode2`（交换取迹）· `hom_visibility`（交换质量上限）· `logical_error_rate.logical_error_accumulated`（多段累乘骨架）。
- **🔴 已知坑**：① **"中继增益"与既有 `passivity` 无增益上界锚（part1:438）语义相反**（那条判"有增益=FAIL"，本条判"增益>1 是好的"）⇒ 必须在 note 显式声明，否则易被判为重复；② 递推类锚**极易落代数恒等**（同 B28 陷阱：线性被积函数时 RK4 精确）⇒ 必须现场证 `残差链比值恒定 ∧ 残差>0`；③ **存储-检索**若不引入时间窗，则整条链是纯代数。

### 2.3 微波-光换能器（Microwave-to-Optical Transducer）

**物理链**：超导微波（~5 GHz）↔ 中介（光机械振子 / 电光腔）↔ 光（~200 THz）。跨 4–5 个数量级的**频率桥**。

- **建议锚 1（主）· 换能效率**（用户点名锚）：
  - golden = **腔电光/光机换能效率闭式** `η = η_in·η_out·(4C/(1+C)²)` 之类（含**输入输出耦合失配**与**协同度 C**；C = 4g²/(κ_m κ_o)）。
  - candidate = **主方程 / Langevin 数值积分**（含侧带分辨极限，`κ ≪ Ω` 时解析；否则需数值）。
  - 与 **B28（MZM 半波电压 Vπ · 电光 Pockels）** 的分歧：①被测标量（**跨频段转换效率·无量纲** vs **调制电压 Vπ·伏特**）②物理构型（**微波↔光双向换能** vs **同频段电光相位调制**）③数值格式（**主方程/侧带数值积分** vs 解析 Vπ 公式）——**三方齐分歧**，可立。
  - 与**光学效率族**（米氏散射 / taper / 光栅耦合 / 光纤-波导对准 / NA 收集）分歧：那些全是**同频段光-光**效率，本条是**跨频段微波-光**。
- **建议锚 2（辅）· 换能噪声**：**附加噪声光子数** `n_add` —— 🔴 **已被 B514 占用**（Caves 极限 `(η/g)(1−e^{−gL})`）⇒ 本条须靶**换能器专属**的噪声（如**热光子占据数** `n_th = 1/(e^{ħΩ/kT}−1)` 经换能折射）或**侧带冷却极限**，并在 note 与 B514 逐项分歧。
- **复用接口**：`qs_m3c.cooperativity_from_g` / `purcell_factor_qv`（协同度定义可直接借）· `lda_solver` 模式求解（光机腔模式体积）。
- **🔴 已知坑**：① **B28 是最近的邻居**，必须三方齐分歧；② 换能效率值**跨 4–5 量级**（典型 1e-6–1e-2）⇒ **tol 绝对口径须按量级标定**（血案 B487 尺度盲）；③ 光机/电光的**侧带分辨**是"解析 vs 数值"的分水岭，须显式声明建模档，否则 golden 站不住。

### 2.4 量子-经典接口（Quantum-Classical Interface）

**物理链**：量子测量结果 → 经典读出（ADC 采样 / 时钟抖动 / 前馈延迟）→ 经典决策 → 反馈回量子系统。

- **建议锚 1 · 时钟抖动导致的相位/保真损失**：
  - golden = 抖动谱 `S_φ(f)` 经控制滤波器后的**相位方差积分**（复用 `qs_m2.cpmg_filter` 的滤波函数思想）⇒ 保真度 `F ≈ exp(−σ_φ²/2)`。
  - candidate = **抖动时间序列蒙特卡洛 + 数值积分谱**。
- **建议锚 2（备选）· DAC 零阶保持的 sinc 衰减**：`|sinc(πfτ)|` —— 但**纯定义式** ⇒ 宜作 smoke 不作锚。
- **复用接口**：`qs_m2.cpmg_filter` / `coherent_chi`（滤波-方差框架）· `cryo_electronics`（读出链噪声）。
- **🔴 已知坑（本块最高）**：① "经典接口"**极易滑向工程参数充数**（采样率 / 延迟 / 位数）⇒ 凡无物理律支撑者**一律归 smoke**，不得登记为 B 锚（同 B482/B485/B488 的"诚实规模"纪律）；② 体检实测 `ADC|DAC|采样率|抖动` 在锚定义内 **零命中** ⇒ 零占用，但也**零地基** ⇒ 本块**复用最薄**，宜排在 M3+ 作。
