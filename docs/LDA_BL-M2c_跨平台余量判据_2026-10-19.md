# LDA · BL 征程 BL-M2c：跨平台余量判据（2026-10-19）

> 状态：**已实施（v0.9.255 · 全量 CI 待绿）**。本档不修锚、不改 `tol`，改的是**跨平台验收标准**。
> 前置：BL-M1（`B82`，v0.9.252）→ BL-M2（同族 7 条，v0.9.253）→ BL-M2b（14 条 tol 收紧，v0.9.254）。

---

## 一、问题：v0.9.254 发布时实测发现

v0.9.254 把 14 条 `tol` 按窗口法收紧，其中三条收到 **`1e-16` 量级**。发布核验时把生产
（py3.9.19 · 无 scipy）现算值与本地（py3.14.3）台账逐值对比，得到：

| 锚 | tol | 生产 resid | 本地 resid | 相对差 | `resid/ulp(\|g\|)` | 生产 `resid/tol` |
|---|---|---|---|---|---|---|
| `B74` | 2.81e-16 | 2.776e-17 | 2.819e-17 | 1.5% | **130 ulp** | 0.099 PASS |
| `B87` | 8.89e-16 | 8.782e-17 | 8.890e-17 | 1.2% | **410 ulp** | 0.099 PASS |
| `B88` | 5.02e-15 | 4.484e-16 | 5.022e-16 | **10.7%** | **579 ulp** | 0.089 PASS |

**判决全部稳定（余量 ~10×），但 `resid` 的绝对值不再跨解释器逐位复现。**

### 机理解释（为什么这不是「执行不到位」）

`resid = |candidate − golden|`，而这两条路径在深隧穿/反共振区算出的量**几乎相等** ⇒
`resid` 是**两个近等值之差**，其大小只有 `|golden|` 的 **100~600 个 ulp**。
此时底层一次减法或 FMA 的**几 ulp 舍入差异**，会按

```
相对漂移 ≈ (平台间 ulp 差) / (resid 的 ulp 数)
```

被放大：`B74` 差 2 ulp / 130 ≈ 1.5%；`B88` 差 62 ulp / 579 ≈ 10.7%。**与实测完全吻合。**

⇒ **v0.9.252/253 立的「生产逐值复现台账」标准，在 `tol → 1e-16` 时物理上失效。**

## 二、新标准：判「判决不变」，不判「末位相同」

```
跨平台验收（BL-M2c）
  ① 主判据：  tol / resid ≥ 5
  ② 扰动探针：resid × (1 + δ_max) 之后，tol / resid' ≥ 3      （δ_max = 0.15，实测 0.107）
```

**要的是「判决跨平台不变」，不是「浮点末位一致」。** 后者既做不到，也不是验收的真正目的。

## 三、脆弱集：现算，不点名

```
脆弱判据：  compare == cmp_abs  ∧  resid > 0  ∧  resid ≤ 1e4 · ulp(|golden|)
```

现算得 **7 条**（台账 396 行）：

| 锚 | ulp 数 | `tol/resid` | ×(1+δ_max) 后 |
|---|---|---|---|
| `B74` | 130 | **9.97×** | 9.0× |
| `B87` | 410 | **10.0×** | 9.0× |
| `B88` | 579 | **10.0×** | 8.7× |
| `B10` | 1 | 9.0e7× | 7.8e7× |
| `B73` | 306 | 2.9e11× | — |
| `B79` | 1566 | 5.8e10× | — |
| `B192` | 2472 | 1.1e9× | — |

**7 条全部已满足，本档零改动、零 `tol` 调整** —— 这正是「先测再定阈值」的好处：
阈值 `1e4 ulp` 与余量要求 `≥5` 都不是拍出来的，而是先算出集合再回看。

## 五、诚实边界

1. `δ_max = 0.15` 是**一次**跨平台实测（py3.9.19 vs py3.14.3）的上界，**不是所有平台/编译选项的严格上界**。
   换 BLAS 后端、开 `-ffast-math`、换 CPU 架构时须**重测并同步调整**（改 `BL_PLATFORM_DELTA_MAX`）。
2. 脆弱集判据按 `ulp(|golden|)` 归一，**对 `golden ≈ 0` 的量不适用**（已排除 `|golden| ≤ 0`）。
3. `cmp_le`（不等式锚 `B19`）不参与 —— 其 `resid` 是「越界量」，与 `tol` 不是同一量纲。
4. 本档未处理 `B31` 的假绿（**M2b-1**），也未处理 8 条「不可收紧」（候选精度不足）。
