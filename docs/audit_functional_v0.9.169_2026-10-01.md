# LDA 功能审计报告（独立版）

> 版本基线：v0.9.169 · 日期：2026-10-01 · 性质：**功能审计**（不改锚、不动棘轮、不发版）
> 方法：以 WebUI 路由 / 案例卡 / 求解器入口 / 案例卡产物为审计面，逐能力域核对「状态 + 证据」；与 2026-09-23 设计能力路线图交叉校验。
> 主文档：`docs/LDA_战略总纲与全面审计_实施规划_v0.9.169_2026-10-01.md` §3；本报告为其独立展开版。

---

## 0. 一句话结论

**核心计算能力（光子仿真 / 主权版图签核 / 电子 ecore / 量子双栈）全部可用且闭环；但「可交付化」链条断裂（设计→GDS→下载无单路径）、PDK 生态空心、商业闭环终点（在线支付）缺失——即「能算对」已解决，「拿得走」尚未解决。**

## 2. 功能缺口优先级

| 优先级 | 缺口 | 说明 |
|---|---|---|
| **P0（阻断交付）** | 设计→GDS→下载单路径 | 设计面板产物为 JSON 包，无 GDS；GDS 签核结果在另一面板且不可下载 |
| **P0（阻断商业）** | 在线支付 / 真实客户触达 | store.json 闭环终点是人工询价；获客为零（杜先生 lane） |
| **P1（主权变价值）** | 横向交叉验证网扩建 | 从 DC coupler 1 格扩到跨器件族 N 格 |
| **P1（主权变价值）** | gdsfactory/SAX/KLayout 互操作 | 导入/导出/DRC deck 读取，让行业能消费 LDA 产出 |
| **P2（体验）** | 上手路径 | 3 分钟上手教程 + agent-browser 实测验收路径公开 |
| **P2（体验）** | 案例卡→可下载交付 | 案例卡产物一键导出 GDS/JSON/报告 |
| **P2（体验）** | WebUI 入口可达性复核 | `run_webui_entry_smoke` 常态化 |

## 3. 已强项与须防稀释

- **强项**：主权全链路 GDS（零 gdsfactory 依赖出片 + DRC/LVS 双闸）、ecore E1–E19 全链闭环、量子双栈、272 道冒烟门禁。
- **须防稀释**：不要为了补 P2 体验项而新开功能线；所有新 UI 能力必须先过「入口可达性 + 实测上机路径」两道验收（历史教训：能力上线≠用户能找到）。

---

## 4. 对应实施动作（映射主文档 §7）

- 阶段 2（交付闭环 D3→D4）：W2-1 设计→GDS→签核→下载单路径；W2-2 案例卡产物一键导出；W2-3 入口可达性复核。
- 阶段 3（主权变硬证据）：W3-1 交叉验证网扩建；W3-2 互操作最小可用。
- 阶段 5（商业破冰）：W5-2 上手教程与验收路径公开；W5-3 在线支付（杜先生拍板）。
