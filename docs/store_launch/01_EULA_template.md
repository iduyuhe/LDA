## 一、定义

1.1 「**设计就绪包**」（Delivery Package）：指甲方通过 LDA 平台交付的、由甲方自主引擎基于公开标准（如 IEEE 802.3 / CWDM4 MSA）与主权物理锚生成的设计交付物，通常包括：GDSII 版图、网表（netlist）、仿真报告（含死锚比对）、DRC/LVS 结果、工艺角说明、本授权协议及诚实声明。

1.2 「**GP-\* 基准**」：甲方公开的产品级基准库，作为设计验证的确定性锚点。

1.3 「**死锚**」：确定性物理定律锚或跨多源实证大数据锚，用于判定设计是否通过，LLM 不进入判决路径。

## 二、授权范围

2.1 甲方授予乙方一项**非独占、不可转让、不可再许可**的使用许可。

2.2 用途：乙方可将设计就绪包用于自身产品研发、原型制作、流片适配及内部评估。

2.3 地域：全球（若涉及量子相关设计，以甲方另行书面许可的区域为准，并遵守适用出口管制法规）。

2.4 期限：永久（自支付完成且交付成功之日起）。
