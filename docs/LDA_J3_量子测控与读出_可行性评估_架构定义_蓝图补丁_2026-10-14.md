## 0. 立项依据

用户 2026-10-14 明确「J3 量子测控与读出（Control & Readout）— 闭环可用性」，即确认 J3 为量子赛道第三征程（**Layer 3 测控闭环层**，蓝图缺口 **G-CTRL***）。

**为什么此刻做 J3**：J1（QEC · 逻辑比特层）与 J2（Transmon QPU · 物理比特层）把「**器件参数 → 物理错误率 → 逻辑错误预算**」这条**下—上层**链打通了（v0.9.233 收官：B506–B509，`run_j2_qpu_smoke` 37 判据，J1↔J2 复利闭环机器可跑）。但这条链目前是**开环**的：

- J2 的 `physical_error_model` 吃的是**给定**的 T1/T2/t_gate —— 它不回答「**这个门是怎么被驱动出来的**」；
- J2 的读出链（`j2_readout_mux`）算的是**静态**通道隔离与 ZZ 预算 —— 它不回答「**读出来之后怎么判定、判定错了怎么回写参数**」；
- 门库 `lda_qeda/gates.py` 的 docstring 自己写明边界：「**不声称具体物理门的脉冲实现保真度（那是器件层，归 transmon_solver / 实测标定）**」—— 这句话就是 **J3 的开工令**。

J3 要补的正是这层：**脉冲怎么打（Rabi/DRAG）→ 门保真怎么标（RB/unitarity）→ 读出怎么判（解调/匹配滤波/Purcell 滤波）→ 参数怎么回写（标定闭环）**，即**闭环可用性**。

🔴 **与 J2 / S 分支的关系（必须先对齐，避免重造轮子）**：

| 层                               | 谁负责                 | J3 做什么                                         |
| ------------------------------- | ------------------- | ---------------------------------------------- |
| 器件物理（f01/α/J/χ/Purcell）         | J2 + D-35/D-74/D-88 | **只读复用**（不改公式、不重做）                             |
| 芯片版图/DRC/LVS/频率避撞/控制线几何         | S 分支（D-133…D-145）   | **只读复用**（`sc_control` 逐线串扰、`sc_readout` 读出腔几何） |
| 物理错误率 / QPU 预算 / 拓扑↔QEC         | J2（B506–B509）       | **只读复用**其**输出量**作 J3 的输入                       |
| **脉冲级控制 + 标定闭环 + 读出解调 + 低温电子学** | **J3（本征程）**         | ✅ **新增**（既有锚/模块均未覆盖，见 §1.2）                    |

三条线共用同一组红线（纯 numpy/scipy · 零量子 SDK · LLM 不进判决路径 · 设计预算口径非实测）。

### 1.3 红线 / 主权可行性（LDA 铁律逐条对账）

- **主权求解器（C 级纯 numpy/scipy，不借 QuTiP/Qiskit/PennyLane/Cirq）**：  
  · 三能级含时驱动 TDSE —— 维度仅 **3×3**，可用 **`scipy.linalg.expm` 精确矩阵传播子**与**自研 RK4** 双路互证（B507 已建立「矩阵传播子 RK4」先例）；  
  · RB 随机序列 —— 单比特 Clifford 群 **24 元**已在 `gates.py`（精确群论），密度矩阵/PTM 演化纯 numpy；  
  · 读出解调 —— 匹配滤波/积分窗纯 numpy 复算术；  
  · 低温电子学 —— 级联噪声因子（Friis/Kraus 等效）纯闭式。  
  ⇒ ✅ **全部可行，无外部依赖**。
- **LLM 不进判决路径**：全部死标量（Rabi 布居、泄漏概率、RB 衰减率/纯度衰减、SNR/分配错误率、抑制比、附加噪声光子数）。✅
- **绝对 tol 按量级标定（B487 血案）**：J3 涉及 **6 类量纲** ⇒ 必须**分别**标定，且用「**绝对 ∨ 相对并列**」（不可用 `max`，否则尺度盲）：  
  · 门错误率/泄漏概率/分配错误率 ~**1e−4…1e−2**（无量纲概率）  
  · 保真度 ~**1e−3**（贴近 1 的量）  
  · 频率 ~**1e0 GHz / 1e2 MHz**  
  · 时间 ~**1e0 µs / 1e2 ns**  
  · SNR ~~**1e0**（无量纲）  
  · 比率（抑制比/提升倍率）~~**1e−2**  
  · 附加噪声光子数 ~**1e0 光子**
- **golden 分级（③仿真值⛔永不作 golden）**：golden 锁定为 ①**闭式物理律**（Rabi `P₁=sin²(Ωt/2)`、退相干极限 `F=(3+2e^{−t/T2}+e^{−t/T1})/6`、Purcell `F_P=4g²/(κγ)`、Caves 量子极限 `n_add ≥ 1/2`）与 ②**已知事实**（Clifford 群 24 元 = 群论事实、π 脉冲面积 = π）；③数值 TDSE/RB 蒙特卡洛/解调仿真**只作候选与标度证据**，**永不作 golden**。✅
- **复用 S/J2 铁律**：频率限带 `f01∈[5.0,6.2] GHz`（S 铁律①）· 耦合器工作区 `f_coupler < f_qubit`（S 铁律②）· 拓扑度上限由拓扑自声明（S 铁律③）· J2 的「同源体检必做」「口径订正用新增+标注」「下界≠可达」三条工程纪律**全继承**。✅

## 3. 蓝图补丁（里程碑 · 复利吃狗粮）

> 每档用 LDA 亲手设计一段真实测控补丁，物理链逐量「**闭式 golden ⇄ 方法学独立候选**」。  
> 🔴 候选锚编号 **B510–B514** 为提案；**每档实现前必须逐锚做同源体检**，判同源即改靶（先例：J2 M0 净增 0 / M3·M4 各否决 2 候选）。

### M0 测控闭环骨架 + 时域驱动脉冲（Rabi）

- **建造**：参数化脉冲库（矩形/Gaussian/DRAG）+ 三能级含时 TDSE 演化器（`expm` 精确 ⇄ RK4）；把「**Rabi 幅度定标 → π 脉冲 → 门保真 → 读出判别 → 参数回写**」串成**标定闭环**（复用 QS-M5 闭环思想 + J2 `physical_error_model` + D-47 读出保真度）。
- **候选锚**：**B510** 共振 Rabi **时域布居** `P₁(t)=sin²(Ωt/2)`（闭式 golden ⇄ 时域 TDSE RK4 数值积分）。
- ⚠️ **立项前体检（必做，且已预设改靶路径）**：须对 **D-91 `solve_drive`** 证**三方分歧** —— ①被测标量（**时域布居函数** vs 静态本征分裂标量）②物理构型（**含时驱动演化** vs 静态哈密顿对角化）③数值格式（**时域 RK4 步进** vs `eigvalsh` 解析）。**若判同源 ⇒ 直接改靶 M1 的 DRAG 泄漏比**（泄漏族已实测零占用）。
- **闭环**：**G-CTRL-1**（闭环可用性主项）。


### M1 单比特脉冲层：DRAG 泄漏抑制

- **建造**：三能级（qutrit）驱动 + DRAG 正交 Q 分量（抑制 |1⟩→|2⟩ 泄漏）；泄漏定义 `P_leak = |⟨2|ψ(t)⟩|²`；扫 DRAG 系数 β 求最优。
- **候选锚**：**B511** DRAG **泄漏抑制比** `L = P_leak(β=0) / P_leak(β*)`（三能级微扰/SW 闭式 ⇄ 三能级 TDSE 数值积分）。
- ✅ **体检预判（实测支持）**：`泄漏/leakage` 在 `BENCHMARK_DEFS` 内 **0 命中** ⇒ **泄漏族零锚占用**；与 **B10**（退相干极限平均门保真度）被测标量不同（**泄漏概率** vs 平均门保真度）。

### M2 门保真标定：RB 衰减 + unitarity

- **建造**：随机 Clifford 序列模拟（24 元群复用 `gates.py`；密度矩阵/PTM 演化）+ RB 指数衰减拟合 + **unitarity（纯度衰减）** 提取 ⇒ **相干误差 vs 非相干误差分解**；以 B10 的 `F_avg` 口径作**对照**（只作对照，不复用其锚）。
- **候选锚**：**B512** RB **unitarity（纯度衰减率 u）**（闭式 depolarizing/purity 律 ⇄ 数值随机序列纯度衰减拟合）。
- 🔴 **体检预判**：蓝图原提案「RB 衰减拟合保真」与 **B10**（平均门保真度 F）**被测标量同族** ⇒ 同源风险高 ⇒ **改靶 unitarity**（`unitarity`/`纯度衰减` 全仓 0 命中）—— 它测的是**二阶纯度衰减**（对相干误差敏感、对去极化不敏感），与 B10 的**一阶 F** 是不同物理量。

### M3 读出链：色散读出 + Purcell 滤波 + 实时解调

- **建造**：把 D-47 的**静态**读出保真度预算升级为**闭环读出链**：匹配滤波/积分窗扫描 → 判别阈值 → **分配矩阵**；加 **Purcell 滤波器**（带通滤波抑制 qubit 经 feedline 的 Purcell 衰减）；复用 J2 `j2_readout_mux` 的 FDM 骨架（不重做）。
- **候选锚**：**B513** Purcell **滤波器抑制比**（`T1^{filter}/T1^{no filter}`：闭式滤波器反射系数 ⇄ 腔-滤波网络 **S 参数谱积分**）。
- 🔴 **体检预判（三重否决已做）**：蓝图原提案「色散 χ=−g²/Δ」**已被 B26 占用** ⇒ 否；「读出保真度」**已被 B30 占用** ⇒ 否；「FDM mux」**已被 J2 B508 占用** ⇒ 否。⇒ 本档唯一候选 = **Purcell 滤波抑制比**，且须对 **B18**（Purcell 因子 F_P，**输入量**）证三方分歧（**抑制比**是「加滤波器后的系统级提升倍率」，与 F_P 这个**器件级因子**不同被测标量；数值格式：闭式反射系数 vs S 参数谱积分）。**若判同源 ⇒ 本档净增 0，如实登记**（不硬凑）。

### M4 系统级测控：cryo-CMOS + 多路复用 + 闭环收官

- **建造**：低温电子学链（**参量放大器 + cryo-CMOS 多路复用器**）噪声/功耗预算；测控闭环**总装**（脉冲→门→读出→反馈→参数回写，报收敛轨迹）；WebUI 面板 `/api/j3_ctrl`。
- **候选锚**：**B514** **相位不敏感放大器附加噪声量子极限**（Caves 极限 `n_add ≥ 1/2` 光子；闭式 ⇄ 数值**级联噪声链**：把 JPA/HEMT/cryo-CMOS 各级折算到输入端口）。
- 🔴 **体检预判**：与 **B467**（TIA 读出噪声底 kT/C）三方分歧（被测标量：**附加噪声光子数** vs 输出电压 rms；物理构型：**微波参量放大器** vs 跨阻放大器；数值格式：**量子极限闭式 + 级联 NF** vs 时域冲激响应积分）。
