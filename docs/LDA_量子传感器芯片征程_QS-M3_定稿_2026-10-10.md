## 2. 物理建模（五链）

### 链① NA 立体角收集效率 η_NA

NV 色心的偶极辐射图样（θ 自偶极轴量起）：

```
I(θ) ∝ sin²θ
上半球总能量 ∝ ∫₀^{π/2} sin²θ · sinθ dθ = ∫ sin³θ dθ = 2/3
η_NA(NA) = [cos³θ/3 − cosθ]₀^{θmax} / (2/3)      θmax = arcsin(NA)
```

- 闭式（`collection_efficiency_na_closed`）：直接代入 `∫sin³θdθ = cos³θ/3 − cosθ`；
- 数值链（`collection_efficiency_na_numeric`）：对 `w(θ) = sin²θ·sinθ·dθ` 逐点求和，取 `θ≤θmax` 的权重占比。
- 边界：NA=1 ⇒ θmax=π/2 ⇒ η_NA=1（全半球）；NA→0 ⇒ η_NA→0。

### 链② 深度 → 收集效率

```
η_coll(d) = η_NA · exp(−d / d_att)          d_att = 出射衰减长度（默认 200 nm）
```

越深（d↑）⇒ 出射路径越长 ⇒ 收集效率指数下降。

### 链③ 最优色心深度 d\*（本档核心）

几何灵敏度 FOM（未归一，越小越好）：

```
η_tot(d) = √(1 + (d₀/d)³) / √η_coll(d)
  · 分子 √(1+(d₀/d)³)：表面自旋浴噪声（谱扩散 ∝ 1/d³）劣化对比度 —— 浅色心劣；
  · 分母 √η_coll：收集效率越低 ⇒ 每单位时间光子越少 ⇒ 灵敏度越差 —— 深色心劣。
```

取 `d(ln η_tot)/dd = 0`：

```
ln η_tot = ½ln(1+(d₀/d)³) + d/(2d_att)
d/dd = ½·[−3d₀³/d⁴ / (1+(d₀/d)³)] + 1/(2d_att) = 0
⇒ 3 d₀³ d_att / (d⁴ + d₀³ d) = 1
⇒ 【d⁴ + d₀³·d = 3·d₀³·d_att】   ← 闭式根方程
```

`f(d) = d⁴ + d₀³d − 3d₀³d_att` 严格单调增（`f'(d)=4d³+d₀³>0`）⇒ **唯一正根，二分必收敛**。

默认 `d₀=20nm / d_att=200nm` ⇒ **d\* = 45.885 nm**。

### 链④ Purcell 腔增强计数率比

```
R/R₀ = 1 + β·F_P,     F_P = 4g²/(κγ₁)
  · g = 单光子 Rabi 耦合；κ = 腔衰减率；γ₁ = 原子退相干率；
  · β = 发射进腔模的分支比（β=0 ⇒ 无腔增强 R/R₀=1；β=1 ⇒ 全进腔模）。
```

🔴 **与 B18（谐振腔 Purcell 因子）同物理量** ⇒ 链④ **不另登记 B 锚**，归 smoke 覆盖。

### 链⑤ bulk 极限对照

```
vs_bulk = η_structured / η_bulk        η_bulk = η_NA(NA=1) = 1（无深度衰减理想上限）
```

比值 ∈ (0, 1]；「达到 bulk 的 x%」是**建模对照**，非实测宣称。

## 3. 四情景结果（模块现算）

| 情景 | NA | 深度 d (nm) | η_NA | η_coll | R/R₀ | vs bulk |
|---|---|---|---|---|---|---|
| baseline | 0.75 | 45.89 (=d\*) | 0.15253 | **12.13%** | 1.0 | 12.13% |
| shallow | 0.75 | 10.00 | 0.15253 | **14.51%** | 1.0 | 14.51% |
| deep | 0.75 | 150.00 | 0.15253 | **7.21%** | 1.0 | 7.21% |
| cavity_enhanced | 0.90 | 45.89 (=d\*) | 0.38757 | **30.81%** | **451.0** | 30.81% |

**读数**：
- shallow（10nm）收集效率**高**（14.51%）但表面噪声重 ⇒ FOM 反而差（最优在 45.89nm，不在最浅处）；
- deep（150nm）收集效率降到 7.21%；
- cavity_enhanced 用 NA=0.9 把 η_NA 从 0.1525 提到 0.3876（2.54×），叠加腔增强 R/R₀=451。

## 6. 诚实边界与未竟项

⚠️ **参数均为设计示例量级**（室温 NV 典型），**无实测锚**：
- `d₀=20nm`（表面噪声特征长度）/ `d_att=200nm`（出射衰减长度）/ `NA=0.75`（高 NA 物镜）/ `(g,κ,γ₁)=(0.05,0.01,0.002) GHz`；
- 本档只证明「解析根方程 ⇄ 网格扫描」与「解析积分 ⇄ 数值采样」数值一致这一**数学事实**。

🔴 **不得作制造 / 性能宣称**：真实最优深度还受晶体取向、表面处理方式（氧化/氢终止）、实际出射几何（金刚石内全内反射）、金属反射镜损耗等**未建模因素**影响；真实收集效率远可能低于本档理想模型。本档**不宣称「已达国际水平」**。

**未竟项（留待后续档）**：
- G5 **器件本体**（PDK 条目：NV 柱 / 腔 / 天线真实几何 + DRC）尚未落地；
- 链④ Purcell 腔增强目前只是比值模型，**腔的真实几何（光子晶体腔 / 微盘）未建模**；
- 深度-收集的**全内反射 / 菲涅尔界面效应**未纳入（当前是纯指数衰减唯象）；
- 表面噪声 ∝1/d³ 是**唯象幂律**，未从自旋浴微观谱推导。

**平台能力提升（吃狗粮产出）**：本档验证了「同一物理量的闭式 ⇄ 数值独立链」这套模式在**几何优化类**问题（含求导数、求极小）上同样成立 —— 拓宽了锚模式的适用面（此前锚多为「标量闭式 ⇄ 数值积分」型）。
