## 1. 四值口径（**为什么不是二值**）

| 状态 | 含义 | 是否欠债 |
|---|---|---|
| **已闭合** | 工作做完，证据链可查（如 `soc` G1–G6、`j3` M0–M4） | 否 |
| **已结算** | 问题有裁决、不再挂账，但**能力/证据未必具备**（判不可锚／派生量／净增 0／决定不修，如 `ecore` G-N 极性缺陷「不改 mna + B14 锁死」） | 否 |
| **未闭合** | 确认仍未做 —— **这才是欠债** | **是** |
| **边界声明** | 永久能力边界，本来就不以「做完」为目标（非流片实测／零能效纪律／理想化模型） | 否 |

> 🔴 把「已结算」塞进「已闭合」= 又一次**概念压扁**（同 N3-b 把「限制」写成「深度变浅」）；
> 把「边界声明」当「未闭合」= **把诚实边界记成欠债**，会诱导以后删掉边界声明。

## 4. 结论（比数字更重要）

1. 🔴 **总数是 126，不是 94**。审计 v3 漏了 **18 条**：`j1`(2) / `j3`(4) / `oi`(7) / `accel`(5) —— 前两者模块级无 `GAPS` 常量、后两者只在 `case_card()` 里返回，而审计只扫了模块级常量。
2. 🔴 **域归属修正**：`d1`/`d2`/`d4` 是**量子域蓝图 v2**，审计 v3 把它们算进「光子 36 条」⇒ 光子/量子的真实构成与旧表**不同数**（旧光子 36 = pchip+sensor+pm+soc+d1+d2+d4；新光子 36 = pchip+pm+soc+oi+accel+sensor）。**同数不同构成 —— 聚合数字又一次掩盖了结构。**
3. 🔴🔴 **v0.9.286 修正分类器漏判**：`soc` 的 6 条状态字面写着 `CLOSED（…）`，旧实现只在状态串里找中文「闭合」二字 ⇒ 全部漏判成未闭，台账对外报「已闭 0」。改为**显式词表 + 12 条自测**（四值全覆盖），自测不过生成器拒跑。
4. **真正的欠债只有「未闭合」一列 = 1 条**（不是历史上被当作欠债的 46 条）；另有 45 条是**永久边界**、11 条是**已裁决不再挂账**。⇒ 对外说「126 条缺口」时**必须带分布**，否则会把边界声明读成欠债。
5. ⚠️ **0 条仍未标**：给 `case_card()` 补 `gaps_status`（字符串型 gaps）或元素 `status`（dict 型 gaps）即可机核。**本表拒绝从散文里猜状态**。
6. 🔴 **v0.9.300 的未闭合下降（15 → 10）不是做活换来的**：6 条经**跨卡口径统一**从「未闭合」转为「边界声明」（同一句「无流片 / 无 PDK」在不同卡里曾被记成不同状态）。**本版没有新建任何能力**，逐条理由见 §6；`RECLASSIFIED_MIN=6` 守着这条痕迹不被抹掉。

### 6.1 判定规则（唯一依据）

> 明天派一个工程师来做，**能做的**才是欠债；**本卡不做 / 项目不做**的是边界声明。

上表条目要求的都不是建模，而是 **流片预算 / 产线 / foundry deck（NDA）/ 低温实验台** —— 这些**任何案例卡都无法在本仓内完成**，与项目对外口径「设计期签核 · 非流片实测」一致。
🔴 **判据不是为降数字发明的**：v0.9.289–299 共十一次「闭合」全部是**建模活**（IL 精度 / CMR 来源 / Werner 组合律 / 中继吞吐 / 源不可分辨性 / 热噪声 / 温漂预算 / 两个解码器 / 封装三项），**没有一条**依赖硬件。

### 6.2 三道机核（`lda/lda_harness/gap_caliber.py`）

1. **同类必须同状态**：同一口径命中的每条缺口，状态必须等于该口径期望值；且 `permanent_boundary` 类**必须跨 ≥2 张卡命中**（防空集合 —— 单卡自说自话不算统一）。
2. **留痕必须写得出依据**：每条理由须含 `非流片` / `须 NDA` / `实验台` / `专卡` / `不重复计债` 之一且 ≥30 字，不许用「口径统一」四个字糊过去。
3. **分工也要机核**：`role_delegated` 类（纠错码层由专卡承载）必须能在承载卡里找到**真实的未闭合条目**，否则判「以分工为名推掉欠债」。

### 6.3 拆而不并（本次唯一新增的欠债）

`schip G-D` 原文混了两件事：「脉冲级 Rabi/Ramsey 标定」（须实验台 ⇒ 边界）与「线路编译 / 噪声仿真」（纯模型活 ⇒ **真欠债**）。⇒ 拆为 `G-D`（边界声明）+ **`G-Db`（未闭合）**。
把两者压进同一条（改成整体边界）就是**借口径统一之名把真活藏起来** —— 这正是 N3-b「限制与事实挤进同一序数」的同型，故本次**先拆再判**。
