## 1. 判定方法（三步问句 · 任一步不过即不能升格）

一条语料要成为实证锚，必须同时满足：

| 步 | 问句 | 不过的后果 |
|---|---|---|
| **① 有模型吗** | 本仓有没有一个模块，能**从语料给的输入**算出这个指标？ | 无 ⇒ **边界声明**（本仓不做此事） |
| **② golden 是直接测量吗** | 这个实测值是不是**别人用同一个公式反解出来的**？ | 是 ⇒ **拒绝**（代数恒等，pass 了也不能说明什么） |
| **③ 判别力够吗** | 把模型算错 1%，判据会不会红？ | 不会 ⇒ 降级或拒绝（tol 被输入精度撑破 = 量级检查而非验证） |

第②步是本轮最容易被忽略的一步。E9/E10 的教训原文：
「`n_g` 必须由几何+材料独立算出，**不得由 FSR 反演**（反演会得到 4.18 并构成循环自证）」。

## 2. 7 条边界声明（不是欠债，是"本仓不做/本仓无此物理"）

### 2.1 五条 T1 + 一条 T2：本仓把 T1/T2 当**输入**，从不预测

全仓 grep 结果（决定性）：所有出现 `T1`/`T2` 的函数签名里，它们是**入参**，没有任何一处从几何/材料算出它们：

| 位置 | 角色 |
|---|---|
| `lda_agent/readout_fidelity.py` | `T1_s` 是入参 |
| `lda_agent/multiqubit_fidelity.py` | `T1_us_list` 是入参（默认全 20 µs） |
| `lda_qeda/physical_error_model.py` | `gate_fidelity_decoherence(t_gate, T1, T2)` —— T1/T2 入参 |
| `lda_l2/pdk_examples.py` | `fixed_params={"T1": 80.0, "T2": 60.0, ...}` |

要预测 `T1`，需要 `1/T1 = 1/T1_TLS + 1/T1_qp + 1/T1_rad + …`，其中
`T1_TLS ∝ 1/(F·tanδ)` ——**`tanδ`（介质损耗角）与准粒子密度、磁通噪声谱都是薄膜工艺的实测参数**。
语料这 10 条里一条都没给（`geometry` 只有材料、衬底、厚度、频率）。

⇒ **双缺**：模型缺 + 输入缺。**按判定问句，这是边界声明，不是欠债**——
因为就算明天写一个 TLS 模型，也凑不出这几片膜的 `tanδ`，产不出锚。

### 2.2 一条 Qi：同上，缺 `Rs`

`Qi = 1/tanδ` 或 `Qi = G/(Rs·...)`。语料给的是 `Nb ~125 nm / SiN 110 nm / suspended`，
没有 `Rs`、没有 `tanδ`、没有几何（CPW 线宽/间距都没给）。⇒ 边界。

## 3. 三条被真算了一遍的（这是本轮唯一的实质内容）

### 3.1 `E-Q-ALSOI-G`（g = 177±5 MHz）—— 🔴 拒绝：代数恒等

语料的 `method` 自己写着：`g ≈ −Δχ(1+Δ/η)`，其中 `Δ = ωq−ωr`。
`geometry` 里 `χ`（`dispersive_shift_MHz=3.5`）、`Δ`（`7.143−5.652 GHz`）、`η`（`−300 MHz`）全都有。

我按 `g = √(χ·Δ·(1+Δ/η))` 复算：

```
Δ = 5.652 − 7.143 = −1.491 GHz = −1491 MHz
1 + Δ/η = 1 + (−1491)/(−300) = 5.97
g = √(3.5 × 1491 × 5.97) = 176.51 MHz        实测 177 ± 5   ⇒ 残差 −0.49 MHz (0.28%)
```

**0.28% 的"吻合"是必然的**：g 本来就是用这个式子从 χ,Δ,η 反解出来的。
把它当锚，等于「用恒等式验证恒等式」——B472 的「同式异写 ⇒ 虚报」就是这个形态。

⇒ **拒绝**（与 E10 拒绝「由 FSR 反演 n_g」同一条纪律）。

### 3.2 `E-Q-ALSOI-FREQ`（f01 = 5.652±0.001 GHz）—— 🔴 拒绝：输入独立性不可核 + 判别力被输入精度卡死

用本仓闭式 `lda_solver.transmon_solver.koch_f01(E_J, E_C) = √(8E_JE_C) − E_C`，
`E_J = 14.8 GHz`（`geometry.EJ_over_h_GHz`）、`E_C = |η|`（`anharmonicity_MHz = −300`）：

```
koch_f01(14.8, 0.300) = 5.6599 GHz      实测 5.652 ± 0.001     残差 +0.0079 GHz (+0.14%)
```

看数字像命中（0.14%、7.8σ_测量/8σ）。**但两条都不成立**：

**(a) `E_J` 的独立性不可核。** 这条锚唯一"独立"的输入就是 `E_J`。
若 `E_J` 是由测得的 `f01` 经 Koch 反解出来的（很常见），则 `f01_pred` 与 `f01_meas` 同源 ⇒ 循环。
语料的 `method` 只写"色散谱测 fq"，**没说 `E_J` 从哪来**。我按 E10 的口径要求「必须核实独立来源」，
**核不到 ⇒ 不升格**（不是"证明它循环了"，是"不能证明它不循环"）。

**(b) 即使 `E_J` 独立，判别力也被输入精度撑破。** 传播输入舍入（`E_J` 3 位有效数字 ⇒ ±0.05；`η` ±0.5 MHz）：

```
∂f/∂E_J = 4E_C/√(8E_JE_C) = 0.201   ∂f/∂E_C = 4E_J/√(8E_JE_C) − 1 = 8.93
σ_f,输入 = √((0.201×0.05)² + (8.93×0.0005)²) = 0.0110 GHz
残差 0.0079 GHz = 0.71 σ_输入          ← 完全被输入舍入解释掉了
```

⇒ 要容纳这个残差，`tol` 必须 ≥ 0.02–0.03 GHz（3σ_输入）。那时锚能测出的最小公式误差是
`0.03/0.201 = 0.15 GHz` 的 `E_J` 偏差 = **E_J 的 1.0%**。
**一个只能测 1% 公式误差的锚，配上 0.14% 的残差，测的是输入精度不是物理。**

> 若将来核到 `E_J` 来自结电阻的 Ambegaokar–Baratoff、`E_C` 来自独立电容提取，可**重开**，
> 但 `tol` 仍会被输入精度卡在 0.02–0.03 GHz —— 那时它最多是 **degraded 档**，不是判决锚。

### 3.3 `E-Q-READ-FID`（0.995±0.005）—— 🟠 不是锚，是一条**真欠债**

这条最有价值：**模型是有的，而且真算下来发现模型是错的（缺一层）**。

`lda_agent/readout_fidelity.py` 的预算：`SNR = 2χ_rad√(n̄ηt_m/(κ_rad(1+2N_amp)))` ·
`ε = ½erfc(SNR/√2)` · `F1 = (1−ε)(1 − t_m/T1)` · `F = (F0+F1)/2`。

论文（Chen et al., npj Quantum Inf. 9 (2023), DOI 10.1038/s41534-023-00689-6，开放获取）关键数据：
**140 ns 读出 · 两态分配保真度 99.5% · 该 qubit 的 `T01 = 6.18 µs`** · 用了 shelving（π12/π23）后等效 `T01` 提到 **85.8 µs**。

用 `t_m=140 ns`、`T1=6.18 µs` 跑模型，取**极限乐观**（`ε→0`，即 SNR 足够大）：

```
t_m/T1 = 2.2654%
F_max = (1 + (1 − t_m/T1))/2 = 0.98867          ← 模型能给出的上界
实测 0.995  ⇒  模型结构性达不到，差 0.63 个百分点（上界就差，不是参数没调好）
```

验算：两档参数（`χ=0.02, κ=0.002, n̄=50, η=1, N=0` 与 `χ=0.01, κ=0.005, n̄=20, η=1, N=5`）
SNR 分别 187.6 / 11.3，`ε` 都到 0，`F` **都停在 0.98867** —— 因为上界由 `t_m/T1` 唯一决定。

改用 shelving 后的等效 `T1_eff = 85.8 µs`：`F_max = 0.99918 > 0.995` ✓

⇒ **根因明确**：模型的 `F1 = (1−ε)(1−t_m/T1)` 把整个读出期间都记成「`|1⟩` 在衰减」，
而 shelving 把布居搬到 `|2⟩`（`T12 ≈ 2T01`）后再读，**等效寿命被拉长 14 倍**。
**模型缺「shelving / 有效寿命」这一层**。

**这一条为什么是"欠债"而不是"边界"**：加一层 `T1_eff(sequence)` 是**纯建模活**，
不需要流片、不需要实验台、不需要 NDA —— 按判定问句「明天派一个工程师来能不能做」，**能做**。
⇒ 这是本轮**唯一产出的实质东西**：一条真欠债，而不是一个锚。

## 4. 结论：A2 也 0 锚 —— 但它换来了两样东西

### 4.1 四域锚 0 增长的第 32 版，原因现在有分类了

| 域 | 为什么 0 锚 | 性质 |
|---|---|---|
| **电子（N1）** | 参数齐的必是仿真；实测的必缺参数（且"参数齐"那份是模板常量） | **语料问题**（> 产业事实，不可解） |
| **超导（A2）** | T1/T2/Qi 需要 `tanδ`/`Rs`/噪声谱，本仓无此物理 **且** 语料无此参数 | **能力 + 语料双缺** |
| 光子 | 有 10 条（E1–E10），其中 6 条仍是自证桩 | 已饱和 |

⇒ **不该再把它写成"四域同时归零"**。电子是**被外部卡住**，超导是**本仓没做**。
后者是可解的——只要先补物理模型、再去要参数；前者不是。

### 4.2 一条真欠债（下一版第一件事是登记它）

`G-READSHELV`：读出保真度预算缺「shelving / 有效寿命」层。
- 判据：`F_max(t_m, T1_eff(sequence))` 必须能复现「同一物理器件在 shelving 前后」两个保真度
  （本文实测：同一 `T1=6.18 µs`，无 shelving 上界 0.98867、有 shelving 上界 0.99918）；
- 对照支路：`T1_eff = T1`（不 shelving）时必须**逐位退化**回现有公式（防新层改坏旧路）；
- 反例保护：不得把 `T1_eff` 当自由参数去拟合 0.995（拟合=循环自证）。

**登记它会动三处**（本版刻意不做，因为"欠债变多"必须单独评审，不能夹在"升格"版里顺手改）：
① 对应 case card 的 `gaps` + `gaps_status`（字符串型需加并行 `gaps_status`）；
② `scripts/gen_gap_settlement.py` 的棘轮 `OPEN_MAX` **8 → 9**（欠债变多，必须显式留痕）；
③ 台账 §6 记一条「本版为何未闭合数上升」。

**短期内不该再开新的域外找锚。** 三轮下来的结论是一致的：

## 7. 诚实边界（本文自身）

- **`E_J` 的独立性我没核**（需回 Keller et al. APL 111, 042603 (2017) 原文，需订阅）。
  所以 §3.2 的措辞是**「不可核 ⇒ 不升格」**，不是"证明它循环"。若有人拿出 `E_J` 来自结电阻的证据，这条可重开。
- **`readout_fidelity` 的 χ/κ/n̄/η 我确实拿不到**（npj 正文未给，指向 Supplementary Note）。
  但 §3.3 的结论**不依赖它们**——上界 `0.98867` 只由 `t_m/T1` 决定，任何参数都到不了 0.995。这是本轮的硬结论。
- **7 条边界我没有逐条去论文核 `tanδ`/`Rs`/噪声谱是否存在公开值**。我只主张「语料这 10 条里没有」，
  不主张「全世界没有」。若某条论文正文给了 `tanδ`，那一条可以重新考虑——但那时仍缺模型（§2.1），还是边界。
- **本版没有改任何台账数字**（缺口仍 118 / 58·11·8·41，锚仍 541）。
  `G-READSHELV` 是**已发现未登记**的真欠债，登记动作留给下一版（§4.2 已列全三处改动）。
