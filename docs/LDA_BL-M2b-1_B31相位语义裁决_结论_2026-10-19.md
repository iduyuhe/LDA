# BL 征程 · BL-M2b-1 裁决结论：`B31` 不是相位语义错位，是「乘性模型差 + 判据形态错」

> 版本锚：v0.9.255（`B31` 未动 · `tol=1.5` 原样）· 出具 2026-10-19
> 前置：`docs/LDA_BL-M2b-1_B31相位语义裁决_立案_2026-10-19.md`
> 状态：**裁决完成 · 处置待批准（未改一行实现）**

## 0. 一句话

立案时的两条线索**都不成立**：`B31` 的 golden 与 candidate **是同一个物理量、同一条链路、同一个参考面**，
差异是**乘性**的模型差 `1.962222`（Drude 电子项 / Soref-Bennett 电子项），不是 `π/2` 加性偏置。
`c = 1.5795 ≈ π/2` 是**数值巧合**（差 0.55%），不是相位多加了 90°。

**真正的问题是判据形态**：拿「绝对 `tol`」去判一个「量级一致」型锚，而 `tol=1.5 > |golden|=0.8049`
⇒ 注入 0 必然通过。**假绿成立，但病因不是语义，是判据。**

---

## 1. 裁决证据（三条独立路径 · 全部现算）

### 证据 1：`V_R → 0` 极限 —— 加性偏置会留下常数残差

```
V_R = 1e-12 :  golden = 4.196e-13   candidate = 8.234e-13
```

两者**同时趋于 0**。若候选真的多加了 `π/2`，则 `V_R→0` 时 `candidate → π/2 = 1.5708` 而非 0。
⇒ **加性 `π/2` 假设被直接否证。**

### 证据 2：`V_R` 扫描 —— 加性看差、乘性看比

| `V_R` | golden | candidate | `c−g` | `c/g` |
|---|---|---|---|---|
| 0.5 | 0.18567569 | 0.36433685 | 1.786612e-01 | **1.962222** |
| 1.0 | 0.33909112 | 0.66537193 | 3.262808e-01 | **1.962222** |
| 2.0 | 0.59294732 | 1.16349406 | 5.705467e-01 | **1.962222** |
| 3.0 | 0.80493887 | 1.57946845 | 7.745296e-01 | **1.962222** |
| 5.0 | 1.15822457 | 2.27269329 | 1.114469e+00 | **1.962222** |

`c−g` **随 V 单调变**（0.179 → 1.114），而 `c/g` **恒定到 6 位**。
⇒ 差异是**乘性缩放**，不是常数偏置；也排除了「参考面不同」（参考面平移也会表现为常数加性项）。

### 证据 3：解析式手算 —— 比值必须是常数，且数值可独立复现

两条链路完全相同（同一 `ΔN_eff(V)` → `Δn` → `Δφ=2π|Δn|L/λ`），差异只在 `Δn` 的模型：

```
SB    : Δn = −8.8e-22 · ΔN                     （线性于 ΔN）
Drude : Δn = −q²ΔN / (2 ε0 n_eff m* ω²)        （线性于 ΔN）
```

⇒ 比值与 `ΔN`（因而与 `V_R`）**无关**，解析值：

```
ratio = q² / (2 ε0 n_eff m* ω² · 8.8e-22)
      = 2.56697e-38 / (1.48651e-11 × 8.8e-22)
      = 1.9623
```

与数值扫描的 `1.962222` 一致（差异来自常数取整）。**三条路径互不依赖，结论一致。**

### 默认定标点（`V_R=3.0`）

```
golden    = 0.804938866203315
candidate = 1.57946845154462
|c−g|     = 0.7745295853     (= 96.2222% · |g|)
|g|       = 0.8049388662     (注入 0 的误差)
c − π/2   = 0.008672          ← 0.55%，纯巧合
```

## 2. 假绿的机制（这才是要修的）

`cmp_abs` 判 `|c−g| ≤ tol`。`B31` 的候选**故意**与 golden 差近 2×（方法学独立，判据 D 不撞），
于是要让它 PASS，`tol` 必须 `≥ 0.7745`；而注入 0 的误差是 `|g| = 0.8049`。

```
tol = 1.5  ⇒  |c−g| = 0.7745 ≤ 1.5 PASS     且     |0−g| = 0.8049 ≤ 1.5 🔴PASS
通过区间 = [0.000, 2.305] = [0.000×, 2.863×] golden   ← 几乎什么都过
```

**可行窗口客观存在**（因为 `|c−g| < |g|`，即比值 1.962 < 2）：

```
需  tol ≥ |c−g| = 0.774530   （真候选过）
 ∧  tol < |g|   = 0.804939   （注入 0 被拒）
窗口 = [0.774530, 0.804939)   宽 3.93%（相对下界）
```

---

## 3. 推荐处置：`tol 1.5 → 0.79`（窗口几何中点）

```
0.79 / 0.774530 = 1.0200      ← 真候选余量 +2.0%
0.804939 / 0.79 = 1.0189      ← 注入 0 超出 1.9%
```

两侧余量近似对称（各 ~2%），是窗口内**唯一自洽的中点选法**。

## 4. 备选处置（不推荐）

**「量级一致型锚」登记法**：保留 `tol=1.5`，把 `B31` 标为 `magnitude_only`（注入 0 探针不适用，
像 `cmp_le` 的 `B19`），另加「比值带 `0.5 ≤ c/g ≤ 2` ∧ 同号」判据来保证仍能拒 0。

**否决理由**：它把通过区间留在 `[0, 2.86×]` —— 一个偏小 50% 的错答案（`c ≈ 0.40`）仍然 PASS。
这正是 BL 要抓的东西，**不能用「重新命名」代替「提高判别力」**。

## 5. 诚实边界

1. **2% 余量是候选与 golden 的模型差所致，不是浮点脆弱**：`B31` 全链路是纯闭式（`math`），
   无迭代求解器 ⇒ 跨平台差异在 `1e-16` 相对量级，2% 余量对浮点安全。**但对参数编辑敏感** ——
   改 `m*`（0.26→0.27）或 `n_eff`（2.4→3.5）会让比值变化 ~4%/46% ⇒ **该锚必然翻红**，
   这是**特性而非缺陷**：动这些物理参数就该重新裁决，不能悄悄滑过去。
2. 该锚的判别力天花板就在此：它能区分「量级对 / 量级错（含 0）」，**不能**区分 `1.96×` 与 `2.05×`。
   想要更细的判别力只能**换候选**（例如带 many-body 修正的模型），不是压 `tol` 能解决的。
3. 本次裁决**未改动 golden**（`Soref-Bennett` 闭式原样）· **未改动 candidate**（Drude 原样）·
   未为了「让它好看」而调 `tol` —— 现有证据只支持「判据形态错」，不支持「谁算错了」。
