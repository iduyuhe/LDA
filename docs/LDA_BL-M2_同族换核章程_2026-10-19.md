## 2. 统一核设计（一条函数，双观测）

```python
def cand_rect_scatter_riccati(E_J, V0_J, a_m, obs="T", N=256, m=ME):
    # 常势段：y = ψ'/ψ 满足 y' = (2m/ħ²)(V−E) − y²，I' = y
    # 出射边界 y(a) = i·k0，RK4 **反向**积分到 x=0
    k0  = sqrt(2mE)/ħ
    k2  = 2m(V−E)/ħ²                     # 势垒 V=+V0；势阱 V=−V0
    y, I, h = 1j*k0, 0j, −a/N
    for _ in range(N):
        (y, I) ← RK4 一步（y 与 I 同时积分）
    r = (i k0 − y)/(i k0 + y)             # 反射幅度
    t = (1 + r) · exp(−I − i·k0·a)        # 透射幅度（见 §7 血案）
    return |r|² if obs == "R" else |t|²
```

- `R`、`T` **各自从模平方直接得**，不走 `1−T` 减法；
- 两条都是 `O(h⁴)`；`|r|²+|t|²−1` 作为**内建自洽量**（可入判据）。

## 7. 🔴 本轮血案（**公式推导两次踩坑，务必先记**）

换核算 `T` 时，透射幅度**不是** `exp(−I − ik a)`，也**不是** `(1+r)exp(−ik a)`：

| 错法 | 现象 | 根因 |
|---|---|---|
| `t = exp(I − ika)` | `B65` 的 `\|t\|²=36.3`（应 0.0112） | 反向积分的符号：`I(0)=∫_a^0 y dx = −∫_0^a y dx` |
| `t = exp(−I − ika)` | `\|R+T−1\|=1.6e-02` | **漏了 `ψ(0)=1+r` 这个因子** |
| ✅ `t = (1+r)·exp(−I − ik a)` | `\|t\|²` 与闭式差 `1e-13`、`\|R+T−1\|=1.4e-12` | 正解 |

**通则**：`t = ψ(a)e^{−ika}/ψ(0)`，而 `ψ(a) = ψ(0)·exp(∫y)` ⇒ 必须**同时**带 `(1+r)` 与 `exp(−I)`；
**单元性 `|r|²+|t|²=1` 是唯一能当场抓住这两类错的判据** ⇒ 本档把它设为内建自洽判据（不只是 note）。

## 8. 验收点（"抹平必红"）

1. **逐锚收敛**：`N/4 → 2N` 相邻比「趋近 4 阶」（写 `|r_last−4| ≤ |r_first−4|`，不写死方向）。
2. **抹平必红**：把任一条候选换回旧核（切片连乘）⇒ `resid` 塌到 `≤1e-15` ⇒ 收敛阶与 `zero_resid` 判据**必红**（先证能变红）。
3. **`tol` 棘轮**：7 条 `tol` 只许更严，放宽即红。
4. **单元性**：`||r|²+|t|²−1| ≤ 10·resid`（内建自洽，任一 `N`）。
5. **跨平台**：生产（py3.9）现算 7 条 `resid` 与本地（py3.14）同量级（差异 ≤ 10×，**不比逐位**——逐位只在台账量化口径内要求）。
