## 2. 未完成：N1 / N3（两条 A/B 级主线）

### 🔴 N1 电子域实证语料锚 —— **v0.9.303 判死**（勘查过了、闸门也过了，结论是走不通）

| 项 | v3 审计计划 | 当前实测 |
|---|---|---|
| 目标 | 8–12 条电子域实证锚（MOSFET I–V / SS / μ_eff / ADC ENOB / MVM 精度） | **0 条** |
| 语料 | 从公开实测取（DOI/URL + geometry + σ） | 语料库 122 条里**电子 0 条** |
| 升格机制 | 已在光子侧跑通（照 E8 的窗口法 `[2·resid, \|g\|/12]`） | 机制在，**没用在电子上** |
| 棘轮 | 本文初版写的 `EMPIRICAL_ANCHORS ≥ 10` **当时并不存在**（是我编的名字） | ✅ v0.9.302 已落成真常量 `benchmarks.EMPIRICAL_ANCHOR_MIN = 10`（`≥` 语义，只增不减），由门禁 ⑪-1 守 |
| 风险（审计自述） | 🔴 公开 MOSFET 数据多为 PDK 保密或**曲线图**（非数字表）⇒ **先做半天语料可得性勘查** | **勘查也没做** |

**必须先做勘查，而不是直接开工**：如果电子语料确实只有曲线图，那 N1 会变成"为了产出锚而把图读成数字"——
这违反「仿真值永不作 golden」的同一条纪律（读图 = 二次数字化，误差不可溯源）。

> **✅ v0.9.302 勘查结论**：语料**存在**（数字表 5 个，含 778 条实测 ADC 记录），所以「找不到语料」这个默认假设是错的。
>
> **🔴 v0.9.303 前置验证结论：两条路都判死**（`docs/LDA_N1_P2b_前置验证_2026-10-26.md`）：
> - **① ADC 衰落**：语料**没有 σ_t** ⇒ 抖动律不可检；退化成「高频 SNDR 不高于低频」（156 条里违反 2 条），
>   而那是**测量一致性约束、不是任何候选模型的预测** ⇒ 注册成锚就是又一道自证桩。
> - **② MOSIS 参数**：三个独立理由 ——
>   (a) 闭式 Vth 需要 `V_FB`，语料不给，而 **`V_FB` 的量级（0.60 V）是答案（0.30–0.36 V）的 1.7–2.0 倍**（缺的比答案还大）；
>   (b) 🔴 **`NCH` 是模板常量**——IBM180/IBM250/TSMC180 两家代工厂两个节点共 5 份报告，`NCH` 五位有效数字逐位相同
>   `2.3549E17`，而 `TOX`/`VTH0`/`K1`/`U0` 都随批次变 ⇒ 不能当衬底掺杂用；
>   (c) 因此 `K1 ≡ √(2qε_si·N_a)/C_ox` 这条**无需外部输入**的恒等式，**5/5 份偏离 1 达 30–78%** ⇒ 参数集互不自洽。
>
> ⇒ **N1 判死**。但 P2b 把 P1 的**假设**升级成了**实测事实**：
> 「参数齐的必是仿真，实测的必缺参数」→ 更强的一条：**「参数齐」的那份实测语料，参数本身是模板常量；参数真缺的那份，缺的项比答案还大。**
> 死结是**「公开实测语料永远不公开配方，而配方才是模型需要的输入」**——产业事实，不是努力能补的。

### 🔴 N3 统一四域签核 schema —— 零启动

现状是"字段齐备但不统一"：四域各自有 `verdict` / `claim_line` / `grade` / `deck`，
但**同一件事（这一条到底是什么级别的签核）在四域用不同字段组合表达**，无法跨域比较。
这是 **B 级、净增锚 0、但对外可讲性增益高**的活，且**独立于 N1/N2**，可与主线并行。

#### 🔴 失校① 订正说明（v0.9.302 · 本文初版在此处错了）

本文初版把 A1 记成「E2/E8 的 `title` 与 `provenance` 不一致」的**活缺陷**，并据此说「实证锚只有 8 条」。
**这是误判，根因是把 `provenance` 读成了「golden 是不是实测」的标签。**

实测四路对拍（v0.9.302 已写成机核判据 `run_empirical_anchor_smoke` ⑪ 组）：

| 数法 | 结果 | 它其实在说什么 |
|---|---|---|
| `anchor == "empirical"` | **10** | ✅ **golden 取自公开实测** ← **这才是"实证锚条数"** |
| `empirical_id` 非空 | **10** | 同上（四路完全等价，差集为空） |
| `title` 含「实证语料锚」 | **10** | 同上 |
| `BENCHMARK_ORDER` 的 E 前缀集 | **10** | 同上 |
| `provenance == "external_empirical"` | 8 | ❌ **验证强度**的派生标签，**与"是否实测"正交** |

`provenance` 由 `benchmarks._vmm_provenance()` **按 `maturity_tier` 推导**：
`strict_independent ⇒ independent_cross_check`、`degraded ⇒ external_empirical`、
`self_certified ⇒ self_authored_closed_form`（E1/E3–E7 靠 override 改回 `external_empirical`）。
所以「实测 golden + 已被独立候选证伪通过」那 2 道（E2/E8）必然落在 `independent_cross_check` ——
它们不是"不是实证锚"，而是**验证强度最高的实证锚**。用 `provenance` 数，恰好把最强的 2 道漏掉。

⇒ 正确分解（10 道实证锚的**二维**读数）：

| 验证强度 | 道数 | `provenance` 派生标签 |
|---|---|---|
| 自证桩（candidate ≡ golden） | **6** | `external_empirical` |
| 严格独立（已被独立候选证伪通过） | **2** | `independent_cross_check` |
| 降级量级（有候选但粗糙度超死标量） | **2** | `external_empirical` |
| **合计** | **10** | 8 + 2 |

**教训（同类第 11 次）**：「同一件事有几个数」不是靠记忆对齐的，得靠**四路对拍 + 反向探针**守。
本版已把「条数」收成单一真源 `benchmarks.empirical_anchor_census()`，
`EMPIRICAL_ANCHOR_MIN = 10` 作棘轮（`≥`，只增不减），任何一处口径漂移都由 ⑪ 组判红。

**②是本轮最有价值的发现**：v3 审计把 N1（电子）定为旗舰，理由是"唯一不需要流片/NDA/新物理的锚空间"。
但实测显示 **超导侧已有 10 条实测语料躺在库里、一条都没升格** —— 这条路的**成本远低于 N1**
（不需要找语料、不需要判"图能不能读成数字"，只需要把已有语料接到升格机制上）。

## 5. 推进规划

### 5.1 对 v3 审计原顺序的修订建议

v3 审计的依赖图是 `N1 → N4`、`N2` 并行、`N5` 等出数。**建议改为**：

```
A1（口径单一真源）── A3（N1 语料勘查）── A2（超导语料升格，最短路径）
        │                 │
        │                 ├──> P2b 前置验证 ──> ✅ 已做（v0.9.303）⇒ **两条都不过 ⇒ N1 判死**
        │                 │                      ⇒ 全部产能转 A2（超导升格）+ A5
A4（schema 统一）────────┴──> A5（超导 L3 补到 ≥4）
```

**修订理由**：
1. **A1 必须先做** —— 否则"实证锚到底几条"自己都对不上（v0.9.302 实测：这件事**真的**曾经对不上，8/9/10 三个数同时在用）。
2. **A3 + P2b 是 N1 的前置闸门，不是 N1 的一部分** —— 两步都走完了，结论是**判死**；不许把曲线图读成数字，不许拿仿真当实测，也不许把「模板常量」当「该批次的掺杂」。
3. **A2 曾被认为"最短路径"，v0.9.304 判完后这个判断也要撤回** —— 语料确实已在库，但其中 6 条（5×T1 + 1×T2）**本仓根本没有对应物理**，2 条是导出量/独立性不可核。"已在库"不等于"能用"。
