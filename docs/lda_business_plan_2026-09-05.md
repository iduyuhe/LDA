## 1. 执行摘要

**LDA（Lightwave Design Automation）** 是开源、Agent 原生的光子集成电路（PIC）与量子芯片（QEDA）设计自动化平台，对标传统电子 EDA 在光/量子时代的等价物。

我们的差异化不是"求解器更快"，而是行业结构性空白——**验证可证伪、主权自主、Agent 原生**：

- **验证可证伪**：判定落物理定律锚 + 实证大数据锚，LLM 不进判决路径，PASS/FAIL 由死标量比对定。
- **主权自主**：A 级能力永不外借；B 级借今踢后；C 级第一天自主（Meep 已隔离、Tidy3D 仅外部 ORACLE）。
- **Agent 原生**：设计→仿真→版图→DRC/LVS→工艺角→几何寄生全链路可由 Agent 编排，并配用户侧智能体客服。

**为什么是现在**：AI 数据中心把光互连推到刚性需求，硅光子市场 2024→2030 以 29.5% CAGR 爆发；2025 年 5 月美国对华 EDA 出口管制为国产替代创造结构性窗口；云原生 + 开源正重构 EDA 付费模式（永久许可 $15万–$50万 → 云订阅 $2500/座/月）。

**本轮诉求**：LDA 处于早期开源项目阶段，正从技术验证走向首个商业试点。本轮拟引入战略与财务投资人，加速 PDK 生态合作、流片验证与获客（具体融资额 / 估值 / 股权结构见第 11 章，待杜先生确认）。

## 3. 问题与机会

### 3.1 行业痛点
1. **验证不可证伪**：传统光子/量子设计工具把"仿真结果是否可信"留给用户主观判断，缺乏独立锚点，失真可在全绿下溜过（LDA 自身体验过：v0.9.10 漏算 3.0103dB 在 84 项全绿下通过）。
2. **主权依赖**：商业求解器（Lumerical / Tidy3D）掌握在美系巨头手中；2025 年 5 月美国对华 EDA 出口禁令使依赖风险显性化。
3. **工具昂贵、门槛高**：永久许可 $15万–$50万，中小团队与学术机构被挡在门外；云转型虽降门槛，但数据主权与本土 Foundry 对接仍薄弱。
4. **光/量子双栈割裂**：光子 EDA 与量子 EDA 由不同厂商、不同范式割裂提供，缺少统一 Agent 原生闭环。

### 3.2 结构性机会
- 硅光子市场 2024 年 21.6 亿美元 → 2030 年 96.5 亿美元（CAGR 29.5%）[MarketsandMarkets]。
- 光子 EDA 软件市场 2025 年约 18 亿美元，2026–2034 CAGR 13.5%，其中量子应用子段 22.4% 最快、云部署 18.7% 最快 [Dataintelo 2026]。
- 量子光子段获全球政府承诺投资 > $4.1B（截至 2026 初）[Dataintelo 2026]。
- 开源（GDSFactory / KLayout / IPKISS）已成低端许可层结构威胁，验证"开源 + 主权自主"路线可行 [Dataintelo 2026]。

## 4. 解决方案：LDA 是什么

LDA 提供光（PDA）+ 量（QEDA）双栈、Agent 原生的设计闭环：

**设计 → 仿真 → 版图 → DRC/LVS → 工艺角 → 几何寄生**

当前核心账目（v0.9.40 运行源码实测）：

| 指标 | 数值 |
|----|------|
| 引擎 | 22（光 15 + 量 7，口径=设计品类） |
| 验证锚 | 50（25 严格独立 / 0 降级 / 25 自证桩，双路径披露） |
| CI core 冒烟 | 97 条全绿（0 SKIP / 0 FAIL） |
| PDK / 图层 | 5 / 8 |
| 超市货架 | 58 |
| 规模基线 | 1M 元素 35.98s/0.85GB；10M 实测 428.42s/30.5GB（O(n^1.08)）；层次化 99.96% 降元 |

**验证红线（护城河核心）**：判定落非 AI ground（物理定律锚 + 实证大数据锚）；LLM 不进判决路径；PASS/FAIL 由死标量比对定。

## 6. 商业模式

### 6.1 开源获客 + 分层变现
- **开源核心（Apache-2.0）**：设计/验证/版图闭环免费开放，建立社区与生态，对标 GDSFactory 开源路线。
- **用户侧产品三档**（国内定价，不得越 5000 元红线）：
  - 入门 ¥599 / 周期
  - 标准 ¥1999 / 周期
  - 专业 ¥4999 / 周期
- **企业订阅（对标云原生）**：参照行业云订阅 $2500/座/月（≈¥1.8万/月）[Dataintelo]，提供私有部署、PDK 定制、SLA 与专属 Agent。
- **生态与服务**：PDK 接入咨询、流片陪跑、培训（契合上海杜特既有产业培训能力）。

### 6.2 获客路径
开源社区（Gitee/GitHub Stars + 技术白皮书 + 智能体客服留资）→ 生态播种（Foundry/高校合作）→ 首个商业试点 → 订阅转化。

**诚实边界**：LDA 当前为早期开源项目，尚未形成规模付费客户；上述定价与路径为已确立策略，商业化兑现依赖本轮融资加速的获客与试点落地。

## 7. 竞争格局与差异化

| 厂商 | 核心路线 | 定价模式 | 与 LDA 关系 |
|------|----------|----------|-------------|
| Synopsys（Lumerical+RSoft） | 全栈求解器+多物理场 | 企业订阅/永久许可 | 外部 ORACLE 基准 |
| Ansys Lumerical | FDTD/EME/INTERCONNECT | 企业订阅 | 外部 ORACLE 基准 |
| Cadence Virtuoso EPDA | 光电协同设计 | 企业订阅 | 对标（系统级） |
| Luceda IPKISS | Python PDK 框架 | 订阅制 | B 级借今踢后 |
| Tidy3D / Flexcompute | 云原生 GPU FDTD | 按量付费（250+ 机构） | 外部 ORACLE 锁 |
| 逍遥科技 Latitude | 国产 PIC Studio | 订阅制 | 国内同业（已融资） |
| **LDA（本平台）** | **验证可证伪 + 主权自主 + Agent 原生** | **开源 + 三档 + 企业订阅** | **差异化维度，非精度超越** |

**关键立场（诚实）**：LDA 在全球光子/量子 EDA 对比中列第 1，是**「验证独立 + 主权自主 + Agent 原生」的维度差异**，不是求解精度已超越 Lumerical / Qiskit（成熟度仍低于商业标杆、尚未流片）。这是结构性空白，而非精度叙事。

**护城河来源**：现有巨头与初创都把"可信验证"交给用户主观判断或黑盒；LDA 把判决锚定到物理定律与实证大数据，且主权模块自主——这是别人短期难抄的架构选择。

## 8. 技术护城河

1. **验证方法论红线**：物理定律锚（解析解/守恒量）+ 实证大数据锚（真实测量/同行结果），判据 D 防自证桩失真；CI core 97 条门禁。
2. **主权分级纪律**：A 级永不借 · B 级借今踢后（gdsfactory/KLayout/SAX；Tidy3D 仅外部 ORACLE）· C 级第一天自主。Meep=GPL v2+ 已隔离（subprocess 只回标量）。
3. **Agent 原生闭环**：设计→仿真→版图→DRC/LVS→工艺角→几何寄生可由 Agent 编排；用户侧智能体客服解答+留资，但不进验证判决路径。
4. **规模能力**：1M 元素 35.98s、10M 实测 428.42s（O(n^1.08)）、层次化 99.96% 降元、已去 GPU 依赖（5 器件 live 5/5）。
