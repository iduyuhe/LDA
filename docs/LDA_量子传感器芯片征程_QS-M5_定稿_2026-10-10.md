## 2. 物理链（三条新锚）

### ① 微波频率锁定（B482）

NV 的 ODMR 谱在零场分裂处呈现 Lorentzian 凹陷。锁定频率 = 凹陷中心 f₀ = D_ZFS = 2.87 GHz。

```
L(f) = 1 − C·(w²/4) / ((f−f₀)² + w²/4)          Lorentzian 线型
S(f) = L(f−δ) − L(f+δ)                          鉴别器（中心差分线型）
```

🔴 **鉴别器零点 = f₀**（洛伦兹对称）、**严格反号对称**（f₀ 两侧符号相反 ⇒ 可判方向）。

**闭环反馈**：
```
step = −S(f) / (slope_nom · loop_gain)
```
- gain=1 ⇒ **一步收敛**（残差 < 1 Hz）；
- gain=0.9 ⇒ **几何收敛**（残差 < 1e-2 Hz，轮数多于 gain=1）。

🔴 **收敛判据 = 残差/线宽**（相对线宽 < 1e-6），**非绝对 Hz** —— 物理鉴别器非线性致 gain=1 也有 ~0.4 Hz 绝对残差（0.376 Hz / 1e7 Hz 线宽 = 3.8e-8 ⇒ 相对判据下干净收敛）。

**锚 B482 = 鉴别器中心斜率** dS/df|_{f₀}（闭环锁定增益的标度）：
- **golden** = 闭式 Lorentzian 中心差分斜率（解析线型）；
- **candidate** = **时域 FID 数值变换斜率**（方法学独立）。

🔴 **反自证桩骨架实证（本档最关键一笔）**：B482 初版设计为「**二分法求锁定点**」⇒ 实测**零残差** —— 鉴别器**严格反对称** ⇒ 锁定点 ≡ f₀ 是**代数恒等**（不是数值方法）。遂**改锚为鉴别器中心斜率**（FID 数值线因**有限 t_max 截断**产生真残差 6.696e-06 ≫ 机器精度），并验残差随 `t_max_factor` **单调收敛**。

### ② 磁场闭环标度自标定（B483）

闭环把频率锁准后，磁场读数依赖**标度因子** k = V/B（读出的电压-磁场转换）。自标定 = 施加已知参考场 B_ref，测读出 V_ref：

```
k̂ = V_ref / B_ref            两点法（点标定）
ε_k = |k̂ − k| / k            标度失配 = 读数相对误差
```

**锚 B483 = 标度因子自标定**：
- **golden** = 闭式两点法 `V_ref/B_ref`；
- **candidate** = **全跨多点 LSQ 斜率**（含噪样本回归，方法学独立）。

🔴 **诚实边界（如实标注）**：两点法在**无噪声**时是**代数精确**的（误差恰 0）⇒ 无真残差；真残差只出现在**含噪全跨 LSQ**候选上（3.439e-08）。门禁 B4/B5 专门断言这一区分（无噪 ⇒ 恰好 0 · 有噪 ⇒ 残差 > 0）。

**链②结论（门禁 B6 常驻）**：闭环读数相对误差 **= ε_k**（标度失配直接决定读数精度）—— 这是本档的物理洞察，把「标度自标定」的必要性钉死。

### ③ 动态范围 + AC 灵敏度（B484）

```
B_min = η · √(1/τ)                噪声底（随积分时间 τ 降）
B_max = (w/2) / γ                 线性段耗尽场（线宽 w，旋磁比 γ）
DR    = 20·log₁₀(B_max / B_min)   动态范围 [dB]
η_AC  = η · √(2Δf)                AC 灵敏度（带宽 Δf 折算）
```

**锚 B484 = AC 灵敏度带宽折算** η_AC = η·√(2Δf)：
- **golden** = 闭式 `η·√(2Δf)`（DC 谱密度 → 带限 AC 噪声）；
- **candidate** = **MC 带限噪声 rms**（方法学独立）。

🔴 **DR 定义如实归 smoke（不登记为锚）**：`DR=20·log₁₀(ratio)` 是**纯定义**（代数恒等无残差）⇒ 如实归 `run_qs_m5_smoke`，**不越级登记为 B 锚**（同 B472–B481 纪律）。

## 3. 动态范围与情景

### 默认参数


### 四情景（`dynamic_range_table()` 现算）

| 情景 | 线宽 w | 积分 τ | 特征 |
|---|---|---|---|
| baseline | 10 MHz | 1 s | 默认 |
| narrowline | 2 MHz | 1 s | 窄线宽 ⇒ DR 小（线性段窄） |
| wideline | 50 MHz | 1 s | 宽线宽 ⇒ DR 大（灵敏度权衡） |
| longint | 10 MHz | 100 s | 长积分 ⇒ 噪声底降 ⇒ DR 升 |

🔴 **单调性（门禁 C4/C5 常驻）**：DR 随线宽**单调增**（宽线宽 ⇒ 动态范围大，与灵敏度权衡）· DR 随积分时间**单调增**（长积分 ⇒ 噪声底降 ⇒ DR 升）。

- NV 动态范围 target **~54 dB**（本档 DR 情景现算：baseline 105 dB / wideline 119 dB —— **口径不同**：本档 DR = 线性段上限/噪声底，蓝图 54 dB 系实测系统口径含读出饱和等工程限制 ⇒ **不做等号宣称**）；

## 6b. 🔴 反自证桩骨架（本档最重要一笔：三处如实处置）

本档是「反自证桩纪律」的一次**系统实证**——三条候选初版设计都撞上**代数恒等**，逐一如实处置：

| 初版设计 | 问题 | 处置 |
|---|---|---|
| B482「二分法求锁定点」 | 鉴别器严格反对称 ⇒ 锁定点 ≡ f₀ **代数恒等**（残差 0） | **改锚为鉴别器中心斜率**（FID 数值线有真截断残差 6.7e-6） |
| B483「两点法自标定」 | 无噪声时**代数精确**（残差 0） | **如实标注**（无噪恰 0）；锚定在**含噪全跨 LSQ** 上取真残差 |
| 「DR 定义 dB」 | 20·log₁₀ 系**纯定义**（代数恒等） | **如实归 smoke**，**不登记为锚** |

🔴 **通则**：加锚前必问「这个 candidate 与 golden 会不会**代数恒等**？」——同式异写（如差分 vs 解析、LSQ vs 两点法在无噪时）都会退化为**零残差**，必须引入**真实的物理/统计源**（数值截断、含噪统计、离散化）才有真残差。此即 **B28「同式异写 ⇒ 虚报」/ B472 同型**.

🔴 **参数二次标定（贴线坑 · QS-M4 B480 同型复现）**：B484 candidate 初版 n=8e6 ⇒ 跨 30 种子最坏偏差 **5.1e-4 > tol 1e-3**（仅 2× 余量，重跑即红）⇒ 改 n=32e6（最坏→2.1e-4）+ **tol 1e-3→5e-3**（**24× 余量**），并验 n→64e6 无收益（σ 由**样本分布形状**主导，非 n）。
- 🔴 **通则**：加噪/蒙特卡洛 candidate 的余量必须按「**跨种子最坏偏差 < tol**」标定，**不得**按单次 seed 值判余量。

🔴 **正向含义验证**：B482/B483/B484 残差均随 `t_max_factor`/n **单调收敛**（实测扫描）⇒ 真数值残差、非代数恒等。
