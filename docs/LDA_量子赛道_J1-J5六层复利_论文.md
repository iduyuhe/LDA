# 量子芯片设计链的六层复利：以物理闭式律为 golden 的 Agent 原生 EDA 方法学

**杜玉河** · LDA 工程团队

## 摘要

我们报告一套面向量子芯片设计的 **Agent 原生 EDA** 方法学及其在 LDA 平台上的落地结果。核心主张有三：① **golden 只能是物理闭式律或实测事实**，第三方仿真值一律不作判决依据；② **每一层只允许向下借用已签核的标量**，形成层间"复利"而非功能堆叠；③ **判据必须机器化并带反向探针**，即"证明判据能变红"先于"证明判据全绿"。

在 Layer 0–5（器件相位 → 量子纠错 → 超导处理器 → 测控读出 → 传感系统 → 量子网络）六层上，我们产出 **48 道规格锚**（Layer 0 24 道 + J1–J5 24 道），**全部为方法学严格独立**（候选实现与 golden 走不同计算路径），**全部被 ≥1 个专属门禁显式覆盖**（100%，显著高于全项目账本 538 锚的 22.9%）。五层专属门禁合计 **191 条判据**，全量 CI 覆盖 **333 个门禁 / 333 PASS / 0 FAIL**。

我们同时如实报告工程中暴露的**四类系统性失效模式**及其通则化处置：判据写死收敛方向、参数契约滞后于算术、签名/常量漂移无看守、以及"缺口登记 ≠ 缺口结算"。

**关键词**：量子芯片 EDA；物理闭式 golden；方法学独立性；判据机器化；层间复利

## 1. 引言

量子芯片设计面临与经典 EDA 同构但更尖锐的问题：**规模不可及**（无法穷举验证）、**跨层耦合强**（门保真度依赖测控、测控依赖低温电子、长程通信依赖以上全部）、**第三方工具不可信作 golden**（仿真器本身有系统误差，且闭源不可审计）。

现有做法通常把"能跑出数"当作验证完成。我们认为这混淆了两件事：

- **可计算性**（能算出数）
- **可签核性**（这个数有出处、有第二方法、有人看守、改一处会报警）

本文只讨论第二件事。

### 1.1 贡献

1. 提出并实现**三档主权分层**（自主 A / 借用 B / 降级 C）与 **golden 四源合法性判据**；
2. 给出 **Layer 0–5 六层复利结构**，并量化"层间复利"的实际复用站点；
3. 实现 **K0–K4 五档判据机器化**（未结项台账 / 断口结算 / 账面终态 / 跨档常量表 / 覆盖矩阵），把"工程纪律"从文档约定变成 CI 会红的机器约束；
4. 如实报告 **415 锚盲区**与四类失效模式。

## 2. 方法

### 2.1 三档主权分层

| 档 | 定义 | 对锚独立性的影响 |
|---|---|---|
| **A 自主** | 纯 numpy/scipy 自研求解器，永不借用 | 构成方法学独立 |
| **B 借用** | 借今踢后：借用后必须能被自研替换，且只允许回传标量 | 在替换完成后计为严格独立 |
| **C 降级** | 有序数降级（物理可比但非同一量） | 不计入独立率 |

🔴 硬约束：不引入 GPL 依赖（Meep / Tidy3D 等）、**LLM 不进入判决路径**、不报 TOPS / fJ-op / 能效。

### 2.2 golden 的四种合法来源

```
① 科学闭式（解析解）        → golden ✅        本文 48/48 锚属此
② 实测事实（实验数据）      → golden ✅
③ 第三方仿真值              → ⛔ 非 golden（仅可作对照）
④ 标准 / 规范（如 ITU、IEEE）→ 规格锚 ✅
```

### 2.3 方法学独立性的操作定义

对每个锚要求**两条不同计算路径**：

- **golden 路径**：闭式解析（含特殊函数、级数、渐近展开）
- **候选路径**：数值方法（RK4、复合 Simpson、蒙特卡洛、最小二乘、迭代求解）

**残差判据**用绝对容差（按物理量级标定），并要求**两个独立闭式互证**——单一闭式的实现错误不会被"与自身比对"发现，只会表现为"与另一闭式不一致"。

### 2.4 判据机器化的四层（K 战役）

| 层 | 治理对象 | 机器化手段 |
|---|---|---|
| **L-a** | 未结项债务 | 受跟踪台账（8 条）+ 生成器 + 29 判据门禁 |
| **L-b** | 跨档常量/签名漂移 | 47 站点复用表（const 存值 · function 存签名） |
| **L-c** | 覆盖盲区 | 门禁×锚三层覆盖矩阵 + 下限棘轮（只升不降） |
| **L-d** | 判据自身可信度 | 反向探针（先证能变红）+ 硬编码历史下限 |

### 3.3 层间复利的量化

跨档复用被机器登记为 **47 站点**（20 条跨档）。最关键的物理复用：

```
qs_m3c.cooperativity_from_g  ──▶  qnet_transducer.cooperativity()   （QS-M3c → J5）
qs_m2.cpmg_filter            ──▶  qnet_classical                    （QS-M2  → J5）
qs_m3.optimal_depth_closed   ──▶  qs_m3b.pillar_height_consistency  （QS-M3 → QS-M3b）
qs_m0.D_ZFS_HZ               ──▶  qs_m5.zero_field_splitting_hz()   （QS-M0 → QS-M5）
```

**守卫机制**：`const` 站点存**现算值**（改值即红），`function` 站点存 **`inspect.signature` 指纹**（改参数名/默认值即红）。跨档复用不再是"隐式约定"。

## 4. 四类系统性失效模式

| # | 模式 | 实例 | 通则 |
|---|---|---|---|
| **F1** | **收敛阶判据写死方向** | 同为 O(h⁴)，RK4 从上方逼近（18.02→16.24），复合 Simpson 从下方（15.52→16.00） | 只判"**趋近标称阶**"：`|r_last−N| ≤ |r_first−N|` |
| **F2** | **参数契约滞后于算术** | `_rates` 先取倒数后校验 ⇒ `T=0` 抛 `ZeroDivisionError` 而非契约 `ValueError` | **值域检查必须在算术之前**；数值核与能力层两处同修 |
| **F3** | **精度断言缺第二闭式** | 分层部分分式系数矩阵连错两版，只表现为"与另一闭式不一致" | 每个精度断言**必配第二个独立闭式** |
| **F4** | **缺口登记 ≠ 缺口结算** | 章程登记"两口径必须并报"，消费侧 grep 零命中；K0 台账有 G-K-6 条目而门禁**从无判据** | **关闭缺口须"双查"**：旧判据是否被打反 ∧ 有无判据在看守 |

## 6. 局限与诚实边界

1. **全部为设计期签核**：不含任何流片/工艺实测，构件参数为设计示例量级而非具体 PDK 认证值。
2. **盲区存在**：本层 48 锚 100% 有专属门禁，但全账本 538 锚中 **415 锚**仅有统一判决（K4 已机器登记，未粉饰）。
3. **指纹不等于行为等价**：跨档表能拦接口形态变化，**拦不住函数体行为改动**（那归各档 golden）。
4. **覆盖判据是下限**：L2 只统计"源码显式提及锚号"，动态拼接锚号不计入。
5. **不构成代工厂签核替代**：不替代工艺 DRC/LVS，不构成流片放行依据。

## 7. 结论

我们给出了一套**可签核**（而非仅"可计算"）的量子芯片设计链方法学，并在六层 48 锚上完整落地：**48/48 严格独立、48/48 专属门禁覆盖、191 条层内判据、333 个 CORE 门禁全绿**。

更重要的也许不是这些数字，而是把工程纪律**机器化**的做法：让"忘记重生成台账""偷偷下调棘轮""给缺口打勾但不结算"这类人类易犯的错，**变成 CI 会红的事件**。
