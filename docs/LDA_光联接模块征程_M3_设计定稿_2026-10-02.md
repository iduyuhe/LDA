## 1. 范围与用户裁定（本轮输入）

用户裁定的 M3 范围（逐字）：

> **M3：3.2T / CPO**

本次不另扩范围。3.2T 在本项目里的**口径先钉死**（否则后面所有数字不可比）：

> **3.2T = 8 × 400 Gb/s（每通道 400G）** · PAM4 · 符号率 **212.5 GBd** ·
> 线速率 **425 Gb/s/lane**（含 6.25% 编码开销）· 聚合 **3.2 Tb/s 编码 / 3.4 Tb/s 线速**。
> 该口径与 **IEEE 802.3dj「400 Gb/s/lane · PAM4 · 212.5 GBd」**一致，且与 M2 的
> 「200 Gb/s/lane = 106.25 GBd」**同一套换算**（每倍频沿用 `Rs = lane_bits / 2`），
> ⇒ 由 M2 的 53.125 GHz 奈奎斯特直接翻倍到 **106.25 GHz**。**不做** 16×200G 的绕路设计。

## 3. 设计口径（五项逐条）

### 3.1 ① 400G/lane 带宽墙：行波电极 MZM（TWMZM）

**为什么必须换调制器族**：M0/M1/M2/M2b 全是**环调制器**（集总电极，f₋₃dB 32.94 GHz @800G）。
400G/lane 奈奎斯特 **106.25 GHz** —— 环调制器的腔寿命限制下界远超此值 ⇒ **必须换 TWMZM**。
（这一条由判据**强制**：M3 的 TWMZM 带宽若 < 奈奎斯特 ⇒ 设计点判死，不是声明。）

**①-1 闭式（golden）**：把两个各建一个一阶极点（物理化简，诚实披露）：
- RC 极点：`f_RC = 1/(2π·R_e·C'_e·L)`（电极总 RC）
- 速度失配极点：`f_vm = c/(2π·(n_g,e − n_g,o)·L)`
- 合成：`|H(f)| = [ (1+(f/f_RC)²) · (1+(f/f_vm)²) ]^(−1/2)`

**①-2 第二独立通道**：把 TWMZM 沿光轴切成 **N 段集总 RC ladder**（每段 R/N、C/N，
沿长度递推电压分布），N→∞ 收敛到 ①-1。**相对误差必须随 N 单调下降**（M2b 热网络同款纪律，
实测 0.565→0.089 那样）。

**①-3 与 oi_m1 互锁**：M3 的 `f_3db` 调用与 `oi_m1` **同一对外口径**（f₋₃dB + 回代 |H|=1/√2），
但调制器族不同（TWMZM vs 环）⇒ 门肆判据「同族同源会假绿」⇒ **互锁判据必须咬族名**
（`modulator_family` 入参参与断言，换族换值必红）。

**噪声/ISI 承接**：M2b 的 CTLE 在 LPO 形态下只能模拟；3.2T/CPO 形态**通常有模块 DSP**
（CPO 光引擎旁就是 ASIC，功耗预算允许）⇒ 均衡形态从「LPO 只有 CTLE」放宽到
「CTLE + FFE（DSP 内）」，但**必须重新走一遍形态映射断言**（不能默认 M2b 结论直接搬）。

### 3.2 ② CPO 电通道（共封装电互连）

CPO 的本质卖点是**电路径从可插拔的 cm 级缩到 mm 级**（ASIC↔光引擎在硅中介层上相邻）
⇒ 相关系数反转：**不再是「光衰减」主导，而是「电通道 + 串扰 + 供电完整性」主导**。

- **闭式（golden）**：短差分线在频域的低通 `|H_tx| = exp(−h·√f)`（电报方程长线近似，
  `h = 2.8 dB/(GHz^0.5)·√(L_tr·L_m)`）—— 与 M2b/M1 的「闭式 ⟷ 数值对拍」同一体例；
- **NEXT 串扰**：容性耦合项 `Xtalk(f) = (C_m/C_tot)·(f/f_0)²` 积分得最坏近端串扰；
- **PDN 地弹**：`V_bounce = L_pdn · Δi/Δt`（PRBS 边沿速率驱动），与 driver 动态功耗同回路；
- **第二独立通道**：1D 电报方程**时域 FDTD** 求波形，与闭式频域**同参数**对拍
  （方法学独立：频域解析 ⟷ 时域分步）。

### 3.3 ③ CPO die↔die 热耦合 + 闭环热调

- 复用 M2b 的 Θ = `r_th0·ln(d_ref/d_ij)`（二维薄片稳态对数场）与有限差分热网络第二通道，
  但**域改为「ASIC die → 中介层 → 光子 die」的跨 die 两层热阻**（`r_th0` 拆成两串）；
- **闭环热调**：光引擎在 ASIC 热背景下的**稳态残余失谐** + **持续加热功耗**
  （不是 M2b 的一次性 P_tune，而是「跟踪 ASIC 慢漂 → 持续耗散」的**稳态功耗**）——
  这是 CPO 相对可插拔的**真实代价**，必须诚实登记（可插拔的 ASIC 热不进光引擎 ⇒ 不需持续跟踪）。

### 3.4 ④ 功耗同口径账（只 mW/W）

逐项：driver 动态 `½·C_line·V_pp²·f` · TIA 静态 · 热调（=③ 稳态）· 光源/泵浦 ·
CPO 特有的 **中介层/供电网络损耗**（可插拔没有）。
**对照口径**：同一 3.2T 聚合速率下，「CPO（光引擎共封装）」vs「可插拔（DSP 在面板侧）」，
**逐项同参**，只报 **mW/lane 与 W/模块** —— 🔴 **不做 fJ/bit / TOPS 换算**（红线）。
第二独立通道：把功耗逐项**加总**与**逐 lane 独立求和**对拍（防「全局口径 ≠ 逐 lane 之和」）。

### 3.5 ⑤ CPO 2.5D 版图签核（G-OI6，主权 DRC/LVS）

`cpo_array` 已有光引擎单 die builder ⇒ M3 扩 **2.5D**：ASIC die + 光引擎 die 并排置于硅中介层，
光纤阵列（FAU）从封装上沿接入，电布线（差分对 + 电源/地）走中介层；
**片外 fiber 不落版图**（与 G-OI2 同口径）· 真 GDS + DRC/LVS 双闸 ACCEPT ·
下载字节 sha256 互证（`deliver_download` 单一真源）。

## 4. golden 选取（「外部对标四层」）

| 量 | golden | 层 |
|---|---|---|
| 400G/lane 符号率 212.5 GBd | IEEE 802.3dj 400 Gb/s/lane 规格 | ④ 标准（限值口径 ✅ 可用） |
| pre-FEC 门限（400G/lane） | 需**逐条核对 + 落规格锚**（M1 血案：`TARGET_BER_KP4` 误写 2.4e-2 ⇒ 裕量算错 ~5dB） | ④ + **窗口判据必配** |
| 电信噪 / 带宽 | 闭式物理律 | ① |
| 电通道/串扰/PDN | 电报方程闭式 ⟷ 时域 FDTD | ① golden + ② 第二通道 |
| 热 | 二维薄片稳态 + 有限差分 | ① + ② |
| 良率 | erf 闭式 ⟷ MC | ① + ② |
| 🔴 **仿真/计算值** | **永不作 golden**（本轮所有数值仿真结论只作第二通道） | ③ ⛔ |

🔴 **规格锚纪律（v0.9.177 血案）**：任何一个**外部常量**进判决，必须先「**取值窗口判据 C**
（这个数必须落在 [a,b]）」+「**改回错值必红的探针 P**」。M3 的 400G/lane 门限与符号率
**当场各配一个 C + 一个 P**，不许像 M1 那样先错一个版本才抓到。

## 8. §7 的修正：G-OI6 实际**已闭合**（D-214 实况回填）

🔴 §7 是 D-211 设计期的**预判**（「拟新增 G-OI6 ⇒ 4/6」）。D-214 落地后的**真实终态是 `5/6`**，此处按实况订正：

| 缺口 | §7 预判 | D-214 实况 | 说明 |
|---|---|---|---|
| G-OI4 电路级模型 · 无 PDK | 开放 | **仍开放** ✅ | 无 foundry 电 PDK ⇒ 无能效宣称资格（红线，T2 锁死） |
| G-OI6 2.5D 版图签核 | 开放（4/6） | **闭合** ✅ | 「几何-拓扑 LVS + 电层 DRC」这一**可做范围**已做完（见下） |

**G-OI6 闭合的具体范围**（`lda_l2/oi_m3.cpo_2p5d_geometry` / `cpo_2p5d_layout`）：

- ASIC die（1800 µm）+ 中介层（`d_out = a + 2·margin`，`margin = 16·pad`，**相对 die 尺寸**外扩 ⇒ 防 die 越出中介层）+ 光引擎 die + FAU 接触点（片外 fiber **不落版图**）。
- 光引擎 die **真复用 M2 的 G-OI2 builder**（`oi_transceiver_pnr`）——吃狗粮，不重造光层几何。实测复用元素 **93 件**。
- 电层 DRC（min width / min space / 差分 pitch 互锁）+ 电网络**拓扑 LVS**（反向完备）双闸。
- 真 GDS：**22006 B / 247 元素 / 6 结构**。

**G-OI6 里「没做」的那部分去哪了** ⇒ 归到 **G-OI4**（`R_e / C_e / L_pdn` 的 foundry 真值、电路级 PDK 核对），**不重复记账**。这是本轮的分账纪律：同一块砖不记两次账。
