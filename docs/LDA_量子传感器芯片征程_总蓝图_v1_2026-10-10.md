## 1. 为什么选「量子传感器」，以及为什么是现在

### 1.1 平台资产盘点（我们手上有什么）

量子栈 `lda/lda_qeda/`（26 模块 · 12,340 行）已相当厚：

**叠加光子栈**可复用的传感公共品（PS 征程已建）：
- `lda_solver/full_vector_mode_solver.py`：全矢量 FDM 本征模（结构场/局域场）。
- `lda_l2/ps_m2.py`：**LOD_real 噪声模型**（热/散粒/探测器/激光 RIN 四源）——可直接复用其「多源噪声合成 → 探测极限」框架。
- `detectors.detector_bandwidth_true` / `apd_avalanche_true` / `ge_pd_responsivity_true`：探测器物理。

### 1.2 缺口（我们要去补什么）

经全仓实 grep 检索：
- **`magnetomet` / `磁力计` / `interferomet`（传感义）/ `陀螺` / `gyro` / `灵敏度`（量子传感义）/ `Ramsey` / `ODMR` / `NV` / `金刚石` 在 `lda/lda_qeda/` 内 = 0 命中**。
- 现有 `scale_bench.py` 里的 "interferometers" 指**光计算网格拓扑**，非量子传感。
- ⇒ **量子传感是一个完全空白的整块**，这正是「征程」的价值：不是修修补补，而是补齐一整条能力链。

### 1.3 为什么值得做（战略价值）

1. **平台纵深**：量子传感是量子技术**最接近商业化**的分支（2025 全球市场 ~12 亿美元，SQUID 配套年增 58%）。LDA 若能设计量子传感器，等于把 QEDA 从「量子计算」扩展到「量子感知」——**QEDA 的第二个支柱**。
2. **天然合流光子栈 + 量子栈**：NV 色心 / 光泵原子磁力计都是**光-自旋-磁**三物理耦合；超导 SQUID 是**电-磁通**耦合。两条路线分别逼出「光量子传感」与「超导量子传感」两条能力链。
3. **可量化的国际对标**：灵敏度（`pT/√Hz`、`fT/√Hz`）是**公开、可核、单一口径**的硬指标——非常适合做「分步达国际水平」的量化阶梯，避免 PS 征程那种「口径混比」陷阱。

## 2. 技术路线选型（三条路线对比）

| 路线 | 传感物理 | 室温? | 国际 SOTA 灵敏度 | 平台可复用 | 主权可实现性 |
|---|---|---|---|---|---|
| **A. NV 色心磁力计** | 光-自旋（ODMR / Ramsey）→ B 场 | ✅ 室温 | 10–50 pT/√Hz（芯片级 26 nT/√Hz；cavity 最优 52 nT/√Hz） | 光子栈（模式/探测器）+ 量子栈（退相干/Ramsey） | ★★★ 纯 numpy/scipy 可闭式建模 |
| **B. 超导 SQUID 磁力计** | 约瑟夫森结磁通→电压 | ❌ 4K | 1–5 fT/√Hz（SOTA ~0.1 fT/√Hz） | 量子栈（sc_* 阵列/DRC-LVS）+ 电子栈（输运） | ★★ 需建约瑟夫森 RCSJ 求解器 |
| **C. 光泵原子磁力计（OPM）** | 光抽运自旋进动 | ✅ 室温 | ~1 fT/√Hz（SERF） | 量子栈（开放系统/光源） | ★★ 原子系综多体建模较重 |

### 🔴 选型决策：**A 为主线（M0–M5），B 为并行第二腿（M6–M8），C 为规模扩展（M9+）**

**理由**：
- **A 先做**：室温、芯片级、纯光学+自旋两能级 —— 与 LDA 现有「光子栈 + 两能级自旋」最贴合，**能在最小新增代码下跑通端到端闭环**，第一档即可「设计出来」。
- **B 次之**：SQUID 灵敏度高一个量级，是「分步达国际水平」的**性能天花板靶**；且量子栈已有超导阵列 DRC/LVS，缺的只是**约瑟夫森 RCSJ 结物理 + 磁通-电压转导**（可闭式建），补它正好检验平台从「光子型」到「超导型」量子器件的迁移能力。
- **C 留后**：作为「规模与集成」阶段的扩展靶，检验平台对**多物理场（气室/激光/线圈）**的整合能力。

> 🔴 **口径先统一再对标（吸取 PS 教训）**：灵敏度一律用 `η = δB · √T`（白噪声谱密度，单位 T/√Hz），**禁与「线宽受限 LOD」「单次测量不确定度」混比**；室温/低温、单点/阵列、AC/DC 必须标注。

## 6. 红线与纪律（本征程全程遵循）

1. **C 级自主**：纯 numpy/scipy；不借 GPL/Meep/Tidy3D/量子 SDK 作判据。
2. **golden = 闭式物理律**：Zeeman 分裂、Ramsey 相位积累、RCSJ 方程、Johnson-Nyquist 噪声、散粒噪声——皆闭式，可作 golden。
3. **LLM 不进判决路径**：PASS/FAIL 由死标量比对决定。
4. **T1 输出永不作 ORACLE**：仿真/计算值不当 golden（除本档「自研求解器 × 闭式律」方法学独立互验外）。
5. 🔴 **灵敏度口径统一**：`η = δB√T` 白噪声谱密度；室温/低温、AC/DC、单点/阵列逐项标注；**禁与线宽受限 LOD 混比**。
6. 🔴 **手写数字必配机器对照**；**新守卫必配「先证能变红」反向探针**；**增锚必同登两处**（`BENCHMARK_DEFS` ∧ `BENCHMARK_ORDER`）。
7. 🔴 **同源体检**：每锚登记前实 grep 全仓，确认族内零占用、非重复计数。
8. 🔴 **全量 CI 照妖镜**：定向全绿 ≠ 无债；加锚/改账本后必真跑全量。

## 7. 立即可启动的范围（QS-M0 提案）

**QS-M0 = NV 色心磁力计基线可设计**，具体交付：

1. `lda/lda_l2/qs_m0.py`：
   - **自旋哈密顿量**：`H = D·Sz² + γe·(B·S)`（D=2.87 GHz 零场劈裂，γe=28 GHz/T），精确对角化求本征频率 ↔ Zeeman 分裂闭式（`Δf = 2γeB`）双验。
   - **Ramsey 磁力计**：相位积累 `φ = 2πγeB·τ`，对比度 `C(τ)`，线宽 `δf = 1/(πT₂*)`。
   - **灵敏度**：`η ≈ ħ/(gμB · C · √(N_ph·T₂*))`（散粒噪声极限），本档给出建模值。
   - **主权版图链路**：NV 色心占位 + 微波天线 + 读出光路 → placement → GDS → DRC/LVS。
2. `lda/run_qs_m0_smoke.py`：常驻门禁（~5s，纯 stdlib + numpy），入 CI core。
3. **锚 B473–B475**（草案）：
   - B473：Zeeman 分裂闭式 `Δf=2γeB` ↔ 精确对角化（严格独立）。
   - B474：Ramsey 相位 acumulation 闭式 ↔ 时间演化数值（严格独立）。
   - B475：散粒噪声灵敏度闭式 ↔ 逐步积分（若代数恒等则如实降自证桩）。
4. **缺口登记**：G1–G4 写入 `qs_m0` 报告。
