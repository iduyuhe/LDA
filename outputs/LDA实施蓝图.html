把「开源光子/量子 EDA · Open-Core 商业化」创业意图，落到可执行的代码主线。本文件为 Plan 形态，经你确认后再开干。

一、创业意图（一句话主线）

LDA 要做的是：用「开源内核 + 自主可控 PDK 供给 + 私有化定制」切西方 EDA 在中国市场的合规/获取软肋，走 gdsfactory 验证过的 Open-Core 路径——免费内核养生态，付费交付与授权变现。所有商业化动作必须服务于一个飞轮：政策/国际前沿需求 → 社区供给「真货」 → 机构/政府付费 → 反哺内核与社区。

红线：香港/澳门/台湾是 parts of China；物理定律锚为唯一判决基准，LLM 不进判决路径；核心求解器自主、主权优先。

二、为什么之前「东一榔头西一棒槌」

根因：我们先后上线了货架页、下单页、定制入口、审批后台，但缺了一个把它们串起来的「会员/计费中枢」——没有用户身份类型（学术/机构）、没有定价分层、没有订阅/授权。四条收入线各自孤悬，所以看起来零散。蓝图先把这条中枢补齐，再让 A/B/C/D 挂上去，结构就立起来了。

⚠️ 已确认：当前生产已上线的是「渠道外壳」（A+B 下单/定制），但计费身份中枢、真货、C/D 平台尚未落地，属于「能收钱、但卖不出差异化价值」的阶段。

五、重新排序的路线图（按依赖，而非按时间点）

🔧 Track 0 · 计费身份中枢（补回缺失的主线，最先做）

  1. 0.1 用户类型字段：注册增加「学术个人 / 机构 / 其他」（必选），store.py 写入 user_type、机构名称、开票信息字段。
  2. 0.2 定价引擎：在 store.py config 定义四类单价/折扣（学术个人 ¥0–999、机构 ¥2999–9999/包 或 ¥999/月/席位、B ¥8万–30万、D ¥50万–300万），下单按 user_type 取价。
  3. 0.3 会员中心页面：可见「我的类型/会员状态/订阅/订单」，维护机构信息。
  4. 0.4 订阅与授权：席位订阅（年/月付、多年折扣）、激活 Stripe（海外个人）+ 对公 PO（机构）。

依赖：无前置。风险低，纯增量。这是让 A/B/C/D 不再散的「骨架」。

📦 Track 1 · 货架与真货（A + M3）

  1. 1.1 货架分级：58 个「前瞻预研」明确定义为免费引流层。
  2. 1.2 设计就绪套件：挑 4–8 个高频货架（IM-800G-DR8 / IM-PSM4 / IM-CWDM4 / IM-CPO-OCS 等）补全参数化脚本 + 工艺假设，升级为「设计就绪套件」。
  3. 1.3 可信基准库：46 个物理定律锚 + golden benchmark 打包，带溯源与审计报告，作为零成本「真货」先落地。

🛠 Track 2 · 定制履约（B 完整化）

  1. 2.1 定制需求表单：需求描述/目标指标/预算区间（已上线入口，补报价单与状态回流）。
  2. 2.2 交付管理：审批后回填交付物链接、状态机闭环到「已交付」。

🌐 Track 3 · 平台与私有化（C + D，远期）

  1. 3.1 C 平台 SaaS：在线设计工作台（托管订阅）。
  2. 3. 2 D 私有化：部署包 + 授权激活 + 年维护，单独立项产品化。

发布节奏建议：Track 0 → Track 1 → Track 2 串行进，Track 3 单独排期（已在商业计划书中定为远期）。
