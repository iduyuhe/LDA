## 〇、先把「解」的边界钉死（本文件最重要的一节）

G-D 原文「**零能效数字纪律 —— 不报 TOPS / TOPS-W / fJ/op**」其实把**两件事**压成了一条。
解除时必须分开，否则等于拆掉平台最硬的信誉资产：

| | 含义 | 处置 | 依据 |
|---|---|---|---|
| **(a) 不许算** | 平台**没有功耗模型**（G-R 明写「时序为宏模型级 · 不做功耗」）⇒ E1–E19 全跑完也拿不到 P | ✅ **解** | 本段新增 `ecore/energy.py` |
| **(b) 不许宣称** | LDA 是设计验证工具链、**不是流片芯片**；用模型算的 TOPS/W 说成「我们的芯片达到 N TOPS/W」= **fabricated** | 🔴 **永不解** | `MEASURED` 档永久空置 |

**⇒ 一句话**：能效数字从此**可以算、可以对外**，但只能落 `MODEL_ESTIMATE` 档、必须带假设清单；
「离 Mythic 120 TOPS/W 差多少」**从此可判定**，「LDA 芯达到 120 TOPS/W」**仍然不可说**。

### 三档口径（`ENERGY_TIERS`，机器可读 + 判据锁死）

| 档 | 允许 | 含义 |
|---|---|---|
| `INTERNAL_TARGET` | ✅ | 内部设计目标反解，假设随便设；**不得对外引用** |
| `MODEL_ESTIMATE` | ✅ | 模型推算；**必须**同时给假设清单 + `is_measured=False`。**本模块全部输出落此档** |
| `MEASURED` | 🔴 **`allowed=False`** | 硅上实测。**本仓无流片无硅 ⇒ 永久空置**（`MEASURED_AVAILABLE=False`） |

探针 C1 专守：假装「有实测算」⇒ 门禁必红。

## 一、功耗模型（此前完全不存在）

逐部件分解，全部落在已建模的 C / V / f 上（**只读消费** E7/E14/E17/E18）：

| 部件 | 闭式 | 说明 |
|---|---|---|
| 阵列单元 | `N²·g·V_in²·duty` | **占空比是关键**（见 §4） |
| 行线充放电 | `n × ½·C_row·V²·f` | `C_row` 由 E7 的 τ/R 同源反解 |
| 逐列 SAR-ADC | `n_conv·½·C_tot·V_ref²·f_s` | `C_tot = C₀·2^bits`（CDAC） |
| 数字逻辑 | `α·C·V²·f` | 活动因子典型 0.5 |
| 漏电 | `n_dev·I_leak·V` | 公开占位量级 |

吞吐 `ops/s = 2N²/T_conv`（`T_conv` 复用 E17 `sar_stage_time`，**不另设时序参数**）。

### 金标（全是「本应恰好为 X」的对照组）

| 金标 | 实测 | 为什么重要 |
|---|---|---|
| 单电容充放电 **½CV²**（**不是 CV²**） | 5.000e-16 J @1fF,1V | 漏因子 2 在项目史上出现过三次 |
| **Landauer 地板** `kT·ln2` | **2.870979e-21 J** @300K | 物理定律锚，比任何实测 landmark 更硬 |
| CDAC 精确恒等 `E(b+1) − 2E(b) = ½C₀V²` | 残差 **7.97e-29 J** | 和式比值是 2.0039 而**非精确 2**（写错就成假判据） |
| 能量守恒 `Σparts = total` | 相对差 < 1e-15 | — |
| 阵列主导能效**与 N 无关** | N=8 与 N=256 **完全相等** 215.349376 | 「本应恰好相等」 |
| 阵列主导能效 ≡ 解析闭式 | 相对差 < 1e-12 | 解析 ⟷ 数值两条路径 |
| 电导敏感性偏离 ≡ 闭式 | 逐点 < 1e-12 | 见 §3 |

## 二、两条标度律（本段最有价值的东西）

### 2.1 🔴 扩规模不提能效

```
ops/s = 2N²/T_conv        P_arr = N²·g·V²·duty
⇒ TOPS/W = 2/(T_conv·g·V·duty)     ← N² 完全相消
```

**数值验证**：N=8 与 N=256 的阵列主导能效**逐位相等**（215.349376 GOPS/W）。
⇒ **想靠堆规模提能效是错的**（堆规模提的是面积效率/总吞吐，不是能效）。

### 2.2 🔴 能效第一杠杆是单元电导

`TOPS/W ∝ 1/g`。实测每降十倍：

| g | 能效 | fJ/op |
|---|---|---|
| 1e-3 S（MOSFET 饱和态） | 213.60 GOPS/W | 4681.7 |
| 1e-4 S | 1867.13 GOPS/W | 535.6 |
| 1e-5 S | 8266.36 GOPS/W | 121.0 |
| 1e-6 S（flash/RRAM 量级） | **12576.81 GOPS/W = 12.58 TOPS/W** | **79.5** |

**每十倍倍数**：8.7413 / 4.4273 / 1.5214 —— **不是恒定 10**，且偏离量**精确等于闭式**
`ratio = 1/(0.1·s + (1−s))`（`s` = 该点阵列功耗份额）。判据逐点锁定 < 1e-12。
⇒ 偏离原因：g 变小时**其他部件成为瓶颈**（进入 ADC/逻辑主导），标度律自然失效。

## 三、三个可对外讲的数字（**全部 `MODEL_ESTIMATE` 档**）

| 场景 | 能效 | 与 landmark 对比 |
|---|---|---|
| 本机占位参数（g≈1 mS） | **211.93 GOPS/W** | Mythic 120 TOPS/W ⇒ 差 **566×** |
| 换真实器件电导（1e-6 S） | **12.58 TOPS/W · 79.5 fJ/op** | **IBM Nature 2023 实测 12.4 TOPS/W（~80 fJ/op）⇒ 几乎持平** |
| 极限（g 更小） | 受 ADC/逻辑主导而饱和 | 交叉规模 `N*` 可判 |

🔴 **这是本段最重要的判断**：与全球领先水平的差距**几乎全部来自器件电导量级（3 个数量级），不在架构**。
架构层（阵列 / ADC / 时序 / 误差预算 / 列共享 / 权重编程）本模型已能复现 IBM 实测量级。

**⇒ 对 E22/E23 的直接指导**：不要在架构上找能效；要**选低电导器件**（flash / RRAM / 低电流 SRAM 模拟 CIM），
并**缩短读出窗口**（duty）。第二条杠杆是 duty，第三条是 T_conv。

### 诚实边界（必须与数字同屏）

- 参数全为**公开典型量级占位（非 PDK）**；`duty_read=0.1` 是占位而非实测；
- 阵列功耗取**满量程最坏**（全行 V_in）⇒ **高估功耗 ⇒ 低估能效**（方向诚实）；
- `N=64` 时阵列占功耗 **98.6%** ⇒ 该点结论对 `g` 极敏感；
- landmark 与 LDA **不同台**（工艺 / 口径 / 精度档均不同）⇒ 只作量级坐标，**不作胜负**；
- **净增 0 锚**：本模型是同一套已建模 C/V/f 的推算，不是独立语料。

## 四、判据换代（**这是最容易做错的地方**）

G-D 解除后，所有「禁报 TOPS」的判据都必须换代，但 **换代方向必须是「标档」而不是「放行」**：

| 位置 | 原判据（会红的条件） | 新判据（会红的条件） |
|---|---|---|
| 卡片 ⑫⑬ / 门禁 B11 | 出现 TOPS | **未标 `MODEL_ESTIMATE` / 暗示实测** |
| 卡片 G-D | 「边界声明 · 不报 TOPS」 | 「**已解除（分三档）** + MEASURED 永久空置 + 原条文作废」 |
| 定位声明 | 「LDA 不报任何 TOPS/TOPS-W」 | 「只报 MODEL_ESTIMATE 档 · **不报任何实测** TOPS/TOPS-W」 |

探针：
- **C1** 假装有实测算（`MEASURED.allowed=True`）⇒ 必红（**这条守的就是红线本身**）
- **C3** 输出改标 `MEASURED` / `is_measured=True` ⇒ 必红
- **C4** 把能效虚报成 120 TOPS/W ⇒ 必红（量级锁）
- **C5** G-D 文案回退成旧条文 ⇒ 必红（防静默回退）
- **C6** 卡片定位声明抹掉分档 ⇒ 必红

🔴 **刻意未改的地方**：`run_ecore_capability_guard_smoke` ⑤（能力面不含 TOPS/TOPS-W）。
它比新口径**更严**，无风险；是否把能效条目纳入能力清单，留待 E22 卡片改版一并处理。

## 六、E21 之后仍未决的三件事（E22 入口条件）

1. **数字控制壳**（RISC-V + 存储层次 + 总线 + 定序）—— 平台**零覆盖**；
2. **编译 / 映射链** —— 产业公认**最大软伤**，平台零覆盖；
3. **器件选型** —— 本段已证明「能效 = 器件电导」⇒ **E22 必须先把器件族定下来**
   （flash / RRAM / 低电流 SRAM），否则所有能效结论都是"给定 g"的条件式。

> 第 3 条是本段新增的硬约束：**在不知道器件电导之前，做数字壳与编译器是在优化一个未被定义的目标。**
