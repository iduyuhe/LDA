1. 愿景（Vision）

1.1 三层愿景递进

  • L0 双栈 EDA（底座·已部分做实）：光子学 PDA + 量子 QEDA 开源 Agent 原生设计软件。
  • L1 能算数的硅（目标）：用双栈设计出光子计算芯片与量子计算芯片——把已会造的「砖」垒成「能算数的楼」。
  • L2 可持续体系（护城河）：开源 + Agent 原生 + 物理判卷 + 社区可独立验货（华为闭源路线做不到）。

1.2 为什么是这两个目标

用户长期诉求；与 LDA 底层同源（天花板方向，非另起炉灶）；商业上计算芯片是硅光价值链溢价最高环节。

2. 战略定位（Strategy）

核心姿态：先铺体系、找条件验证、机会来即闭环。
风险隔离（验证卡脖不拖垮建设）；机会窗口（体系 ready 可控，窗口来临时只灌数据）；护城河不丢（开源+独立验货不向闭源妥协）。

2.2 与产业路径差异化

维度华为/海思（闭源内化）国内 EDA（闭源商用）LDA（开源+独立验货）
真机 ORACLE自有产线自产代工 PDK（NDA）foundry/MPW 只读消费
是否对外闭源闭源卖钱开源可复验
可复核性不可外部复核不可外部复核可独立验货

结论：产业界无「开源+独立验货」成功对标，差异化护城河在此，战略不妥协。
