## 2. 为什么「追锚」彻底没戏（不是推测，是逐类实测）

审计文档已判「可锚性射程 = 物理层」。本轮把量子侧**最后可能的新物理输入**也逐一扫了：

| 候选新物理输入 | 量子侧命中 | 可锚性判定 | 依据 |
|---|---|---|---|
| TLS 两能级损耗 | 27 处（`sc_readout`） | ❌ 不可锚 | `Q=1/tanδ` 是定义式 ⇒ resid≡0 |
| T1/T2 退相干 | **141 处** | ❌ 不可锚 | 已有，且是 exp 衰减 ⇒ 撞 B502–B504 同族 |
| Purcell 因子 | **88 处** | ❌ 不可锚 | 已有锚（B18/B513） |
| BCS 能隙 / 准粒子 | **0** | ❌ 不可锚 | `Δ=1.764·k_B·T_c` 是定义式；准粒子率是积分 ⇒ 无闭式 golden |
| Johnson-Nyquist 热噪声 | 1 处（`detectors`） | ❌ 不可锚 | `√(4kTRΔf)` 是定义式 ⇒ resid≡0 |
| 表面阻抗 Rs / Mattis-Bardeen | 1 处（注释） | ⚠️ **仅能力层** | `Lk=μ0λ²/(w·t)·coth(t/λ)` 是闭式，但给 B22 加 `α_kin` 属**参数化扩展**（同标量·同构型·同数值格式）⇒ 净增 0 |

**结论**：`BCS 能隙` 全仓零命中看似是"新物理输入"，但它给出的都是**定义式或积分**——
定义式 resid≡0（假锚），积分无闭式 golden（D3 已用同类理由判死）。**没有第三条路。**

> 🔴 这条要写进记忆：**「新增物理输入」不等于「新增可锚物」**。判据是"这个量有没有独立的第二条数值路径"，
> 而不是"这个物理现象在平台里有没有"。TLS / T1T2 / Purcell 都已经有实现，但它们要么是定义式、要么已占锚。

## 3. 本轮挖出的两个确定 bug（不在任何账本里）

### 🔴 Bug-1 · `resonator_freq_ghz` 单位错，返回偏 1e6 倍

**位置**：`lda/lda_qeda/sc_readout_mux.py:87-90`

```python
def resonator_freq_ghz(length_um: float, eps_eff: float = 6.5) -> float:
    v_ph = C_UM_PER_S / math.sqrt(float(eps_eff))     # µm/s
    return float(v_ph / (4.0 * float(length_um) * 1e-6) / 1e9)
                                  # ↑ length 转成了 m，与 µm/s 除 ⇒ 偏 1e6
```

| 项 | 值 |
|---|---|
| 输入 δ | 与 `resonator_length_um(5.0, 6.5)` 精确互逆（5879.5617 µm） |
| 实际返回 | **5,000,000.0** |
| 正确值 | **5.0000**（GHz） |
| 偏差 | **1e6 倍** |
| 正确写法 | `v_ph / (4.0 * length_um) / 1e9`（µm/s ÷ µm = 1/s） |

**为什么 344 道门禁没抓到**：`resonator_freq_ghz` **全仓零引用**。
`resonator_length_um` 有 3 处调用（line 150 / 432 / 433），方向是对的、没 bug；
反向函数写完就没人用 ⇒ 也就没人验。

> 🔴 这是**「死函数 = 无门禁覆盖 = 自由腐烂」**的实证。它与已知的 `dead_assert_guard`（死断言）
> 是同一风险族，但现有那道门禁只扫 `assert`/`check(...)` 文本，**不扫"公开导出但无人调用的函数"**。

### 🔴 Bug-2 · `ε_eff` 口径漂移：同一平台四个值，互差 8.33%

同一个物理量（超导 CPW 有效介电常数）在量子侧有 **4 个互不相同的取值**，且**互相零引用、零注释说明**：

| 来源 | 用途 | ε_eff | n_eff | vs 反提真值 | λ/4 腔长 @5 GHz |
|---|---|---|---|---|---|
| `sc_control._fringe_x:235` | 串扰 fringe 电容 `C_x=ε_eff·ε0·L·t/gap` | **6.0000** | 2.44949 | **−3.608%** | 6119.642 µm |
| `sc_readout._control_xtalk:690` | 同上（逐桩串扰） | **6.0000** | 2.44949 | **−3.608%** | 6119.642 µm |
| `sc_readout_mux.DEFAULT_MUX_PLAN:54` | **传播速度** `v_ph=c/√ε_eff` | **6.5000** | 2.54951 | **+4.425%** | 5879.562 µm |
| 设计常量（`n_eff=2.5`） | B22 等锚的给定参数 | 6.2500 | 2.50000 | +0.409% | 5996.000 µm |
| **`cpw_quasi_static` 反提真值** | 几何 `w=10/g=6/Si/h=500` | **6.224562** | 2.494907 | 0（基准） | 6008.239 µm |

**影响量级**：

- 6.0 ↔ 6.5 互差 **ε_eff 8.333%** ⇒ **腔长互差 240.080 µm = 3.996%**
- 腔长固定为真值时，频率从 **5.0927 GHz** 漂到 **4.8929 GHz**，**峰峰 199.8 MHz**

**为什么这是可签核风险**：超导 FDM 读出音间隔典型 **10–50 MHz**。**200 MHz 的偏**
意味着同一个谐振器会落到隔壁**四到二十个音**的位置上——FDM 频率规划直接失效，
而 `sc_readout_mux` 自己的 `RED_LINE_DISCLOSURE` 还写着「f_r/κ/g/ε_eff 为设计参数（非 golden）」。

> ⚠️ **必须诚实定性**：这三处的 ε 在**物理语义上不完全是同一个量**——
> `sc_control`/`sc_readout` 的 ε 是「线间 fringe 场填充」，`sc_readout_mux` 的是「全截面填充因子」。
> 所以**不能直接判成"抄错了"**。真正的问题是：**四个值都没有来源、没有交叉引用、
> 没有任何地方声明它们"允许不同"及差多少**。这是**口径漂移（caliber drift）**，
> 而不是简单的复制错误。修法也因此不是"统一成一个数"，而是**建单一真源 + 显式声明偏离理由**。

## 4. 结构性风险：静态零调用 13 个（含已被证明真错的那个）

`lda_qeda` 公开函数 **391** 个，静态统计全仓零引用 **13** 个：

```

control_gds                   sc_control.py         qpu_budget_verdict        qpu_error_budget.py

```

**必须声明这个统计的局限**（否则会误判）：

- `run_tunable_selfchecks` / `run_array_loss_selfchecks` **实际是被调用的**——
  以**函数对象**形式传入 `run_schip_s5_smoke.py:236/239` 的回调表（`SC.run_tunable_selfchecks, 8`），
  不带括号 ⇒ 静态正则判"零调用"是**假阳性**。
- `*_gds` / `*_svg_preview` 多数同理（`examples/lda_schip_s*.py` 里以对象形式登记）。
- **只有 `resonator_freq_ghz` 是「零引用 + 实测数值错」双重确定。**

⇒ 所以正确做法**不是**"按静态零调用清死代码"（会误删），而是**建动态可达性判据**：
把每个公开函数在**真实门禁跑一遍后的调用轨迹**里查一次，未出现且无 `__all__` 声明 ⇒ 才判死。

## 6. 推荐序与理由

**A2 ✅ → A1 ✅ → B1 ✅ → B2 ✅ → A3 →（C 类按需）**

1. **A2 先做**：零引用 ⇒ 改它**不牵动任何既有判据**，风险最低；但它是**已证实的数学错误**，
   "修一个确定错的东西"优先级永远最高。附带补的往返一致性判据还能防同类复发。
2. **A1 次之**：它是本轮最硬的工程发现（199.8 MHz 频率歧义），但改 3 个模块默认值会牵动
   S4/S5 —— 必须**先跑基线快照、再改、再逐条比对**，属于"值得做但要小心做"。
3. **B1/B2**：纯增量物理，风险低，能让 A9 的版图反提从"准静态"逼近"设计可用"。
4. **A3**：结构性护栏，放最后（它是防复发，不产生新能力）。
5. **C 类**：**建议明确不做**。理由见 §2——下界是有理量、SK 是浮点，两者都撞已知的判死理由，
   做了也拿不到判别力，只增加维护面。

**为什么不是先做 B1**：动力学电感会让 n_eff 从 2.4949 升到 ~2.5 附近，
**可能正好解释上一轮观测到的 0.2037% 偏差**——这很有吸引力，但它是"解释已有小偏差"；
而 A2 是"1e6 倍的真错"、A1 是"200 MHz 的歧义"。**先修大的，再修小的。**

## 8. 明确不建议做的事（防以后重复讨论）

| 不建议 | 理由 |
|---|---|
| 再加量子新域去凑锚 | 边际 0.50 锚/版；且本轮已把 TLS/BCS/热噪声/表面阻抗逐类扫完，全是定义式或已占锚 |
| 把 TLS 损耗立成锚 | `Q=1/tanδ` 是定义式 ⇒ resid≡0 ⇒ 属假锚（同 B516/B517 的 `reserved_null` 类） |
| 给 B22 加 `α_kin` 当新锚 | 参数化扩展（同标量·同构型·同数值格式）⇒ 按章程净增 0 |
| 按"静态零调用"批量删函数 | 函数对象传递会造成假阳性（`run_*_selfchecks` 实证）⇒ 必须动态可达性判定 |
| 做 SABRE / Clifford+T 综合 | 下界是有理量、SK 是浮点，两者都撞已判死的理由，拿不到判别力 |
| 把 ε_eff 四处"统一成一个数"了事 | fringe 场填充 ≠ 全截面填充，物理语义不同；正解是单一真源 + 显式声明偏离 |
