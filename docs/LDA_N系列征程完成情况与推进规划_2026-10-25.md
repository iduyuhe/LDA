## 2. 未完成：N1 / N3（两条 A/B 级主线）

### 🔴 N1 电子域实证语料锚 —— 零启动（这是唯一能产生正锚量的动作）

| 项 | v3 审计计划 | 当前实测 |
|---|---|---|
| 目标 | 8–12 条电子域实证锚（MOSFET I–V / SS / μ_eff / ADC ENOB / MVM 精度） | **0 条** |
| 语料 | 从公开实测取（DOI/URL + geometry + σ） | 语料库 122 条里**电子 0 条** |
| 升格机制 | 已在光子侧跑通（照 E8 的窗口法 `[2·resid, \|g\|/12]`） | 机制在，**没用在电子上** |
| 棘轮 | `EMPIRICAL_ANCHORS ≥ 10` 只升 | 现值 **8**（见 §3 失校①） |
| 风险（审计自述） | 🔴 公开 MOSFET 数据多为 PDK 保密或**曲线图**（非数字表）⇒ **先做半天语料可得性勘查** | **勘查也没做** |

**必须先做勘查，而不是直接开工**：如果电子语料确实只有曲线图，那 N1 会变成"为了产出锚而把图读成数字"——
这违反「仿真值永不作 golden」的同一条纪律（读图 = 二次数字化，误差不可溯源）。

### 🔴 N3 统一四域签核 schema —— 零启动

现状是"字段齐备但不统一"：四域各自有 `verdict` / `claim_line` / `grade` / `deck`，
但**同一件事（这一条到底是什么级别的签核）在四域用不同字段组合表达**，无法跨域比较。
这是 **B 级、净增锚 0、但对外可讲性增益高**的活，且**独立于 N1/N2**，可与主线并行。

## 5. 推进规划

### 5.1 对 v3 审计原顺序的修订建议

v3 审计的依赖图是 `N1 → N4`、`N2` 并行、`N5` 等出数。**建议改为**：

```
A1（修口径自证）── A2（超导语料升格，新机会）
                        │
A3（N1 语料勘查）────────┤
                        ├──> A5（超导 L3 补到 ≥4）
A4（schema 统一）───────┘
                        │
                        └──> 若 A3 勘查通过 ⇒ N1 正式开工（8–12 条电子实证锚）
```

**修订理由**：
1. **A2 应排在 N1 之前** —— 语料已在库，是**已验证可行的最短路径**；先跑通"升格流程"再做 N1，风险更低。
2. **A3 是 N1 的前置闸门，不是 N1 的一部分** —— 勘查不通过就如实判死，不许把曲线图读成数字。
3. **A1 必须先做** —— 否则"实证锚到底几条"自己都对不上，后面所有关于锚数的判断都没有基准。

### 5.2 分阶段排期（按"每版可验收"切）

| 阶段 | 内容 | 验收标准 | 预计 |
|---|---|---|---|
| **P0** | A1 修 E2/E8 标题与 provenance 不一致 | 账本内 `title` 含"实证语料锚"的条目 **≡** `provenance==external_empirical` 的集合（机核判据，非人工） | 1 版 |
| **P1** | A3 语料可得性勘查（**先做**，因为它决定 N1 是否成立） | 产出一份「每条候选指标的可得性表」：数字表 / 仅曲线 / 需 NDA / 无 ⇒ **判死也交付** | 半天 |
| **P2** | A2 超导 10 条语料升格 | 每条：公开实测 + DOI/URL + device geometry + σ；候选侧独立复算；`EMPIRICAL_ANCHORS` 棘轮 **8 → 18**（只升） | 2–3 版 |
| **P3** | A3 通过则 N1 开工；不通过则转 A5 | 电子域 `external_empirical` 从 **0 → ≥8**（通过）或"如实判死 + 转投超导 L3"（不通过） | 3–5 版 |
| **P4** | A4 schema 统一 + A5 超导 L3 ≥4 + A6 两口径合并 | 四域同一 schema 可跨域比较；超导 L3 ≥4；`schip` 两口径合并或显式声明 | 2 版 |

### 5.3 三条硬约束（不许为达数量而放松）

1. **语料可得 ≠ 锚可做**：先验 golden 拿得到，**再验候选物理成立**。两条都过才算一条。
2. **仿真值永不作 golden**；曲线图读数**视为二次数字化，不可溯源** ⇒ 不作为 golden。
3. **净增锚必须伴随棘轮**：`EMPIRICAL_ANCHORS` 只升不降，且每加一条要有"可外部复算"的证据链。
