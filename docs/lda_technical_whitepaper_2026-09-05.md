## 0. 摘要

LDA（Lightwave Design Agent）是对标商业 EDA 的**开源、Agent 原生**光子设计自动化（PDA）+ 量子 EDA（QEDA）等价物。它把三件事作为第一性原则，而不是事后补丁：

1. **验证可证伪**——判决落「非 AI ground」（物理定律锚 + 实证大数据锚），LLM 不进判决路径，PASS/FAIL 由死标量比对定。
2. **Agent 原生**——设计、接线、回归、文档由 AI 自写与自驱，但核心求解与判据主权自主。
3. **主权自主**——A 级能力永不借外部依赖；B 级借今踢后；C 级第一天自主。

本文给出 LDA 的技术架构、核心账目、验证方法论、主权纪律，并与全球主流光子 / 量子 EDA 工具做**技术侧对比与排名**（数据截至 2026-09，含 Web 检索与 LDA 内部运行账本）。

## 1. 定位与为什么存在

| 维度 | LDA 的立场 |
|------|-----------|
| 对标 | 商业 EDA（光子布局 / 仿真 / 验证）的开源等价物 |
| 范式 | Agent 原生——核心由 AI 自写，而非 GUI 点击工具 |
| 双栈 | 光 PDA（15 引擎）+ 量 QEDA（7 引擎）统一在同一求解核 |
| 护城河 | 标准 + 生态 + PDK 供给，而非封闭求解器 |
| 红线 | 验证判据不可被 LLM 污染；主权不可被 A 级依赖绑架 |

LDA 不是「又一个光子布局库」。它的差异化在于：把**验证锚的独立性**和**主权自主**作为架构约束，而非商业选项。

## 2. 技术架构：从设计到流片的闭环

完整闭环：**设计 → 仿真 → 版图 → DRC/LVS → 工艺角 → 几何寄生**。

- **22 引擎**（光 15 + 量 7，口径 = 设计品类）
- **11 包**，合计 **33 类**能力面
- **求解核 `lda_solver/`：40 模块**
- **pdks = 5 / layers = 8**
- **超市 58 货架**（基础档 ¥599 / 标准档 ¥1999 / 高端档 ¥4999 / 开放下载）

规模改造线（已落地）：

| 改造项 | 成果 |
|--------|------|
| P0-1 层次化 GDS | CPO 250k：897,600 → 331 元素，**99.96%** 压缩（v0.9.33） |
| P0-2 LVS 几何均值 cell | 1M 全链 35.98s；**10M 实测 428.42s / 30.5GB**，O(n^1.08)（v0.9.36） |
| T-8 去 GPU | 5 器件 live **5/5 零 SKIP**（v0.9.38） |
| T-9 锚题覆盖矩阵 | 33×48 覆盖矩阵，21/22 引擎 + 7/11 包（v0.9.37） |

诚实边界：3D FDTD 1000³ ≈ 96GB 不可行；A* 布线 ≈ 5ms/障碍 ⇒ 顺序布线 O(N²)。这些是规模结论的已知上限。

## 4. 验证方法论（不可逾越的红线）

**判据落非 AI ground**：

- **物理定律锚**（B 类）：由麦克斯韦方程 / 量子力学等第一性原理死标量比对。
- **实证大数据锚**（E 类）：由大规模实证数据集比对。
- **系统级锚**（S 类）：由系统级一致性约束比对。

**LLM 不进判决路径**：

- 客服 Agent、文档生成、接线建议可由 LLM 驱动，但 **PASS/FAIL 由死标量比对定**，LLM 输出不参与判决。
- 自证桩判据 = 残差≡0 且扰动无响应（基线取候选自身）；充要特征「跟着 golden 走」。判据 D（v0.9.27）：扫候选自身离散参数恒 ~1e-16 ⇒ 假独立；须双向标定。
- 不等式锚一律 `cmp='le'`；一律 `spec.compare_fn`，禁裸 `abs`。

**已知不可接（勿重试）**：S1–S6 · S9–S12 · E1/E3–E7 · B2 · B11 · B16/B17/B18/B21 · B5/B6/B7（ORACLE 锁）。

## 5. 主权与依赖纪律

| 级别 | 含义 | 代表 |
|------|------|------|
| **A 级** | 永不借外部依赖 | 核心求解 / 判据（主权红线） |
| **B 级** | 借今踢后 | gdsfactory / KLayout / SAX；Tidy3D 仅外部 ORACLE |
| **C 级** | 第一天自主 | 自有版图 / 接线 / 回归 |

**Meep = GPL v2+ 已隔离**：通过 subprocess 只回标量，不污染 LDA 代码库（GPL 传染性被阻断在进程边界）。

**Tidy3D = 仅外部 ORACLE**：作为基准 oracle 调用，不进 LDA 自身判决路径。

## 6. 全球光子 EDA 工具对比排名（2026）

维度说明：**开源**（许可自由度）、**AI/Agent 原生**（是否 LLM 驱动设计）、**验证锚独立性**（判据是否物理/实证死标量）、**主权风险**（是否厂商 / 硬件锁定）。

| 排名 | 工具 | 定位 | 许可 | 开源 | AI 原生 | 验证锚独立性 | 主权风险 |
|------|------|------|------|------|---------|------------|----------|
| 1 | **LDA** | Agent 原生 PDA+QEDA | MIT(计划) | 是 | **是** | **强**（物理+实证） | **无**（A 级自主） |
| 2 | gdsfactory | 开源布局+仿真+LVS 端到端 | MIT | 是 | 否 | 弱（用户自证） | 低（B 级可借） |
| 3 | Meep | 开源 FDTD 求解 | GPL | 是 | 否 | 弱 | 中（GPL 隔离） |
| 4 | Luceda IPKISS | 商业 PIC 全流程 | 商业 | 否 | 否（Canvas 协） | 中 | 高（厂商锁定） |
| 5 | Ansys Lumerical | 商业黄金标准求解 | 商业 | 否 | 否（PyLumerical） | 中 | 高 |
| 6 | Tidy3D | 云端 FDTD SaaS | 商业 SaaS | 否 | 否 | 弱 | 高（ORACLE 锁） |
| 7 | COMSOL | 通用多物理场 | 商业 | 否 | 否 | 中 | 高 |

**解读**：

- **gdsfactory 9.39.3（MIT）** 是社区最强的开源 PIC 流：端到端布局 + 仿真接口 + LVS，25+ 开源 PDK，被 Google/Meta/MIT 用于流片。它是 LDA 的 B 级可借底座，但**非 Agent 原生、验证靠用户自证**。
- **Luceda IPKISS** 是工业级商业全流程（Python/PDK/CAPHE，源于 Ghent/imec），但闭源、厂商锁定，主权风险高。
- **Ansys Lumerical 2026 R1.2** 是器件/系统求解标杆（FDTD/EME/FEM/多物理场 + GPU + qINTERCONNECT 量子光子线路），但闭源昂贵、主权依赖。
- **Tidy3D（Flexcompute）** 比 Meep 快 300×（云端 GPU），但 SaaS 计费 + ORACLE 锁，主权风险最高——LDA 仅作外部基准。
- **Meep（GPL）** 纯开源 FDTD，支持 GDSII 导入，但无 GPU、慢，LDA 以进程隔离方式借用其标量输出。
- **COMSOL** 通用多物理场，非 PIC 专用。

LDA 排名居首，不是因为求解精度已超越 Lumerical（尚在 C 期前、未流片），而是因为**它把验证锚独立 + 主权自主 + Agent 原生作为架构第一性原则**——这是现有工具的结构性空白。

## 7. 全球量子 EDA / SDK 对比排名（2026）

| 排名 | 工具 | 定位 | 许可 | 开源 | AI 原生 | 验证锚独立性 | 主权风险 |
|------|------|------|------|------|---------|------------|----------|
| 1 | **LDA QEDA** | Agent 原生 QEDA | MIT(计划) | 是 | **是** | **强**（锚） | **无** |
| 2 | Qiskit | IBM 开源 SDK | Apache 2.0 | 是 | 否 | 中（transpiler 审计） | 中（IBM 硬件绑定） |
| 3 | PennyLane | Xanadu 微分 / 混合 ML | Apache 2.0 | 是 | 否 | 中 | 低（厂商中立） |
| 4 | QuTiP | 开源主方程 / Lindblad | BSD | 是 | 否 | 强（数值可复现） | 低 |
| 5 | Cirq | Google 设备感知 | Apache 2.0 | 是 | 否 | 中 | 中（Google） |
| 6 | Strawberry Fields | Xanadu CV 光子 | Apache 2.0 | 是 | 否 | 中 | 低 |
| 7 | Braket | AWS 托管 SDK | Apache 2.0 | 是(SDK) | 否 | 弱 | 高（AWS） |

**解读**：

- **Qiskit**（IBM，生态最大，transpiler + Runtime 审计追溯）是量子 SDK 事实标准，但硬件绑定 IBM。
- **PennyLane**（Xanadu，参数移位梯度 + 混合 ML）厂商中立，适合变分量子算法。
- **QuTiP**（BSD，主方程 / Lindblad 主方程，数值可复现）是开放量子系统研究首选，验证锚独立性最强。
- **Cirq**（Google，Moment 显式时序 / 设备感知）适合硬件对齐调试。
- **Strawberry Fields**（Xanadu，连续变量光子）专注光子 CV 工作流。
- **Braket**（AWS）统一管理后端执行，但云锁定。
- **LDA QEDA** 排名居首同理：Agent 原生 + 锚独立 + 主权自主，是量子 EDA 的结构性新范式（当前成熟度低于 Qiskit 生态，但维度不同）。

## 10. 结论

LDA 不是又一个光子布局库，而是把「**验证可证伪 + Agent 原生 + 主权自主**」作为第一性原则的开源 EDA 新范式。它在光子侧对标 gdsfactory/Luceda/Lumerical，在量子侧对标 Qiskit/PennyLane/QuTiP，但差异化不在求解精度（当前成熟度仍低于商业标杆），而在**架构维度的结构性空白**——验证锚独立、LLM 不进判决路径、主权不可被 A 级依赖绑架。

对采用者的建议：把 LDA 当作**验证可信度 + Agent 原生工作流**的底座，把商业求解器（Lumerical/Tidy3D）作为外部 ORACLE 基准，而非黑盒真理来源。
