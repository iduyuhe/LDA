LDA 系统战略愿景 · 能力成熟度图谱 · 进阶路线图

开源 Agent 原生光电/量子芯片设计软件（光 PDA + 量 QEDA）。本图聚焦「为什么做、做到什么程度、下一步往哪走」，与前五张（系统分层 / 部署 / 55 锚 / 应用 / 能力）互补。数据截至 2026-09-14，来自项目规划文件与 CI 账本。
愿景一句话：光电接缝上的可证伪设计入口。

我们不做整条链——只做这条链上「唯一既没有可证伪工具、也没有统一接口的那一格」。护城河 = 标准 + 生态 + PDK；判决权在物理定律锚，签字权在人，LLM 不进判决路径（代码级红线，不是口号）。

战略定位与红线

Positioning · Red Lines

护城河 标准 + 生态 + PDK

验证红线：判决落非 AI ground（物理定律锚 + 实证大数据锚）；AI 出题、物理定律判卷；PASS/FAIL 由死标量定，排序完全确定性、无随机无 LLM。

责任边界：全生命周期 8 段，只承担 3–5 段（设计实现→版图签核→出带包）。断点 1（需求冻结）由 T0 模板补、断点 6（封测）委托伙伴。

主权红线 借 / 锁分层（电域已解锁）

🔓 电学器件内核（泊松-玻尔兹曼 / 漂移-扩散 / 载流子连续性）：已解锁自研 —— T1-B：DEVSIM 冷备 + 自研 1D 泊松 + 2D 漂移-扩散（均 4 判据 smoke），C 级自主。

🔒 链路级电域判决（SerDes/DSP/BER/眼图）：仍锁死 —— 无工艺统计锚 ⇒ 硬做必假绿，客户已有 Cadence。

🔒 foundry TCAD 工艺真值：数值内核已解锁，工艺真值永久锁死（NDA 不给）。
🔒 封测实体产线：全锁，先委托后自建。

「不做」每一条都有产业根因；电学内核已按 Foundry TCAD 分层解锁裁定（2026-09-11）解锁自研。

主权分级 A 永不借 · B 借今踢后 · C 自主

A 级（核心求解器/判决路径/锚库）：永不借代码。
B 级（边缘求解/新增锚）：借今踢后——先用、限成熟节点、逐步自研替换。
C 级（如自研 FDTD）：完全自主。

Meep=GPLv2+ 已隔离：subprocess 只回标量，不进核心。Foundry TCAD 分层解锁（2026-09-11）：T1 数值内核允许，T2 工艺真值永久锁死。

生态开放四层光谱 获客引擎，不是研发外包

① 实测语料/对抗题（已在做·风险最低）
② PDK 适配/器件库/文档（判据我们写）
③ 边缘求解模块+新增锚（先判据后代码）
④ 核心求解器/判决路径/锚库（不开放代码，只开放对抗）

最大风险 = 假绿（自证桩批量生产）。规避机制：判据先于代码，且判据由 maintainer 写——与「AI 出题、物理判卷」同构。
