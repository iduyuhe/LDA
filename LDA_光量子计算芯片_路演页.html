它是什么

可编程干涉仪网格 = 量子处理器

线性光学中，N 个模式的任意酉变换 U 由无源分束器 + 相移器实现； 而任意 N×N 酉都可分解为 O(N²) 个 2×2 酉（Clements 必要性定理：恰好 N(N−1)/2 片 2 模门）。 把这个分解铺成网格版图，就是一颗「按需编程」的量子处理器——换一组相位就换一个酉，硬件不动。

每片 MZI（方框）= 一个分束器 θ + 一个相移器 φ（2 个可编程参数）； 同层配对互不共享波导 ⇒ 同层可同步；层间交替错位 ⇒ 每层都是真匹配。

核心突破

四条硬结论

① 紧界可达
通用 N 模酉的相邻耦合紧下界 = N。矩形 Clements 网格的深度恰好 = N（每层真匹配）， 且元件数不增（仍 N(N−1)/2）。对照平台三角 Reck 最优 2N−3 —— 换拓扑即深度减半。
② 参数计数会骗人
「可及参数 ≈ ⌊N/2⌋·D」只是上界。实测可达子流形维数后发现：全最大匹配序列门数线性增长， 而可达维数恒为 2N（乘积块对角，与深度无关）；最优浅电路是交替砖墙； 参数计数下界 N−1 不可达。
③ 「通用」与「省损」不可兼得
损耗墙的本质是深度墙，深度下界 Ω(N) 由参数计数钉死。时间复用把元件数从 O(N²) 降到 O(1)， 但每模损耗反而更贵；只有放弃通用性的浅电路才越墙（而那已非通用）。 这给出了 Borealis 216 模「浅电路 + 放弃通用性」的机器可判依据。
④ 约定必须精确到块级恒等式
平台单元与主权分解的相位臂相反：裸替换在 2×2 层面只差一个标量（看似无害）， 但嵌入 N×N 后该标量只落在本门的 2 个模上 ⇒ 注入逐模相位且与邻门不对易 ⇒ 整网格 ≠ U（连全局相位都不是），相位不变口径保真度仅 0.0054。

工程纪律

为什么这些数字可信

判决不靠模型

是否通过由死标量比对（闭式物理律 vs 数值） 给出，LLM 不进判决路径；判定位是 int / bool / 死字符串。

外部真值分层

闭式科学原理与 A 级实测事实可作外部基准； 仿真/计算值永不作基准；与 Borealis 只比规模与架构，不比数值。

机器可判的护栏

每个能力配常驻门禁 + 突变探针 （探针证明断言真的会变红）；本芯片案例的 UI 面板亦有 24 判据把数字对回报告与平台常量， 文案漂移即红。

诚实边界（随本页同步）

  1. 本成果是设计 + 数值正确性证明（数学 + 构造性数值 + 版图签核流程），非流片后实测。
  2. 损耗 / 效率均为设计预算口径（per_mzi 2.4 dB、per_step 2.6 dB），非实测 PDK。
  3. 与 Borealis 只比规模 / 架构 / 参数计数，不比数值（CV Gaussian Boson Sampling vs DV 被动 LOQC，物理模型不同）。
  4. 「综合对标分」是平台自定义量，非国际公认指标，仅作内部趋势追踪。
  5. 最优性证据限于 N ≤ 8 / D ≤ 6 搜索空间（N=4 穷举）⇒ 不宣称全局最优证明。
  6. 每模口径不含波导交叉损耗，属下界。
