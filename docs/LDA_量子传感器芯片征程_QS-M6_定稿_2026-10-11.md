🔴 **本档复用而非重造**：
- **复用 `sc_coupler`（D-139 可调耦合器 SQUID）的 `E_J(Φ)` 闭式**（`√((E_J1+E_J2)²cos²(πf)+(E_J1−E_J2)²sin²(πf))` 同式）—— 但登记的是**传感器链**的独立物理量（传感器临界电流 I_c / 转导 ∂I_c/∂Φ / 灵敏度 B_N），**功能不同**（耦合器可调性 J_qc/J_eff vs 磁力计读出链）；
- **复用 `sc_readout` 的阵列/DRC/LVS/signoff 范式**（QS-M4 已复用其纪律）；
- **复用 QS-M5 的闭环标定范式**（本档不重做标定，专注器件物理）。

## 2. 物理链（三条新锚）

### ① 约瑟夫森 RCSJ 结（链①）

**直流约瑟夫森关系**：`I_s = I_c·sin δ`（δ = 结相位差；δ=π/2 达 I_c）。

**RCSJ 微分方程**（resistively-capacitively-shunted junction）：

```
ħC/(2e)·δ″ + ħ/(2eR)·δ′ + I_c·sin δ = I_bias
```

- **等离子频率**：`ω_p = √(2eI_c/ħC)`（默认档 **19.617 GHz**）；
- **McCumber 参数**：`β_c = ω_p R C`（默认档 ≈0.157，**非滞回**区）；
- **Ambegaokar–Baratoff 零温闭式**：`I_c·R_n = πΔ/(2e)`（结临界电流-正常态电阻乘积由能隙 Δ 锁定）。

🔴 **积分器时间尺度纪律（本档血案）**：弛豫时间 `τ_relax ≈ 1/(ω_p²RC)`（默认档 ~0.33 ns）⇒ 积分总时长须 ≳3τ_relax；步长 `dt ≤ 1/(40·ω_p)`（保证 ω_p 周期内 ≥40 步）。

**判据**（RK4 相位动力学积分器实测）：
- 偏置 < I_c ⇒ 相位**锁定**于 `δ_eq = asin(I_b/I_c)`（末态相位残差 **2.665e-15 rad**）；
- 偏置 > I_c ⇒ **逃逸**（δ′ ≈ 1.05e11 rad/s，washboard 势倾斜）；
- `0.99·I_c` / `1.01·I_c` 两侧判据**翻转**。

### ② SQUID 环路临界电流 + 磁通-电压转导（链② · B485/B486）

**对称双结并联 SQUID 环路临界电流**（磁通量子化约束两结相位差 δ1−δ2 = 2πf ⇒ 矢量叠加取模）：

```
I_c(Φ) = 2·I_c0·|cos(π·Φ/Φ0)|         （Φ0 = h/2e 磁通量子；f = Φ/Φ0）
```

- f=0 ⇒ 2·I_c0（两结同相）；f=0.5 ⇒ 0（完全相消）；周期 Φ0。

**磁通-电压转导**（分流传导函数，f 在 |cos| 光滑区间内）：

```
∂I_c/∂Φ = −2π·I_c0·sin(πf)·sgn(cos πf) / Φ0        （A/Wb）
```

🔴 **转导是性能核心**：磁灵敏度 `B_N ∝ 1/|∂I_c/∂Φ|`。

**数值互验**：
- I_c(Φ)：**相位空间扫描**（`I(δ)=I_c0·[sinδ+sin(δ+2πf)]` 扫 δ∈[0,2π) 取 |I| max）；
- 转导：**数值中心差分**。

🔴🔴 **本档最重教训（反自证桩关键坑）**：**相位扫描在 f=0.25（及一切使极值点 δ*=π/2−πf 落 2 幂网格节点的 f）时恰好命中极值 ⇒ 残差恒 0（代数恒等）**，会被 `run_benchmark_falsifiability_smoke` 判**自证桩** ⇒ 独立锚**必须固定在非对齐 f=0.30**。

### ③ 磁通噪声 → 磁场灵敏度（链③ · B487）

**Johnson–Nyquist 分流电阻热噪声**（白噪声底）：

```
S_I = 4·k_B·T / R                       （A²/Hz）
S_Φ = S_I / (∂I_c/∂Φ)²                  （Wb²/Hz）
B_N = √(S_Φ) / A_eff                     （T/√Hz，A_eff = 环路有效拾取面积）
```

**数值互验**：**蒙特卡洛 Johnson 噪声传播**（生成 n_mc 个电流样本，经转导折算磁通样本，取数值方差 ⇒ S_Φ）。
