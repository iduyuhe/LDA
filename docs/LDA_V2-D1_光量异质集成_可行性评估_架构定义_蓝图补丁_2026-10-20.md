### 4.1 M1 裁决：**不立新锚**（负结果机器化 · v0.9.259 实测）

章程 §3/§4 原定 M1 两条（Fresnel 反射损耗 · Beer–Lambert 界面吸收）。**同源体检（全账本 539 锚现扫）结论：两条 100% 已被既有锚覆盖，且连候选方法都对得上** ⇒ 判**参数化扩展、重复计数**（R1 红线），**不立新锚**。

| 章程原定 | 覆盖锚 | 被测标量 | golden | 候选方法 | 结论 |
|---|---|---|---|---|---|
| `interface_fresnel_loss(n1,n2,θ)` | **B413** | `normal_incidence_reflectance` | `R0=((n1−n2)/(n1+n2))²` 闭式 | 1D FD Helmholtz 总场解 | **完全同一** |
| `interface_absorption_loss(α,L)` | **B493** | `qs_pump_transmission` | `T(L)=T₀·exp(−n·σ_abs·L)` 闭式指数 | RK4 空间推进 | **完全同一** |

**四条理由（机器守，每条 ≥12 字）**

1. 被测标量与既有覆盖锚完全同一（反射率 R0 / 透过率 T(L)），再立即同一物理量重复计数。
2. golden 闭式（Fresnel 反射系数 / Beer–Lambert 指数）与既有覆盖锚逐项相同，独立性不成立。
3. 候选方法学亦相同（1D FD Helmholtz 总场解 / RK4 空间推进），连「不同源」这一条也站不住。
4. 同族 Fresnel 已有 13 条（R0/Rs/Rp/Ts/Tp/Runpol/ΔR/TsTp/θB/|t_s|/TIR/β/能量守恒）⇒ 族内已饱和。

**机器化（「负结果也要机器化」纪律）**

- 新增**非门禁**模块 `lda_harness/d1_registries.py`：裁决面 + 覆盖锚方法规格 + **哨兵指标名**（`fresnel_interface_loss` / `interface_absorption_loss` / …）。
  🔴 锚号**只在此处**出现 —— 写进门禁源码会被 K4 的 L2 文本代理算成「有专属判据」，虚增覆盖面。
- 门禁 `run_v2d1_smoke.py` **H/I 组 5 判据**：
  - **H1** 覆盖锚仍在且方法未漂移（metric ∧ golden 形态 ∧ candidate 形态 ∧ ORDER）；
  - **H2** **哨兵指标名未被偷登记**（日后换名重立同一物理量 ⇒ 必红）；
  - **H3** 裁决面完整（verdict ∧ ≥3 理由 ∧ 每条 ≥12 字 ∧ 覆盖锚 ≥2 且各有方法规格）；
  - **I1/I2 反向探针**（先证能红）：篡改 metric ⇒ H1 必红 · 注入哨兵名 ⇒ H2 必红。

⚠️ **M1 本档净增 0 锚**（账本不因 M1 变化；本版账本 539 → 540 全部来自 M3 的 B524）；M1 的界面损耗**物理面**由 B413 族 + B493 **复用覆盖**，D1 不再重复实现同一闭式。

### 4.2 M1 腾出的预算 → **M3 前移**（v0.9.260 落地 B524）

M1 判「不立新锚」后，锚预算按「补真空白」原则前移到 **M3 低温共集成热接口**：同源体检显示 `kapitza|界面热阻|thermal boundary|温跳|声学失配|dmm|amm` 在 `BENCHMARK_DEFS` 内 **0 命中**，且它是低温异质集成的**实际瓶颈**（`R_K ∝ T^{−3}`）。交付锚 **B524 Kapitza 界面热导 h_K**：golden = DMM + 低温 Debye 精确闭式；candidate = 内能温度中心差商 + 谱积分数值求和（O(ε²) 真截断）。实测 golden=**1.162106474762e+05 W/(m²·K)** · tol **0.05** · 残差 **9.664e-06（5174×）** · 残差链比恒 **4.00**。

### 4.3 M2 裁决：**不立新锚**（可锚性数值体检 · 派生量）

章程 M2 原定「光纤阵列对准容差 / 角度失配」。体检（数值实测 + 三处比对）：

| 判据 | 实测/结论 |
|---|---|
| 物理同一性 | `Y=P(η(d)≥η_min)`，`η(d)=exp(−d²/2w²)` ⇒ `η≥η_min ⟺ abs(d)≤d_max` ⇒ **无新物理量**（派生量） |
| 闭式同族 | `Y=erf(d_max/(√2σ))` 与 M0 的 γ̄ **同属 erf 族** |
| 数值格式同族 | 候选取「限窗复合 Simpson」⇒ 与 M0 **同格式** ⇒ 三处中**两处同族**（仅「被测标量是概率」一条分歧） |
| MC 路线 | 跨 **8 个固定种子取最坏**：N=1e5 → **1.615e-03** · N=1e6 → **3.736e-04**（相对 4e-4）⇒ 达不到「残差 ≤ tol/100」所需余量，且**跨种子不可复现** |
| Simpson 路线 | 收敛链 **12.75/15.25/15.82/15.96/16.02**（O(h⁴) · n=256 resid **6.695e-12**）虽干净，但同族 |
| 角度失配 | part5 note 已记「复振荡被积函数 ⇒ 谱精度 ⇒ 假独立」⇒ 不重复尝试 |

**⇒ 判「派生量 · 不立新锚」**；机器化：`D1_M2_ADJUDICATION`（`lda_harness/d1_registries.py`，含**实测证据字段** `empirical`）+ 门禁 **K/L 组 4 判据**（K1 哨兵未被偷登记 · K2 裁决面完整 · **K3 负证据在册** · L1 反向探针）。

⚠️ **本档净增 0 锚**；D1 的封装耦合**物理面**由 part5 单通道锚覆盖，平台不重复实现同一耦合律的统计包装。

## 5. golden 合法性（四源）

- **M0**：闭式 erf（**科学闭式**）⇄ 有限窗复合 Simpson 求积（真截断）。
- **M1**：Fresnel / Beer-Lambert 均为**科学闭式**；候选用多层膜 TMM（真截断，O(h²)）。
- **M2**：~~高斯重叠为科学闭式；候选用数值二维积分 / MC~~ ⇒ 🔴 **裁决撤销**（§4.3）：良率为既有耦合律的统计包装，闭式与候选格式均与 M0 同族；MC 实测跨 8 种子最坏 N=1e6 仍 **3.736e-04**（相对 4e-4）⇒ 余量不足且不可复现。
- **M3**：**DMM 透射 + 低温 Debye 精确热容**为**科学闭式**（`h_K=(1/4)[α_{1→2}v₁C₁+α_{2→1}v₂C₂]`，`C=(12π⁴/5)nk_B(T/θ)³`）；候选用**内能温度中心差商 + 谱积分数值求和**（真截断 **O(ε²)**，实测比恒 4.00）。
  🔴 **血案**：谱积分被积函数光滑指数衰减 ⇒ 梯形/Simpson 指数收敛、n=256 即到浮点地板 ⇒ 会把锚变成「代数恒等」假绿 ⇒ 截断必须放在**位移轴**上。

🔴 **禁止**：仿真器输出、第三方 QEC/光电子 SDK、实测唯一样本作 golden（仅可作规格锚）。
