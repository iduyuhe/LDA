# 发布节奏（Release Cadence）

> 立此文档的直接原因：v0.9.353 / .354 / .355 三个版本**各跑了一次 ~3h 全量 CI、各写了完整
> CHANGELOG，却从未发布**（直接被 .357 覆盖）。累计约 **9 小时**无人消费。
> 反面同样有害：线上站点是「活的证据」，长期不发布会让它和对外讲的数字对不上。
> 所以这条纪律**上下界都要有**。

## 一、三件事必须分开

| 事 | 触发 | 成本 | 是否推送 |
|---|---|---|---|
| **提交** | 每个可验证增量（判据全绿） | `--tag core-fast` **≈19 min** | 否 |
| **全量验收** | 每 3–5 个提交，**且发布前必跑** | `--tag core` **≈3.3 h** | 否 |
| **对外发布** | 见下节触发条件 | ≈1 h（CI 已绿前提下） | **是** |

过去的错误是把这三件绑在一起：每次提交都推送 + 部署，于是「发布」变成了日常动作，
而 3.3h 的全量也因为「反正每次都要跑」被当成日常成本，最后为了省时间就容易跳过。

## 二、对外发布的触发条件

按顺序取**第一条命中**：

1. **阶段收口** —— S1 / S2 / S3 / S4 任一完成（B1 统一数据模型、B2 标准格式层、
   B3 端到端干线、B4 对拍框架）。**不看天数，立刻发。**
2. **满 7 天** —— 最早的未发布版本距今 ≥ 7 天 ⇒ 发。
3. **例外随时发** —— 线上故障、安全/合规修复、对外演示或路演前。
4. 以上都不命中 ⇒ **暂不发布**，继续攒。

**上限：每天最多 1 次。** 发布不是日常动作；同一天要发第二次，只允许是回滚。

## 三、发布前必做（缺一不可）

```
1) lda/run_ci_regression.py --tag core          # 393 道全绿
2) lda/reports/last_full_core_green.json        # status=green 且道数与当前一致（F4 守）
3) git push gitee + github                      # 三端 MATCH 同一 sha
4) remote_deploy.py --expect-head <全 sha>
5) check_ledger.py 524 3 19 546 B530            # ALL_OK 13/13
6) 端点严格 JSON + 关键受跟踪文件逐字节对拍
```

第 2 条不是形式：**F4 判据**要求「完整 core 凭证存在、`status=green`、道数 == 当前 `CORE_SMOKES`
且 `fail=0`」。跑一次失败的全量会写 `status=failed`，F4 立刻转红 —— 「跑过但要红」不算跑过。

## 四、为什么「批量发」的风险是可控的

批 8 个版本再发，理论上「一次押注太多、出问题难二分」。本仓已消解：

- `remote_deploy.py --expect-head <全 sha>` —— 发布的必须是**那一个** commit，不是「大概那个」；
- 三端 MATCH + 生产逐字节对拍 —— 错位当场暴露；
- 回滚 = 重新部署上一个 sha，不依赖「撤销一堆改动」。

因此批量的风险**低于**频繁发布：频繁发布的真实代价是「全量 CI 被当日常 ⇒ 更容易在没跑全量的
情况下发布」。

## 五、版本号语义

| 号段 | 含义 |
|---|---|
| v0.9.x | 内部迭代（可发可不发） |
| **v0.10.0** | **阶段一收口**：能读真 PDK + 公开网表 → 布局布线 → 写 DEF → 外部工具能读回 |

发布与「讲得出一句话」重合时，节奏自然就稳。

## 六、机器守在哪

- `run_ci_gate_contract_smoke` 组 F（F1–F6）：快档真子集 / 排除集由实测台账驱动 /
  快档耗时占比 <25% / 完整 core 凭证与道数一致 / 凭证四形态反向探针 / 续跑复用判据六条同时成立。
- **每周一 09:30 自动巡检**（automation「LDA 发布节奏巡检」）：读生产 `/api/health` 的
  `version`，与仓库版本、CHANGELOG 条目比对，按本文档第二节出结论 + 发布前必做清单。
  **只建议，不执行。**

## 七、诚实边界

- 「7 天」是**防止线上长期落后**的经验值，不是从数据推出来的最优解；
- 巡检只能看「版本号差距」，看不到「这一版对外有没有可讲的实质内容」——
  那道判断仍在人（和当轮对话）手里；
- 本纪律约束的是**对外发布**，不约束提交频率：提交越勤越好，19 分钟一道。
