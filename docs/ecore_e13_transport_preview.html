🔴 诚实边界（本段最重要）

仍是漂移扩散（DD）框架 ⇒ 不含量子修正 / 速度饱和 / 带间与栅隧穿 / 弹道输运。 ⇒ 深亚阈值 SS 不受影响（那里由玻尔兹曼尾决定 —— 这正是 G1/G2 判据仍严格成立的原因）， 但 I_on 偏高、I_off 偏低。
迁移率为常数（无场依赖退化 / 无表面散射）⇒ I_on 绝对值不可当器件性能，只作相对趋势与 SS 判据。
无 LDD / halo / 应变 / 栅重叠；结构为教科书突变结 + 2 nm 平滑；本段固定 300 K、只做 DC。
参数为公开典型量级占位（非 PDK，无实测锚）；2D 仿真 = 每单位宽度电流（A/m），不是绝对安培。
补齐后仍不可用：量子修正 / NEGF（超 T1 范围）· 真实迁移率标定 · 工艺角/PDK/硅验证（T2 永久锁）。
LDA 是设计 & 验证工具链，不是流片芯片 ⇒ 不报 TOPS / TOPS-W / fJ/op。EAR 744.23（成熟节点用途）。
