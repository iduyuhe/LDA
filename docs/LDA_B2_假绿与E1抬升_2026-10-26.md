> 2026-10-26 · v0.9.314 · 全部数字本机复算（零外部数据、零依赖）
> 复现：`cd lda && python lda_l2/mode_solver_response.py` ·

## 结论先行

上一版把「抬 6 道自证桩（E1/E3–E7）」列为下一步首选。做了才知道，**这 6 道不是同一类东西**：

| 锚 | 量（golden） | tol | 本版判定 | 决定性数字 |
|---|---|---|---|---|
| **E1** | n_g 4.18 ± 0.05 | 0.10 | 🔴 **已抬升（严格独立）** | 候选 **4.179230** ⇒ \|Δ\|=**7.70e-4**（tol 的 **1/130**） |
| E3 | FSR 10.44 nm | 0.10 | 仍不可接（**须层堆 + TM**） | 要判到 0.1 nm ⇒ n_g 需准到 **0.96%**（±0.047）；`eps` 构造器无 400 nm 薄 BOX + Si 衬底，且无 TM 分支 |
| E4 | crossing IL 0.18 dB | 0.10 | 仍不可接（**须 3D 全波**） | 容差占 golden 的 **56%**；2D-EIM 平板近似的垂直散射误差本身就 >0.1 dB |
| E5 | MMI excess 0.05 dB | 0.10 | **结构性不可判** | 判到 0.1 dB 需 L_π 准到 **1%**；2D-EIM 的 L_π 自己就漂 **2%**（21.05→21.48）；L_π 差 1% ⇒ 摆动 **0.199 dB = 2.0×tol** |
| E6 | 传播损耗 0.087 dB/cm | 0.05 | **结构性不可算** | 需 σ/L_c 两唯象参数（只能由同批实测拟合）⇒ 任何"算得 0.087"都是循环自证 |
| E7 | crosstalk −41 dB | 5.0 | 可接但**窗口不成立** | B7 同族候选在 −40 dB 上 \|Δ\|=**4.64** = 窗口的 **93%**；余量 7% ⇒ 判据窗口 `baseline < tol < signal` 不满足 |

**同时挖出一个更严重的东西**：B2（`n_eff` 锚）——**它一直是"严格独立"，但它的候选是个常数函数**。
详见 §2。这一条比"抬 6 道"重要得多：它不是"少了一道验证"，是"多了一道假的"。

## 1. E1：为什么这次抬得动 —— 结论没错，前提错了

v0.9.9 的判断是「E1 不可接」，理由是当时**唯一可用的两把梯子**都坏了：

| 当时的梯子 | 实测 | 坏在哪 |
|---|---|---|
| 标量亥姆霍兹 FDFD | n_g = **3.74** vs 4.18（差 10%） | 高对比度 3.48/1.44 下标量近似不成立，网格细化无效（R16 已证伪） |
| 3D 相位法 FDTD | λ=1.53/1.55/1.57 → n_eff **非单调**，n_g = **8.76** | 相位差精度不足，差分被噪声主导；单次 305 s |

**「E1 不可接」这句话在当时是对的。** 错的是把它当成永久结论——梯子换了，结论就得重算。

### 换的梯子：staggered Yee 全矢量

`lda_solver/full_vector_mode_solver.py`（Fallahkhair/Li/Murphy, JLT 26(11) 1423, 2008）：
H 在格点、E 在格心、散度约束**代数消去** Hz、PML 用复坐标拉伸。它的可信度不是自称的：

- 与一篇公开论文的**独立实现**逐位对拍：SOI 600×220 TE0 = **2.570410** vs **2.570409755**（Δ≈2e-7）；
- 与商用 FDE 差 **0.004**（2.570 vs 2.566）。

### 三条不许省的细节（少一条就假红或假绿）

```
候选 n_g = 4.179230       golden = 4.18 ± 0.05       tol = 0.10
|Δ| = 7.70e-4  =  tol 的 1/130  =  实测 σ 的 1/65
```

1. **材料色散必须开**。关掉（n 取常数）得 **4.0383**，\|Δ\|=0.1417 **> tol** ⇒ 直接假红。
   常数折射率在这里是**错的物理**（n_g 是 n(λ) 的导数放大器），不是"更保守的近似"。
2. **三点差分的网格与窗口必须完全相同**（λ=1.5376/1.5476/1.5576，h_grid 固定 0.01）。
   否则测到的是网格伪变化——半矢量那侧曾因此让 n_g 乱跳 5.93/1.85/1.61。
3. **几何必须整格**：h=0.22 ⇒ 半高 0.11 必须落在网格上。若用 0.05 的粗网格，
   半高会被 snap 到 0.10（**厚度差 9%**），n_eff 立刻掉 0.2 —— 我第一次就踩了这个坑，
   把 EIM 偏差从 0.198 算成了 0.280。

### 判据窗口（铁律 `baseline < tol < signal`）

| 量 | 值 | 相对 tol |
|---|---|---|
| baseline（残差 7.70e-4） | 7.70e-4 | 0.0077× |
| tol | 0.10 | 1× |
| signal（n_core ±10%） | **0.4076**（4.5868 / 3.6744） | 4.1× |

信号是 tol 的 4.1 倍 ⇒ 这个 tol **能抓住**该抓的偏离，不是放水。

## 2. B2：一个"不能失败"的候选，和一个方向判反的归因

B2 自 2026-09-10 起是 **Tier-3 严格独立**，依据是「FV-FDM 2.644 + PWE 2.614 两个独立全波都在 tol=0.05 内复现 EIM golden 2.6509」。三条实测把这条依据拆了。

### 2.1 候选的返回值下限就是它的种子

候选写死 `eigsh(sigma=(2.65·k0)²)`，而选模规则是「在这一簇里取 n_eff 最小的那个」。
`eigsh` 的 `sigma` 是**搜索中心**：它只返回**最靠近 σ** 的 k 个本征值。于是：

| 几何 | σ（种子） | 返回 n_eff |
|---|---|---|
| **5×2 µm**（2 µm 厚、5 µm 宽的硅） | **2.65** | **2.6445** ← 真值必趋 n_core=3.478，**物理上不可能** |
| 同一 5×2 µm、同一网格 | **3.00** | **3.0028** ← **只改了种子**，答案跳 +0.358 |
| 0.5×0.22 µm（B2 本来的几何） | 2.65 | **2.6479**（三次重复逐位相同，可复现） |

⇒ 两件事同时成立：**答案盯着种子**（σ 2.65→3.00 就跳 0.358），**却不盯着几何**
（0.5×0.22 与 5×2 差 10 倍，答案只差 0.003）。

一块 5 µm 宽、2 µm 厚的硅，TE0 就是体材料模（n_eff→3.478）。它答 **2.6445**，差 0.83 ——
**物理上不可能**。这不是精度问题，是它根本不在解那个问题。

### 2.2 对参数不响应（连符号都错）

| 扰动 | 候选答案 | 变化 | 物理方向 |
|---|---|---|---|
| baseline | 2.6479 | — | — |
| n_si **+10%** | 2.6551 | +0.0072 | 应升 ↑ |
| n_si **−10%** | 2.6526 | **+0.0047** | 应降 ↓ —— **反了** |
| w −10% | 2.6491 | +0.0012 | 应升 ↑ |
| h +10% | 2.6475 | −0.0004 | 应升 ↑ |
| n_clad=1.0 | **选模失败** | — | — |

响应幅度最大 0.0072，而 tol 是 0.05 ⇒ **它动 7 倍小于容差**。
换句话说：`|2.644 − 2.651| = 0.007` 的"通过"是**常数巧合**，不是验证。

### 2.3 golden 本身也偏了 —— 而这条线索一直被写在注释里

同一套全矢量求解器扫宽度，EIM（B2 的 golden 族）与它的差：

| w (µm) | EIM | 全矢量 | EIM − 矢量 |
|---|---|---|---|
| 0.4 | 2.5723 | 2.2403 | **−0.3321** |
| 0.5 | 2.6509 | 2.4532 | **−0.1977** |
| 0.6 | 2.7006 | 2.5725 | −0.1281 |
| 1.0 | 2.7871 | 2.7487 | −0.0384 |
| 2.0 | 2.8329 | 2.8243 | −0.0087 |

偏差**随宽度单调收缩到 0**（w→∞ 回到精确平板 2.8529，`_slab_neff` 解析解）
⇒ 这是 **EIM 两步降维忽略角区的系统性效应**，不是随机噪声。
两条旁证：
- 同一 EIM 换个降维顺序（先高后宽）给 **2.6327**，与先宽后高差 **0.0182** —— 一个本不该存在的自由度；
- B2 自己的 note 早就写着「文献锚点 ~2.4–2.6」，而 tol=0.05 的窗口装不进 2.44。**这句话矛盾了很久，没人算。**

### 2.4 最刺眼的一条：终审锁把"对的"判成了"低 0.20"

`_VMM_FINAL_VERDICT['B2']` 原文记录了三个方法：
FV-FDM 2.644 / PWE 2.614 / **Marcatili 2.448（"系统性低估 0.20"）**。

现在知道方向反了：

| 方法 | 值 | 谁在偏 |
|---|---|---|
| Marcatili 1969 解析 | **2.448** | ← 对的那一侧 |
| 半矢量（另一套离散） | **2.472** | ← 同一侧 |
| 全矢量 staggered（外部对拍 2e-7） | **2.453** | ← 同一侧（真值 ≈ 2.45） |
| EIM 两步 | 2.651 | ← 高估 0.198 |
| PWE（收敛不足） | 2.614 | ← 高估 0.16 |

三个聚在 2.45 的方法被一个聚在 2.65 的方法判成"偏低"，**因为那个 2.65 被当成了锚点**。
这是本仓第五次「golden 本身有问题」，也是第一次发现"多方法一致"可以靠**共享同一个错误的中心**伪造出来。

### 2.5 处置

- `candidate` 撤出 ⇒ `maturity_tier` 退回 `self_certified`，`provenance=self_authored_closed_form`，标记 **re_review**；
- 终审锁原文**保留**并加 `superseded_by_v0914`（推翻记录本身是证据，不删）；
- **不是"永不升"**：重立需要 ①与 EIM 无共享降维近似的解析/半解析真值，或 ②改判实证锚（可公开溯源的 500×220 实测 n_eff）；
- **不是"tol 太紧所以放宽"**——放宽即取消验证。

## 3. 新立判据：响应率 ρ —— 现有 8 项判据的共同盲区

`run_benchmark_falsifiability_smoke.py` 已有 8 项判据，它全过了。为什么？

| 判据 | 常数候选的表现 | 结果 |
|---|---|---|
| ① 独立性普查（\|Δ\|>0） | \|Δ\|=0.007 > 0 | 算作"真独立" ✅ 放过 |
| ② 正向 PASS | 0.007 < tol 0.05 | PASS ✅ |
| ③ **反向**（扰动后必须 FAIL） | golden 动了、候选不动 ⇒ diff 变大 | **看起来"抓到了错"** ✅✅ 最危险 |
| ④ 灵敏度（最小可检出扰动） | 对常数无定义 | ✅ |
| ⑤ 无回归 | 全绿 | ✅ |
| ⑥ 披露剩余自证桩 | 它被算成严格独立，**连披露都没有** | ✅ |
| ⑦⑧ 口径一致 | 它确实在独立候选清单里 ⇒ 一致 | ✅ **口径一致反而放大了错误** |

**③ 是最要命的**：它问的是「候选会不会跟着**被扰动的 golden** 走」，
而常数候选在 golden 移动时 diff 必然变大 —— 于是它比"真候选"更"安全"。

### 判据：ρ ≡ |Δ候选| / |Δ参考|

同一组参数扰动下比较候选与参考的**响应幅度**，并单列**符号一致率**：

```python
rho = min(|cand(p_i) − cand(p_0)| / |ref(p_i) − ref(p_0)|)   # 逐扰动取最小
verdict = DEAD_CONSTANT   if rho < 1e-6
        | NOT_RESPONSIVE  if rho < 0.5 or sign_consistency < 0.99
        | RESPONSIVE      otherwise
```

- `b2_fvfdm_neff`：ρ ≈ **0.013**（n_si ±10% 时它动 **0.0071/0.0047**，全矢量动 **0.378/−0.356**）、符号一致 **1/2** ⇒ `NOT_RESPONSIVE`；
- E1 新候选：ρ = 1（同一实现作参考）且符号全对 ⇒ `RESPONSIVE`，信号 0.4076 = 4.1× tol。

**为什么必须单列符号**：坏的候选不止"不动"，还有"反向动"——
n_si −10% 反而升高（2.6526 > 2.6479），这种错误**幅度很小、方向很坏**，只有符号抓得住。

门禁落点（`run_benchmark_falsifiability_smoke.py` ⑨-1~⑨-4）：
种子决定返回值 / 体材料极限给物理不可能值 / ρ⇒NOT_RESPONSIVE / **未被重新挂载**。
最后一条是给"撤出"本身上的锁：注释里说撤了、账本里还挂着，是最常见的回潮方式。

## 4. 那个被写错两次的弯曲效应

E1 的 golden 来自**环**（R = 66.8/2π = 10.63 µm），候选解的是**直波导**。旧记录对这个差给出了两个数：

| 位置 | 原文 | 实测 |
|---|---|---|
| `part1.py` E1 note | 「弯曲使 n_g 天然高 **~0.46**」 | **+0.0033**（差 **138×**） |
| `_adapter_p1.py` ring_fsr | 「弯曲使 n_g 天然高 **~0.157**」 | **+0.0033**（差 **47×**） |

用同仓 `bend_mode.bend_waveguide_ng`（共形变换 n²→n²·(1+x/R)²，第一原理）实测：

```
R = ∞      n_g = 4.022777
R = 60 µm  n_g = 4.022882   Δ = +0.000105
R = 30 µm  n_g = 4.023197   Δ = +0.000420
R = 10 µm  n_g = 4.026554   Δ = +0.003778     ← 30→10 放大 9.0× = (30/10)²，1/R² 律自洽
R = 10.63  n_g = 4.026119   Δ = +0.003343     ← E1 那只环
```

⇒ 弯曲只值 **+0.0033**，是残差 0.157 的 **1/47**。**两个旧数都是错的，而且错在不同的方向**
（0.46 是把"标量 FDFD 的精度不足"记到了几何账上；0.157 是"残差反推出来的解释"）。
按纪律两处都已订正，并在 note 里写明"那个数从没被算过"。

## 6. 诚实边界

- **E1**：残差 7.7e-4 远小于实测 σ=0.05 ⇒ 只能宣称「**在测量不确定度内一致**」，
  **不能**宣称「求解器精度已被 7.7e-4 验证」——那要更小的 σ。
- **E1 的 golden 是环、候选是直波导**：弯曲 +0.0033 已计入讨论（可忽略），但环的
  侧壁粗糙度、波导截面圆角未建模 ⇒ 这是"几何对齐到一阶"，不是"同一器件"。
- **B2 的降级不等于「EIM 无用」**：EIM 在宽条/弱限制下回到精确平板（3 µm 处差 0.85%），
  仍是设计阶段的好工具。错的只是**拿它当 tol=0.05 的基准**。
- **E3–E7 的"不可接"是当下的判断，不是永久判决**：E1 就是被推翻的例子。
  但推翻需要**换梯子**（新求解器/新物理），不是**放宽容差**。
- 本版所有数字可在本机复算，不依赖任何外部数据、不联网、不调用外部 ORACLE。
