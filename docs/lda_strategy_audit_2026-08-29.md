## 二、战略定位审计

### 2.1 原始定位回顾

> 对标 EDA，专攻**光芯片（PDA）+ 量子芯片（QEDA）**。战略：开源优先 · Agent 原生 · 底层核心由 AI 自写 · 自己做领先者。护城河 = 标准 + 生态 + PDK 供给（带可信基准套件的开放内核），非求解器代码。

### 2.2 审计结论：定位无漂移

| 定位要素 | 今日事实 | 判断 |
|---|---|---|
| 光+量双栈 | 货架 58 = 光子 50 + 量子 8（咨询制·出口管制合规红线） | ✅ 双栈未偏废 |
| 开源优先 | 三端同步（Gitee/GitHub/生产）；代码全公开 | ✅ |
| AI 自写核心 | 求解核/锚/基准全部第一方；今天无新增核心，但商品化层由 AI 起草 48 货架数据 | ✅ |
| 自己做领先者 | 护城河动作：58 货架商品化 + 国际对标（可溯源公开规格）——**对标表本身就是标准/生态的展示** | ✅ 加厚 |
| 非求解器护城河 | 今天 0 行求解器代码，全部是商品层/商务层——**护城河策略执行得很纯粹** | ✅ |

**审计意见**：今天的商业化动作（商品化数据、国际对标、评价收集、定制导流）不是护城河之外的分叉，而是护城河的**外化展示**——它把「开放内核 + 可信基准」翻译成了专业买家看得懂的商品语言。方向完全正确。

## 五、商业化准备线审计（2026-08-28 → 29 全貌）

这是本次审计的核心增量。以「创新超市整合 → 定制全流程 → 我的模块 → 认证安全 → 找回密码 → 对公凭证 → 一键登录 → 货架商品化三批」为序。

### 5.1 商务闭环完整性（对照「能收钱、能交付、能服务、能收集」四要素）

| 要素 | 能力 | 实现 | 判定 |
|---|---|---|---|
| 能收钱 | 个人微信收款 + 企业对公转账 | 收款码/对公五要素统一配置（admin 可改、全站生效）；身份三档折扣（学术 6 折/机构 8.5 折）；对公申请免登录 + 转账凭证截图上传 | ✅ |
| 能交付 | 设计就绪包 + 兑换码授权 + 定制开发 | 50 开放货架下载（限次兑换码原子化防并发超额）；定制需求 4 状态机（待接单→开发中→已交付→已验收）多文件交付物；对公审批生成兑换码 | ✅ |
| 能服务 | 用户自助 + 管理后台 | 「我的」模块（概览/许可证资产/定制进度/资料/改密/退出）；admin 五 tab（订单/对公申请/收款配置/账号重置/意见需求） | ✅ |
| 能收集 | 需求信号 | 货架评价/意见（免登录+管理员聚合带联系方式）；定制需求方向枚举（6 方向）；定制导流（想定制→先看现成货架） | ✅ |

### 5.2 货架商品化三批（战略价值评估）

| 批 | 内容 | 对护城河的贡献 |
|---|---|---|
| 一 | 首批 10 货架商品化 + 评价需求收集 | 把「开放内核」翻译成商品语言；评价=需求信号 |
| 二 | 48 货架全量（58/58）+ 站内同类对比 | 全货架可看懂；对比表=决策加速器 |
| 三 | 定制需求导流 + 按钮文案 | 需求漏斗闭环：看懂→对比→反馈→转化 |

**审计意见**：货架商品化三批把「创新超市」从一张货架列表升级成完整的商品漏斗。其中最有战略价值的是**国际对标体系**——58 个货架全部带可溯源来源的公开对标（IEEE/ITU-T/厂商/期刊/市场报告），这是「标准+生态」护城河在商品层的直接体现，也是 B 阶段公众号/分享会的硬核素材。

### 5.3 用户实测暴露的两处真实缺陷（必须写入审计教训）

1. **`dict(self.headers)` 鉴权静默丢 token**（用户实测发现）：21 处用 dict() 转 HTTPMessage，生产某些时序返回空 dict → 登录后跳转「请先登录」。已全量改 `_bearer(self.headers)`。
2. **admin.html 缺 `.hide` CSS**（用户实测发现）：三个面板同时显示、tab 切换从未生效。已补。

**教训**：这两个 bug 都是「读代码看不出来、只有真打请求/真实浏览器才暴露」的类型。项目已固化的「安全回归 + 全量回归 + 生产实测 + playwright 真浏览器」四段验证正是为此而生——**这套验证文化是今天最大的工程资产**。

## 九、下一步规划建议框架

### 9.1 主线判断
