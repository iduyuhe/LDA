## 二、口径全景（此前散落在 4 个模块，无一处登记关系）

同一件「IR drop / 规模」在四域里是**两组正交口径**：

### 2.1 第一组：量的定义（far vs avg）

| 口径 id | 定义式 | 语义 |
|---|---|---|
| `ir_far_drop_rel` | `1 − V[n−1]/v_in` | 驱动最远那一列**还剩多少电压** —— 判「驱得动驱不动」 |
| `ir_avg_rel_err` | `1 − mean(V)/v_in` | MVM 的**平均输出误差** —— 判「算得准不准」（E9 规模律用此） |

🔴 **实测可差 1.5~5 倍**（N=64：0.5478 vs 0.3738），**不可互读**。

### 2.2 第二组：模型的边界（1D vs 2D 含列线）

| 口径 id | 模型 | 实测（N=32） |
|---|---|---|
| `ir_far_drop_rel` | 1D 三对角，列端理想虚地 | 0.208061 |
| `ir_far_drop_rel_2d_with_col` | 2D 稠密 MNA，含列线串联电阻 | **0.270012** |

### 2.3 第三组：约束范围（仅 IR vs 全链）

| 预算 | `max_rows_ir_only`（乐观上界） | `max_rows_full_chain`（**对外应报**） |
|---|---|---|
| 10% | 26 | **22** |
| 5% | 18 | **12** |
| 2% | 11 | **1** |
| 1% | 8 | **1** |

🔴 **工程结论**：2%/1% 预算下全链只到 **N=1** —— 紧预算由**失配/量化**主导，**不是 IR**。
这条以前完全看不见，因为只报了 IR 那一档。

### 2.4 还有一处单位陷阱

`array_scale.max_scale_for_budget` 吃**分数**（0.05），`budget.max_scale_full_chain` 吃**百分数**（5.0）。
两者在同一行代码里相邻调用极易错 100 倍。已登记进 `BUDGET_UNIT`，并只允许在 `scale_ceiling_paired` 内转换。

## 三、解析金标（本段唯一的硬判据）

行线 IR-drop 有**闭式解**。由 KCL 递推

```
p_0 = 1,  p_1 = 1 + g·r,  p_m = (2 + g·r)·p_{m−1} − p_{m−2}
```

特征根 `u = e^α`、`α = arccosh(1 + g·r/2)`，由两个边界条件定系数，得

```
p_m = (u^{m+1} + u^{−m}) / (1 + u)         （≡ σ(α)·e^{αm} + σ(−α)·e^{−αm}，σ = sigmoid）
far_drop_rel = 1 − 1/p_{n−1}
avg_rel_err  = 1 − S/(n·p_{n−1})，  S = u(u^n − u^{−n})/(u² − 1)
```

**为什么这是金标而不是自证**：解析解与 `row_line_profile` 的 Thomas 三对角数值解是**两条独立路径**
（一路走代数闭式，一路走三对角消元）。实测 9 档 N（2…1024）**最大绝对差 3.8e-14**。

外加一条**精确代数恒等**作对照组：**n=2 时 avg ≡ far/2**（差 < 1e-15）——
不是拟合，是 `p_0=1, p_1=1+gr` 的直接推论。

> ⚠️ 诚实边界：这仍是**模型内部**的解析⟷数值一致性，**不抬锚**（不是独立语料）。
> 它的价值是：以后任何一次改求解器/改模型，这条会立刻红。

## 六、诚实边界（写进模块披露）

- 工艺参数沿用 E6/E7 的**公开典型量级占位（非 Foundry PDK）**；
- 解析金标验的是**求解器实现**，不验物理模型正确性（与 295/296/298 同族纪律）；
- 列线电阻贡献量化基于**一阶几何闭式**提取（`R=ρL/(W·t)`），无 3D 场解；
- 规模上界是**设计期版型容量**，非流片能力；**不报 TOPS / TOPS-W / fJ/op**；
- 净增 **0 锚**（自产设计数据是仿真值 ⇒ `self_certified` 级，**永不作 golden**）。

## 八、E20 总结论

1. **四层口径全部自洽、可复现、有明确语义** —— 之前不是"算错了"，是**没登记、没标注、没对拍**。
2. 🔴 **唯一真正算错的是我们的措辞**：「二阶项」低估了 30~41%。这条比任何数字都值得记下来 ——
   数字可以现算，措辞会被人当真十年。
3. **对外能力从此成对报**：5% 预算 ⇒ 仅 IR 18 / 全链 12。**只报 18 就是虚报能力**。
4. **紧预算下全链只到 N=1** —— 这是 E21 做数字控制壳/编译链之前必须先消化的现实：
   在当前模型下，5% 预算的可用阵列是 **12 行**，不是 256，也不是 1024。
