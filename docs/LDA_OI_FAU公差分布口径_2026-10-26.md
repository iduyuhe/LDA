## 2. 模型与闭式

横向失准 `d`（2D，只有横向平动）下两个同参数高斯模的**功率**耦合

```
η(d) = exp( −(d/w)² )        w = 1/e² 强度半径
```

若两轴失准 `iid N(0, σ²)`（等价地 `d²` 服从均值 `2σ²` 的指数分布），三条闭式：

| 量 | 闭式 |
|---|---|
| 期望效率 | `E[η] = w²/(w² + 2σ²)` |
| `p` 分位效率 | `η_p = p^{2σ²/w²}` |
| 良率（损耗 ≤ L₀） | `Yield(L₀) = 1 − 10^{−(w²/(2σ²))·L₀/10}` |
| 反演（良率 → 公差上限） | `σ_max = w/√(2β)`，`β = −10log₁₀(1−Y)/L₀` |

三条**互为恒等**：`E[η] = ∫η dP` 且 `Yield(L₀) = P(η ≥ 10^{−L₀/10})`
⇒ 自检 ⑤ 用「由良率反解 `p` 再取分位」来核，**不是三条各写一遍**。

---

## 3. 三条可判定的结论

### 3.1 「±0.5 µm」单独拿出来**不确定**（跨 8.8 倍）

| 约定 | σ（µm） | E[η] | 期望损耗（dB） |
|---|---|---|---|
| corner（现实现：带边缘当位移） | — | 0.97260 | **0.1206** |
| gauss_1sigma | 0.5000 | 0.94737 | **0.2348** |
| gauss_2sigma | 0.2500 | 0.98630 | **0.0599** |
| **gauss_3sigma（最常见）** | 0.1667 | 0.99387 | **0.0267** |
| uniform_square（硬极限） | 0.2887 | 0.98182 | **0.0797** |

⇒ 最悲观 / 最乐观 = **8.8 倍**。本层**不选**哪一个，把五种并列给出来（判据 S4 只判「≥5 倍」）。

### 3.2 现有那个数是**角点**，是 ±3σ 期望的 **4.51 倍**

- 角点（`d = 0.5 µm`）：`0.1206 dB`
- ±3σ 期望（`σ = 0.5/3`）：`0.0267 dB`

### 3.3 角点 ≡ `σ = tol/√2` 的期望（差 1.4%）

由一阶恒等 `ln(1+2x) ≈ 2x`：角点 `(10/ln10)(tol/w)²` vs 期望 `(10/ln10)ln(1+2σ²/w²)`
⇒ 相等当且仅当 `2σ²/w² ≈ (tol/w)²` ⇒ `σ ≈ tol/√2`。

**换句话说**：「把带边缘当位移」隐含了 **±tol ≈ ±1.41σ** 这个约定 —— **而没有人把它写下来过**。

## 5. 两处口径由**计算**钉死，不靠注释

### 5.1 `w` 是**哪个半径**？

真的去数值积分两个同参数高斯模的 2D 重叠（`E(r)=exp(−r²/w²)`，强度 `∝exp(−2r²/w²)`
⇒ **1/e² 强度半径恰为 `w`**）：

| 候选 | 与数值积分的差 |
|---|---|
| `exp(−(d/w)²)` | **3.1e-14** ✓ |
| `exp(−d²/2w²)` | 3.4e-02 ✗ |

🔴 **本模块第一版把「振幅重叠」直接当成「功率耦合」**（漏了取模方）⇒ 自检 ① 当场抓出。
教科书上那个 `exp(−d²/(2w²))` 对应的是 `w` = 1/e **场**半径，**不是这个口径**。

### 5.2 三个闭式的 `2` 因子必须一致

第一版把 `2σ²` 写成 `σ²`：`E[η]` 偏大、良率 0.52 vs 实测 0.77（差 5σ 以上）。
**修的是同一处，红的是三处（③④⑤）** —— 这正是「两条闭式互相反解」这条判据的价值：
单看一条会以为「就是某个 2 倍，无所谓」。

## 8. 诚实边界

1. 模场按**理想高斯**、两端口径**相同**、失准只有**横向平动**（不含角度失准、波长失配、
   模场半径失配）。
2. **分布形状是给定的，本层不推断它** —— 真分布须材料样品 + 应力台 ⇒ `G-OI7b` 边界。
3. 「±tol」该按 3σ 还是硬极限，本层**不选**，把五种约定并列。工程上选哪个是**规范问题**，
   不是算得出来的。
4. `E[η]` 是**效率的期望**再取 dB，**不是 dB 的期望** —— 两者不等（Jensen），本层只给前者。
5. 良率的定义是「耦合损耗 ≤ L₀」，**不含**其它损耗项（波导 / 分束 / 端面反射）。
6. 本层**未新增任何锚**：只证统计恒等式（三条闭式互洽）与量级差（角点 vs 期望），
   没有物理标量对实测。
