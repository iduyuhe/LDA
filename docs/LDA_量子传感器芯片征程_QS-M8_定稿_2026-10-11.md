## 6. 🔴 本轮工程坑（可复用）

1. **门槛下限必须随族收紧**（本轮**首次**在同类任务中由门禁自己顶回）：新增 `sec-qsensor`
   后案例卡族 10→11，而 `run_webui_entry_smoke.CASE_PANELS_MIN` 仍为 **10** ⇒ 减面探针 **G7**
   （摘掉一张卡的 `data-stage` 断言 E1b 必红）**当场变红**。这是「下限类棘轮必随成果收紧」的
   机器化兑现 —— 不收紧，守卫就自己报红。修法：`CASE_PANELS_MIN` **10 → 11**，并同步
   `run_sensor_panel_smoke.F10` 的下限（`>= 10` → `>= 11`）。
2. **手写数字必须有机器对照面（本档给了一个新姿势）**：九档「模块自检项数」不登记 smoke 级
   判据数（那些只能靠跑昂贵的全量 smoke 才知道），而登记 **模块 selfcheck 字典长度**
   —— 它**可现算、可逐位对拍**（B15），且任一档增删自检项当场红。⇒ **「选一个能现算的口径」
   比「给一个不准的口径配一条昂贵的守卫」更好**。
3. **探针的「还原复绿」会被原地突变击穿**：本探针 M1/M5/M7 是**原地改**容器
   （`NV_LEG[k]=…` / `GAPS[10]["status"]=…` / `MILESTONES[0][…]=…`）；`_ORIG` 若只存**引用**，
   `_restore()` 把同一个已被改的对象塞回去 ⇒ 还原不复绿（本轮实测抓到）。⇒ **可变容器必须
   `copy.deepcopy` 备份、还原时深拷贝回填**。
4. **昂贵的 in-process 门禁会让突变探针超时**：门禁单次 ~21 s × 15 次 ≈ 300 s（Bash 默认
   120 s 会 SIGTERM 掉）。⇒ 把门禁要现算的 `qs_m*` 设计入口**记忆化**（纯函数、且本探针的
   突变只打 `QS` 与 `routes.py`/`index.html`，从不改 `qs_m*`）⇒ 语义不变、总耗时降到 ~25 s。
5. **`ast` 而非字符串 `in`**：E2/E3 的「零重计算」判据若用源码字符串 `in`，会命中自己的
   docstring（本模块 docstring 写着「不 import numpy/scipy/lda_l2」）⇒ 恒红（血案 6 的镜像）。
6. **口径差异要显式立项**：`optimization_gain` 在 qs_m7 里以**舍入基线 79.25** 定义（= 定稿口径），
   而 `squid_leg.b_n_baseline` 是 QS-M6 的**全精度 79.2505…**。若面板用后者重算收益比，
   与 `qs_m7.physics.sensitivity_gain` 差 **2.94e-4** ⇒ B14 红。⇒ 面板显式采用 **QS-M7 定义口径**
   并在代码注释里写明（口径错一处，余量判断反向）。

## 7. 诚实边界

- 面板全部数字为**建模值 / 设计预算**；`verdict` 恒 `DESIGN_BUDGET`（**非** ACCEPT/PASS）。
- 灵敏度口径统一 `η = δB·√T`（白噪声幅度谱密度 T/√Hz）；**禁与线宽受限 LOD / 单次测量不确定度混比**；
  室温（NV）/4 K（SQUID）、DC/AC、单点/阵列逐项标注。
- 蓝图 §3 的 26 / 52 nT/√Hz 与 1–5 fT/√Hz 系**公开文献值**，仅作**对标准星**；LDA **不冒充实测**、
  **不宣称「已达国际水平」**、**不与他方同台比较数值**、**不报 fabricated 能效**、**不宣称量子优势**。
- 两条腿均**不含**流片/封装/低温布线实现，**不含**量子纠错码层。
- **零量子 SDK**（不依赖 Qiskit / Cirq / PennyLane / QuTiP / Strawberry Fields）；
  **LLM 不进判决路径**（门禁以 `ast` 遍历真实 import 断言）。
- **G11（OPM / 原子磁力计 · 多物理场整合）仍未闭合**，蓝图 QS-M9 待办。
