## 1. 可行性评估

### 1.1 现存地基（已实测，非口头声称）

本评估对既有模块做了**真实运行验证**（python 3.14.3 · `PYTHONPATH=D:/agent_LDA/lda`）：

| 资产        | 文件 / 入口                                                        | 实测结论（d=5 · p_phys=5e-3 · 目标 1e-15）                                                                              |
| --------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 表面码拓扑     | `lda/lda_qeda/surface_code.py`                                 | 25 数据比特 + 24 稳定子；**k=1**（GF(2) 秩，精确）；全部稳定子对易（精确 Pauli）；低于阈值（p<p_th=1%）；`p_L(d=5)=3.75e-3`；达 1e-15 目标最小 d=**89** |
| 量子门库      | `lda/lda_qeda/gates.py`                                        | **11 门全幺正**（‖U†U−I‖≤1e-12）；{H,T,CNOT} **通用**（T∉24 元 Clifford，群论）；Clifford 群大小=24                                |
| 容错拓扑 spec | `lda/lda_agent/qeda_topology.py` (D-74) + `/api/qeda_topology` | 门库 + 表面码 + cross-resonance 组合验收 **PASS**；资源 `2d²−1` 物理比特/逻辑比特                                                   |
| 良率/容错映射   | `lda/lda_l2/yield_fault_tolerance.py` (C12)                    | 网格冗余审计 / 单故障扫描 / 修复上界 / 方案可靠性                                                                                   |
| 量子 IR     | `lda/lda_ir/quantum.py`                                        | `Transmon`(B9) / `Resonator`(B12) / `Coupler`(B13) 器件骨架 + 物理定律锚                                                 |
| CR 门      | `lda/lda_qeda/cross_resonance.py`                              | SW 主导阶有效 ZX 耦合（有效模型 + 退相干预算）                                                                                    |

**结论**：J1 启动成本极低——逻辑比特层所需的拓扑、门、阈值标度、容错映射、IR 已全部具备且通过死标量验收。J1 不是从零造轮子，而是**把点式地基补成闭环征程**。

### 1.2 待补缺口（J1 建造项）

| 缺口                                       | 现状                            | J1 是否覆盖 |
| ---------------------------------------- | ----------------------------- | ------- |
| 阈值**曲线**（p_L 随 p、d 的标度 + 阈值穿越）           | 仅有 `logical_error_rate` 单点标度式 | ✅ M0    |
| **解码器**（MWPM / Union-Find 正确性 + 复杂度）     | 零                             | ✅ M1    |

| **端到端逻辑错误率**（噪声→解码→逻辑错误计数）               | 零                             | ✅ M4    |

### 1.3 红线 / 主权可行性（LDA 铁律逐条对账）

- **主权求解器（C 级纯 numpy/scipy，不借 GPL/Meep/Tidy3D）**：解码器可**自主实现 Union-Find（Delfosse–Nielsen）**——纯 numpy 可写，无需 networkx/scipy 图算法；MWPM 的 blossom 复杂度高，改以「**暴力最小权穷举**作 golden（d≤5）⇄ **Union-Find 数值候选**」配对，规避外部依赖。✅ 可行。
- **LLM 不进判决路径**：全部死标量比对（k=1、对易、解码成功率、p_L 单调性）。✅ 可行。
- **绝对 tol 按量级标定（B487 血案）**：解码后逻辑错误率量级 ~1e-3、阈值 ~1e-2、成功率 ~1e-0——**三类判据必须分别按各自量级定 tol，且用「绝对 ∨ 相对」并列**（不可用 `max(绝对,相对)`，否则尺度盲）。✅ 已立项为锚纪律。
- **golden 分级（③仿真值⛔永不作 golden）**：端到端 p_L 是蒙特卡洛仿真输出（③），**只作证据/标度关系，不作 golden**；golden 锁定为①闭式物理律（阈值标度指数、k=1、对易、平凡综合征精确恢复）与②已知事实（表面码阈值≈1% 去极化噪声文献值）。仿真值用于**验证标度关系**（如 p_L(7)<p_L(3) 子阈值抑制），不单独作判决。✅ 口径已对齐。

### 1.4 风险与缓解

| 风险                              | 缓解                                                    |
| ------------------------------- | ----------------------------------------------------- |
| 解码器正确性难证                        | 暴力穷举最小权解码器作 golden（d≤5）；Union-Find 在其上逐例对拍            |
| 尺度盲（B487 血案）                    | tol 按量级分档 + 绝对∨相对并列 + 跨量级反向探针（大/小量纲各一真一桩）             |
| 蒙特卡洛非确定性                        | 固定 RNG 种子、N shots 取均值±std；明确「仿真值=证据非 golden」          |
| 阈值曲线过悲观（A=0.03 渐进前因子使 min_d=89） | J1 价值正在于**实测解码后速率远低于裸标度界**——用蒙特卡洛证明解码器把可达 d 显著压低，叙事自洽 |

## 3. 蓝图补丁（里程碑 · 复利吃狗粮）

> 每档用 LDA 亲手设计一枚真实逻辑比特补丁，物理链逐量「闭式 ⇄ 方法学独立候选」。

### M0 阈值与标度（threshold & scaling）

- 建造：逻辑错误率标度 `p_L(d,p)=A·(p/p_th)^((d+1)/2)` 与蒙特卡洛解码标度的对照；阈值穿越 ~1%。
- 候选锚：**B497** 标度闭式 ⇄ 数值解码标度（严格独立）；**B498** 子阈值抑制 `p_L(d=7) < p_L(d=3)`（数值标度关系）。
- 闭环：G-QEC*（阈值部分）。

### M1 解码器（decoder）— 关键缺口 G_Q9 主项

- 建造：自主 Union-Find 解码器 + 暴力最小权 golden（d≤5）；解码正确性、成功率随 p 单调。
- 候选锚：**B499** 平凡综合征精确恢复（无噪声⇒单位恢复，精确）；**B500** Union-Find 恢复权重 ≤ 暴力最小权（穷举 golden ⇄ 数值 UF）；**B501** 解码成功率随 p 单调（p<p_th 高于阈值）。
- 闭环：G_Q9（解码器部分）。

### M2 综合征提取（syndrome extraction）

- 建造：稳定子测量电路；flag qubit 钩错（hook error）检测；综合征权重分布。
- 候选锚：**B502** 稳定子本征值闭式 ±1 ⇄ 数值投影；**B503** flag qubit 钩错检测（闭式钩错几何 ⇄ 数值电路模拟）。

### M3 容错逻辑门（FT gates）

- 建造：transversal 门（H/S/CNOT）+ lattice surgery（merge/split）；逻辑操作错误预算链。
- 候选锚：**B504** transversal CNOT 逻辑门保真预算链（闭式保真界 ⇄ 数值传播）；**B505** lattice surgery 合并 2→1 逻辑比特数（闭式 ⇄ 数值版图计数）。

### M4 端到端逻辑错误率（end-to-end）+ 收官

- 建造：噪声→解码→`p_L(p,d)` 全曲线；资源 `2d²−1` 并入拓扑 spec；WebUI 面板。
- 候选锚：**B506** 端到端 `p_L(7) ≪ p_L(3)`（数值标度关系 · 子阈值抑制）；**B507** 解码后可达 d 显著低于裸标度界 min_d=89（证据曲线）。
- 闭环：**G_Q9 + G-QEC*** 全部闭合；三同步 + 冻结快照全量 CI 干净记录 → bump 发布。

> 建议首发粒度：**M0 + M1 先验证复利模式**（最薄可闭环、最高杠杆、直接补 G_Q9 解码器），全绿后再扩 M2–M4。

## 5. 红线合规声明

- 主权求解器：解码器/噪声/逻辑错误率全纯 numpy/scipy，不借外部图算法库。
- LLM 不进判决路径：全部死标量。
- 绝对 tol 按量级标定（跨量级三档）+ 绝对∨相对并列 + 突变探针「先证能变红」。
- golden 分级：①闭式物理律 + ②已知事实(阈值≈1%) 作 golden；③蒙特卡洛仿真值只作证据/标度关系，不作 golden。
- 诚实边界：示例量级标「非实测」；SOTA（真实硬件逻辑错误率）未达如实标注对照比；**不报 fabricated 能效**。
