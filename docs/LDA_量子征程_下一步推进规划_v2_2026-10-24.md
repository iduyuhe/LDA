本轮勘察发现一个真问题（**F-11**），而且**我自己把它踩了两遍**：

平台**已经有**「假独立」判据，且相当成熟（v0.9.24 从 B10 身上学到的「残差为零但扰动有响应」这一层）。
但**这个判据的结果没有进报告**。于是我拿报告里的 `golden`/`candidate` 反算残差，得出
「519 道 strict 里有 **87 条数值逐位相同**」—— 结论：报告说谎。

**全错。** 报告里的 float 经 `deterministic.canon()` **只保留 9 位有效数字**；
对量级大的锚，9 位有效数字的最后一位本身就有 **1e7**（B100 = 3.65647835e+16 Hz），

⇒ F-11 是**双层失真**：① 报告数值精度不足以判断残差；② 证据类型从未暴露。
**两层叠加的结果是：外部读者拿报告做分析，会得到与真相差 6 倍的结论（87 vs 14）—— 我自己就是活例。**

这与 F-8（K4 看不见纪律门禁）、F-10（17/95 分母错）是**同一类问题的第三次出现**：不是缺判据，是缺"让人看见判据做了什么"。

⇒ **下一步主线 = M6 证据可观测**；M7 做光子域方法论回灌（不对称已量化）；M8 对外物料（需决策）。**M5 仍是外部阻塞，继续不排期。**

## 2. 本轮勘察的发现

### 2.1 F-11 · 独立性证据存在但不可见（**核心发现**）

`verification_report.json` 里 541 条结果，按 `candidate_class==strict_independent` 筛出 519 条。

🔴🔴 **这份统计我做了两遍，第一遍全错 —— 而错误本身是 F-11 的第二个证据。**

**第一遍（错）**：直接拿 `verification_report.json` 里的 `golden` / `candidate` 算 `|Δ|`，
得到 **87 条「逐位相同」**。看似严谨，但忽略了报告是**格式化后的存证**：
`deterministic.canon()` 对所有 float 取 **9 位有效数字**（`SIGNIFICANT_DIGITS = 9`）。

对量级大的锚，9 位有效数字的**最后一位本身就有 1e7**：

```
B100  圆波导 TE01 截止   golden = 3.65647835e+16 Hz   tol = 1e7
      报告里 golden 与 candidate 显示完全相同（都是 3.65647835e+16）
      真实残差 1e5~1e7  ≫ 1e-12  ⇒ 它属于 RESIDUAL_NONZERO，与"假独立"毫无关系
```

⇒ **报告数值的精度本身不足以判断残差。** 拿它做二次统计会得出系统性错误的结论。

**第二遍（对，用判决时的原始 float —— 由 `run_harness` 直接分档写出）**：

| 档 | strict 519 | 全体 541 |
|---|---|---|
| `RESIDUAL_NONZERO` | **505** | 508（+3 道降级） |
| `PERTURBATION_RESPONSE` | **14** | 14 |
| `STUB` | — | 19 |
| 合计 | **519** ✓ | **541** ✓ |

**两个口径能对上，这本身就是交叉验证**：报告口径下 87 条「显示相同」里，
**79 条真实残差 ≥ 1e-12**（属 `RESIDUAL_NONZERO`），只有 **8 条**真落在机器精度内；
再加上 6 条「报告显示不同、但真实 `0 < |Δ| < 1e-12`」⇒ **8 + 6 = 14** ✓。

🔴 **这才是 F-11 必须做的真正理由**：不只是「没告诉你证据类型」，
而是 **报告数值精度不足以判断残差**。任何人拿报告反算都会错，而且错得很有说服力
（87 条，16.8%，看起来是个重大发现）。

**那 14 条是谁**：`B10` 是典型 —— 候选是真的 4×4 Liouvillian 超算子 RK4 积分，
但生产档位 `|L|·t ≈ 2.5e-4` ⇒ 残差恒 1.11e-16、与步数无关（物理上不可标定），
靠「扰动 T1/T2/t_gate 有 1.5e-5 响应」证明是真候选。

🔴 **看起来像严重问题，实际不是** —— `run_harness.py:176` 的 `_behaves_independently()` 早已处理这件事：

```python
if abs(r.candidate - r.golden) >= 1e-12:
    return True                      # 残差非零 ⇒ 独立有证据
...
return candidate_responds(...)       # 残差为零 ⇒ 再看"对扰动有没有物理响应"
```

并且代码里留着 v0.9.24 的教训原文：
> B10 的候选是真的 4×4 Liouvillian 超算子 RK4 积分，但生产档位 `|L|·t≈2.5e-4` ⇒ 残差**恒为 1.11e-16、与步数无关** ⇒ 物理上不可标定，必然落进 1e-12。旧判据会把它误判成「假独立」。

⇒ **87 条全部通过了 `candidate_responds`**（否则 `run_harness` 的 `assert not _fake_independent` 会直接失败、报告生成不出来）。

**但证据类型没有进报告。** 报告只有 `golden / candidate / tol / passed / independent / candidate_class`，没有"这条的独立性是靠残差还是靠扰动响应"。

**后果是可测量的**：本轮我第一次统计出 87 条时，判断是"honest_note 的 519 声明与实测矛盾，这是平台最严重的诚实性风险"；查完代码才推翻。**一个熟悉代码的人都要走一遍这个误判，外部验货者几乎必然走错。**

### 2.2 F-12 · 方法论不对称：量子侧有纪律，光子侧没有

| 目录 | 模块 | 行数 | `ANCHORABLE` 声明 | `why_not_anchored()` |
|---|---|---|---|---|

量子侧（1.9 万行）**每个新增能力模块都必须机器化回答"为什么不可锚"**（D-215~D-227 十二版的纪律，`ANCHORABLE=False` + `why_not_anchored()` 带候选实测与重评条件）。

### 3.3 M7 · 光子域方法论回灌（详细）

**版本**：v0.9.281 起 · **决策号**：D-229 起 · **类型**：平台侧（净增 0 锚）

**第一步（必做，且先做扫描不做改造）**：给 `lda_l2` 100 个 + `lda_agent` 53 个模块做一次**结构扫描**，输出三张清单：

| 清单 | 判据 | 用途 |
|---|---|---|
| A「有 golden/闭式但未声明可锚性」 | 模块内定义了 `golden_*` / 闭式函数，但无 `ANCHORABLE` 声明 | 候选补声明对象 |
| B「纯工程/IO/编排模块」 | 无物理闭式、无 golden | 应显式标 `ANCHORABLE=False`（**不是不标**） |
| C「物理闭式但从不被账本引用」 | 有闭式，`golden_fn` 不在任何锚里 | **可能是"做了但没出锚"的浪费，也可能是死代码** |

🔴 **扫描先于改造**：C 类是唯一可能"发现真问题"的清单（要么补锚，要么证明它不该出锚）。**不预设结论、不批量刷 `ANCHORABLE=False`** —— 那会制造一批"为了合规而写的声明"，反而降低信息量。

**第二步**：只对 **A 类** 补 `ANCHORABLE` 声明与 `why_not_anchored()`（带候选实测与重评条件，口径与量子侧一致）；**B 类**批量标 `ANCHORABLE=False` 但 `why_not_anchored()` 只写一句分类理由即可（工程模块不需要候选实测记录）。

**第三步**：把 **F-11 的证据分档**用到光子侧 —— 光子 452 条锚的 `PERTURBATION_RESPONSE` 分布是多少？如果光子侧大量依赖扰动响应证据，那 M6 的价值比现在估计的更大。

**不动的东西**：光子侧 452 条锚的分类、判决、tol、候选实现**一律不改**。M7 只加"声明面"，不加"判决面"。

**风险与边界**：
- 中风险：C 类清单可能出现"看着该出锚但出不了"的条目 ⇒ 那是**结论**，如实写进文档，不硬凑锚。
- 边界：**光子侧没有"五层全栈"模型**（那是量子域按 J1–J5 建的），M7 **不硬套** CLM；只回灌四条可迁移的方法论：**可锚性三形态判死 / 双层界代替浮点 golden / 覆盖分档 / 声明-验证分离**。

## 8. 诚实边界

- **CLM 9/24 是自建口径**，不是行业标准；它只回答"五层 × 设计/制造 各能到什么程度"，不回答"这套能力值多少钱"。
- **14 条 `PERTURBATION_RESPONSE` 的存在本身是一条边界**：它说明这些锚在**生产档位**上无法用残差验证独立，只能退到"候选随参数变化"。这不是缺陷（B10 的物理原因已记录），但**也不能当作与残差证据等价的证明**。
- **M6 不提升任何锚的可信度**：它只是把可信度的**证据类型**写清楚。若外部把「505 有残差证据」读成「505 已验证」，那是误读 —— 有残差只说明**两条路径给出了不同但接近的值**，不说明两条路径都对。
- **M7 的 C 类清单可能得不出行动项**（可能全部是"该出锚的已出，剩下的不该出"），那也是一份有价值的结论。
- **本规划不含任何排期日期**：除 M5 外部阻塞外，M6/M7 都是"能做完就做完"的内部工作，写日期只会造假承诺。
