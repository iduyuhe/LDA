> 系统层主线（E15→E18）**第二段**。E15 把四类误差串成一条链（回答「实际几个有效位」），

## 一、缺口取证（为什么必须做）

### 1.1 现状：权重是「直接灌进去」的

| 位置 | 现状 |
|---|---|
| `crossbar_mvm.CrossbarMVM(weights, ...)` | `weights` 直接是**电导 (S)** 或**栅压 (V)**，当作**已知且精确**的输入 |
| `mvm_datapath.AnalogMvmUnit(W, s, rf, vfs)` | `G[:M,:] = g_base + s·W` —— 由数字权重**解析地**算出电导，一步到位 |
| `layout.crosspoint_cell(..., net_gate)` | 权重栅 `wg_{i}_{j}` 是**对外端口**，docstring 明写「**栅驱动/编程路径属 E7+，本段不含**」 |
| 全仓检索 | `program` / `write_verify` / `stuck` / `drift` / `retention` 在 `ecore/` **零命中** |

⇒ **平台从来没有「写入」这一步**：权重从数字数组到物理电导是**无损、瞬间、确定**的。
真实模拟 CIM 芯片完全不是这样 —— 编程是**最贵、最容易出错、最需要架构配合**的环节。

### 1.2 与 E8 的分工（**不是重复**）

| | E8 器件失配 | **E16 编程通路** |
|---|---|---|
| 来源 | **制造**（几何/掺杂涨落，Pelgrom） | **写入动作本身**（脉冲分辨率/噪声/卡位/漂移） |
| 时点 | 流片后**固定** | **每次编程都不同**（可重写、可校验） |
| 可控性 | 不可控（器件面积是唯一旋钮） | **部分可控**（脉冲幅值/步数/校验判据 = 设计自由度） |
| 模型 | `g = kp(W/L)(1+Δβ)(Vg−Vth0−ΔVth)` | 见 §2（写-校验迭代动力学） |

⇒ 两者**物理机制不同、设计对策不同**（失配靠面积/校准，编程靠脉冲策略），**必须分开建模**。

### 1.3 为什么这是「系统层」而非「器件层」

E16 **不吃新物理**（不新增 PDE 求解器、不改任何器件模型），它做的是：
把「写入动作」这一**系统行为**建模出来，并把它**接进 E15 的误差预算链** ——
这正是 E15 立项时定下的「系统层主线」的延续（E15 统一口径 → E16 补缺环 → E17 时序 → E18 列侧共享）。

## 二、编程模型（1T1R 类模拟电导 + 写-校验）

### 2.1 器件与操作

模拟电导单元（RRAM / 闪存类，**公开典型量级占位 · 非 PDK**）：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `g_min_us / g_max_us` | 1.0 / 100.0 µS | 电导窗口（**100:1**，公开典型） |
| `prog_bits` | **6** | 可编程电平数 **2⁶ = 64**（模拟 RRAM 公开典型 4–6 bit） |
| `alpha_pulse` | **0.30** | 每脉冲按目标残差的比例修正量 |
| `sigma_pulse_rel` | **0.02** | 每脉冲**写入噪声**（相对目标，2%） |
| `tol_rel` | **0.02** | 写-校验目标容差（2%） |
| `max_pulses` | **64** | 脉冲上限（写入时间预算） |
| `stuck_p` | **1e-3** | 单元卡位概率 |
| `nu_drift` | **0.05** | 电导漂移幂律指数 |
| `t0_s` | **1.0** | 漂移参考时刻 |

**编程操作 = 写-校验（write-verify）循环**：

```
g ← g_erase                        # 起始（擦除态，远离目标 ⇒ e_0 可达 1）
repeat up to max_pulses:
    g ← g + α·(g* − g)  +  η       # α = 比例修正；η ~ N(0, (σ_p·g*)²) 写入噪声
    if |g − g*| / g* ≤ tol_rel: break
```

### 2.2 五个闭式 golden（判据的锚，全部可手算）

| # | 闭式 | 表达式 | 性质 |
|---|---|---|---|
| **G-1** | **电平量化步长** | `lsb_rel = 1/(2^k − 1)`（相对电导**窗口**） | 纯代数 |
| **G-2** | **确定性写-校验轨迹** | `e_k = e_0·(1−α)^k` | 精确（等比数列） |
| **G-3** | **到容差所需脉冲数** | `k* = ceil( ln(tol/e_0) / ln(1−α) )` | 精确（闭式解） |
| **G-4** | 🔴 **写入噪声地板** | `σ_∞ = σ_p / √(α(2−α))` | 精确（无穷级数求和） |
| **G-5** | **漂移幂律** | `g(t)/g(0) = (t/t0)^(−ν)` ⇒ 重校准间隔 `t_max = t0·(1−β)^(−1/ν)` | 精确 |

**G-4 的推导**（必须写清楚，它是本段最有价值的结论）：
`e_{k+1} = (1−α)e_k + η_k/g*` ⇒ `Var(e_∞) = σ_p²·Σ_{j≥0}(1−α)^{2j} = σ_p² / (1−(1−α)²) = σ_p² / (α(2−α))`。
⇒ **单脉冲噪声 σ_p 是硬地板**：`σ_∞ ∈ [σ_p, σ_p/√(α(2−α))]`，
**写-校验最多只能把地板抬升 `1/√(α(2−α))` 倍**；`tol_rel < σ_∞` 时**期望意义上不可达**（越校验越白校验）。
⇒ **设计指令：要把编程精度做上去，必须降单脉冲噪声 σ_p（脉冲整形 / 电流限制），而不是加脉冲数。**

**G-5 的架构含义**：`ν=0.05` 时窗口内电导按 `(t/t0)^{−0.05}` 掉 ——
`t=1000 s` 已掉 **29.2%**；5% 漂移预算对应 `t_max = (0.95)^{−20} ≈ 2.79 s`。
⇒ **漂移是 RRAM 类模拟 CIM 必须频繁重刷的根因**（本结论**条件于 ν 的取值**，已显式披露）。

### 2.3 三分类归属（接 E15 的合成律）

| 误差项 | 类别 | 依据 | 默认值（8×8） |
|---|---|---|---|
| `weight_prog_level` | **BOUNDED** | 量化误差**有界**，界 = `lsb_rel/2` | **0.794%** |
| `weight_prog_residual` | **RANDOM** | 写入噪声 ⇒ 单元级独立 ⇒ 输出 **σ/√N** | **0.990%** |
| `weight_prog_stuck` | **BOUNDED** | 卡位单元**最坏**方向（默认 `p=0` ⇒ 不出现） | 0 |
| `weight_prog_drift_spread` | RANDOM | 漂移指数 ν 的**单元间离散**（**共模漂移可被单次全局增益校准掉**） | 见 §2.4 |

🔴 **分类不是形式主义**：`residual` 是随机项 ⇒ 会被 **1/√N 平均**；`level` 是有界项 ⇒ **不被平均**（N 无关）。
若把两者都当"随机"或都当"有界"，8×8 与 256×256 的结论会**系统性错开**（E15 已证）。

### 2.4 🔴 漂移的两个部分（**本段的诚实要点**）

| 部分 | 表达式 | 是否进预算 | 理由 |
|---|---|---|---|
| **共模漂移** | `1 − (t/t0)^(−ν)` | **不进**（单列报告） | **所有单元同向** ⇒ **单次全局增益校准即可消除** ⇒ **不构成精度上限** |
| **离散项** | `σ_ν·ln(t/t0)` | 进（RANDOM） | 单元间 ν 不同 ⇒ **校准不掉** ⇒ 才是真正的精度上限 |

⇒ **通则：一个能被单次校准消掉的项，不是精度上限**（与 E8「列系统项可由 L1 校准、逐单元失配才需 L2」同型）。
**默认 `include_drift=False`**（读时刻是应用相关的，不该由库替用户假设）。

## 三、与 E15 的桥（**本段是「系统层」的证明**）

### 3.1 接口设计

- `weight_prog.programming_budget_terms(...) -> List[Dict]` —— 返回 **E15 `make_term` 格式**的误差项
  （`name` / `category` / `rel_pct` / `source` / `note`）。
- `budget.collect_terms(..., include_programming: bool = **False**, prog_terms=None)` ——
  **可选注入**（与既有 `adc_err_lsb` / `dac_inl_lsb` / `row_load_rel` 同一范式）。
  🔴 **不 import `weight_prog`**（由调用方构造 terms）⇒ **无环依赖**。

### 3.2 🔴🔴 保护性约束（本段最重要的一条）

**`include_programming` 默认 `False`** ⇒ **E15 已发布数字逐位不变**
（8×8 `worst = 4.06012%` / `bits_eff = 4.622` / 5% 上界 `N≤12`）。

- 理由（同 `NmosParams` / `mna.vcvs` 纪律）：E15 的 **`run_ecore_e15_smoke.py` 硬编码这些数**、
  案例卡 / 物料 / DOCX 全部已上线 ⇒ **改默认 = 静默改掉已发布数字**。
- 做法：**保留默认口径**，把「含编程」的结果作为**显式开启的新结论**，并**新增判据守住默认不变**。
- 附带好处：**E15 自己的门禁自动成为 E16 的回归保护**（它若红，说明我们误改了默认）。

### 3.3 实测结论（**已实测 · 回填**）

| 口径（8×8） | worst | 有效精度 | 主导项 |
|---|---|---|---|
| **E15 现状（四类）** | 4.06012% | **4.6223 位** | 器件失配 44.0% |
| **+ 模拟写入**（仅写入残差，无电平量化） | 4.20838% | **4.5706 位**（−0.052） | 器件失配 37.2% |
| **+ MLC 6 位**（残差 + 电平，窗口 ≈5:1） | **5.27562%** | **4.2445 位**（**−0.378**） | 器件失配 30.4% |
| + MLC 8 位 | 4.47205% | 4.4829 位 | 器件失配 35.2% |

**电平位数敏感性（🔴 设计指令）**：

| 编程位数 | 电平项 | 8×8 有效精度 |
|---|---|---|
| 4 bit | 4.4824% | 3.5244 位 |
| **6 bit** | 1.0672% | 4.2445 位 |
| 8 bit | 0.2637% | 4.4829 位 |
| 10 bit | 0.0657% | 4.5482 位 |
| 12 bit | 0.0164% | 4.5650 位 |

⇒ **电平位数 ≥ 8 位后收益趋于饱和**（4.483 → 4.565，渐近 4.5706 = 纯模拟写入值）——
因为残余误差转由**器件失配 + IR drop** 决定。**「多给几位电平」不是免费的午餐。**

**🔴 可及规模（5% 预算）**：

| 口径 | n_max |
|---|---|
| E15 默认 | **12** |
| + 模拟写入 | **11** |
| + MLC 6 位 | **1（即 N≥2 已无解 —— 电平项是 N 无关的常量，吃满整个预算）** |

⇒ **6 位 MLC 编程下，5% 误差预算连 2×2 阵列都不满足** —— 这是本段最强的架构结论。

**可讲的一句话**：**加上权重编程通路后，8×8 阵列的有效精度从 4.62 位掉到 4.24 位（−0.38 位）；
而若采用 6 位多电平编程，5% 预算下的可及规模从 12 行塌到「无解」。**
⇒ 这两条**单看 E1–E15 任何一段都得不出来** —— 这就是 E16 接链的价值。

**其他实测锚**：写入噪声地板 `σ_cell`（单元级）= **0.70014%**（闭式 ⟷ MC rel 0.13%）·
输出 `σ_out(8)` = **0.2475%** · `iters_to_tol` = **13** · 良率 `(1−1e-3)^48` = **0.953111** ·
漂移 @1000 s 共模 **29.21%** / ν 离散 **1.0362%** · 重校准间隔（ν=0.05）β=1%→**1.2226 s** /
5%→**2.7895 s** / 10%→**8.2253 s** · 端到端实测 σ ⟷ 矩阵感知严格式 **rel 0.31%**（6 bit）/ **0.53%**（模拟）。

🔴 **卡位（`p=1e-3`）只影响尾部**：实测 max **1.07% → 22.83%**、mean 0.47% → 1.53%、
良率 **95.31%** ⇒ **卡位是良率问题，不是均值精度问题** ⇒ 预算默认不含卡位（另设 `include_stuck`）。

## 六、诚实边界（本段自带）

- 🔴 **参数为公开典型量级占位（非 PDK · 无实测锚）**：`α / σ_p / tol / ν / p_stuck` 全部是**设计自由度**，
  不是某颗真实芯片的标定值。**结论随参数变** ⇒ 报告必须携带参数。
- 🔴 **漂移结论条件于 ν**：`t_max ≈ 2.79 s`（5% 预算 · ν=0.05）是**参数推出的**，
  **不是普适断言**；换 ν ⇒ 换数。
- 🔴 **器件模型是行为级**：写-校验是**比例修正 + 加性噪声**的**现象学模型**，
  **不含**真实 RRAM 的细丝动力学 / 非线性 / 脉冲宽度依赖 / 温度加速 / 器件的物理随机性谱。
- 🔴 **无循环耐久与保持的耦合**：不做 endurance / retention 联合退化。
- **只覆盖静态**（同 E15）：不含编程**时间**（脉冲宽度）、不含写缓冲/驱动电路、不含编程能耗。
- **不报 TOPS / TOPS-W / fJ/op**（全征程纪律）。
- 🔴 **保护性约束**：**默认路径下不改任何既有模块的默认值与闭式**（B11/B14 逐位守住）。
