## §0 一页结论

**LDA 的器件级内核在什么范围内可信、出了范围会怎样** —— 分两类，性质完全不同：

| | A 数值窗口 | B 物理窗口 |
|---|---|---|
| 含义 | PDE 与教科书闭式一致的范围 | 玻尔兹曼 / 1D 假设本身适用的范围 |
| 谁决定 | **界面网格分辨率** | **物理模型本身** |
| 是否随网格变 | ✅ 随（越细越宽） | ❌ 不变（不可被数值手段改善） |
| 实测/文献 | **LDA 实测** | **文献判据**（LDA **算不出**） |
| 值（@N_A=1e17 cm⁻³） | ψ_s ∈ φ_F·[1−1.54, 1+1.54] = [−0.54, 2.54]·φ_F | ψ_s ∈ [−0.119, 0.952] V（≈[−0.29, 2.29]·φ_F） |

> 🔴 **核心结论：物理模型先失效、数值后崩**（物理窗口半宽 / 数值窗口半宽 = **0.835 < 1**）。
> 即：**当前瓶颈是物理模型（1D + 玻尔兹曼），不是数值精度** —— 把网格再细化也推不动真正的边界。

## §1 A · 数值窗口（LDA 实测）

**定义**：MOSCAP 1D 自洽泊松（`lda_solver/mos_1d.py`）的解与教科书 Sze 完整闭式
`Q_s(ψ_s)` 相对差 < 1e-3 的连续区间。

| 参量 | 扫描范围 | 窗口（以 φ_F 归一） | 结论 |
|---|---|---|---|
| **N_A** | 1e16 → 1e18 cm⁻³ | ≈ [−0.54, 2.54] | **基本不变** |
| **T** | 250 → 400 K | ≈ [−0.52, 2.55] | **基本不变** |
| **dx_if**（界面网格） | 0.05 → 0.02 nm | [−0.40, 2.40] → [−0.50, 2.50] | **变宽** |

- 参考值（dx_if = 0.02 nm）：**ψ_s ∈ φ_F·[1 ± 1.54]**。
- 等价表述：**表面载流子浓度 ≲ N_crit ≈ 5.5e26 m⁻³**。
- 超出后：界面薄层（积累层/反型层）**薄于界面网格** ⇒ Q_s 被系统性低估
  （实测 ψ_s = 3φ_F 时相对差 **48.8%**）。
- 🔴 **N_crit 是「数值」上限**（网格分辨率），**不是**物理简并边界（≈1e25 m⁻³）。

---

## §2 B · 物理窗口（文献判据 · LDA 算不出）

1. **玻尔兹曼适用上限**：表面载流子浓度达到简并边缘（≈1e25 m⁻³）时统计失效
   ⇒ |ψ_s − φ_F| ≲ 0.56 V（@300 K）。
2. **1D MOS 电容无源/漏、无沟道长度** ⇒ 一切**二维效应**不在模型内。
3. **与网格无关**：这是模型假设的边界，细化网格、加阶数都推不动。

## §4 能力边界汇总

**能算**：1D MOS 电容自洽泊松（ψ(x)/Q_s/V_g/V_th，前提 ψ_s 在数值窗口内）· 教科书闭式 ⟷ PDE
交叉验证 · 长沟道平方律三区 + 小信号 gm/gds · 体效应（经典 √ 式）。

**算不了**（诚实登记）：

| 项 | 需要什么 |
|---|---|
| 短沟道 V_th roll-off | 2D MOS 求解器（**本平台无**） |
| DIBL | 2D 横向势垒调制 |
| 速度饱和 / 高场输运 | v–E 关系 + 高场求解 |
| 迁移率退化 | 垂直场相关 µ_eff（经验 θ 标定） |
| 工艺角 / PDK / 良率 | foundry 数据（**T2 永久锁**） |
