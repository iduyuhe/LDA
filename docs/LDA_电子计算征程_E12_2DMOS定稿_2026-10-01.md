## 二、勘查结论（读 `drift_diffusion_2d.py` 586 行 + `mos_1d.py` 485 行）

### 2.1 与 p-n 结 2D 内核的**本质差异**（不是配置差异）

| 维度 | `drift_diffusion_2d`（p-n 结） | 2D MOSFET 需要 |
|---|---|---|
| 电极数 | 2（阳/阴） | **4（栅/源/漏/衬底）** |
| 边界条件 | **硬编码**：x 两端 Dirichlet + y 诺伊曼 | **分段表驱动**：栅 Dirichlet / 源漏 Dirichlet / 衬底 Dirichlet / 钝化诺伊曼 |
| 介质 | 均匀（ε_si 常数） | **变系数**：ε_ox(3.9) / ε_si(11.7) 突变 ⇒ ∇·(ε∇ψ) |
| 结构 | 平面结 | **n⁺/p/n⁺ 剖面 + 栅氧 + 结深 x_j** |
| 提取量 | W / E_max / I(V) | **V_th(L) / roll-off ΔV_th / DIBL ΔV_th/ΔV_d** |

⇒ **「接不上」的根因与 E11-b 同型**：不是缺接线，是**缺一类结构求解器**。

### 2.2 可复用面（不复制第二份）

  这套在 E11-c 的 `mos_1d` 与 `drift_diffusion_2d` 里都已验证

### 2.3 缺口（必须新增）

1. **变系数有限体积泊松** `∇·(ε∇ψ) = −ρ`（界面用**调和平均** ⇒ 电位移连续**自动满足**，无需写界面 BC）
2. **分段 BC 表**（栅/源/漏/衬底/钝化）
3. **2D n⁺/p/n⁺ 掺杂剖面**（含结深 x_j、栅外 n⁺ 岛、tanh 平滑过渡）
4. **V_th 提取**（沿界面取 `min_x ψ_s(x)` = "虚拟阴极"，二分/secant 求其达 `+φ_F`）
5. **短沟道扫描**：`rolloff_sweep(Ls)` / `dibl_sweep(Vds)`

## 三、物理约定（**关键：避免符号/参考点血案**）

- ψ 为**相对本征能级**的静电势：`n = n_i·e^{ψ/V_T}`，`p = n_i·e^{−ψ/V_T}`。
  ⇒ 平衡 p 区 `ψ_bulk = −φ_F`；平衡 n⁺ 区 `ψ = +V_T·ln(N_SD/n_i)`。
- **栅 Dirichlet**：`ψ_gate = ψ_bulk + V_G − V_FB`
  （推导：`V_G = V_FB + (ψ_s − ψ_bulk) + V_ox`，且 `V_ox = ψ_gate − ψ_s`）
  校验：`V_G = V_FB` ⇒ `ψ_gate = ψ_bulk` ⇒ 平带 ✓
- **强反型判据（2D）**：`ψ_s = +φ_F`（= mos_1d 里"相对体"的 `2φ_F`）✓
- **长沟道极限**（解析可行性自证）：
  `V_th = V_FB + 2φ_F + √(2q·ε_si·N_A·2φ_F)/C_ox` —— **与 `moscap_vth_closed_form` 逐字同式**
  ⇒ 2D 解 L→∞ 应收敛到它（**这是本段最强的判据**）

## 四、两种数值变体（+ 一条解析 golden = 三方验证）

| 代号 | ρ 的取法 | 用途 |
|---|---|---|
| `mode='majority'` | 只保留**多数载流子**（p 区 `q(p−N_A)`、n 区 `q(N_D−n)`）⇒ 经典**耗尽近似**（不含反型层电荷） | 主扫（roll-off / DIBL / 长沟道收敛，**与 golden 同假设**） |
| `mode='boltzmann'` | 全玻尔兹曼 `q(p−n+N_D−N_A)`（含反型层） | 抽样互验（差异 = 反型层电荷贡献，物理量级） |
| golden | `moscap_vth_closed_form`（教科书 1D 长沟道） | 判决真值 |

**V_d 偏压的处理（诚实设计）**：
- `mode='majority'`：漏端 Dirichlet 取 `+V_d` 即可 —— 耗尽近似下**不含自由载流子**，
  不存在准费米势分裂问题 ⇒ **DIBL 可算，且方法学上是标准做法**（Yau/Toyabe 类分析同框架）
- `mode='boltzmann'`：要求 **V_d = 0（平衡）**；`V_d≠0` 时显式 `ValueError`
  （平衡玻尔兹曼 + 偏压 Dirichlet 会让漏端载流子浓度非物理 ⇒ 必须由 Gummel/准费米处理，
  属 **E13 候选**，本段不假装能做）

## 五、判据（门禁 `run_ecore_e12_smoke.py`）

**物理正确性**
- B1 **长沟道收敛**：L=1µm 的 `V_th(2D)` ⟷ `moscap_vth_closed_form`（rel < 实测容差）
- B2 **单调收敛**：L↓ ⇒ |V_th(2D) − V_th(1D)| 单调增（短沟道偏离）
- B3 **roll-off**：ΔV_th(L) = V_th(L) − V_th(1µm) < 0 且随 L↓ 增
- B4 **DIBL**：V_th(V_d=1V) < V_th(V_d=0.05V)；DIBL = ΔV_th/ΔV_d > 0
- B5 **网格收敛**：nx↑ ⇒ V_th 稳定（相对变化 < 容差）
- B6 **栅氧正确性**：t_ox↑ ⇒ V_th↑（体电荷项）；去掉氧化层（ε_ox→ε_si）⇒ V_th 显著偏移
- B7 **自然长度一致性**：λ = √(ε_si·t_ox·x_j/ε_ox) 与 E11-d 的 `dibl_characteristic_length` 同阶
- B8 **两变体互验**：`majority` ⟷ `boltzmann` 在 V_d=0 的 V_th 相对差 = 反型层电荷贡献（小且可解释）
- B9 **与 E11-d 文献式同阶**（**对照，非 golden**）：Yau roll-off 量级与 2D 数值解同量级

**突变探针（≥5，先证能变红）**
- C1 抹掉横向电场（强制 1D）⇒ roll-off 消失 ⇒ B3 必红
- C2 抹掉漏端偏压 ⇒ DIBL 消失 ⇒ B4 必红
- C3 把 ε_ox 设成 ε_si（去氧化层）⇒ V_th 偏移 ⇒ B1/B6 必红
- C4 界面判据点取错（用 max 而非 min）⇒ 短沟道趋势反向 ⇒ 必红
- C5 注入「LDA 已算 I-V / TOPS」⇒ 诚实护栏必红

**诚实护栏**
- 不宣称 I-V（本段为**准平衡/耗尽**静电求解，不含漂移扩散输运）
- 不宣称 PDK / 工艺标定；不报 TOPS/TOPS-W/fJ/op
- `is_oracle=False`；`guard_t1_not_oracle` 接线
