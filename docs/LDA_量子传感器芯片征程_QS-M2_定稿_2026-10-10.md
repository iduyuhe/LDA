## 1. 本档定位（吃狗粮第三档）

QS-M0 交付「NV 色心磁力计**最小闭环**」；QS-M1 把灵敏度升级为**可比较可溯源的 FOM 体系**。
但 QS-M0/M1 的 η 都是**理想散粒极限**——假设白噪声、无穷相干时间。

QS-M2 补上**物理真实性**：真实器件的灵敏度被两大因素降级——
① **退相干**：T₂*（非均匀展宽）在有动力学去耦（DD）时会被 T₂（回波）替换；
② **多源噪声**：光子散粒之外还有微波相位抖动、温度漂移、环境磁噪声。

| 维度 | QS-M1 | QS-M2 |
|---|---|---|
| η 口径 | 散粒极限（理想白噪声） | **四源正交合成 η_real** |
| 相干时间 | 单一 T₂* | **T₂* → T₂（DD 提升）** |
| 噪声源 | 光子散粒 | **光子散粒 + 微波 + 温度 + 磁** |
| 物理机制 | Laplace 散粒统计 | **回波相位方差 + CPMG 滤波函数** |
| 平台缺口 | G3 | **G4 自旋相干时间建模** |

## 2. 🔴 退相干物理（本档核心 · 闭式可作 golden）

单色（单频）噪声 `B(t)=b·cos(ωt+φ)`，初相 φ 均匀分布。相位积累 `Φ(t)=γ∫B(s)ds`，
对 φ 平均后小信号相干衰减 `W=⟨cosΦ⟩≈1−⟨Φ²⟩/2`：

| 时序 | 相位方差（归一化 `(γb/ω)²=1`） | DC 极限 | 阶数 |
|---|---|---|---|
| **FID**（自由感应衰减） | `⟨Φ²⟩_fid = 2(1−cos ωt)` | `~(ωt)²` | **二阶** |
| **Hahn 回波**（中间 π 脉冲） | `⟨Φ²⟩_echo = 2(1−cos(ωt/2))²` | `~(ωt)⁴/32` | **四阶** |

🔴 **回波的四阶抑制**：DC/低频噪声下 `⟨Φ²⟩_echo ~ (ωt)⁴/32` 远小于 `⟨Φ²⟩_fid ~ (ωt)²`
⇒ 回波把低频噪声**四阶压制**——这正是**动力学去耦（DD）**提升相干时间的物理根因。

🔴 **数值稳定性**：模块用 **haversine 等价式** `2sin²(x/2)` 求值——
直接 `1−cos` 在 x<1e-4 时会**灾难性抵消到 0**（相对判据假绿）；haversine 保住小 x 相对精度。

### DD 脉冲串（CPMG-n）

滤波函数（闭式时序）：

```
F_n(ω,t) = |Σ_{j=0}^{n} (−1)^j (e^{iωt_{j+1}} − e^{iωt_j})|²,   t_j=(2j−1)t/(2n)
```

- `F_n(ω→0) = 0`（DC 恒被重聚）；
- 首个通带峰位 `ω_peak ∝ n/t` ⇒ n 越大，低频抑制越强；
- 相干积分 `χ(t) = (1/π)∫ S(ω)·F_n(ω,t)/ω² dω`，幂律噪声谱 `S(ω)=A·ω^(−α)`。

## 3. 🔴 多源噪声合成（真实灵敏度）

四独立噪声源**正交合成**（白噪声幅度谱密度平方和）：

```
η_real = √(η_ph² + η_mw² + η_temp² + η_mag²)     [T/√Hz]
```

| 源 | 表达式 | 说明 |
|---|---|---|
| `η_ph` | 散粒极限闭式（同 QS-M1） | 光子散粒 |
| `η_mw` | `η_shot(C) − η_shot(C_eff)`，`C_eff=C·e^(−σ_φ²/2)` | 微波相位抖动**附加**项 |
| `η_temp` | `|dB/dT|·S_T`（K/√Hz） | 温度漂移 |
| `η_mag` | `B_noise`（T/√Hz） | 环境磁场噪声 |

🔴🔴 **微波口径（本档吃狗粮抓到的关键易错点）**：`η_mw` 必须是**散粒极限之外的附加项**
`η_mw = η_shot(C) − η_shot(C_eff)`，**不得**把 `C_eff` 直接回代散粒式——否则散粒本身
被重复计入 ⇒ baseline 虚高 √2。σ_φ=0 时 `η_mw` **恰为 0**（`reverse_mw_zero_at_no_jitter` 常驻守护）。

### 四情景（本档现算值）

| 情景 | T₂ | η_real (pT/√Hz) | 说明 |
|---|---|---|---|
| **baseline** | T₂*=1µs | **846.59** | 纯光子散粒（=QS-M0/M1 设计点） |
| **realistic** | T₂*=1µs | **847.88** | 叠加微波抖动(σ_φ=0.2)+温度+环境磁 |
| **dd_enhanced** | T₂=10µs | **267.91** | DD 把相干时间 10× ⇒ 散粒项降到 267.72 |
| **bench** | — | 846.59 | 反向探针 |

## 4. 🔴 净增锚 B475（严格独立）

**B475 = 自旋回波（Hahn echo）相位方差**（Batch B-41）：

| 项 | 内容 |
|---|---|
| **golden** | 解析闭式 `⟨Φ²⟩_echo = 2(1−cos(ωt/2))²`（haversine 稳定式） |
| **candidate** | **时间域数值积分链**：时间网格 + 均匀初相 φ_k → 波形 `B(s;φ)=cos(ωs+φ)` → t/2 处符号翻转（π 脉冲）→ 梯形积分 `Φ(φ_k)` → 对 φ 取 `⟨Φ²⟩` → 乘 ω² 归一化 |
| **方法学独立** | golden = 解析推导（∫cos 闭式 + φ 平均恒等式）；candidate = 纯采样+梯形积分+数值 φ 平均，**不用任何闭式** |
| **实测残差** | **rel = 2.541e-09**（tol 1e-3 的 3.9e5× 余量；时间/φ 网格离散化引入，**非**机器精度） |
| **分类** | `strict_independent`（`candidate_responds=True`：`omega_t` ±10% 扰动有物理响应） |

🔴 **与 B474 不同物理对象（非重复计数）**：B474 走灵敏度 η 的**线宽 FOM 路径**
（时间包络 FWHM→σ_f→η 标量）；B475 走**相干时间建模本身**（回波相位方差函数族）——
candidate 物理对象不同，方法学互不重叠。

🔴 **诚实收敛（同 B472/B473/B474 纪律）**：QS-M2 另含
「四源噪声正交合成」（平方和恒等）、「CPMG 滤波函数 DC 归零」（极限恒等）两项，
均**非独立标量物理量** ⇒ 如实归 `run_qs_m2_smoke` 覆盖、**不登记为 B 锚**（宁可少，不越级谎报）。

## 8. ⚠️ 诚实边界（须与结论一起读）

1. **四源噪声参数均为设计示例量级**（σ_φ=0.2 rad · |dB/dT|=2e-9 T/K · S_T=1e-3 K/√Hz ·
   B_noise=1e-11 T/√Hz），**非实测**；η_real 为**建模值**，**不作制造/性能宣称**。
2. **退相干闭式为归一化无量纲相位方差**（b=1, γ=1 约定），只证明
   「回波方差闭式 ⇄ 时间域数值积分」数值一致这一**数学事实**。
3. 真实器件的 T₂ 受**自旋浴谱、脉冲误差、有限脉宽**等未建模因素降级，实际远差于本模型。
4. **本档不宣称「已达国际水平」**（征程第一阶段「先能设计出来」尚未走完）。
5. C 级自主（纯 numpy；`_batch_b41_numeric` 顶层 scipy-free），LLM 不进判决路径。
