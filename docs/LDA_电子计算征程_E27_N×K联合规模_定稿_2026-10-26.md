## 0. 一句话结论

本段做「N × K 联合优化」，结果**否掉了两件之前一直当成结论的东西**：

1. **列共享 K 的收益是凭空造出来的**（E23 隐含「ADC 全静态」，β=1，物理不成立）；
2. **E22–E26 的能效全建在一个 5% 预算做不出来的规模上**（N=64 vs 可及 N=12，差 5.33×）。

⇒ **能效第一杠杆是行线电阻，不是 K。**

## 1. 审计 K：E23 的收益隐含 β=1

`drive_scheme.scheme_energy_report`：

```python
adcw = E.adc_power_w(bits, max(1, ceil(n / share_k)), f_s)   # f_s = 1/t_conv，**不随 K 变**
```

= **ADC 数量 ÷K，而采样率不变**。这等于假设「一个 ADC 一次转换就能覆盖 K 列」。
但物理上：**采样率 ×K 或转换周期 ×K 必居其一**，两者都没建模。

### 正确分解

```
P_adc(K) = n·f0·E_dyn + (n/K)·P_static          # 动态部分完全不受 K 影响
         = n·f0·E_conv·[1 − β·(1 − 1/K)]       # β ≡ E_static / E_conv
```

⇒ **K 的收益上界 = `1/(1−β)`**，而 β 正是 E26 判定「不可建模」的那一部分。

### 再加 mux 侵蚀（E19 · ∝K）

```
净收益 = 1/(1−β(1−1/K)) × e(K)/e(1)
```

🔴 **必须相对 K=1 归一化**：K=1 本身有 0.043% 的基线 mux 开销，
不归一化会把基线开销误算成"K 的损失"（**分母用错对象** · 与血案 290 同型）。

| K | `β*` 盈亏平衡 |
|---|---|
| 2 | 0.00087 |
| 8 | 0.00346 |
| 32 | 0.01370 |
| **64** | **0.02703** |
| 160 | 0.06494 |

| β | K=64 净收益 |
|---|---|
| **0.0188**（E26 占位：仅比较器预放大 45 µW） | **0.9918× ⇒ 净亏损** |
| 0.10 | 1.08× |
| 0.30 | **1.3813×** |
| 0.50 | 1.91× |

🔴 **K 的收益符号由不可建模的 β 决定 ⇒ K 不能作为设计杠杆。**

## 2. 审计 N：所有能效数字都建在做不出的规模上

`E_op,adc = E_conv/(2·N·K)` ∝ **1/N**（ADC 能量被 `2N²` 个 op 摊薄）。

| N | 来源（5% 预算） | ADC 项（28nm 锚） | 相对 N=64 |
|---|---|---|---|
| **12** | **可及 · 基准 M1（0.504 Ω/段）** | **179.2 fJ/op** | **5.33×** |
| 26 | r/4 | 82.7 | 2.46× |
| 42 | r/10 | 51.2 | 1.52× |
| **64** | **E22–E26 一直用的** | **33.6** | 1.00× |
| 140 | r/100（理想上限） | 15.4 | 0.46× |

### 对外的真实区间

| | 区间 | vs Mythic 8.3 |
|---|---|---|
| N=64（旧 · **做不出**） | 14.9 ~ 66.2 fJ/op | 1.8× ~ 8.0× |
| **N=12（可及）** | **79.6 ~ 353.3 fJ/op** | **9.6× ~ 42.6×** |

🔴 **E26 报的「1.80×~7.98×」口径没错，但它描述的是一个 5% 预算做不出来的规模。**

## 3. 方向反转：杠杆是行线电阻

| 杠杆 | 路径 | 5% 预算下的效果 |
|---|---|---|
| **行线电阻 r↓4×** | N 12→26 ⇒ ADC 项 ÷2.17 | **能效 ×2.17** |
| **行线电阻 r↓10×** | N 12→42 | **×3.50** |
| 行线电阻 r↓100× | N 12→140 | ×11.63（**理想上限，不可达，仅参考**） |
| 列共享 K=64（β=0.0188） | 静态 ÷64 × 侵蚀 | **×0.99（净亏）** |
| 列共享 K=64（β=0.30） | 同上 | ×1.38 |

⇒ **在 5% 预算下，"能做多大"决定"能效多好"，而"能做多大"由行线电阻决定。**

### 为什么行线电阻是唯一杠杆

- 阵列功耗 `∝N²` 与 ops `∝N²` **相消** ⇒ 规模本身不改善能效（E21 已证）
- 但 ADC 功耗 `∝N`（每列一个）而 ops `∝N²` ⇒ **ADC 项 ∝1/N** 被摊薄
- 而 `N` 的上界由 **IR drop ∝ N²·r** 决定 ⇒ **r 是唯一能动 N 的东西**

## 6. 我自己踩的坑（判据当场抓住）

`β*` 第一版写成 `(e(1)/e(K) − 1)/(1−1/K)`，正解是 `(1 − e(K)/e(1))/(1−1/K)`。

两者不等：0.0273 vs 0.0270（差 2.7%）—— **`1−x` 与 `1/x−1` 只在 x 极接近 1 时近似相等**。

判据 ④（`β=β*` 代回必须 ≡ 1）残差 **4.8e-3** 当场抓红。

> 与血案同型：这是"代数恒等写错"，而**写成判据就能抓住**。
> 若只写"β* ≈ 0.03 左右"这种模糊判据，这个错会一直静默。

## 7. 对下一段的硬指令

### 🔴 不要再优化 K

β 未知 ⇒ K 的收益连正负号都不定。**在 β 实测之前讨论列共享是本末倒置。**

### 🔴 唯一值得做的是行线电阻

它通过抬高 N 上界，**确定地**改善能效（×2.17 @ r/4、×3.50 @ r/10）。

具体要做的是**版图层的三件事**（都不在模型内，必须实测/提取）：

1. **换金属层**：M1（0.084 Ω/□）→ 高层厚金属（常见 0.02~0.03 Ω/□）⇒ r↓3~4×
2. **加宽行线**：线宽 ↑2× ⇒ r↓2×（代价是单元面积/密度）
3. **双端驱动**：电流分两路 ⇒ 有效 IR drop ↓~4×（等效 r↓4×）

⇒ **三者叠加可到 r/8~r/32 量级 ⇒ N 上界 35~75 行 ⇒ 能效 ×2.9~×6。**

### 需要的数据

- **金属层方块电阻**（真实 PDK 或公开工艺参数）⇒ 把 r_div 从"设计目标"变成"可算值"
- **参考缓冲静态电流**（定 β）⇒ 才能判定列共享是否值得
