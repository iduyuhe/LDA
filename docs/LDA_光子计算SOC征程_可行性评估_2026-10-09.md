## 0. 一句话定位

利用 LDA 平台**亲手设计一款光子计算 SOC 芯片（PIC）**：先求"设计得出来 + 行为验证得出来"，分阶段把性能与集成度推到国际可比量级；同时以"自己先用、先检验"的方式倒逼平台补齐集成能力短板。这是继电子计算（E1–E19）、光子计算（M1–M5）、量子、光子传感器（PS）、光联接（OI）、光子存储（PM）征程之后，平台能力的**集大成吃狗粮征程**。

---

## 1. 缘起与战略动机

1. **L6 战略定位落地的硬证据**：LDA 的 L6 定位是"模拟/光子计算加速器的设计平台"（见 `docs/LDA_光子模拟AI加速器参考设计_v0.9.171` 与战略总纲 §8）。亲手设计一款真实光子计算 SoC，是该定位最硬的"吃狗粮"证据，也是对客户最有力的**整芯片**案例（模块级参考设计无法替代整芯片联调证据）。
2. **发现集成债的唯一途径**：平台铁律"定向全绿 ≠ 无债"——模块级全绿无法暴露集成债。把光子核 + 电子外设 + 光 IO + 光源 + 标定 + 版图逼到**同一颗芯片联调**，才能发现并消除集成级缺口。
3. **平台能力升级的反向驱动**：征程中暴露的每一处平台短板（光源、电子外设、多层 GDS、热串扰标定）都转化为平台能力增量，且全部可由平台自主新建（纯 numpy/scipy、闭式物理律、LLM 不进判决路径，符合主权红线）。

## 2. 范围锁定（4 项决策，2026-10-09 用户拍板）

| # | 决策项 | 用户选择 | 工程含义 |
|---|---|---|---|
| D1 | 主应用 / 计算核路线 | **先最小可证伪单核** | 一个能端到端跑通的 N×N 光子核 + 行为级电子外设，作为征程起点，最快出"吃狗粮"闭环 |
| D2 | "国际水平"对标轴 | **集成度（单片含光源+电子+IO）** | 对标"同一份设计+GDS 内协同集成的子系统完备度"，非能效维度（见 §7 红线） |
| D3 | 片上激光器 | **封装级 / 外部光源起步** | 复用现有外部黑箱（G5 网关可绕过），首期不建激光模型，G1 延后 |
| D4 | 流片意图 | **设计 + 行为验证 + 主权版图（不流片）** | 平台当下能力可达大部分；G4（foundry PDK）延后，不阻断首期 |

**🔴 范围调和（防误读）**：D2 选"集成度"但 D3/D4 选"封装光源 + 不流片"，二者**不矛盾**。本征程的"集成度"定义为——在**同一份设计 + 主权 GDS artifact** 内，把"光子核 + 行为级电子外设 + 光 IO + 封装光源接口 + 标定环"协同设计进一颗芯片；**不要求**单片激光（G1）或真实流片（G4）。这恰好是首期可交付、可机器核验的集成度证明。

## 4. 可行性评估结论

**结论：✅ 建议启动（GO），分期推进。**

- **"能不能设计出来"= 能**：平台已具备"设计光子计算核 + 光电行为级协同 + 主权版图签核"的完整能力，足以交付"光子计算 SoC 的设计与行为验证 + 光子核主权 GDS"。
- **最硬缺口已主动排除出首期**：G1（单片激光）、G4（foundry PDK）由 D3/D4 延后，不阻塞首期；G2/G3/G5 属平台可自主新建能力（符合主权红线），补齐即平台升级。
- **风险可控**：首期交付为"设计 + 行为验证 + 主权版图（不流片）"，无外部流片依赖、无能效宣称红线触碰；风险集中在工程集成（G2/G3/G5 的建造质量），可由 CI 门禁 + 突变探针逐阶段拦截。

## 5. 重要性 & 必要性

### 重要性
1. L6 战略定位的最硬"吃狗粮"证据与对客整芯片案例。
2. 逼出平台最难积木的联调，是发现集成债的唯一途径（模块级全绿 ≠ 集成无债）。

### 必要性
1. **不做的代价**：LDA"能设计光子计算加速器"只停在模块/参考设计级，客户要"整芯片"时无法交付；集成债无人发现，平台能力天花板被锁死。
2. **做的必要性**：自然承接 M1–M5 光子计算 + E1–E19 电子 + PS/OI/PM 各征程，是"吃狗粮"集大成者；每补一处缺口即平台能力增量，投资回报确定。

## 6. 对标口径与红线纪律（🔴 必须先把口径对齐）

平台红线：**无电域锚、无 foundry 数据 ⇒ 禁止报 TOPS / pJ·op / fJ·bit / 能效**。

因此"达到国际水平"在**能效维度无法宣称**，本征程对标轴锁定为（按 D2）：

- **集成度（主对标）**：同一份设计 + 主权 GDS 内协同集成的子系统完备度（光子核 + 电子外设 + 光 IO + 封装光源接口 + 标定环）。
- **架构正确性（辅证）**：端到端推理精度 vs 数字 golden（L6 已证 0 落差，可直接继承）。
- **矩阵规模 / 组件数（渐进）**：由 S4 规模爬升逼近 Lightmatter Passage / Lightelligence PACE 量级，但**仅作规模记录，不作能效宣称**。

> ⚠️ 任何对外物料不得出现 pJ/bit、TOPS/W、fabricated 能效等数字（红线 T2）。

## 9. 诚实边界（红线）

1. 本评估基于平台**当前实码状态**（2026-10-09 盘点）；缺口 G1–G6 为规划项，非已证能力。
2. 首期交付为"设计 + 行为验证 + 主权版图（不流片）"——**非 tape-out sign-off**，不报能效、不报 fabricated 指标。
3. 光子核容量受酉约束（被动网格，增益介质锁死 T2 禁区）；任意权重走 SVD 双网格路线。
4. 行为级电子外设参数（τ / R_f / VπL）为设计预算常数，非实测锚，不得作性能宣称。
5. 对标"国际水平"仅限集成度 / 架构正确性 / 规模记录三维，能效维度红线禁止。
