LDA 研发规划与实施计划（2026-09-11 红线重排版）

文档性质：执行视角（姊妹文档 BP 修订版为融资/商业视角）。本版依据：LDA_研发规划与实施计划_2026-09-09.md + 2026-09-10/11 杜先生终审裁定（docs/lda_active_device_redline_clarification_2026-09-10.md §七/§八/§九）。

0. 一句话定位

LDA = 光电接缝上的可证伪设计入口。 不做整条链，只做「封装测试占 79.9% 成本的那一格」。红线重排后新增：原禁区「电域求解器 / Foundry TCAD」的 T1 数值内核（载流子输运 PDE 求解）现已解锁——可在主权可控（B 级 DEVSIM fork / C 级自研）前提下做电-光器件载流子分布真求解，但输出不作真值 ORACLE，且 T2 工艺真值 / 电-光耦合增益 / 封测产线 / 流片仍锁死。

1. 战略边界（🔴 本版核心修订：三不做 → 分层边界）

1.1 分层边界：T1 可解锁 / T2 锁死 / 封测锁死

原「三不做」项新分层口径T1（可解锁）T2（永久锁死）
电域求解器拆 T1/T2T1 电学内核：泊松+漂移-扩散+连续性方程，求 N(x)。DEVSIM（Apache-2.0）fork 或自研 → B/C 级，不破 A 级。电-光耦合增益当真值（激光 L-I / SOA 增益 / 增益谱）、A 级商业电学求解器（Sentaurus/Lumerical/COMSOL）、foundry 工艺真值、封测产线、流片。
Foundry TCAD拆 T1/T2T1 数值内核：漂移-扩散+载流子输运 PDE（与电域 T1 同一内核）。DEVSIM fork 或自研 → B/C 级。foundry 专有工艺模型（implant/diffusion/etch/stress）+ 流片实测 ORACLE。LDA 只消费 PDK 接口。
封测实体产线维持原样—完全锁死（C 期能力）。先委托测试、后自建。

A 级永不借（维持不变）：Lumerical / Ansys / Synopsys / Cadence 不采用。DEVSIM（Apache-2.0）属 B 级，fork 镜像冷备即合规。

T1 解锁 5 条铁律（须同时满足，否则破 IRONLAWS）：① 成熟节点用途声明（规避 EAR 744.23）；② 仅开源/自研内核 + 公开文献/PDK 标定，禁 import A 级商业；③ T1 输出不作真值 ORACLE，判决仍落 foundry 实测/文献/标准；④ 不流片不抢制造；⑤ subprocess 仅回标量不污染核心。
🔴 EAR 744.23 出口管制诚实提醒（钉入红线）：按「用途（先进节点）」管制 ECAD/TCAD，非按代码许可。开源 TCAD 技术主权不受美系绑定，但明知用于中国先进制程仍可能触线；成熟节点/非先进用途不在范围。「开源 ≠ 完全不受 IP 影响」。

影响范围：B 档「载流子动力学 / 探测器带宽真求解」经 T1 可做；激光 L-I / 增益谱 / SOA 仍维持禁区；A 档（闭式/行为层）早已授权且不依赖 T1 内核。

1.2–1.5 其余边界（维持 09-09 版，新增项见下）

  • 全生命周期 3–5 段：T1 内核解锁后第 3 段（设计实现）扩到载流子分布级，但仍不碰第 6 段（封测验证，委托伙伴）。
  • AI 分工铁律：AI 出题、物理定律判卷；T1 内核输出不进死标量判决。
  • 生态开放：新增 T1 内核 PR 主权扫描（DEVSIM Apache-2.0 合规 + 离线构建证据）。
  • 跨期工程铁律：新增 EAR 744.23 合规门禁（用途声明 + 离线构建证据缺失即 CI 红）。

3. 逐期实施计划（WBS + 验收 + 风险）

T0 需求架构层（基本完成）

已完成：Pareto（CORE）、NLP 入口（4/4）、S8 接入（4/4）、红蓝队闭环（DeepSeek 蓝队+GLM 红队+锚判卷+30min cron，CI 152）。剩余：人终审 UI 收口 + 演示物料。

T1 光电接口层 + 电学/TCAD 数值内核（T1 解锁层）— 🔴 最大变化

T1-A 光电接口层（原·110 万）：紧凑模型 schema / SPICE 网表 + Cadence 适配 / 参数↔物理校准接 B29+B30+B33 / 反向护栏 参数±20%响应必变。明确不做 SerDes/DSP/眼图/BER（T2 锁死）。

T1-B 电学/TCAD 数值内核（🔴 新增）：① DEVSIM Apache-2.0 fork 镜像冷备 + 离线构建验证；② 自研 drift-diffusion+连续性 1D 内核（Gummel/Newton 求电势→N(x)），Sze 教科书闭式作 golden；③ N(x)与 DEVSIM 双向标定 + T1 输出不作 ORACLE 守卫 + EAR 744.23 用途声明；④ subprocess 隔离（沿用 Meep 纪律）。验收：N(x)双向标定 Δ≤容差且网格收敛单调；ORACLE 守卫必响；离线构建+用途声明齐备；零 A 级。

T1-C 主动器件扩展：A 档（闭式，已授权） Si 载流子色散 Vπ / EAM-QCSE / 探测器带宽 τ=RC（B33 已立）/ 激光器 FSR·布拉格·线宽，各立物理定律锚 + 独立交叉候选（先评审后写码）。B 档部分真求解（经 T1-B） 载流子动力学 / 探测器带宽真求解，与闭式下限交叉验证；激光 L-I/增益/SOA 仍锁死。

T2 真值链

3–4 轮 MPW + 委托封测（ficonTEC 年产能 30–40 台，交期 5–7 月，须早锁）+ 实测回流规范。🔴 T2 工艺真值仍永久锁死，只消费 PDK。🔴 与 T1-B 衔接：B 档真求解在 T1-B 算出但输出不作 ORACLE；T2 的 MPW 实测是这些真求解的标定与验收来源，互补不替代。

T3 设计侧虚拟制造 2.0

工艺波动链路（巩固）+ 可封装性链路（新建）+ 载流子分布→封装良率链路（T1-B 赋能，新增） + 设计决策反向追溯。验收：设计改动→封装良率同向可复现。

T4 标准位与生态

L0 IR schema 冻结 + ≥2 外部采用 + ≥1 foundry 签 PDK + 生态治理三件套（含 DEVSIM/T1 内核许可扫描）。

5. 跨期治理与 CI 纪律

  • 发版前必跑 --tag core 全量回归看 rc。
  • 每个新护栏必须有反向测试证明会响。
  • 判据先于代码；主权扫描 import+license 双扫（含 DEVSIM/T1 内核 Apache-2.0 合规扫描）。
  • 🔴 EAR 744.23 合规门禁：T1 内核交付/演示/文档缺成熟节点用途声明 + 离线构建证据 → CI 红。
  • 三分类一致性：README ≡ harness ≡ /api/verification_ledger，漂移即红。
