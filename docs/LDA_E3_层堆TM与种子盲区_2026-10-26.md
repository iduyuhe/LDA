## 1. 为什么这件事一直没做

`solve_modes_eps(eps, xv, yv, k0, ...)` 早就支持任意 2D 截面，但全仓 14 处调用**全是单芯** ——
没有一处构造过「Si 衬底 / 400 nm BOX / Si 芯」这种三层堆。接口在，用例不在。

层堆的第一个坑不在求解器，在**掩码**：

```python
# 缺省：ε > (min+max)/2 判"芯"
core_vmask = core_vertex_mask(eps)   # ✗ Si 衬底比芯还宽 ⇒ 衬底也被算成"芯内"
```

衬底模的 `conf_core` 因此接近 1，`conf_min` 筛不掉它，选模直接选到衬底模上。
`stacked_section()` 显式只圈 0.45×0.25 那块（实测掩码 **209** 顶点 = 芯格数，不含 4 µm 宽的衬底）。

## 2. 缺省种子在层堆上静默返回 0 个模

```python
σ_default = k0·(n_lo + 0.85·(n_hi − n_lo))
```

这个启发式假设「**只有一个**高折射率芯，基模靠近折射率上限」。层堆里 `n_hi` 是 **Si 衬底**，
σ 落进衬底模簇，全部被 `conf_min` 剔除 ⇒ 返回 `[]`。

| 用法 | 结果 |
|---|---|
| 缺省 σ（一次求解） | **0 个模** |
| 扫 σ ∈ [1.6, 3.45] 步 0.15，合并去重 | **3 个模**：TE 2.4055 / TM **1.8318** / TM 1.8180 |

调用方看到的是「这结构没有导模」。真相是「搜索中心放错了地方」。
🔴 **静默的空列表比报错更危险**：它不会被任何断言发现，只会让下游安静地变成 `nan`。

⇒ 正解是 `spectrum_scan()`：把 σ 扫一片再合并去重。
**这不是"调参找答案"** —— σ 只是 ARPACK 的搜索中心，扫一片换来的是**不漏模**。
（与 v0.9.314 的 ρ 判据是一对：一个管「候选不响应参数」，一个管「求解器看不见模」。）

## 3. 实测：差 9.0× tol

截面 Si(sub) / SiO₂ 400 nm / Si 450×250 nm，`h_grid=0.025` 使芯与 BOX 边界**全落在格线上**
（250 nm 的半高 0.125 = 5×0.025；BOX 界面 −0.525 = −21×0.025）。

```
quasi-TM 基模 n_g = 4.5403   @λ = 1.5576（三点差分 1.5376 / 1.5576 / 1.5776，三点同网格同窗口）
FSR = λ²/(n_g·2πR) = 11.339 nm     实测 10.440 nm       差 0.899 nm = 9.0× tol(0.1)
n_g 相对差 7.7%                     判到 0.1 nm 只需要 0.96%（= tol/FSR）
```

**tol 预算是这一版最有用的一行**：`dFSR/FSR = −dn_g/n_g` ⇒ 相对容差 ≡ tol/FSR = 0.96%
⇒ 要判到 0.1 nm，`n_g` 必须准到 **±0.047**。现在的 0.38 差了 8 倍，**这不是"再调调网格"能补的**。

## 4. 为什么 7.7% 不是网格问题：导模 vs 漏模

新立单点判据 —— **改求解窗口，答案动不动**：

| 衬底深度 sub | 0.8 µm | 1.4 µm | 2.0 µm |
|---|---|---|---|
| TM n_eff | 1.8318 | 1.8257 | **丢失（NaN）** |

真导模的场在包层指数衰减 ⇒ 窗口加大 n_eff 逐位不变。漏模靠 Dirichlet 盒截断 ⇒ 窗口就是
人为边界。薄 BOX（400 nm）下的 TM 模场持续向 Si 衬底辐射 ⇒ **它是漏模，真实 n_eff 是复数**，
而 `solve_modes_eps` 的算子是对称实的，只能给实 n_eff。

阈值不是拍的：同仓半矢量对**真导模**的窗口散射实测 **<1e-5**（见 E2 note），
而这里的散布是 **0.0061** —— 大 **600×**，且 2.0 µm 那档**直接把模丢了**。
判据因此写成「散布 > 1e-3 **或** 任一窗口丢模 ⇒ LEAKY」。

⇒ E3 新的、可执行的卡点：**要判 0.1 nm 须复 n_eff（PML / 漏模本征值），而不是更细的网格。**
这条比"须层堆+TM"精确得多，也真的派得出活。

## 5. 记账

账本 **541** · strict **519** · 降级 3 / 自证桩 19 / 独立率 **95.93%** · 缺口 **127** —— **全部不变**。

## 6. 诚实边界

- 4.5403 是**实** n_eff 的差分。漏模的真实 n_eff 是复数 ⇒ 它只能当"上界型估计"，不宣称是物理解，
  更不宣称"E3 的真值被算出来了"。
- 空列表也可能是"确实没有导模"。本版能说的只有一句可机核的话：**这个截面有 3 个模，
  而缺省参数一个都看不见**。
- 未改 `solve_modes_eps` 的缺省行为（动它要碰该模块 13 条既有判据）。本版只在**调用侧**给正解 + 判据，
  并把"缺省盲区"写成常驻自检 ⑪，防止有人以为默认值对所有截面都成立。
- 上包层取了空气（`clad="air"`）。语料未写明上包层；若实际是 SiO₂，TM 基模 n_eff 会高约 0.14
  （实测 1.9748 vs 1.8318），n_g 随之变化 —— **这是语料边界，不是模型可调项**，故如实标注而不择优。
