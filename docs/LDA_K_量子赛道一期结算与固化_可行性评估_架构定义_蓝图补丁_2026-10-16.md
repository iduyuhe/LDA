## 0. 定位（为什么是「结算与固化」而不是「新域扩张」）

量子赛道蓝图 v1（Layer 0–5 · **J1→J5**）已**全蓝图收官**：六层复利链（逻辑比特 → 物理比特 → 测控闭环 → 传感系统 → 量子网络）打通并上线，账本 538 锚、独立率 95.91%。

🔴 **但一期留下了三类「未结项」，且都已**在盘面可证**：

| 类 | 实例（均为现算核实，非转录） | 性质 |
| --- | --- | --- |
| **债务类** | ① **QS-M3c `cooperativity` 两口径断口未结算**（章程 R3b 登记 `11844.8 ↔ 1.3185` ≈ 8982×），且**消费侧未并报**——本征程 M3 的 `qnet_transducer.py` grep「口径/2n/约定/8982」**零命中** ② **B516/B517 编号预留但无终态** | 断口 / 账面空洞 |
| **平台类** | ③ **J1（QEC）在 WebUI 既无面板也无端点**（`sec-j1` / `/api/j1_qec` 全仓 grep **零命中**，而 J2–J5 四层面板+端点齐备）④ **跨档复用常量无机器表**（确凿 2 处：`qnet_transducer.cooperativity()` 函数内 `from lda_l2.qs_m3c import cooperativity_from_g`；`qnet_classical` 顶层 `from lda_l2.qs_m2 import cpmg_filter`）⑤ 六层门禁**覆盖矩阵**未机器化 | 漂移风险 / 覆盖盲区 |
| **对外类** | ⑥ 一期收官**无对外白皮书** ⑦ 六层面板**无聚合总览入口** ⑧ 论文未出 | 交付欠账 |

⇒ **K 征程 = 把这三类未结项一次性清偿并机器化，顺带把六层复利叙事对外固化 —— 为蓝图 v2 奠基。**

🔴 **纪律声明**：本征程**以「不加锚」为常态**（清偿型工作的产出是**口径澄清 + 机器护栏**，不是新物理量）。净增锚仅在三处可能发生：K1 若恢复隐含规格锚、K2 若 B517 同源体检通过立靶、K2 若 J1 面板补齐带出跨层面判据。**预估净增 0–3 锚**——不足此数**不硬凑**（同 J4 M1/M2、J5 M2/M4 的净增 0 纪律）。

🔴 **定调结论（2026-10-16 · 见 §6）**：范围 = **全含 K0–K6**（清偿 + 固化 + 对外 + 蓝图 v2 奠基）· K1 以净增 0 为常态 · B516/B517 **先同源体检再定** · J1 面板补齐**纳入** · K6 **只起草缺口矩阵、不动实现** · **K0 待「开工」指令启动**。
