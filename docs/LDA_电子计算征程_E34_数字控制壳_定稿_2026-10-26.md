## 0. 一句话

E20–E33 建的是一颗**阵列**，不是一颗**芯片**：没有标准单元、没有综合、没有时序、没有数字控制。
本段把这条腿从 **0** 建到「能综合一颗真控制壳并证明它对」，用的全是自己写的工具链。

---

## 1. 为什么这一步必须由人裁决

「借 Yosys / OpenROAD」技术上是最优解：成熟、开源、有 SAT 等价性、有 P&R。
但它会把平台从 **C 级自主** 拖到「依赖 GPL 工具链」，而那是对外口径，不是技术细节。

三条路摆在桌上，代价不同：

| 路线 | 对外口径 | 代价 | 得到的东西 |
|---|---|---|---|
| 借（Yosys + OpenROAD） | 🔴 必须改写「C 级自主」 | 低 | 完整数字流程（含 P&R） |
| **自主建（本段所选）** | ✅ 口径不变 | **高**：从单元库开始写 | 逻辑前端（综合/STA/等价性），**无 P&R** |
| 混合 | 需逐项说明边界 | 中 | 边界最模糊，最难诚实 |

**裁决：自主建。** 因此本段的「完成」定义只有一种合法写法：
**逻辑前端全部自建并机核通过；P&R 明确不做，且不假装做了。**

## 2. 六层是什么

| 层 | 模块 | 做什么 | 它的判据（能打红的那条） |
|---|---|---|---|
| 0 | `dcell` | 18 单元 / 130 管的互补 CMOS 库 | **`n_tr` 拓扑必然**（INV=2T / NAND2=4T / DFF=24T）+ 族内 `k_drive` 与串联数同序 |
| 1 | `drtl` | 可综合 Verilog 子集前端 + **引擎 A** 解释器 | `~0` 必须是 32 位 · 位宽上下文必须保进位 · 非阻塞必须读旧值 |
| 2 | `daig` | AIG 布尔网络（常数传播 / 结构哈希 CSE） | 只做**可证明等价**的变换；比较器累积方向 |
| 3 | `dsynth` | 综合（AST→AIG→单元网表）+ **引擎 B** 仿真 | **网表真实性**（输出必被单元驱动 / DFF 数 == 状态位 / 无前向引用） |
| 4 | `dsta` | STA + 面积/功耗 | **三条独立路径金标**：图传播 / 逐级累加 / 代数相乘，rel < 1e-12 |
| 5 | `dequiv` | 双引擎穷举 + **响应率 ρ** + 锁步序列对拍 | 逐位相等、容差 0；**ρ < 0.8 ⇒ 判据无判别力，绿也不算数** |
| 6 | `dctrl` | **CIM 控制壳**（第一个真实设计） | 18 位累加器的**双向**位宽判据 + 1500 拍锁步零失配 |

## 3. 本段自己踩的六个坑（全部被机核抓出）

这一段最该记的不是「建成了」，而是**六个真缺陷都是在自查/对拍里现形的**，一个都没漏到发布。

| # | 缺陷 | 表现 | 谁抓到的 |
|---|---|---|---|
| 1 | 延时单位多乘 1e3 | INV@4fF 报 **13,864 ps**（应 13.86）⇒ 全链偏 **1000×** | 手工核对 FO4 量级 |
| 2 | `k_drive` **跨族**比较 | 28 个假违规（NOR 的串联是 PMOS，迁移率低，同串联数下 k 必然更大） | `library_self_check` ③ |
| 3 | **位宽上下文缺失** | `output [4:0] y = a + b`（15+1）得 **0**（应 16）—— 静默丢进位 | 前端自检的 15+1 对照组 |
| 4 | 无符号比较器**累积方向反** | `2 < 1` 判为 **真** | 双引擎穷举（cmp_mix 第 18 号向量） |
| 5 | `case` 的「保持」起点错 | `case(x) 1: if (a) y<=b; endcase` 在 `a=0` 时把 y 保持成 **default 的值** | **锁步序列对拍**（单点随机向量抓不到） |
| 6 | 非阻塞读到了**新值** | `scnt <= scnt+1; if (scnt==17)` ⇒ 完成条件整体偏 **1 拍** | 锁步（引擎 A 错、引擎 B 对） |

### 3.1 第 2 条是一个「判据本身错」的标本

第一版判据：**全库按 `n_series` 排序，要求 `k_drive` 单调不减** ⇒ 报 28 个违规。

错不在库，在判据：它把**不可比的对象放进了同一个序**。NOR 的下拉是 NMOS、上拉是 PMOS（串联），
PMOS 迁移率约为 NMOS 的 1/2.5 ⇒ 同串联数下 NOR 族必然更慢。正确判据必须**先按族分组**，
再补一条跨族的**方向**判据（NOR > NAND、AND > NAND）。

⇒ 记一条通则：**「单调」必须在可比域内定义，跨域单调是伪判据。**

### 3.2 第 4/5/6 条是「双引擎」的价值证明

三条缺陷分别落在：引擎 B（综合）、两侧共享的语义（case 合并）、引擎 A（解释器）。
**如果只有一个引擎，三条全是「看起来对」。** 第 6 条尤其关键 —— 它是**引擎 A 错、引擎 B 对**，
说明对拍不是「以 B 为准」，而是「谁错都藏不住」。

## 4. 控制壳：第一个真实设计

不再用玩具例子自证。控制壳驱动的是 E20–E33 那个 87×87 阵列：

```
        IDLE ──start──→ SCAN ──adc_done──→ ACC ──(还有行)──→ SCAN
          ↑                                  │
          │                                  └──(最后一行)──→ NEXTB
          │                                                    │
          └──────────(18 拍移完)── READ ←──(最后位平面)── NEXTB ─┘
```

### 4.1 位宽全部由物理动态范围反解（不是凑的）

| 信号 | 位宽 | 反解 |
|---|---|---|
| `row_sel` | 7 | ⌈log₂87⌉ |
| `bit_sel` | 3 | 8 bpc（E22 器件族硬门槛） |
| `acc` | **18** | 累加次数 = 87 × 8 = **696**；每次 ≤ 255 ⇒ 上界 **177,480**；2¹⁷=131,072 **不够**、2¹⁸=262,144 够 |
| `scnt` | 5 | 扫完 18 拍 |

🔴 **18 这个数有双向判据**：只证「18 位够」对「随便给个宽位宽」的候选**永远绿**；
必须同时证「**17 位不够**」，判据才有判别力。`acc_width_witness()` 把两半都写成机核。

### 4.2 规模

| 指标 | 值 | 口径 |
|---|---|---|
| 组合门 | **1,284** | 可签核（结构性事实） |
| DFF | **56** | = 3+7+3+18+18+5+1+1（声明决定，**精确**） |
| 面积 | 240.8 µm² | 🔴 `MODEL_ESTIMATE`（一阶面积模型，±factor 2） |
| 漏电 | 270.9 nW | 🔴 同上 |
| 锁步 | **1500 拍 / 24,000 次比对 / 零失配** | 可签核 |

## 5. 闭环：数字壳会不会成为真瓶颈

```
SAR 由 CDAC 建立时间决定的最快时钟  →  97.68 MHz   (t_clk = 10.24 ns)
数字壳 Fmax（一阶 STA）             →  1535.4 MHz  (t_clk_min = 651 ps)
headroom                            →  15.72×      ⇒ 数字不是瓶颈
```

**这一步的意义**：E17/E24 的模拟时序反解出的时钟要求，数字壳必须跑得到。
跑不到，SAR 就被迫降频，整条阵列变慢 —— 那时**数字就是真瓶颈**，而这件事只有建了数字链才知道。

⚠️ **架构差异必须说清**：本控制壳是**单 ADC 时分复用**（逐行 × 逐位平面串行），
E17 `per_sample_report` 假设 **ADC 并行**。两者「每样本耗时」是**两个架构的数，不可相除**。
本段只做上面那一条可比的事，不做「数字壳让系统快 N 倍」这类无法成立的比较。

## 6. 诚实边界（本段最该读的部分）

| 没有的东西 | 后果（不可用一句话带过） |
|---|---|
| **布局布线（P&R）** | **无物理面积、无真实线延时、无扇出驱动（buffer insertion）** ⇒ 面积/延时/Fmax 全是**一阶估算**，不是签核值 |
| 时钟树（CTS） | 无时钟偏斜 ⇒ 本段 `hold_ok=True` 但 **`hold_checked=False`** —— **没有真正检验保持时间**，不制造「验过了」的错觉 |
| 多工艺角 / OCV | 只有 tt 单角 ⇒ 真实芯片的慢角延时**必然更大** |
| DFT / 扫描链 | 无法测试制造缺陷 |
| 与阵列版图拼装 | 无顶层整合 / IO ring / 电源网格 ⇒ **这是「CIM 阵列 + 数字前端」的签核，不是 SoC 签核** |
| SAT sweeping / rewrite | 门数**显著高于**商业综合器；这一差距公开承认，不以「面积接近」表述 |

**能签核的只有结构性事实**：门数、DFF 数、逻辑深度、关键路径节点序、功能等价性（穷举/锁步）。
凡带工艺系数的（面积/延时/功耗）一律 `claimable=False`。
