**本档回答的工程问题**：前四档给出的全是**物理量**（灵敏度 / 相干时间 / 最优深度）。但一个真实的 NV 量子传感器芯片需要**可制造的器件本体** —— 承载色心的纳米柱怎么画？腔什么样？微波天线怎么布？本档第一次给出**器件几何 + 可制造性规则 + PDK 登记**。

**平台缺口**：**G5**（量子传感专用 PDK 器件 —— NV 柱 / 腔 / 天线）。QS-M3 落地其**几何半（物理链）**，本档落地其**器件本体半（几何 + 工艺 + PDK）** ⇒ **G5 闭合**。

## 2. 三器件本体

### ① NVPillar —— NV 色心纳米柱

| 几何量 | 默认值 | 说明 |
|---|---|---|
| 柱顶直径 dia | 0.30 µm | ≥ 光刻极限（min_pillar_dia） |
| 柱高 h | **≈ 0.166 µm** | 🔴 = 最优色心深度 d\*（45.885 nm）+ 柱顶余量 0.12 µm（**现算**） |
| 锥角 taper_deg | 12° | 干法刻蚀侧壁角 |
| 柱间距 gap | 0.60 µm | 防刻蚀负载效应粘连 |
| 基底平台 base_w | 1.40 µm | ≥ dia + 2·sidewall + 2·min_base_overhang |
| 侧壁保护层 | 0.05 µm | 钝化（抑制表面噪声） |

版图 = Si 芯层（柱身锥形 + 左右基底平台）+ Metal 层（两侧侧壁保护带）。

🔴 **柱高与 QS-M3 严格同源**：`nv_pillar_height_um()` 现算 `qs_m3.optimal_depth_closed(20, 200)/1000 + h_top`。这是把 QS-M3 的**物理量 d\*** 投影成**几何量 h** —— **不是第二个独立物理量**（故本档零净增锚）。

### ② NVCavity —— NV 耦合光子晶体腔

| 几何量 | 默认值 | 说明 |
|---|---|---|
| 孔周期 period | 320 nm | 光子晶体格 |
| 孔半径 hole_r | 90 nm | ≥ min_cavity_hole |
| 孔间壁厚 min_web | **140 nm** | = period − 2·hole_r（**派生现算**） |
| 波导线宽 wg_w | 0.45 µm | 中心线缺陷腔 |
| 腔区长度 cav_len | 0.60 µm | 缺孔段 |

版图 = Si 芯层（中心波导 + 双侧孔阵列，圆多边形近似孔）。

🔴 **腔增强光子学量与 QS-M3 同源**：Purcell 因子 `F_P = 4g²/(κγ₁)` 真源在 `qs_m3.SCENARIOS['cavity_enhanced']` / `qs_m3.purcell_factor`；本档只给**几何**（周期/半径/腔区），**不复制 g/κ/γ₁ 数值**。该物理量与账本锚 **B18 同物理量** ⇒ 只作器件本体登记。

### ③ MWAntenna —— 微波环形天线

| 几何量 | 默认值 | 说明 |
|---|---|---|
| 环半径 loop_r | 20 µm | 环形天线 |
| 导线宽 trace_w | 1.20 µm | ≥ min_antenna_trace |
| 线间距 gap | 1.00 µm | ≥ min_antenna_gap |
| 馈线宽/长 | 2.0 / 15.0 µm | 引出 |
| 焊盘边长 pad_w | 20 µm | RF/偏置接入 |
| 天线→NV 距离 nv_dist | 2.00 µm | 与 QS-M1 微波噪声链同源 |

版图 = Metal 层（环 + 馈线 + 焊盘）。

🔴 **微波场强/噪声量与 QS-M1 同源**：「天线→NV 间距」的物理后果（耦合强度 vs 噪声）真源在 `qs_m1`；本档只给几何。

## 3. 可制造性 DRC（九条专用规则）

| 检查项 | 限值 | 归属 | 物理含义 |
|---|---|---|---|
| min_pillar_dia | 0.20 µm | 柱 | 刻蚀可实现 + 承载单 NV |
| max_pillar_height | 0.50 µm | 柱 | 高宽比侧壁塌陷 |
| max_taper_angle | 20° | 柱 | 干法刻蚀侧壁角 |
| min_pillar_gap | 0.40 µm | 柱 | 防刻蚀负载粘连 |
| min_base_overhang | 0.10 µm | 柱 | 防柱根悬空 |
| min_cavity_web | 0.05 µm | 腔 | 孔间壁厚（结构强度） |
| min_cavity_hole | 0.05 µm | 腔 | 孔半径（刻蚀可实现） |
| min_antenna_gap | 0.60 µm | 天线 | 防击穿/串扰 |
| min_antenna_trace | 0.50 µm | 天线 | 电迁移/损耗 |

🔴 **专用规则名而非通用 min_width**：柱径 0.30 < 通用 min_width 0.35 ⇒ 若沿用通用规则，「本该可制造」的 NV 柱会被**误判违规**（口径错 ⇒ 结论反向）。

🔴 **几何量由 `primitives.qs_device_geometry` 同源导出**（与版图几何共用同一函数 + 同一参数解析），绝不在此重算。

## 4. 账本落点（**零净增锚**）

| 项 | 本档前 | 本档后 | 说明 |
|---|---|---|---|
| 账本 | 495 | **495** | 零净增锚 |
| 严格独立 | 473 | **473** | 不变 |
| 降级 | 3 | **3** | 不变 |
| 自证桩 | 19 | **19** | 不变 |
| CI core | 311 | **312** | +1 门禁 |

**为何零净增锚？**（三条与既有物严格同源，非新独立物理量）

1. **NV 柱柱高 h** = QS-M3 最优色心深度 d\*（账本锚 B476 的物理量）+ 柱顶余量 ⇒ **几何投影，非第二个独立标量**；
2. **腔增强 Purcell 量**（g/κ/γ₁ → F_P）与账本锚 **B18 同物理量** ⇒ 只作器件本体登记；
3. **微波天线几何**与 QS-M1 微波噪声链同源（几何在此，场强/噪声量在 `qs_m1`）。

同 B472–B475 纪律：**宁可少，不越级谎报。**

## 6. 本档另修一处 QS-M3 遗留守卫空转

🔴 **发现**：v0.9.219 顶行把 `run_qs_m3_smoke` 判据数写成「（25 判据）」而**未加 `**` 强调标记** ⇒ `run_webui_pm_render_path_smoke` 的 W10 正则（`` `run_x` **N 判据``）**恒不匹配** ⇒ **W10b「当前版本行至少含 1 条可对照条目」当场判红**。

- 该缺陷**未被 QS-M3 的定向门禁覆盖**（W10 族不在 QS-M3 定向跑集内）⇒ 由**全量 CI 照妖镜**抓出（**定向全绿 ≠ 无债**，又一实证）。

- **通则**（重申）：README 顶行声明的每个 `run_*` 判据数都必须在 `_W10_EXTRA` 内，且必须是 `**N 判据**` 形式（缺 `**` ⇒ 正则失配 ⇒ W10b 红）。

## 7. 诚实边界与未竟项

### 诚实边界

- 器件几何为**设计示例**（柱径 0.30 µm / 柱高 ≈ d\*+0.12 / 腔周期 320 nm / 环半径 20 µm），可制造性规则为**工艺常识建模**，**非**任何 foundry 的真实金刚石/悬浮工艺 deck。
- 🔴 本档**不做**任何器件级性能宣称（灵敏度 / Purcell 增强 / 自旋相干时间），**不宣称**「已达国际水平」。
- 🔴 单位红线：腔孔周期/半径以 nm 输入，可制造性派生量一律换算 µm（DRC 限值同为 µm 口径）。

### 未竟项（登记）

- **G5 已闭合**（几何 + 工艺 + PDK 三半齐备）。
- 器件本体为**单一器件**级别；**阵列级**（多 NV 柱阵列 + 寻址 + 集成读出）未建 ⇒ 候选后续档 **QS-M4（阵列化 / 系统集成）**。
- 光子晶体腔的 **Q 因子 / 模式体积 V** 未作物理建模（本档只给几何）⇒ 若需器件级 Purcell 增强宣称，须先建 Q/V 物理链（候选 **QS-M3c**）。
