LLM 不进判决路径 —— PASS/FAIL 一律由解析闭式 / 麦克斯韦确定性死标量比对；智能体客服仅对话，求解/判决由内核与 harness 完成。 🔴 登录闸门 + 租户隔离 + 并发护栏 —— 重计算须登录（store 会话或 Bearer）；公开写端点 IP 限流 10/10min；逐端点串行锁 + 全局并发封顶（≤4）+ 参数哈希缓存。 🔴 A/B/C 主权分级 + 出口管制 —— A 级主权永不借；外部 ORACLE 子进程隔离（GPL 不进核心）；量子货架咨询制（出口管制合规红线）。 🔴 诚实边界 —— 自证桩不假绿（candidate≡golden 仅回路闭合）；规模缺口如实标注（R2/R3/R4/R15）；对外账本动态推导、不写死数字。 🔴 部署链路 —— 本地 → 三端同步(gitee/github) → CI 护栏 → 生产 root@115.191.20.92:3006（lda.weomnitech.com.cn）。详见《部署拓扑图》。
