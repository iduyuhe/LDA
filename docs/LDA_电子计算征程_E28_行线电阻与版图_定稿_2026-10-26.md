## 1. 物理基础：两条精确不变性

```
R = ρ·L/(W·t) ≡ R□·L/W,   R□ = ρ/t
C' = ε₀·ε_r·W/d
```

| 不变性 | 实测 | 推论 |
|---|---|---|
| **`C` 与金属厚度 `t` 无关** | 5 层（M1→RDL）C 全为 **0.220996 fF**，偏差 **0.00e+00** | **换层是纯收益**：R↓ 而 C 完全不动 |
| **`R·C` 与线宽 `W` 无关** | 4 档 W 全为 **0.111382**，偏差 **2.49e-16** | **加宽只换静态 IR**，代价是动态功耗 ∝C |

🔴 这两条是本段全部结论的承重墙，**都写成了判据**（探针：让 C 依赖 t ⇒ 必红）。

> 保守处理：真实厚金属的 ILD 通常更厚 ⇒ `C` 会更低，本题**不占这个便宜**（按不变处理）。

## 2. 三条降阻路径（各自的物理与代价）

| 路径 | 手段 | `r` 收益 | 代价 |
|---|---|---|---|
| **A** | 换更厚的金属层（M1 t=0.20 → RDL t=2.00） | **×10** | via stack + 额外掩模（工艺成本） |
| **B** | 加宽线宽（W 0.40 → 0.80） | **×2** | `C` ×2 ⇒ 动态功耗 ∝W；**RC 不变** |
| **C** | 双端驱动 | **×4**（IR ∝ N²/8 vs N²/2） | 驱动器 ×2 + 左右边界路由通道 |

### 双端驱动的推导

```
单端最坏（远端）：Σ_{m=1..N} m·r·I      ≈ rI·N²/2
双端最坏（中点）：Σ_{m=1..N/2} m·r·I    ≈ rI·N²/8
                                        ⇒ r_eff = r/4
```

## 4. 代价必须同屏（本段纪律）

## 5. 我在本段自己踩的两个坑（都被判据当场抓住）

### ① 锚值不得取显示精度

门禁里按 `%.2f` 的显示值硬写 `AN_SHARES = [0.09, 0.24, ...]`，
而实际第一个值是 **0.0942**（行线份额）⇒ 相对差 **4.67%** > 3% 容差 ⇒ B8 当场红。

⇒ **硬编码锚值必须取 ≥4 位有效数字**，不能用显示格式反推。

### ② 推荐口径必须写成显式可判定约束

第一版判据要求「推荐方案 C 代价 = 1.0（零代价）」，而推荐规则是「C ≤ 2.0」——
**判据与实现不一致**，`best_plan` 返回 `abc08`（C×2）而判据期望 `ac`（C×1）⇒ 当场红。

⇒ 改成两项显式约束（`C ≤ 2` 且 `份额增量 < 2pp`），并**不再用"纯收益/零代价"这类无法判定的词**。

> 这与项目的"**判据必须可判定**"一致：`零代价` 不是可判定的量，`C ≤ 2.0` 才是。
