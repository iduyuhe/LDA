⑤ LDA 能算什么

  • 1D MOS 电容自洽泊松（ψ(x)/Q_s/V_g/V_th）· 前提：ψ_s 在数值窗口内
  • 教科书闭式 ⟷ PDE 交叉验证（V_th · Q_s 跨点）
  • 长沟道平方律三区特性 / 小信号 gm·gds（`ecore/mosfet.py`）
  • 体效应（V_th 随衬底偏置的经典 √ 式，长沟道）

⑥ LDA 算不了什么（诚实登记）

  • 短沟道 V_th roll-off 需 2D MOS 求解器（本平台无）
  • DIBL 需 2D 横向势垒调制
  • 速度饱和 / 高场输运 需 v–E 关系 + 高场求解
  • 迁移率退化 需 垂直场相关 µ_eff（经验 θ 标定）
  • 工艺角 / PDK 标定 / 良率 需 foundry 数据（**T2 永久锁**）
