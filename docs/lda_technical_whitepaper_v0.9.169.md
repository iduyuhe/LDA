## 0. 摘要

LDA（Lightwave Design Agent）是对标商业 EDA 的**开源、Agent 原生**光子设计自动化（PDA）+ 量子 EDA（QEDA）+ **电子模拟计算核（ecore）** 三栈等价物。它把三件事作为第一性原则，而不是事后补丁：

1. **验证可证伪**——判决落「非 AI ground」（物理定律锚 + 实证大数据锚），LLM 不进判决路径，PASS/FAIL 由死标量比对定。
2. **Agent 原生**——设计、接线、回归、文档由 AI 自写与自驱，但核心求解与判据主权自主。
3. **主权自主**——A 级能力永不借外部依赖；B 级借今踢后；C 级第一天自主（纯 numpy/scipy）。

本文给出 LDA 的技术架构、核心账本、验证方法论、主权纪律，并与全球主流光子 / 量子 / 模拟计算 EDA 工具做**技术侧对比与排名**（数据截至 2026-10，含 Web 检索与 LDA 内部运行账本实测）。

**一句话定位**：LDA 不是「又一个光子布局库」，而是把**验证锚的独立性**和**主权自主**作为架构约束的开源芯片设计平台；并率先切入全球尚无标准工具的 **L6 层——模拟/光子计算架构编译**（算法 → 光/模拟硬件映射）。

| 维度 | LDA 的立场 |
|------|-----------|
| 对标 | 商业 EDA（光子布局 / 仿真 / 验证 / 模拟计算）的开源等价物 |

## 4. 验证方法论（不可逾越的红线）

**判据落非 AI ground**：

- **物理定律锚**（B 类）：由麦克斯韦方程 / 量子力学 / 半导体物理第一性原理死标量比对（`_PHYSICAL_LAW` 覆盖至 B458）。
- **实证大数据锚**（E 类）：由大规模实证数据集 / 公开文献（DOI/arXiv/公开 URL）比对。
- **系统级锚**（S 类）：由系统级一致性约束比对。

**LLM 不进判决路径**：

- 客服 Agent、文档生成、接线建议可由 LLM 驱动，但 **PASS/FAIL 由死标量比对定**，LLM 输出不参与判决。
- 自证桩判据 = 残差≡0 且扰动无响应（基线取候选自身）；须双向标定（判据 D）防假独立。
- 不等式锚一律 `cmp='le'`；一律 `spec.compare_fn`，禁裸 `abs`。
- **外部对标四层纪律**：① 科学原理闭式 = golden ② 实测事实（DOI/arXiv/公开 URL，方法学独立 + 不拟合回算）= golden ③ 仿真/计算值 ⛔ 永不作 golden ④ 标准 = 接口/限值 ✅ 可用。

**已知不可接（按纪律冻结，不重试）**：S1–S6 · S9–S12 · E1/E3–E7 · B2 · B11 · B16/B17/B18/B21 · B5/B6/B7（ORACLE 锁）。

## 5. 主权与依赖纪律

| 级别 | 含义 | 代表 |
|------|------|------|
| **A 级** | 永不借外部依赖 | 核心求解 / 判据（主权红线） |
| **B 级** | 借今踢后 | gdsfactory / KLayout / SAX；Tidy3D 仅外部 ORACLE |
| **C 级** | 第一天自主 | 自有版图 / 接线 / 回归（纯 numpy/scipy） |

- **Meep = GPL v2+ 已隔离**：通过 subprocess 只回标量，不污染 LDA 代码库（GPL 传染性被阻断在进程边界）。
- **Tidy3D = 仅外部 ORACLE**：作为基准 oracle 调用，不进 LDA 自身判决路径。
- **Foundry TCAD = T2 真值锁死**：无 foundry 数据，不消费、不拟合回算。
- `lda_solver/redline.py` 单一真源（`T1_OUTPUT_IS_ORACLE=False`）；`four_layer_redline_gate.py` S9 四层立项闸门（G1 主权 / G2 LLM 不进判决 / G3 VMM 锚 ≥ self_certified / G4 不假报 strict）。

## 8. 电子模拟计算核（ecore · E1–E19 闭环）

LDA 不只在光/量双栈，还把「**模拟矩阵乘计算核（MVM 交叉阵列）**」作为电子征程主线，对标 Mythic 类模拟存算，路线为纯标准库、主权自主。

| 段 | 内容 | 关键结论 |
|----|------|---------|
| E1–E5 | 电路级（MOSFET / MNA / 模拟 MVM / 交叉阵列 / 数据通路） | 参考列是输出列；MNA 地节点钉扎 |
| E6 | 版图签核（首出真 GDS） | 主权 GDS 实证 |
| E7 | 寄生后仿 | 寄生 RC 闭环 |
| E8 | 失配/噪声/校准 | 接 E8 失配（Pelgrom） |
| E9 | 规模压力 | 1024² 86.6KB · 压缩比 3571× · 上界 5% ⇒ N≤18 |
| E11–E14 | 器件层（MOS 1D/2D/PDE/输运）+ 外设（DAC/ADC/行驱动） | 器件层撞物理模型墙（物理窗口/数值窗口=0.835）；产业层 T2 永久锁 |
| E15–E17 | 系统层（端到端误差预算 / 权重编程 / 时序） | 8×8 有效 4.622 位 · MLC 6 位 4.2445 位 · 8×8 129.565ns ⇒ 7.7181MSa/s |
| E18–E19 | 面积维度（列侧共享静态+动态代价） | 单列 CDAC 128000µm² vs 64×64 阵列 23302µm²；面积-时间积守恒 |

> **红线**：ecore 仍**不报 TOPS / TOPS-W / fJ / op**。规模墙是精度墙不是速度墙；系统层 5 格无硬天花板。

## 10. 路线图与诚实边界

**C 期未做（诚实披露）**：

- 真实 foundry PDK 准入 / 一次真实流片闭环 / 与国际标准工具互操作深度 —— 属 C 期或外部阻塞，当前未做。
- 横向交叉验证网目前仅 DC coupler 一格，扩建为跨器件族 N 格是明确工程路径。
- 已知不可接清单按纪律冻结，不重试。

**战略主线（下一步）**：

- **L6 模拟/光子计算架构编译**：以 ecore MVM + 光子 MESH4/8 为基元，拼出「光子/模拟 AI 加速器参考设计」——全球无标准工具的层，谁先立谁定义标准。
- **交付闭环 D3→D4**：设计→GDS→签核→下载单路径打通，能力变成可交付物。
- **生态互操作**：gdsfactory/SAX/KLayout 导入导出，主权闭环变行业可消费。
- **GPU / PLC / MCU 命题改写**（详见商业计划书 §7）：不做全数字 GPU/MCU（错 domain、无 PDK、无数字 P&R）；改写为「光子 GPU（光子/模拟 AI 加速器）+ 平面光波导电路 PLC（PDA 本命）+ 边缘 AI 混合信号 MCU 子系统（延伸 ecore）」。

## 11. 结论

LDA 不是又一个光子布局库，而是把「**验证可证伪 + Agent 原生 + 主权自主**」作为第一性原则的开源 EDA 新范式。它在光子侧对标 gdsfactory/Luceda/Lumerical，在量子侧对标 Qiskit/PennyLane/QuTiP，在电子模拟计算侧对标 Mythic 类存算，但差异化不在求解精度（当前成熟度仍低于商业标杆、尚未流片），而在**架构维度的结构性空白**——验证锚独立、LLM 不进判决路径、主权不可被 A 级依赖绑架，并率先切入 L6 模拟/光子计算架构编译。

对采用者的建议：把 LDA 当作**验证可信度 + Agent 原生工作流**的底座，把商业求解器（Lumerical/Tidy3D）作为外部 ORACLE 基准，而非黑盒真理来源。
