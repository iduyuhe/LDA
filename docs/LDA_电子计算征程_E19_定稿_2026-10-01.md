## 一、为什么必须做（缺口取证）

E18 补上了全仓此前**完全没有建模**的「面积」维度，并自点名（G-S 诚实边界）留下一个缺口：

> 「共享的**动态代价**（多路开关电荷注入 / 串扰 / 采样孔径抖动）**未建模**」

E18 的口径是**纯静态**：它算清了共享的**面积-时间乘积守恒**、**保吞吐 ⇒ 面积 ∝ 1/K²**、拐点 `K*=160`，但**只覆盖静态 + 面积/周期估算**—— 没有把「复用一个多路开关去驱动 K 列」这件事带来的**动态非理想**算进去。

E1–E17 全仓 `charge_injection` / `clock_feedthrough` / `aperture_jitter` / `switch_settling` 在 `lda_l2/ecore/` **零命中**（失配/噪声只在 E8 的器件级 Monte Carlo 里有，列侧读出开关未接）。

⇒ **「共享开关的动态代价到底是什么、会不会造新墙」这个 E18 自己承认没答的问题，本轮答掉。**

## 三、三大动态代价量化

### ① 复用开关电荷注入 + 时钟馈通 = 确定性 pedestal（可校准）+ Pelgrom 随机残差

开关关断瞬间沟道电荷注入采样电容，且时钟通过栅漏重叠耦合：

```
Q_inj      = α · (C_ox·W·L) · V_ov              （α=0.5 对称分配经典模型）
ΔV_inj     = Q_inj / C_s
C_gd       = W · C_ox · L_ov                     （栅漏重叠）
ΔV_ft      = C_gd / (C_gd + C_s) · ΔV_clk         （时钟馈通）
pedestal   = ΔV_inj + ΔV_ft                       （确定性 · 可单点失调校准消除）
```

随机残差（校准后幸存，Pelgrom 口径）：

```
σ_ΔVth  = A_VT / √(W·L)
σ_ped   = α · (C_ox·W·L) / C_s · σ_ΔVth          （1σ）
```

**本轮实测（W/L=500 ⇒ W=50µm · L=0.1µm · C_ox=8.6 fF/µm² · C_s=1 pF · V_ov=2.6 V · L_ov=0.05µm · ΔV_clk=3 V）**：
- 确定性 pedestal ≈ **119 mV ≈ 11.9% FS**（大，但**确定性 ⇒ 可单点校准剔除** ⇒ **不进精度预算**，与 E16「共模漂移可被单次全局校准消除」同口径）；
- Pelgrom 随机残差 σ_ped ≈ **28.9 µV ≈ 0.003% FS**（≪ kT/C=64 µV ≪ LSB=3.9 mV）⇒ **不是墙**。

⇒ 🔴 **诚实结论 ①**：电荷注入的**真成本不是精度，是校准负担**（N 列需 N 次失调校准）；其随机残差可忽略。

### ② 采样孔径抖动 σ_v = 斜率 · σ_t（地板仍是 E18 的 kT/C）

采样开关在抖动 Δt 上开启，满量程正弦最陡斜率 ⇒ 最坏电压误差：

```
σ_v_jitter = π · f · V_ref · σ_t          （σ_t = 时钟抖动 rms）
```

**本轮实测（σ_t=1 ps · V_ref=1 V · C_s=1 pF）**：
- 参考带宽 100 MHz ⇒ σ_v ≈ 314 µV ≈ 0.031% FS（**已越过 kT/C=64 µV，但远低于 LSB=3.9 mV**）；
- 🔴 **越过 kT/C 的频率** `f_ktc ≈ 20.5 MHz`（此后抖动成为**主导噪声源**，但仍非精度限）；
- 🔴 **越过 LSB 的频率** `f_lsb ≈ 1.24 GHz`（此时才成为绑定精度限）。

⇒ 🔴 **诚实结论 ②**：孔径抖动在**低/中带宽被 kT/C 与 LSB 埋住**，仅当输入带宽 >~20 MHz 才越过热噪地板、>~1.2 GHz 才越 LSB ⇒ **条件性，非墙**。且因 `σ_v` 与 C 无关，而共享（尤其保吞吐）**抬高了 kT/C 地板** ⇒ 抖动**相对更显著**（反相关于 E18 静态收益，与③同族）。

### ③ 多路开关建立时间对吞吐的侵蚀（复用 E14 R_on · E17 建立律）

K 列共享一套 ADC，每次切换多路开关须先把采样节点（固定采样电容 `C_s`）建立好：

```
τ_mux      = R_on_mux · C_s
t_mux      = settle_half_lsb(τ_mux, bits)    （复用 E17 G-2）
```

`R_on_mux=6.41 Ω · C_s=1 pF ⇒ τ_mux=6.41 ps ⇒ t_mux ≈ 40 ps`，相对 `T_conv(1)=92.1 ns` 仅 **0.043%**。

🔴 **关键不对称性**（E18 静态模型此前漏计）：`C_s` 是**固定绝对**采样电容（与 CDAC 共享无关），故 `t_mux` 不随 K 缩小：
- **plain 共享**（不保吞吐）：每列周期 `K·(T_conv(1)+t_mux)` vs E18 基线 `K·T_conv(1)` ⇒ 侵蚀 **恒定 0.043%**（可忽略）；
- **保吞吐共享**（C_tot 同比降 K，吞吐保住）：每列周期 `K·(T_conv(1)/K + t_mux) = T_conv(1) + K·t_mux` vs E18 基线 `T_conv(1)` ⇒ 侵蚀 **∝ K**，**在 K*=160 处达 ≈ 6.95%**。

⇒ 🔴 **诚实结论 ③**：多路开关建立是 E18 静态模型**此前未计的真实动态代价**；在激进保吞吐共享下回升到 ~7% 每列周期，**反相关于 E18 的面积收益**—— 这是 E19 给出的**唯一新的、非平凡的动态代价**。

## 五、诚实边界（写进模块披露）

## 七、E19 总诚实结论（闭合 G-S）

在可达共享度内，三项动态代价**都不是精度墙**：① 电荷注入的确定性 pedestal 虽大但**可校准** ⇒ 不进精度预算，随机残差可忽略（真成本=校准负担）；② 孔径抖动仅在高带宽（>~20 MHz）越 kT/C、>~1.2 GHz 越 LSB，**条件性**；③ 多路开关建立是固定绝对开销，plain 共享下可忽略，**保吞吐共享下随 K 回升、K* 处 ≈7%**—— 这是 E18 漏计的真实动态代价，且反相关于 E18 面积收益。

⇒ **共享的真实新代价 = 「保吞吐共享的开关建立开销」+「高带宽孔径抖动」；二者都反相关于 E18 静态收益，但都不造新墙**（不硬造精度腿 / 不报 TOPS）。E18 主线收口成立。
