## 1. 本档定位（吃狗粮第二档）

QS-M0 交付了「NV 色心磁力计**最小闭环**」——能把一款量子磁力计**设计出来**，
灵敏度 η 算得出一个数（0.847 nT/√Hz 设计点）。

QS-M1 要解决的是**下一层问题**：一个「数」不足以支撑设计决策。工程上真正要回答的是
**「换一组 FOM 参数，灵敏度怎么变？哪条路径可信？这个数与什么口径对齐？」**。
故本档把灵敏度从**单标量**升级为**可比较、可溯源的 FOM 体系**。

| 维度 | QS-M0 | QS-M1 |
|---|---|---|
| 输出 | 一个 η 数 | **四情景 FOM 表**（baseline/cited/degraded/bench） |
| 口径 | 文中注明「η=δB√T」 | **机器强制**（`SENSITIVITY_CALIBER` + `assert_caliber`） |
| FOM 输入 | T₂*（单一） | **三独立可测量**（对比度 / 线宽 / 光子计数率） |
| 交叉验证 | 闭式 ↔ 数值（相位域） | **T₂* 路径 ↔ 线宽路径**（跨物理域） |
| 平台缺口 | G1/G2 | **G3 量子传感指标求解与报告** |

## 2. 🔴 统一口径（全征程唯一真源）

**η = δB·√T**，单位 **T·Hz^(-1/2)**（白噪声**幅度谱密度**）。

```python
SENSITIVITY_CALIBER = "eta_dB_sqrtT__amplitude_spectral_density__T_per_sqrtHz"
```

- **禁与线宽受限 LOD 混比**（LOD 单位 T，是单点分辨力，不是谱密度）——PS 征程血案：
  两口径混比 ⇒ 余量判断反向。
- `assert_caliber()` 在**报告前强制自检**：传入非本口径常量即 `ValueError`（反向探针实证）。
- **逐项标注条件**：本档全为**室温 300K · DC · 单点 · per√Hz**（`MEASUREMENT_CONDITIONS`）。

## 3. FOM 体系：三条独立可测量 → 散粒噪声极限

量子磁力计的灵敏度由三条**能直接测量**的 FOM 决定：

| FOM | 符号 | 本档取值来源 |
|---|---|---|
| 条纹对比度 | C | Ramsey 幅度（无量纲，0<C≤1） |
| 频域线宽 | σ_f | 对比度包络 `C(τ)=e^(−(τ/T₂*)²)` 的频域高斯宽度 |
| 光子计数率 | n_ph | 荧光光子率（光子/秒） |

**散粒噪声极限**（闭式）：

```
η = ħ/(gμB) · √(1+a²) · √2 / (C · √(n_ph · T₂*))     [T/√Hz]
```

线宽与相干时间**双向互解**（高斯对偶）：

```
σ_f = √2/(2πT₂*)    ⇔    T₂* = √2/(2πσ_f)
```

## 4. 四情景 FOM 表（本档现算）

| 情景 | T₂* | C | n_ph | η [pT/√Hz] | 含义 |
|---|---|---|---|---|---|
| **baseline** | 1 µs | 0.03 | 1e5 | **846.59** | QS-M0 设计点（本征散粒极限） |
| **cited** | 10 µs | 0.10 | 1e6 | **25.40** | 公开文献量级（**对标准星**，非 LDA 实测） |
| **degraded** | 0.1 µs | 0.01 | 1e4 | **25429.43** | 含微波展宽 + 磁场不均匀降级 |
| **bench** | 1 µs | 0.03 | 1e5 | **846.59** | 反向探针专用 |

单调性（机器守）：T₂*↑ ⇒ η↓ · C↑ ⇒ η↓ · n_ph↑ ⇒ η↓ · a↑ ⇒ η↑；
情景序：degraded **劣于** baseline（25429 ≫ 846）· cited **优于** baseline（25.4 ≪ 846）。

## 5. 锚 B474（**严格独立**）

| 项 | 值 |
|---|---|
| 编号 | **B474**（Batch B-40） |
| golden | 散粒极限闭式（**T₂* 路径**）`fom_sensitivity_golden` |
| candidate | **数值线宽提取链**（**线宽 FOM 路径**）`fom_sensitivity_cand` |
| 默认参数 | T₂*=1e-6 / n_ph=1e5 / C=0.03 / a=0.0（`B474_DEFAULT_PARAMS`） |
| 判据 | \|Δ\| = **2.344e-15** · rel = **2.769e-06** · tol=1e-3 的 **361× 余量** |

**方法学独立**（非「同式异写」）：

- golden：直接代数代入 T₂*（T₂* 路径）；
- candidate：**不以 T₂* 解析式代入 η**，而经
  「时间域对比度包络 → **数值 FWHM 提取** → σ_f → 反解等效 T₂*' → 合成 η」逐步数值链。

残差 2.769e-06 由**网格离散化**引入（非机器精度 1e-16），逐参数点稳定复现。

**🔴 与 B473 不同物理量（非重复计数）**：B473 候选走**相位域**（相位噪声率 ρ_φ +
复指数演化核数值差商）；B474 候选走**时间/频域**（对比度包络 FWHM 数值提取）。
两锚方法学互不重叠。

## 6. 🔴 诚实收敛（吃狗粮纪律）

宁可少，不越级谎报）。本批如实只登记 **B474 一锚**。

## 7. 常驻门禁 `run_qs_m1_smoke.py`（入 CI core）

**17 判据**：

- `selfcheck_qs_m1` **12 项**：口径自检 / 口径反向探针（混入 LOD 必被拒）/ 双路径一致
  （rel<1e-9）/ 单调性 ×3 / 情景序 ×2（degraded 劣于 baseline、cited 优于 baseline）/
  反向探针 ×3（零对比度发散、零光子率发散、零线宽抛异常）/ 暗计数劣化；
- **锚接线复核 5 项**：B474 入 `BENCHMARK_ORDER` / golden 有限 / `candidate_responds` /
  within tol / **非代数恒等**（rel>1e-12）。

🔴 **锚接线复核是 QS-M0 血案的常驻防线**：「账本登记了」≠「候选链接上了」。
`run_qs_m1_smoke` 直接 import `_b474_qs_fom_linewidth_cand` 现算 `candidate_responds`，
任何「登记了但没接上」的静默漏都会被当场判红。

纯 numpy（无 scipy 泄漏），实测 <2s ⇒ 入 core；`_BUILTIN_TIMEOUT_OVERRIDE` 300s。
