## 一、为什么必须做（缺口取证）

E1–E17 建起了**精度链**（E15）、**写入链**（E16）、**时间链**（E17），但**列侧读出电路（TIA + ADC）始终是「每列一份」**：

| 位置 | 现状 |
|---|---|
| `crossbar_mvm.CrossbarMVM` | `amp='ideal'` ⇒ **每列一个理想运放（VCVS）** 做 TIA |
| `mvm_datapath.AnalogMvmUnit` | 输出定标按列 ⇒ 隐含**每列一个 ADC** |
| `converter.sar_convert` | SAR/CDAC 是**单通道**模型（一次服务一个输入） |
| `layout.array_footprint` | 只算**阵列本体**足迹（18×18.5 µm² @ 8×8）—— 列侧读出**完全不进面积** |

**全仓检索**：`share` / `mux` / `multiplex` / `复用器` / `时分` 在 `lda_l2/ecore/` **零命中**（唯一 `share_pct`/`share_periphery` 是 E15 的误差份额，语义无关）。
⇒ **「列侧电路能不能共享、共享的代价是什么」这个架构问题，此前无人能答。**

**量级预估（本轮实测）**：`CONV_PROCESS` 的 `c_unit_f = 1 pF`、8 bit ⇒ `C_tot = 256 pF`；
按 MIM 电容密度 2 fF/µm² ⇒ **单列 CDAC 面积 128 000 µm²**，
而 8×8 阵列本体足迹只有 **333 µm²** ⇒ **单列读出是阵列的 384 倍**；N=8 全并行读出 **1.03 mm²** = 阵列的 **3090 倍**。
⇒ **在二进制 CDAC 口径下，列侧读出电路压倒性支配芯片面积** —— 这正是「为什么必须共享」的量化论据。

## 三、核心第一原理：面积-时间乘积守恒（不保吞吐）

设每个转换器面积 `A_u`、每次转换周期 `T_conv`、N 列：

- **全并行**（K=1）：面积 `N·A_u`，每列周期 `T_conv`
- **K 列共享一套**：面积 `(N/K)·A_u`，每列周期 `K·T_conv`

⇒ **`A_total × 每列周期 = N·A_u·T_conv = 常数`（与 K 无关）**

**共享只沿「等面积-时间双曲线」移动，不改变乘积。**（同 E17「时间按拓扑合成」的地位：本段的第一原理。）
要突破这条双曲线，只有两条路：**① 缩短 `T_conv` 本身**；**② 复制瓶颈级（反向）**。

## 四、第二原理：保吞吐共享 ⇒ 面积 ∝ 1/K²（不是 1/K）

若要**共享 K 倍同时保住吞吐**，必须把 `T_conv` 缩短 K 倍。由 E17 G-5：

```
T_conv = (bits+1)·t_clk,   t_clk ≥ R_on·C_tot·(bits+1)·ln2
⇒ T_conv ∝ C_tot·(bits+1)²
⇒ 缩 T_conv 的唯一物理路径 = 降 C_tot（降 CDAC 电容）：C_tot(K) = C_tot(1)/K
```

⇒ 面积闭式（**双项**）：

```
A(K) = (N/K)·( C_tot(1)/(ρ·K) + A_logic )
     = N·C_tot(1)/(ρ·K²)  +  N·A_logic/K
       └── 电容项 ∝ 1/K² ──┘   └── 逻辑项 ∝ 1/K ─┘
```

⇒ 🔴 **保吞吐共享时，面积 ∝ 1/K²**（而不是不保吞吐时的 1/K）。
**拐点** `K* = C_tot(1)/(ρ·A_logic)`：`K < K*` 电容项支配（1/K² 收益显著）；`K > K*` 逻辑面积支配（退化为 1/K）。
8 bit / 1 pF / 2 fF·µm⁻² / 800 µm² ⇒ **`K* = 160`**。

## 五、第三腿：精度（诚实结论 —— kT/C 在可达共享度内**不是**约束）

降 `C_tot` 的代价是采样热噪声 **`σ = √(kT/C_tot)`（物理律）** ⇒ 位数上限 `log2(V_ref/(k_σ·σ))`。

```
bits_ceiling(K) = log2( V_ref / (k_σ·√(kT·K/C_tot(1))) ) = ceiling(1) − 0.5·log2(K)
```

8 bit / 1 pF / 300 K / k_σ=3 ⇒ `bits_ceiling(1) = 17.92` ⇒ 要跌到 **8 位**需
**K_crit ≈ 1.05×10⁵** ⇒ **远超任何合理共享度**。

⇒ 🔴 **诚实结论：在「纯二进制 CDAC + CDAC 电容支配面积」口径下，kT/C 不是本架构的实际约束；
共享的真实代价是「吞吐」而非「精度」**（精度腿是**很远的渐近地板**，给出公式与交叉点即可，不硬造）。

## 七、诚实边界（写进模块披露）

面积是**宏模型占位**（ρ=2 fF/µm² · A_logic=800 µm² · A_tia=400 µm² 为公开量级，**非 PDK**）；
真实芯片用分段 CDAC / 更小 C_u / 采样电容共享 ⇒ 面积远小于此；**只覆盖静态**（不含动态功耗 / 时钟树 /
供电网络 / 驱动器面积）；**不做功耗估算 ⇒ 不谈能效**；共享的**动态代价（多路开关电荷注入 / 串扰 /
采样孔径抖动）未建模**；**不报 TOPS / TOPS-W / fJ/op**。
