## 1. 缺口原文与拆法

`pm_case.PM-G9` 全文：

> PD 响应度（A/W）/ 加热器薄膜方阻（Ω/sq）取**公开工程典型区间**（非实测、非逐条 DOI 复核）；
> 读出速率 / 输入光功率 / 驱动摆幅 / EIC 通道 pitch 为**设计假设** ⇒ 外设结论只给
> **区间 + 恒等式 + 单调性**，**无绝对真值**。

这句话把三件性质不同的事压成了一句：

| 成分 | 性质 | 本轮判定 |
|---|---|---|
| 「区间取公开典型」 | 数据来源问题 | 不改区间（改区间才是编数据）⇒ 但**可以核验它合不合法** |
| 「非实测 / 非逐条 DOI」 | 取得数据的活 | **边界** ⇒ `PM-G9b` |
| 「⇒ 无绝对真值」 | **推理**（且未验证） | **纯建模** ⇒ `PM-G9a`，本轮做掉 |

关键是第三行：它是一个**未经检验的推理**。本版逐条检验，结论是**它对一部分结论成立、对另一部分不成立**。

## 2. ① 区间能否通过物理核验

响应度与量子效率有严格恒等式：

```
R = η·q/(hν) = η·λ / 1239.841984        （λ 用 nm，h·c/q = 1239.841984 eV·nm）
```

两个直接后果：

**硬上限**（令 η = 1）：

```
R ≤ λ/1239.84 = 1550/1239.841984 = 1.250159 A/W     @1550 nm，无内部增益
```

**区间核验**：锚区间 `(0.8, 1.0)` 反解

```
η = R·1239.84/λ  ⇒  η ∈ [0.63992, 0.79990]
```

⇒ 三项全过：量纲一致、`η ⊂ (0,1]`、距物理上限还有 **25.0%** 余量。
**这个区间不是随手取的**，它有物理含义（InGaAs PIN 的公开工程口径）。

**反向探针（T3）**：任何「1550 nm、R = 1.3 A/W」的声明 ⇒ η = 1.040 > 1 ⇒ **可证不可能**
（除非是 APD，那要另写 `R = M·η·λ/1239.84` 并背过剩噪声因子 `F(M)`）。

## 3. ② 不确定度到底进不进结论

读出链里（`pm_m4.readout_chain`）：

```
信号  ΔV_j ∝ Z · R · P_in · ΔT_j
噪声  σ²   = 2q(R·P_in·T)B + 4k_B T B / R_f
```

**两处都只经由乘积 `u ≡ R·P`**（热噪声项与二者无关）。于是 SNR 是 `u` 的**单变量函数**：

```
SNR(u) = u / √(2qBu + 4k_BTB/R_f)
```

三条可判定的后果，全部在**真实链路**上实测（不是另写玩具公式）：

| 判据 | 内容 | 实测 |
|---|---|---|
| T4 | `SNR(2R, P/2) ≡ SNR(R, P)` | 相对差 **0.0** |
| T5 | `P_min(R)·R ≡ u*(BER 目标)` | 三档相对离散 **8.5e-12** |
| 自检 ⑧⑨ | `P* = 2k_B T/(q·R·R_f)`：散粒≡热 ∧ **与带宽无关** ∧ `P* ∝ 1/R` | `P* = 3231.5 nW` |

**容差不是"差不多"**：二分在 `[1e-9, 1e-2]` 上迭代 52 次 ⇒ **绝对**分辨率 `1e-2/2^52 ≈ 2.2e-18`，
而 `p_min ≈ 1e-7` ⇒ **相对**分辨率 ≈ `2.2e-11`。判据只能测到这个量级，取 ≤1e-9 已是工程极限。

⇒ **「无绝对真值」对这三条不成立**：R 的 25% 不确定度只让**所需读光功率**同比例变 25%
（`P_min(1.0)/P_min(0.8) = 1/0.8`），**不改变任何定性结论**。

## 4. ③ 本版最意外的发现：`worst_pair` 是退化标签

原本想证「最坏判决对与 R 无关」。实测反过来：

M1 的 16 档透射率是**等分线性**阶梯（`T_j = T_0 + j·ΔT`，相邻差恒为 `ΔT`），
而 `readout_chain` 对**所有**判决对用**同一个** `σ_V`（取最低电平那一行的噪声）。于是

```
ΔV_j = Z·R·P_in·ΔT      ← 与 j 无关
⇒ 15 个判决对的 SNR 完全相同（实测相对离散 8.9e-15，纯浮点噪声）
```

`readout_chain()["worst_pair"]` 是 `min()` 在 15 个**并列值**里挑 ⇒ 挑中哪个由浮点噪声决定：

| R (A/W) | `worst_pair` | 该对 SNR |
|---|---|---|
| 0.8 | `(12, 13)` | 5802.4720 |
| 0.9 | `(7, 8)` | 6429.8156 |
| 1.0 | `(8, 9)` | 7040.1471 |

⇒ **该字段不可引用为结论**。可引用的结构事实是「所有对同 SNR」（判据 T6 锁死）。
这是「比值判据抓不住量级错」的同族：**并列的标签看起来像结论，其实没有信息**。

> 注：不修 `readout_chain` 的 `σ_V` 口径（那是另一个口径问题：等分线性阶梯下相邻电平的
> 光子数不同 ⇒ 散粒噪声本应不同）。本版只**如实标注这个标签退化**，不擅自改链路。

## 5. ④ 方阻只从驱动口径这一个口子进去

`R_h = R_sheet · n_sq`（`n_sq = L_h/w_h = 6.556/0.600 = 10.93`），`R_h ∈ [109.3, 546.3] Ω`。

| 驱动口径 | 关系 | 方阻 10→50 Ω/sq 的结果 |
|---|---|---|
| **电压驱动**（现役 `write_driver`：`P = V²/R_h`） | `P ∝ 1/R_sheet` | 功耗 `19.93 → 3.99 mW`，跨 **5.000×** |
| **恒功率驱动**（电流源 / 闭环调功） | `V = √(P·R_h)` | 功耗**绝对值**；电压 `0.603 → 1.349 V`，跨 **2.2361× = √5** |

⇒ **同一个器件、同一个区间，「有没有绝对真值」的答案不同** —— 这是**口径问题，不是数据问题**。

配套可判定设计界（恒功率驱动下）：

```
R_sheet ≤ V_max² / (P_req · n_sq) = 3.3² / (3.3314e-3 × 10.93) = 299.2 Ω/sq
```

现区间上限 50 只是它的 **1/6** ⇒ **方阻不构成约束**（判据 T7，反解回代给回 `V = 3.300000000000`）。

### 顺带纠一句卡上从未被核过的话

现役 `V_DRV_DEFAULT = 3.3 V` 若**直接电压驱动**，对 `P_π = 3.3314 mW`：

```
P(3.3 V) = 19.93 … 99.67 mW   ⇒  过驱 5.98 – 29.92 倍
```

⇒ 「3.3 V 直驱」在物理上**不能用于写相变**，必须限流 / 调占空比 / 闭环调功。
这不是区间问题，是**可判定的设计结论**（判据 T8）。

而 `GAPS` 从 v0.9.293（加 `PM-G8b`）起就是 **8 条** ⇒ 该判据**一直是红的**。

（`run_pchip_case_smoke` import 的是 `pchip_case`，名字相似但不是同一个模块）。

1. 判据改成**派生**：`card["gaps_total"] == len(GAPS)`；

> **纪律升级**：此前写的是「不在**发布前**子集里的护栏 = 会静默变红」。

## 8. 诚实边界

- `R ≤ λ/1239.84` 的前提是**无内部增益**。APD 可超此界，代价是过剩噪声因子 `F(M)`。
- `P_min·R ≡ u*` 的**精确性**来自「噪声也只经由 `R·P` 依赖」这一点。**一旦加入暗电流**
  （与 `R` 无关的固定项）该律立刻退化为**近似** —— 本层没有暗电流项，所以它是精确的，
  **不能**外推到有暗电流的模型上。
- 不含：模场半径失配 / 波长失配 / 角度失准 / 方阻温系数 / 接触电阻 / 1-f 噪声 / ISI / DSP。
- **不改任何区间、不新增任何锚**：本层只证恒等式与作用域。
- 「±tol 该按 3σ 还是硬极限」这类**约定**问题本层不选；本版只回答「哪些结论不依赖它」。
- `worst_pair` 退化的**根因**（`σ_V` 全局取值）本版只标注、不修 —— 修它要动链路口径，
  那是另一个版本的事。
