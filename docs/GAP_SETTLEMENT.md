## 1. 四值口径（**为什么不是二值**）

| 状态 | 含义 | 是否欠债 |
|---|---|---|
| **已闭合** | 工作做完，证据链可查（如 `soc` G1–G6、`j3` M0–M4） | 否 |
| **已结算** | 问题有裁决、不再挂账，但**能力/证据未必具备**（判不可锚／派生量／净增 0／决定不修，如 `ecore` G-N 极性缺陷「不改 mna + B14 锁死」） | 否 |
| **未闭合** | 确认仍未做 —— **这才是欠债** | **是** |
| **边界声明** | 永久能力边界，本来就不以「做完」为目标（非流片实测／零能效纪律／理想化模型） | 否 |

> 🔴 把「已结算」塞进「已闭合」= 又一次**概念压扁**（同 N3-b 把「限制」写成「深度变浅」）；
> 把「边界声明」当「未闭合」= **把诚实边界记成欠债**，会诱导以后删掉边界声明。

## 4. 结论（比数字更重要）

1. 🔴 **总数是 112，不是 94**。审计 v3 漏了 **18 条**：`j1`(2) / `j3`(4) / `oi`(7) / `accel`(5) —— 前两者模块级无 `GAPS` 常量、后两者只在 `case_card()` 里返回，而审计只扫了模块级常量。
2. 🔴 **域归属修正**：`d1`/`d2`/`d4` 是**量子域蓝图 v2**，审计 v3 把它们算进「光子 36 条」⇒ 光子/量子的真实构成与旧表**不同数**（旧光子 36 = pchip+sensor+pm+soc+d1+d2+d4；新光子 36 = pchip+pm+soc+oi+accel+sensor）。**同数不同构成 —— 聚合数字又一次掩盖了结构。**
3. 🔴🔴 **v0.9.286 修正分类器漏判**：`soc` 的 6 条状态字面写着 `CLOSED（…）`，旧实现只在状态串里找中文「闭合」二字 ⇒ 全部漏判成未闭，台账对外报「已闭 0」。改为**显式词表 + 12 条自测**（四值全覆盖），自测不过生成器拒跑。
4. **真正的欠债只有「未闭合」一列 = 23 条**（不是历史上被当作欠债的 55 条）；另有 32 条是**永久边界**、11 条是**已裁决不再挂账**。⇒ 对外说「112 条缺口」时**必须带分布**，否则会把边界声明读成欠债。
5. ⚠️ **0 条仍未标**：给 `case_card()` 补 `gaps_status`（字符串型 gaps）或元素 `status`（dict 型 gaps）即可机核。**本表拒绝从散文里猜状态**。
