## 零、分层总览（先给结论）

有源器件按"离红线距离 / 验证成熟度"分 **A-1 / A-2 / A-3 / B** 四层：

| 层 | 性质 | 当前状态 | 是否破红线 | 可否立即动手 |
|---|---|---|---|---|
| **A-1** | 已落地的严格独立有源锚 | B15/B28/B29/B30/B33 在库，CI 全绿 | ✅ 不破 | 已闭环 |
| **A-2** | 契约已评审·纯闭式+独立交叉候选 | B31/B32/探测器响应度 R，待写码 | ✅ 不破 | **可立即扩** |
| **A-3** | 契约存疑·待评审定夺 | B34（FSR 疑似 B3 复刻）、激光器线宽（涉有源载流子） | ⚠️ 待定 | 须先裁定 |
| **B** | 真器件物理（激光 L-I / 增益 / 载流子动力学 / 带宽真求解） | 红线结构性封死 | ❌ 撞三不做+A级 | **待决项（拍板）** |

**一句话**：A-1/A-2 现在就能做、不破任何红线；A-3 须先裁定再动手；B 档不是"能力不够"，是**边界外**，留给杜先生拍板是否维持终审锁或划出口子。

## 二、A-2 层 · 可立即扩清单（契约已评审，待写码）

> 共同护栏（来自契约 §共同规范）：纯物理定律闭式 + 独立交叉候选；载流子密度由耗尽近似闭式给、**绝不求解漂移-扩散**；tol=实测偏差 2.2~2.5× 余量；反向 10% 扰动必 FAIL；注册进 `benchmarks.py` + `verification_adapters.py` + 对应 smoke；三分类守恒守护同步。

### 2.1 B31 · Si 载流子色散相移（Soref-Bennett 闭式）
- **物理对象**：PN 结耗尽型 Si 相位调制器，反偏 V→载流子浓度变→折射率变→相移。
- **golden**：Soref & Bennett 1987 (IEEE J. Quantum Electron. 23, 123) 唯象闭式 `Δn_eff = c1·ΔN + c2·(ΔN)² + c3·ΔP_e + c4·(ΔP_h)²`，c1~c4 用文献公认值（禁拟合回算）。
- **独立候选**：Drude 自由电子气 `Δn_eff = −q²·ΔN/(2·ε0·n_eff·m*·ω²)`（微观 vs 宏观，非代数恒等→判据 D 不撞）。
- **红线自检**：ΔN(V) 一维耗尽近似闭式 → ✅ 不破电域求解器。
- **落地动作**：写 `b31_*` 候选函数；ΔN 上限（耗尽近似失效区）标 honest_tier；评审风险① c1~c4 取公认值。
- **优先级**：高（范式成熟，与 B33 同 independent_cross_check 打法）。

### 2.2 B32 · EAM-QCSE 吸收边位移（Kane 闭式）
- **物理对象**：电吸收调制器（FK / QCSE），外加场 F→带边位移→消光比。
- **golden**：Kane 1956 FK 位移 `ΔE_g = (ℏ·e·F)²/(2·m_r*·E_g)`（m_r* 约化质量）。
- **独立候选**：严格 2-band k·p 模型数值积分吸收谱，扫 F 定带边位移交叉。
- **红线自检**：纯电磁/能带闭式 + 数值带结构，无载流子动力学 → ✅ 不破。
- **落地动作**：**先明确器件是体材料(FK)还是 MQW(QCSE)**，否则 golden 选错（评审风险）。
- **优先级**：高（但须先定材料体系）。

### 2.3 探测器响应度 R = ηqλ/hc（新增锚，active_models 已有公式未注册）
- **物理对象**：pin/APD 光电探测器响应度，已见于 `lda/lda_design/active_models.py` 闭式 `R = ηqλ/hc`。
- **golden**：`R = ηqλ/hc`（设计规则锚，η 为外量子效率由 PDK 给）。
- **独立候选**：量子效率链 `η = (1−R_f)·(1−e^{−α·L})·Γ` 解析 vs 经验标定值交叉；或外部 datasheet ORACLE 比对。
- **红线自检**：纯光电闭式，无有源载流子动力学 → ✅ 不破。
- **落地动作**：从 `active_models.py` 抽闭式进 `benchmarks.py`，配独立候选 + tol；与 B33 同属"探测器行为闭环"可一并落地。
- **优先级**：高（公式已存在，纯注册成本最低，凑齐"调制—探测—热调"行为闭环）。

## 三、A-3 层 · 待评审定夺项（须先裁定，勿盲目扩）

### 3.1 B34 · 激光器腔体 FSR（⚠️ 疑似 B3 复刻）
- **golden**：`FSR = c/(2·n_g·L)` —— 与现有 **B3（环形谐振腔 FSR）同源方法学**（频域周期取值）。
- **风险**：若直接新增为独立锚，判据 D 可能判"同性质复刻"→ 虚报独立候选数。
- **裁定选项（待杜先生/锚裁判定）**：
  - **(a) 并入 B3**：在 B3 候选里加 `laser-cavity` 工况（有源腔含增益介质色散），不单列新锚 → 推荐，避免虚报。
  - **(b) 独立**：须证成"新物理对象（有源腔增益色散）"使方法学真正不同源。
- **动作**：未裁定前不写码。

### 3.2 激光器线宽 Schawlow-Townes（⚠️ 边界模糊，已搁置）
- 公式 `Δν = hν·n_sp·(1+α²)/(4π·P·τ_p²)` 含自发辐射因子 n_sp（依赖有源区载流子）。
- **风险**：虽为闭式，但 n_sp 牵连有源载流子 → 边界模糊，可能越界入 B 档。
- **裁定选项（待拍板）**：
  - **(a) 归入 A 档**：视为纯闭式，给定 n_sp 即算（n_sp 作外部输入，不求解载流子）。
  - **(b) 归入 B 档禁区**：因涉有源载流子，维持不做。
- **动作**：上一轮已裁定"先搁置、不急于求成"，待杜先生拍板归属。

## 四、B 档 · 红线待决项（真器件物理，结构性封死）

> 以下每一类都需要**电-光耦合求解器（漂移-扩散 Poisson + 连续性方程）+ Foundry TCAD 工艺 ORACLE + A 级商业工具（Lumerical DEVICE / Sentaurus）**，三条红线同时撞 → 在当前架构下**物理上无解**，非能力缺口。

| 待决项 | 真物理内容 | 撞哪条红线 | 裁定（2026-09-11 分层解锁 §八·电域求解器 §九） | 落地口径 |
|---|---|---|---|---|
| **B-1 激光器 L-I / 阈值** | 速率方程求阈值/斜率效率/L-I 曲线 | 增益介质模型 + A 级 | 受「增益介质模型+A级」约束维持禁区（电域求解器 T1 已解，非约束） | 激光 L-I/增益仍禁；仅闭式阈值估算入口（`I_th≈q·N_th/τ` 给定 N_th）可做 |
| **B-2 SOA / 增益谱** | 增益介质模型 + 行波耦合 | 增益介质模型 + A 级 | 维持禁区（同 B-1） | 不做 |
| **B-3 载流子动力学** | 漂移-扩散真求解（载流子浓度时变） | 原撞 电域求解器+Foundry TCAD（已分层解锁 §九+§八） | **T1 数值内核已解锁** | 经 DEVSIM fork / 自研漂移-扩散内核做，限成熟节点+公开参数+验证纪律不变 |
| **B-4 探测器带宽真求解** | 渡越时间 / 暗电流 / APD 倍增噪声 | 原撞 电域求解器+Foundry TCAD（已分层解锁 §九+§八） | **T1 数值内核已解锁** | B33 维持 RC-limited 闭式；渡越/暗电流/APD 经 T1 内核落地 |

**B 档裁定本质（2026-09-11 杜先生拍板）**：
- **分层解锁落地**：Foundry TCAD 拆 T1（数值内核·可解锁）/ T2（工艺真值·锁死）。T1 解锁前提 5 条铁律见红线澄清 §八。
- **仍锁死项**：封测实体产线 / A 级永不借 / T2 工艺真值 / 验证纪律 / 战略定位 / 不贪多纪律 全部维持；电域求解器 T1 内核已随 Foundry TCAD 合并解锁；激光 L-I·增益·SOA 受「增益介质模型+A级」约束仍禁。
- **出口管制提醒**：EAR 744.23 按用途(先进节点)管制非代码许可，开源≠自动不受 IP 影响——T1 内核限成熟节点用途声明。
