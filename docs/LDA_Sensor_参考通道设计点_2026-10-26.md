`42.37` 不是独立指标，是 v0.9.297 恒等式的一个推论：

```
dT_req   = LOD_elec/(dn/dT)      = 7.6584 µK       （CMR=1 时 parity 所需温度稳定度）
δT_floor = T·√(k_B/C_ring)       = 324.50 µK       （器件自身热涨落底）
CMR_req  = δT_floor/dT_req       = 42.3713
```

## 2. 先纠一个自己的错：不变式写错了

第一版想当然写成「同一道墙 ⇒ `CMR_req × dT_stab ≡ const`」。**假的**：`CMR_req ∝ dT_stab`
⇒ 乘积 ∝ dT²，4 档（`dT = 1e-5 … 1e-2`）实测相对离散 **1e6**（自检 ③ 当场抓出）。

正确的两条**精确**恒等式：

```
CMR_req(dT_stab) · dT_req  ≡ dT_stab                     相对 1.7e-16
CMR_req(dT_stab) / dT_stab ≡ (dn/dT)/LOD_elec            相对 1.1e-16
```

⇒ 「CMR 门槛」与「温控门槛」**不是两个指标，是同一个乘积的两端**。这句才是「1.27× 不是一堵墙」的依据。

## 3. 同一道墙 1.2711×，三个旋钮

| 档 | 手段 | 反解 | 闭合幅度 | 代价（**量纲不同**） |
|---|---|---|---|---|
| **A 分光比** | 幅度平衡更紧 | `δ ≤ 1/42.3713 = **2.3601%**` | **1.2711×**（精确） | 一道 trim/校准工步 |
| **B 锁相平均** | `CMR_eff = CMR_typ·√N` | `N = ⌈(42.3713/33.3333)²⌉ = **2**` ⇒ `CMR_eff = **47.1405**` | **1.4142×**（**取整过冲**） | 读出带宽 ÷2（或测量时间 ×2） |
| **C 放大热容** | `δT_floor ∝ 1/√C` | `C ×**1.6158**`（`C∝R` ⇒ R 10 → **16.158 µm**） | **1.2711×**（精确） | `FSR ∝ 1/R` ⇒ FSR ÷1.6158 |

### 🔴 B 档的整数性是它自己的缺陷

连续解 `n* = (req/typ)² = 1.6158`，但**平均次数必须取整** ⇒ 取 `N=2` 就过冲到 `√2/√n* = 1.4142×`。
「只要 2 次平均」听起来比「trim 到 2.36%」轻松，但它**过冲 11%**，代价还落在带宽上。

⇒ 三档代价量纲不同（**工步 / 带宽 / 面积·动态范围**），**本层不排序、不相加**，也不给「最优档」结论
（判据 T8 把这条写成显式断言：`cost_units_distinct` 必须为真）。

### C 档是写判定时才发现的

```
δT_floor = T√(k_B/C) ∝ 1/√C
CMR_req  = δT_floor/dT_req ∝ 1/√C
```

⇒ **把环做大 1.6158× 就能把那道墙直接推倒**：回代 `CMR_req' = 33.333333333`，与工艺典型**逐位相等**
（`abs(差) < 1e-9`）。代价是 FSR 同比例缩小 —— **动态范围换共模抑制**，是设计取舍不是免费午餐。

## 4. 两条反向探针，其中一条自己踩空过

1. **A 档必要性**：`δ` 取工艺典型 3% ⇒ `CMR` 只有 33.3333 < 42.3713 ⇒ 「A 档必须比典型更紧」非恒真。
2. **锁相律**：若误用**线性**律（`CMR_eff = CMR_single·N`）⇒ 4× 比值下只需 `N=4` 而非 `√N` 律的 `N=16`。

> ⚠️ 第一版把探针挂在 1.27× 这一档 —— **两种律都给 N=2，没有判别力**。
> 这不是「探针太弱」，是**探针必须选在使两个假设分道的参数上**。改到 4× 才分开（16 vs 4）。

## 7. 诚实边界

- 三档都是**设计预算**，不是实测抑制比。`CMR = 1/δ` 是**架构极限**，实际还受探测器非线性、
  时序失配恶化 ⇒ A 档的 2.3601% 是**下界要求**不是可达值。
- `CMR_eff ∝ √N` 假定残余漂移**零均值、样本间独立**；若有 1/f 或慢变，收益**低于** √N
  ⇒ B 档 `N=2` 是**乐观下界**。
- 片载参考通道**硬件**（分光器 / 双探测器 / 共模布局）与实测共模抑制比须流片 ⇒ `-b` **边界**。
- `C ∝ R` 来自 `ring_heat_capacity_j_per_k(R) = ρc_p·2πR·w·h`（线性）；真实环的弯曲损耗、
  模式变化未建模 ⇒ C 档的 R = 16.158 µm 只是**热学侧**可行点，不是「设计好了」。
- 三档代价量纲不同 ⇒ **不排序、不相加**；本层不给「选哪一档」的结论。
- 现役对外数字**一个字没改**：`DEFAULT_NOISE["CMR"]=1.0` · `LOD_temp=9.3e-7` · `dominant_limit="temp"`。
