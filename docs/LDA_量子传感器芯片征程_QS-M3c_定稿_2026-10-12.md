## 2. 物理建模（三链）

### 链① 腔品质因子 Q = ω/κ

```
腔能量 Ring-down：dU/dt = −κU（κ = 能量衰减率 = 角频率线宽）
闭式（golden）：Q = ω/κ          ω = 2πc/λ
数值候选：RK4 时间推进能量衰减 dU/dt=−κU（U₀=1）⇒ U(T) ⇒ 反解 κ_cand=−ln(U(T))/T ⇒ Q_cand=ω/κ_cand
```

- **方法学独立**：golden 走「闭式除式」；candidate 走「数值 ODE 反解」（RK4 四阶，不含闭式除式）。
- 默认档（ω=2πc/1550nm, Q=1e4, κ·t≈1）· 残差链 **2.248e-6 → 1.334e-7 → 8.122e-9 → 5.011e-10**（比值 **16.86/16.42/16.21×** ⇒ **O(h⁴)**）。

### 链② 有效模体积 V_eff = A·8a/15

```
单波腹腔模包络 E(x)=E₀·(1−4x²/a²)（x∈[−a/2,a/2]，中心单极大、边界归零）
V_eff = ∫ε|E|²dV / max(ε|E|²) = A·∫(1−4x²/a²)²dx = A·8a/15   （∫_{-a/2}^{a/2}(1−4x²/a²)²dx = 8a/15）
闭式（golden）：V_eff = A·8a/15
数值候选：中点求积 ∫_{-a/2}^{a/2}(1−4x²/a²)²dx（×A）
```

- **方法学独立**：golden 走「解析积分」；candidate 走「数值求积」。
- 🔴 被积函数为**四次非多项式** ⇒ 中点法**非精确** ⇒ 真 O(h⁴) 残差（偶函数在对称区间中点法额外加速，比值严格 16.00×）。残差链 **8.345e-7 → 5.215e-8 → 3.260e-9 → 2.037e-10**。
- 🔴 选包络的教训：初版用驻波 sin²(πx/a) ⇒ 等距中点法下残差 ~1e-16（sin² 在中点网格上被**精确积分**）⇒ 会成为「死测试」；改抛物线包络后残差链干净单调、非零。

### 链③ 单光子耦合 g = (μ/ħ)√(ħω/(εV_eff))

```
单光子能量 U = ½ħω = ½ε∫|E|²dV ⇒ 场幅 E₀ = √(ħω/(ε·V_eff))
g = μ·E₀/ħ = (μ/ħ)·√(ħω/(ε·V_eff))     ε = ε₀n²
闭式（golden）：g = (μ/ħ)·√(ħω/(ε·V_eff))，V_eff = A·8a/15
数值候选：数值积分 ∫|E|²dV（⇒ 数值 V_eff）⇒ E₀ ⇒ g
```

- **方法学独立**：golden 走「闭式 V_eff」；candidate 走「数值场能积分」。
- g ∝ V_eff^(−1/2)，残差随 V_eff 积分残差 ⇒ O(h⁴)。残差链 **4.172e-7 → 2.608e-8 → 1.630e-9 → 1.019e-10**。

## 6. 诚实边界与未竟项

⚠️ **参数均为设计示例量级**（金刚石微盘腔 telecom 典型），**非实测 PDK**：

- `n=3.4`（金刚石折射率）/ `λ=1550nm` / `Q=1e4` / `a=1.55µm` / `A=5e-14 m²` / `μ=1e-29 C·m` / `γ₁=1e9 s⁻¹`；
- 本档只证明「闭式 ⇄ 数值候选」数值一致这一**数学事实**。

🔴 **不得作制造 / 性能宣称**：真实微盘腔还受辐射损耗、表面散射、侧壁粗糙度、弯曲模分裂等**未建模因素**影响；单波腹抛物线包络是**理想可分离模式**近似，非真实腔模（真实微盘为 WGM 回音壁模）。本档**不宣称「已达国际水平」**、**不报 fabricated 能效**。

**未竟项（留待后续档）**：

- G5 **器件本体**（PDK 条目：NV 柱 / 腔 / 天线真实几何 + DRC）尚未落地；
- 真实腔模（回音壁模 WGM / 光子晶体腔 H1/L3 缺陷模）的**全电磁本征模**未建模（本档用解析可分离包络近似）；
- V_eff 的横向截面 A 目前为**均匀常量**，未建真实侧向场衰减（艾里斑 / 高斯包络）；
- 强耦合判据 g > κ,γ₁ 的**定量达成判定**留待腔 QED 系统链（g=1.65e10 Hz vs κ=1.22e11 s⁻¹ —— 本设计示例**尚未**进入强耦合区，如实记录）。
