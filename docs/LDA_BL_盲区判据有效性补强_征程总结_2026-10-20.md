## 2. 征程方法论

- **前提纠正（本征程的起点）**：K4 的 L2 定义是「CORE 门禁源码（去注释后）**显式出现该锚号**」——这是**文本代理**。在门禁里写一行锚号就能让 L2 +1，而判据强度一点没变 ⇒ **纯指标游戏，与「不虚报」红线冲突**。因此真命题不是「覆盖率数字」，而是**判据判别力**；L2 只在判别力验完之后才允许升级（M4 的前置是 M0–M3）。
- **每档三步**：① **现算体检**（不读 `verification_report`，实测其「零残差 86 条」现算只有 **19 条为真**）；② **分档处置**（能修的修、修不了的书面披露、结构性偏松的登记锁死）；③ **机器锁死 + 棘轮**（只减不增、反向探针两侧都验）。
- **阈值窗口法（不靠拍脑袋收 tol）**：`tol` 必须同时满足 `|g|/tol ≥ 10`（不许太松）与 `resid ≤ tol/2`（候选真有余量）⇒ 可行窗口 **`[2·resid, |g|/10]`**（实操上界取 **`|g|/12`**）。**窗口为空 ⟺ 候选精度撑不住 ⇒ 不可靠压 tol 治**。
- **一条铁律**：**报告不可用于残差审计**（6 位舍入）· **`compare_fn` 返回误差值不是布尔** · **反向探针必须两侧都验**（只验一侧 = 恒真式空转）。

## 6. 本征程血案（已固化进 IRONLAWS）

1. 🔴🔴 **「均匀段切片 TMM」不是独立方法**（B65/B66/B67/B68/B81/B82/B83/B84）：`S(w)^N ≡ S(N·w)` 精确恒等 ⇒ 候选与闭式**数学等价**，残差只剩浮点路径差。**换任何观测量（T/R/φ）都治不好**，解药是换**有真实截断阶**的核（Riccati+RK4 四阶）。
2. 🔴 **文本代理 = 指标游戏，且会吃掉自己的体检域**：门禁文案里出现锚号 ⇒ L2 +1、盲区 −1。本征程**第四次踩**（v0.9.257 点名两条 ⇒ L2 124→126、盲区 414→412）。⇒ 锚号只许出现在**非门禁模块**（`bl_registries.py`）与**数据面**（台账/manifest），门禁只 `import` 并写「见 `BL_TIGHT_FIXED`」。
3. 🔴 **`compare_fn` 返回误差值不是布尔**（签名 `(candidate, oracle) -> float`）⇒ 判 PASS 必须 `err ≤ tol`。把它当 bool 会让**全部反向探针失真**。
4. 🔴 **`verification_report.json` 不可用于残差审计**（6 位舍入：报告「零残差 86 条」现算仅 19 真零、67 条假零）⇒ 必须现算 oracle 与 candidate。
5. 🔴 **`tol → 1e-16` 后「生产逐值复现」物理上失效**：resid 落到 **130/410/579 ulp**，平台间几 ulp 舍入差被放大成 **1.5%/1.2%/10.7%** ⇒ 验收标准改判**余量**（`tol/resid ≥ 5` ∧ 扰动 ×1.15 后 ≥3×）。
6. 🔴 **收敛阶判据不可写死方向**：写「趋近标称阶」；相邻比趋近的是 **16 = 2⁴**（写 `|r−4|` 会 5 条假红）。
7. 🔴 **反向探针必须两侧都验**：`X/X ≥ 5` 是恒真式；正解 = 口径抽成函数，「人为压紧必 False ∧ 台账值必 True」。
8. 🔴 **受跟踪 JSON 基线只能就地改字段**：用 `json.dumps(sort_keys)` 重写 `timeout_budget_baseline.json` ⇒ **13836 行假 diff**；正解 = `git checkout --` 还原后只做目标数字文本替换（2/2 行）。
9. 🔴 **bump 版本后必须重生含 `version` 快照的台账**（`k0_audit.py --write`），否则「子进程重跑 ≡ 磁盘」必红。
10. 🔴🔴 **M4 的循环依赖（首轮重生即实测）**：`bl_audit` 的体检域若读 K4 的**并集盲区**（M4 后 = 18），而 manifest 又来自它的 `rows` ⇒ `rows` 塌成 **0**、manifest 空。**正解 = 体检域取「文本盲区」**（`gates` 文本覆盖的补集 = 414），环被拆断。
