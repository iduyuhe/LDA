## 一、路线① 2D FDTD 全场时域 —— **控制实验即失败**

新建 `lda_solver/fdtd2d_mmi.py`（Yee TEz + 阻抗匹配海绵吸收层 + 解出的 slab
基模注入 + 端口模重叠投影）。逐个修掉 5 个实现缺陷后仍不可用：

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | Yee 数组形状错（`Hy[:-1,:]` 而 `Hy` 已是 `(Nx-1,Ny)`） | 改 `Hy +=` |
| 2 | 对称几何只栅格化上半（`(0, hw)`） | 改 `(-hw, hw)` |
| 3 | 输出臂落在吸收层内（域太小） | 加 `sponge`/`clad_y_um` 参数扩域 |
| 4 | 余弦源激发的多是包层辐射（导模占比 0.1~0.4%） | 换成解出的 `slab_fundamental_mode`（n_eff=2.6127） |
| 5 | 仅对 E 场阻尼 ⇒ 吸收层阻抗失配反射 | E/H 按同一 σ/ε 律阻尼 |

**决定性反证（控制实验）**：无损介质中的 **0.5 µm 直波导**，导模幅度沿线
衰减 **≈0.7 dB/µm 且非单调**。这是数值缺陷（吸收层/源注入），不是 MMI 物理。

> 按「全绿≠无失真」纪律：**不拿一个连直波导都测不准的求解器去判 0.05 dB 的锚**
> （那会给 golden 配上十几 dB 的假残差）。该实现**已删除、不入库**——
> 留下坏求解器会让后人误用。

## 二、路线② 2D-EIM 本征模展开 EME —— 本征分解正确，**建模层不合格**

新建 `lda_solver/mmi_eme.py`（入库，作为可复用求解能力）。
方法：解接入波导基模 → 解多模区全部导模 → 输入场展开 → 各模按 β 传播 →
与两条输出臂基模重叠 ⇒ `excess = −10·log10(|t₁|²+|t₂|²)`。

### 2.1 先证明求解核本身是对的（否则后面的否定没有意义）

| 校验 | 结果 |
|---|---|
| 有限差分本征分解 ↔ **解析超越方程**（偶模 `w=u·tan u` / 奇模 `w=−u·cot u`，二分求根） | 9 模 **max\|Δn_eff\| = 4.36e-3**（dl=0.005，符合 O(dl²)） |
| 模式基正交归一 | max\|ΦᵀΦ−I\| = **2.28e-15** |
| 能量守恒（纯相位传播不得生灭） | \|\|E_out\|\|² = Σ\|c\|² = 0.99486964（差 **<1e-9**） |
| 左右输出对称（几何严格对称） | 不平衡 **2.22e-13** |
| 确定性 | 两次调用**逐位相同** |
| 判据 D（设计点 W±0.2 µm 双向） | Δ = **6.94 / 2.60 dB** |

⇒ **本征分解、传播、投影都是对的**。问题在 2D-EIM 这一建模层。

### 2.2 自成像自检不合格（MMI 的定义性质）

MMI 的定义性质是「L = 3L_π/4 处出现**单重自像**」——理想时应逼近理论上限
`p_in² ≈ 0.9898`。本模型实测：

| W_mmi | 导模数 | L_π (µm) | 自成像保真度 | 理论上限 |
|---|---|---|---|---|
| 2.8 | 9 | 21.41 | **0.8746** | 0.9898 |
| 4.0 | 13 | 42.60 | 0.7128 | 0.9894 |
| 6.0 | 19 | 92.84 | 0.5494 | 0.9876 |

🔴 **模数越多反而越差**（0.87 → 0.71 → 0.55），方向与该是「越宽成像越干净」
相反 ⇒ 不是窄 MMI 的模数瓶颈，而是**色散偏离抛物线在长距离上累积**。

### 2.3 对拍长 L_π 病态敏感 —— 结构性不可判

锚题 L=27 µm 落在模型自洽成像长度（(9/8)·L_π ≈ 24.1 µm）的**侧翼**，此处
excess 对长度极敏感。L_π 相对误差 ε 等价于以**等效长度 L/(1+ε)** 传播：

| L_π 相对误差 | 等效长度 | excess | 摆动 | 相对 tol |
|---|---|---|---|---|
| −5% | 28.42 µm | 3.555 dB | | |
| −1% | 27.27 µm | 4.382 dB | **0.199 dB** | **2.0× tol** |
| 0 | 27.00 µm | 4.333 dB | — | — |
| +1% | 26.73 µm | 4.581 dB | **0.199 dB** | **2.0× tol** |
| +5% | 25.71 µm | 6.375 dB | **2.820 dB** | **28.2× tol** |

而 2D-EIM 自身的 L_π 就远不稳定：本模型网格 dl 从 0.04 细化到 0.005，
L_π 从 **21.05 漂到 21.48（2%）** —— 已超过 ±1% 这条线。

> **判到 tol=0.1 dB 需要 L_π 优于约 1%**。对 220 nm SOI 的 MMI，2D-EIM
> （乃至任何非三维矢量模型）都给不出。⇒ **E5 在原理上不可判。**

### 2.4 模型能力上界 —— 换几何解释也救不回来

放开 (L, y_split) **全平面寻优**，模型自身能达到的最好结果：

```
最优 excess = 0.436 dB   @ L=38.53 µm (=1.810 L_π), y_split=0.80 (=0.286 W), T=0.9045
```

即便如此，仍是 golden 0.05 dB 的 **8.7 倍**、超出 tol **4.4 倍**。
锚题几何（L=27, W=2.8）下实测 **excess = 4.333 dB**。

## 三、与既有判定的关系

`docs/lda_tech_roadmap_2026-09-03.md` §1.2 已判 E5 违反 **C2 + C5**：
> ① 缺 MMI 的 W/L（`device` 字段提到 2.8×27 µm² footprint，但 `geometry` 未收录）；
> ② 0.05 dB = 1.15% 功率，与自研求解器数值噪声地板同量级；
> ③ 实测不确定度 ±0.05 恰等于 tol ⇒ 窗口为零。

本报告把其中的 ① ③ 从**论证**升级为**实测**：

- ① 的后果被量化：W/L 只能从自由文本 `device` 字段取，而模型对 L 病态敏感
  （±1% 拍长误差 ⇒ 2× tol），**几何口径的微小歧义直接淹没判据**；
- ② 得到修正：0.05 dB 本身**不是**主要障碍（EME 是确定性代数，噪声地板极低），
  真正的障碍是**建模误差（L_π）远大于 tol**。这比原判据更精确。

项目 memory 的「已知不可接（勿重试）」清单已含 `E1/E3-E7`，与本次实测一致。

## 五、方法论教训（同类第 5 次「标签≠行为」）

判据 D 与敏感性度量**一度测成假阴性**：

- 在**锚题 L=27** 处，`excess(L)` 恰落在**局部极值**，局部导数退化到
  **0.18 dB/µm**（看起来"很稳健"）；`W_mmi +0.1 µm` 只响应 **0.05 dB**，
  判据 D 险些被判"无响应"。
- 改用两条稳健度量才拿到真值：
  - **判据 D 在设计点测**（L = (9/8)L_π、y_split = W/4，物理量与设计点对齐）
    ⇒ Δ = 6.94 / 2.60 dB；
  - **敏感性用 ±ε 档位极差**（对操作点不敏感）而非局部导数 ⇒ 2.0× / 28.2× tol。

> **写成铁律**：敏感性/判别力度量**不得用单点局部导数**——在极值点它会
> 系统性给出「很稳健」的假象。用**档位极差**，或把测量点放在物理量与设计
> 参数对齐的工作点上。

（前四次同类：D-78 门禁变量 `store_token`、v0.9.15 独立候选标签、
v0.9.42 前端硬编码 `DIR_SHELVES`、v0.9.44 `to_public()` 加字段却在端点断链。）
