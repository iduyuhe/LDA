# LDA 电子计算 SOC 征程 · 可行性 / 重要性 / 必要性评估（讨论稿）

> 2026-10-26 · **讨论稿，未动手** · 决策人：杜玉河
> 议题：用 LDA 平台设计一款电子计算 SOC 芯片，从「能设计出来」分步逼近国际水平，同时检阅并补齐平台短板。

## 〇、一句话结论

| 维度 | 判断 | 置信度 |
|---|---|---|
| **必要性** | **高** —— 但不是「再做一颗芯片」，而是「把平台上唯一有付费市场的域，从『模型堆』变成『可交付物』」 | 高 |
| **可行性（端侧 CIM SoC 级）** | **可行** —— 模拟计算域已建 60%（E1–E19），缺的恰是把它变成 SoC 的三块（数字控制壳 / 编译映射 / 能效） | 高 |
| **可行性（国际先进水平）** | **不可行**，且**不是技术问题** —— 卡在 PDK 商务、先进工艺、流片资金，全在 T2 永久锁之外 | 高 |
| **「分步达到国际水平」这个目标** | 🔴 **目前不可判定** —— 国际标尺是 TOPS/W，而平台红线是**不报 TOPS/fJ-op**（G-D）。**要么改红线，要么改目标，二者必选一** | 高 |

**建议**：动手，但**先改目标函数**。目标不是「做出国际水平的芯片」，而是「做出第一颗经得起客户审的设计 + 补齐三块真短板 + 建立可复核的能效口径」。这个目标可判定、可在现有资源内完成，且完成后「国际水平」才第一次成为可讨论的问题。

## 二、与国际水平的精确差距

### 2.1 国际标尺（2026 年公开数据，A 级来源）

| 代表 | 路线 | 关键指标 | 工艺 | 状态 |
|---|---|---|---|---|

| **d-Matrix Corsair** | 数字 SRAM CIM | 2400 TFLOPS MXINT8 / 9600 MXINT4 · 2GB @150TB/s · 600W/卡 | **台积电 N6** | **2026-06 量产**，C 轮 2.75 亿美元（微软 M12 / 淡马锡），英伟达拟投 |

| **后摩 H30** | 数字 SRAM | 整 SoC 7.3 TOPS/W · AI 核 15 TOPS/W | — | 已发布 |

### 2.2 产业公认的五大瓶颈 ⟷ 平台覆盖情况（本文最重要的对照表）

| 产业瓶颈（公认） | 量化（公开） | LDA 是否已建模 |
|---|---|---|
| **① ADC/DAC 开销** | 占面积 **30–81%**、功耗 **50–58%**；精度↑ ⇒ 能耗**指数**上升 | ✅ **E14/E15/E18 已建模**（含 K\*、面积-时间守恒） |
| **② 器件非理想性**（漂移/变异/噪声） | 模拟原生精度仅 4–8 bit | ✅ **E8/E16 已建模**（Pelgrom + MC + 漂移 + 良率） |
| **③ 良率**（大阵列少量失效即毁整片） | — | ✅ **E16**（`yield_fraction` / stuck 误差上界） |
| **④ 编译墙 / 软件生态** | 业界公认为**最大软伤**（无统一编译/算子/仿真，迁移成本高） | 🔴 **零覆盖**（`compiler_frontend` 是**光子酉矩阵**编译器，与数字无关） |
| **⑤ 系统可扩展性**（容量/片间互联/热） | 单片容量放不下 7B 模型；缺 NVLink 级互联 | 🔴 **零覆盖** |

**⇒ 这是本次评估最硬的结论**：平台**恰好**精确建模了产业公认的**前两大电路级瓶颈**（①②③），却**完全没有**触碰产业公认的**最大软伤**（④）与**系统层**（⑤）。**继续在模拟 CIM 电路里加 E20/E21，边际收益已接近零——因为剩下的真短板不在电路层。**

### 2.3 差距分解：哪些是平台能补的，哪些永远补不了

| 差距 | 量级 | 平台能补？ | 说明 |
|---|---|---|---|
| 能效对标（120 TOPS/W） | 无法比 | 🔴 **不能**（红线禁止） | **必须先改红线**才知道自己差多少 |
| 阵列规模（N≤12 → 1024） | ~2 个数量级 | ⚠️ **部分能** | IR drop 是主因，已有模型；但受 G-B（无 PDK）限制，改的是模型不是硅 |
| 精度（有效位数） | 待量化 | ✅ 能 | E15 已有口径，缺的是对标 ENOB 的诚实映射 |
| 数字控制壳（RISC-V/存储层次/接口） | **从 0 到 1** | ✅ 能（工程量中等） | 全平台零覆盖 |
| 编译 / 映射链 | **从 0 到 1** | ✅ 能（工程量大） | 全平台零覆盖，产业最大软伤 |
| **真流片 / 真 PDK / 真实测** | — | 🔴 **永远不能** | T2 永久锁 + N1 语料已判死；只能靠商务签约注入 |

## 三、可行性三问

### 3.1 「能设计出来吗？」—— 分层答，不能一刀切

| 层级 | 结论 | 依据 |
|---|---|---|
| **电路级设计** | ✅ **已经做到了** | E1–E4 闭环，verdict `DESIGN_VERIFIED` |
| **版图 + DRC/LVS 签核** | ✅ **已经做到了** | E6，出真 GDS（AREF 层次化） |
| **子系统级（含误差/时序/规模预算）** | ✅ **已经做到了** | E15–E19 |
| **SoC 级（含数字控制/存储/接口）** | 🔴 **没做，且平台零基础** | 无 RTL / 综合 / STA / 标准单元库 / DFT / 数字 P&R / 功耗签核 |
| **真芯片（流片）** | 🔴 **本仓永不做** | T2 永久锁 |

> 🔴 **「数字」这一块平台真的一片空白**：全仓 grep 无 standard cell / 逻辑综合 / 静态时序分析；`lda_layout` 是**光子 MZI mesh P&R**；`lda_l3/production_plan` 是研发生产调度解析，不是芯片设计流程。**这不是「补一补」，是从 0 建一条数字前端链。**

### 3.2 「能达到国际水平吗？」—— 目标本身不可判定，必须先拆

**三个岔路口，必须先选一个，否则会做出一堆无法结项的成果：**

| 选项 | 含义 | 代价 | 我的判断 |
|---|---|---|---|
| **① 对标 d-Matrix / Mythic（云端/旗舰）** | 2400 TFLOPS 或 120 TOPS/W | 台积电 N6、600W、2.75 亿美元融资、量产团队 | 🔴 **不可行**，与本仓（纯 numpy、无 PDK、无流片）**结构性矛盾** |
| **② 对标知存 WTM2101（端侧小算力，已量产级）** | 50 GOPS / 5µA / 1.8MB / RISC-V / 40nm | 一个 20–30 人团队、一次 MPW 流片 | ✅ **可行的对标锚**，且**平台缺的恰好是这套的三块** |
| **③ 不对标芯片，对标「设计工具链深度」** | 平台能审别人的芯片设计 | 无硅成本 | ✅ 最诚实，但**商业叙事弱** |

**关键观察**：知存 WTM2101 是 40nm、50 GOPS、5µA —— **不是尖端指标**。它说明「国际水平」是个**谱**，不是一根线。**端侧这一档，是纯软件+设计能力能摸到的。**

### 3.3 「能检验平台吗？」—— 这是最有价值的部分，且已被验证 19 次

**平台自家历史就是证据链**（每一段都逼出了真实短板，全部是事前不知道的）：

| 段 | 逼出的平台短板（此前完全缺失） |
|---|---|
| E1 | 平台**无晶体管级模型、无电路仿真器** |
| E6 | 平台**无电子工艺层栈语义**（`layers.py` 只有光子/超导栈） |
| E7 | **无导线 RC 提取、无带寄生后仿** |
| E18 | 🔴 **全仓此前完全没有「面积」这个维度** |
| E19 | 全仓 `charge_injection` / `aperture_jitter` / `switch_settling` **零命中** |

⇒ 「吃狗粮检阅平台」这条路径的 ROI **已被自家 19 次实践验证**，不是信念。

## 四、重要性与必要性

### 4.1 商业必要性（最强论点）

| 论据 | 内容 |
|---|---|
| **唯一有付费市场的域** | 光子芯片客户极少、量子更少；**电子 CIM 是四域里唯一有真实批量出货的**（知存千万颗、d-Matrix 已量产） |
| **销售的第一道门** | 客户见面的第一个问题必然是「**你们自己做过芯片吗**」。当前答案只能是「没有」（0 流片 / 0 实测）。这条路线的**最大产出不是技术，是把「自我引用」变成「自我证据」** |
| **平台能力的对外可读性** | 541 锚是内部计量，客户看不懂；**一颗可审的芯片设计**客户看得懂 |

### 4.2 技术必要性

| 论据 | 内容 |
|---|---|
| 电子域是**最大能力-可信度剪刀差** | 19 里程碑 / 10,033 行 / 21 门禁，但 **0 锚** —— 67 条判据全判「模型内部自洽」 |
| 唯一能暴露**系统层**短板的场景 | 编译墙 + 系统扩展这两个产业最大瓶颈，**只有做 SoC 才会撞上**，做单点模型永远撞不上 |
| 已有 19 次成功先例 | 见 §3.3 |

### 4.3 🔴 必须说清的一条反直觉结论（防期望错位）

> **「自己设计一颗芯片」不能抬锚。**
>
> 项目红线：golden = 闭式物理律 **或公开实测语料**；**仿真值永不作 golden**。
> 自产设计数据是仿真值 ⇒ 只能作 `self_certified`（自证桩），**不进 541**。
>
> ⇒ **电子域的 0 锚，不会因为做这颗芯片而变成正数**。抬锚的唯一路径是**真流片回来做实测**（10 条实证锚全是这么来的），那是钱与时间问题，不是设计能力问题。
>
> **所以两件事必须分开立项、分开计量**：
> - 「补平台短板」← 设计 + 系统层，**本次可做**
> - 「抬电子域锚」← 流片 + 实测，**本次做不了**，不要混进来当 KPI
