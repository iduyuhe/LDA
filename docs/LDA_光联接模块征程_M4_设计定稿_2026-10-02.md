## 1. 范围与用户裁定（本轮输入）

**用户裁定原文**：
> 3.2T 已封顶 ⇒ 转向 CPO 形态深化（热-光-电协同设计空间）

**M4 的定位**：M0–M3 把速率推到 3.2T 后，**每一域都已单独算过**（光：TWMZM 带宽墙；电：CPO 电通道 / PDN / NEXT；热：die↔die 热堆叠 + 闭环热调），但
🔴 **三域从未在同一条耦合链上联立求解** —— 热调只在光子 die 内闭环，电通道只管自己的 S 参数，光的波长偏移没有喂回信道规划。

M4 交付的不是「再一个器件模型」，而是把**热-光-电三域串成一条有反馈的耦合链**，并回答三个此前无人能答的问题：

| 问 | 此前状态 | M4 要回答 |
|---|---|---|
| **Q1** 给定 ASIC 功耗 `P_asic`，CPO 的环工作点还锁得住吗？ | M3 已发现**单向加热器不可行**（只能 cool），但没给工程解 | 给出**固化点预偏移**设计（代数解，零热调功耗） |
| **Q2** 热致波长偏移会不会把 WDM 信道规划解推翻？ | 从未联立（热在 1311 nm 器件层、规划在信道栅格层） | 在热平衡温度下**重规划**并验收隔离度 |
| **Q3** CPO / OBO / 可插拔 三形态的**三域代价**能否同口径对比？ | M3 只对比了功耗一项 | 三域（热耦合 / 电损耗 / 光耦合）同口径矩阵 |

**红线不变**（与前四程一致）：C 级自主（纯 numpy + 标准库）· 零商业 EDA/SPICE · LLM 不进判决路径 · 🔴 **不报 TOPS / TOPS-W / fJ-op / pJ-bit**（三域代价只出 **mW / W / K / nm / dB / GHz**）· 无 foundry 真值处一律按 T2 锁死并显式声明。

## 3. 设计口径（六项逐条）

### 3.1 ① 热-光-电耦合链（把三域串成一条有向链）

**物理链**（每一段都已有单一真源，M4 只做**联立**）：

```
P_asic ──[M3.die_thermal_stack]──> ΔT_photon ──[M3.tuning_slope_nm_per_k]──> Δλ_self
                                                                                  │
                                          ┌───────────────────────────────────────┤
                                          ▼                                       ▼
                              信道失谐 Δλ/FSR(mod)                   需补偿的热调功率
                          ──[M1.plan_lwdm_channels]──> 信道可用性      ──[M3.R_h 单通路]──> P_heat
```

**接口**：`co_design_chain(p_asic_w=None, t_amb_c=None) -> Dict`
**输出（只出物理量，🔴 不出能效比）**：
- `d_t_photon_k` · `d_lambda_self_nm` · `d_lambda_frac_fsr` · `channels_shifted`（等效信道数）
- `p_heat_required_mw_per_lane`（补偿所需）· `feasible`（单向加热器能否补）
- `direction`（`heat` / `cool`）
- `link_ok`（链上每一段都落在其**取值窗口**内 —— 窗口判据，见 §5）

**互锁（方法学独立，非同源相等）**：
- 通路 A：`M3.tuning_slope_nm_per_k()` = `S / R_h`（标定链）
- 通路 B：**材料闭式** `dλ/dT = λ·[(1/n_eff)·(dn/dT) + α_Si]`（热光 + 热膨胀，用 `active_models` 单一真源）
- 判据：两通路相对差 < **阈值**（具体阈值由实测定档，写进门禁，不写死「看起来合理」的数）

🔴 **为什么这是「方法学独立」而非「同源相等」**：通路 A 走的是**器件标定**（`tunable_wdm` 的 S，含 `R_th` 经验值），通路 B 走的是**材料物理闭式**（不含 `R_th`）。两者共用 `dn/dT` 但**传递函数不同**（A 除以 `R_h` 再乘 `R_th`，B 是直接的材料响应）—— 探针只打一侧即可造真实分歧。

### 3.2 ② 固化点预偏移（CPO 的真实工程解，**代数解**）

**断口 D2 的物理**：ASIC 热把光子 die 抬 `ΔT_photon = 16.5 K` ⇒ 环共振**红移**；而集成加热器**只能加热（红移更多）**，不能制冷 ⇒ 无法把环拉回**室温设计点**。

**工程解（CPO 业界标准做法）**：把环的**设计固化点**（nominal 工作波长）从室温 `T_amb` 挪到**热平衡温度** `T_eq = T_amb + ΔT_photon`。这样：
- 稳态热调功耗 `P_heat = 0`（无需补偿）
- 且仍需保留**双向可调余量**应对负载波动

**接口**：`setpoint_prebias_design(p_asic_w=None, t_amb_c=None) -> Dict`
**输出**：
- `t_eq_c`（热平衡温度）· `setpoint_shift_nm`（= 温度偏移折算的波长偏移）
- `p_heat_required_mw_per_lane`（预偏移后 = **0**，代数解）
- `residual_nm_after_prebias`（= **0**，代数解）
- `residual_nm_without_prebias`（= M3 的 1.676 nm，对照）
- `solution = "algebraic"`（🔴 显式标注，与 M3 同口径）
- `tec_required`（是否需要 TEC：预偏移后 **False**）

🔴 **探针靶子（必红）**：把预偏移的**热平衡温度**算成 `T_amb`（即忽略 ASIC 自热）⇒ 残余回到 1.676 nm、`p_heat` 回到非零 ⇒ 判据必须翻红。

### 3.3 ③ 热致偏移 ⟷ WDM 信道规划的耦合（首次联立）

**物理**：温度变 ⇒ 波导 `n_eff` 变 ⇒ **FSR 变**（`FSR = λ²/(n_g·L_ring)`，`n_g` 亦有热系数）⇒ 梳齿规避的最优 `m` 可能变 ⇒ **信道规划解可能被推翻**。

**接口**：`thermal_channel_replan(d_t_k=None, ...) -> Dict`
**复用**：`oi_m1.plan_lwdm_channels()`（切到 **O-band 栅**，与 M2 一致 —— 复用 M2 `plan_m2_rings` 的先例）
**输出**：
- `m_baseline` / `m_at_t_eq`（冷态 vs 热态的规划解）
- `fsr_nm_cold` / `fsr_nm_hot`
- `min_xt_db_at_t_eq` · `max_il_drop_db_at_t_eq`
- `plan_still_valid`（隔离度 ≥ 阈值 ∧ IL ≤ 阈值）
- `m_changed`（解是否被推翻）

**🔴 D4 波段桥接（本项的核心纪律）**：
- `wl0_nm` **必须**取自 `oi_m2.OI_M2_PROCESS["wl0_nm"]`（1311.0），**不得**新写常量；
- 判据：`M4 波段 == M2 波段` **且** `M4 波段 != M1 plan_lwdm_channels 默认 1550.0`（显式声明断层，不是默默混用）；
- 探针：把 M4 的波段改成 1550 ⇒ 互锁判据必红。

### 3.4 ④ 封装形态族三域矩阵（形态深化的实义）

**三形态**：`CPO`（共封装）· `OBO`（板上光学）· `pluggable`（可插拔）

| 域 | 物理量 | CPO | OBO | 可插拔 |
|---|---|---|---|---|
| **热** | die↔die 热耦合 `θ` | 强（M3 实测 0.2877 ⟷ 0.3130 K/W 双通道） | 中 | ≈ 0（热隔离） |
| **电** | 总线长度 `L_bus` | **mm 级** | cm 级 | **~10 cm 级** |
| **电** | 电通道损耗 `IL_elec` | 最小 | 中 | 最大 |
| **光** | 光纤耦合 | 片外 FAU（有 CTE 失准） | 片外 FAU | **光纤直连（最优）** |
| **热** | `ΔT_photon` | **最大（ASIC 热直灌）** | 中 | **最小** |

**接口**：`package_form_factor_compare() -> Dict`
**输出**：三形态逐项 `mW/W · K · dB`（🔴 不折算能效比），并给出**结论式判词**（哪一形态在哪个域占优）。

🔴 **诚实边界**：三形态的 `θ` 差异用**公开封装架构常识 + 几何缩放**（`oi_m2b.thermal_coupling_log` 的几何因子），**不是**实测封装数据（T2 锁死）。

### 3.5 ⑤ FAU CTE 热-机械失准 → 光纤耦合损耗

**物理**：硅光 die 与光纤阵列（FAU）材料 **CTE 失配** ⇒ 温度变化下横向对准漂移 `Δx` ⇒ 与模场 `w` 的**高斯交叠**下降 ⇒ 耦合损耗。

```
Δx = (α_die − α_fau) · L_arm · ΔT        (µm)
IL_coupling = −10·log10( exp(−(Δx/w)²) )  (dB)
```

**材料 CTE（公开手册值，②实测事实层）**：
- Si：`2.6e-6 /K` · 光纤（SiO₂）：`0.55e-6 /K` · 玻璃 FAU：`3.2e-6 /K` · 封装胶：见参数表

**接口**：`fau_cte_misalignment(p_asic_w=None, arm_len_mm=None, w_um=None) -> Dict`
**输出（实现键，D-217 定稿）**：`p_asic_w` · `d_t_k` · `cte_si_per_k` · `cte_glass_fau_per_k` ·
`cte_mismatch_per_k` · `arm_len_mm` · `mfd_w_um` · `dx_um` · `dx_nm` · `ratio_dx_over_w` ·
`il_cte_db` · `assembly_tol_um` · `il_assembly_db` · `cte_is_dominant` · `note`。
🔴 **实测（D-217）**：`dx_nm` **118.8 nm** ⇒ `il_cte_db` **0.0068 dB** ≪ `il_assembly_db` **0.1206 dB**
（装配公差 ±0.5 µm）⇒ `cte_is_dominant=False`（**反直觉诚实结论**：封装 IL 预算的主因是装配公差，不是 CTE）。
🔴 **探针靶子**：把 CTE 失配置 0 ⇒ `Δx=0` ⇒ `IL=0` ⇒ 判据必红（证明判据真的在算，不是恒绿）。

### 3.6 ⑥ 三域 Pareto 前沿（共享自由变量 = 电极长度 `L`）+ 🔴 VπL 规格锚约束

**为什么 `L` 是三域共享变量**：
- **光**：带宽 `BW(L) ∝ 1/L²`（M3 已证并互锁）⇒ 短电极带宽高
- **电**：电通道损耗 `IL_elec(L)`（有损线，∝ L）⇒ 短电极损耗低
- **电**：驱动功耗 ∝ **电极电容** `C_elec = C′·L` **且** 驱动摆幅 `V_pp ∝ Vπ ∝ 1/L`（`VπL` 恒定）⇒ `P_drv ∝ L·(1/L)² = 1/L` ⇒ **短电极功耗高**

⇒ 真正的三目标权衡（max BW / min IL / min P_drv）。

🔴 **本项在定稿阶段抓出了我自己的一个假设缺口**（见 §8 风险 2 原始预判）：
初稿我按「`VπL` 恒定 ⇒ `P_drv ∝ 1/L`」写，但**未核 `oi_m3` 是否真的含 `VπL`**。核查结果：
- `OI_M3_PROCESS` **没有 `VπL`**；M3 的 `driver_dynamic_mw=153.0` 用的是**封装线电容** `c_line_cpo_pF=1.0 pF`（**与 L 无关**）⇒ 按 M3 原模型，`P_drv` **不是** L 的函数，三目标退化（BW 与 IL 同向而要 L 小）⇒ **Pareto 前沿不成立**。
- **修正**：M4 显式计算**电极电容** `C_elec = C′·L`（= `200 fF/mm × 2 mm = 400 fF`），并**引入 `VπL` 规格锚**。反证该口径正确：`R = 2 Ω/mm × 2mm = 4 Ω`，`RC = 4 Ω × 400 fF = 1.6 ps` ⇒ `f_RC = 99.472 GHz`，与 M3 实测 **逐位一致** ⇒ 电极电容确实是 `C′·L`。

**接口**：`pareto_front_l_electrode(l_grid=None, vpi_l_v_cm=None, overdrive=None, ...) -> Dict`
**输出**：
- 前沿点集 `[{l_mm, bw_ghz, il_db, p_drv_mw}, ...]`（**非支配集**）
- `n_dominated` / `n_front` · `m3_design_on_front`（`L=2.0 mm` 是否在前沿上）· `knee_l_mm`

🔴 **本项的第二重交付：VπL 一致性诚实断口**（不粉饰、不偷改 M3）

由 M3 设计点反解其**隐含**调制效率：`VπL_implied = v_pp_diff_v × L = 1.2 V × 2 mm = 2.4 V·mm = 0.24 V·cm`；
而公开 SiP TWMZM 典型 `VπL ≈ 1.0–2.5 V·cm`（= 10–25 V·mm）⇒ **M3 设计点比公开工艺激进 4.2–10.4 倍**。

**如实报出三种解释（不预设立场）**：
1. M3 的驱动摆幅应远高于 `1.2 V`（反解：`VπL = 1.5 V·cm` ⇒ 要 `V_pp = 1.2 V` 需 `L = 12.5 mm`，届时带宽与 `f_RC` 全部重算）；
2. 需要**更高效率调制机制**（TFLN / 异质集成，`VπL` 可低至 ~0.2 V·cm）；
3. 或 M3 的摆幅常量本身是**规格锚假设**（本轮**不修改 M3**，只登记断口）。

**输出**：`vpi_l_implied_by_m3` · `vpi_l_public_typical` · `vpi_l_gap_ratio` · `vpp_required_at_public_vpi_l` · `consistent_with_public_process`（bool）

🔴 **探针靶子（必红）**：把 `VπL` 规格锚**写成 M3 隐含值**（0.24 V·cm）⇒ 差距判据必红（防止「用被查对象自证」）。

## 8. 复用纪律与风险预判

**复用**：本程**零新造**光/电/热求解器 —— 全部走 `oi_m1/m2/m2b/m3` + `active_models` + `tunable_wdm` 的既有单一真源。M4 只做**联立 + 桥接 + 形态对比 + 前沿**。

**风险预判（写下来，D-218 逐条核）**：
1. 🔴 **波段断层**（D4）是本程最大风险 —— 一旦把 1311 nm 的 `Δλ` 加到 1550 nm 的信道栅上，整条链的余量判断会**反向**。**必须**机器化钉住。
2. 🔴 **`P_drv ∝ 1/L` 是假设**（`VπL` 恒定）—— 若 M3 的电极模型不含 `VπL` 锁定，前沿会失真。D-217 实现前先核 `oi_m3._electrode_primers`。
   **✅ 已核（D-216 定稿阶段，风险已兑现并修正）**：`OI_M3_PROCESS` **确实不含 `VπL`**，M3 的 `driver_dynamic_mw` 走封装线电容（**与 L 无关**）⇒ 按 M3 原模型三目标退化、**Pareto 不成立**。已修正为「显式电极电容 `C′·L` + `VπL` 规格锚」，并用 `f_RC = 99.472 GHz` 反验电极电容口径正确；由此**额外**长出断口 **D8**（隐含 `VπL = 0.24 V·cm` 比公开 SiP 工艺激进 **4.2–10.4×**）—— 这正是「先讨论方案再动手」的价值：**假设在定稿阶段就被打掉，而不是留到实现后变成假绿**。
3. 🔴 **三域代价不可折算能效比** —— 一旦出现「总功耗 / 速率」的比值，即触红线。门禁的 `_positive_surface` 禁词扫描必须覆盖 M4 新增文本。
4. 🔴 **`θ` 的三形态差异必须有物理依据**（几何缩放），不能拍脑袋 —— 否则 §3.4 变成「编数字」。
