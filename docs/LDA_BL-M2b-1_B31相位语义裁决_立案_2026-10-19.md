# BL 征程 · BL-M2b-1 立案：`B31` 相位语义裁决（**立案 · 待排期**）

> 版本锚：v0.9.254（BL-M2b 已登记，未动 `B31`）· 出具 2026-10-19

## 1. 为什么单独立案

`B31`（`phase_shift_rad` · Drude 自由电子气相移）现算：

| 量 | 值 |
|---|---|
| `golden` | `0.804938866203 rad` |
| `candidate` | `1.57946845154 rad` |
| 差 | **`0.77453 rad` ≈ 44.4°** |
| `tol` | `1.5` |
| 残留占 `tol` | **52%** ⇒ **判 PASS** |
| `cand − π/2` | `0.00866 rad` |

两条线索：
1. `c = 1.5795` 距 `π/2 = 1.5708` 只差 **0.0087**（0.55%）⇒ 高度疑似**候选多加了 π/2**（或等价地：一个按 `atan2(Im,Re)`、一个按 `|arccos|` 取值域不同）；
2. 也可能是**参考面不同**（相移相对入射面 vs 相对势垒中心）或符号约定不同 —— 相位族的经典坑。

**这不是「tol 松」的问题，是「两个量可能根本不是同一个物理量」。**
若属实，`B31` 目前是**假绿**：它 PASS 的唯一原因是 `tol` 大到能吞掉 44°。

## 2. 裁决方法（三条独立路径，不用「谁看着像」）

| 路径 | 做法 | 判据 |
|---|---|---|
| **A. 解析导数** | 由 Drude 相移闭式对 ω 求导，与「数值阻尼振子相位」的导数比对 | 两路径若同源，导数应在机器精度内一致；`π/2` 常数偏移在导数上**消失** ⇒ 可区分「常数偏置」与「真不一致」 |
| **B. Kramers-Kronig** | 由电导率/介电函数实部经 KK 积分反推相位，独立第三路径 | 与 A、与候选三方比对，**多数决 + 残差量级** |
| **C. 极限检验** | 取 `ω → ∞`（相移 → 0）与 `ω → 0`（相移 → π 或 0）两个解析极限 | 只有一条路径能同时满足两个极限 ⇒ 定谁错 |

**裁决输出**：`{谁错: golden | candidate | 两者语义不同}` + 书面理由 + 证据残差三行。

## 3. 三种可能的处置（裁决后二选一，须再批准）

| 情形 | 处置 | 影响 |
|---|---|---|
| **候选多加了 π/2** | 修候选（去偏置），`tol` 收紧到窗口内 | 账本不变；`B31` 从 `注入0 放行` 与 `余量不足` 两面**同时除名** |
| **golden 定义域错**（如该报 `π − φ`） | 改 `golden` 语义 ⇒ **须批准改 golden** | 账本不变，但属「改判决基准」 |
| **两者语义不同**（一个相对入射面、一个相对中心） | 统一参考面后二选一，另一个登记为等价变体 | 账本不变；需在 note 写清参考面 |

## 4. 本档边界

- **不动 `B31` 的任何数值**（`H4` 判据锁死：`tol` 必须仍为 `1.5`，且必须留在不可收紧登记面）；
- 不因为「想让它好看」而调 `tol`（这正是 M2b 拒绝对它压 tol 的原因）；
- 裁决需新证据，**不得**用「改到能过」当结论。
