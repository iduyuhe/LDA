LDA 1000 万投资决策备忘录

主题：要不要投 1000 万做电域、实现「光电一体化」｜日期 2026-09-09｜对象：杜先生 / 潜在投资人 结论：钱要，但不用于攻电域。 建议投向真值链与生态，并先以 100 万做 12 个月的可证伪验证。 ⚠️ 文中成本为公开行情量级估算，实际以询价为准；所有对外引用前须复核 README 顶行权威账本。

0. 一句话结论

行业领袖不是功能最全的那一家，是「别人引用你的数」的那一家。

1000 万投进电域，三年后我们会多一个谁都不用的电域求解器和一堆更漂亮的假绿；投进真值，三年后我们的每一个数字后面都能跟一句「这个数是硅上测出来的」。

1. 为什么不建议投电域：三个硬数字

#数字含义
11000 万 ≈ 140 万美元而一个 112G SerDes IP 授权 $8M–$15M（5nm，2025 行情，且常不外卖）⇒ 连买一个都不够，更别说自研
2Cadence 官方立场112G SerDes 的 make-or-buy，答案永远是 buy。理由：只有最有经验的团队才敢尝试，且必须做 test chip 验证。参考 Alphawave：2017 成立专攻高端 SerDes，2019 才有份额，靠的是创始团队带出来的经验
3硅光 MPW $8k–95k/次IMEC / CEA-Leti 200mm：$8k–$30k；TSMC / GF 300mm：$45k–$95k ⇒ 同样 140 万美元可跑几十轮流片

同样一笔钱：在电域连入场券都摸不到，在真值上能跑几十轮设计-制造-测试循环。

2. AI 智能体为什么救不了这个场

LDA 的 40+ 求解模块确由 AI agent 自举写成——这是事实。但电域的卡点不在写代码：

电域真正缺的AI agent 能生成吗
工艺统计模型（由 PDK 提供）❌ 生成不出来；foundry 给不给取决于关系与合规，不取决于钱
实测真值（流片 + 封测 + 测试）❌ 生成不出来，要硅
客户信任与生态锁定❌ 生成不出来

AI agent 能生成代码，但生成不了真值和信任。

更深一层：光域 AI 做得动，是因为判决锚来自物理定律（麦克斯韦方程给出解析解与守恒量，天然可证伪）。电域的判决锚来自工艺统计模型和量产实测，那不是方程能给的。

⇒ 没有可证伪的判决锚，AI 写出来的东西进不了 LDA 的判决路径——那就成了我们最忌讳的东西：一个更漂亮的自证桩（52 锚中已有 25 个，教训深刻）。

2.1 一个必须交出的反证：Ricursive 与「designless」

事实（2026-09-09 公开检索）：AlphaChip 的两位创造者 Anna Goldie 与 Azalia Mirhoseini 于 2025 年 12 月创立 Ricursive Intelligence，公开宣称「我们不是 EDA 公司，不与 EDA 竞争，不使用标准 EDA 工具链」，目标为端到端（workload → GDSII），把行业从 fabless 推向 designless。

时间轮次金额投后估值
2025-12种子（红杉领投）$35M$750M
2026-01A 轮（Lightspeed 领投）$300M$4B
2026-05A 轮扩展（GV 领投）$650M+$4.65B

累计约 $985M；投资方含 NVentures（英伟达）、AMD Ventures、GV（谷歌风投）、红杉、Lightspeed、DST。三阶段：阶段一（当前）承接物理设计与设计验证；阶段二端到端；阶段三 designless。

这组事实说明什么：

  1. 「打破链」确实有人在做，且有顶级资本下注 ⇒ 关于「链」的判断必须加限定：今天没被打破，但正在被试图打破。
  2. 但它打的是电子链，不是光电链。
  3. 它印证「钱不够」：Ricursive 累计融资近 $985M，且公开说明资金主要花在 GPU 算力小时上；1000 万人民币（≈$1.4M）是该赛道的零头。

最关键的分野：为什么电子链能被 AI 端到端打，光子链不能

AI（尤其强化学习）能进入一个环节的前提，是该环节有可精确计算的判决信号（reward）。

电子链光子链
判决信号PPA（性能/功耗/面积）、时序、线长、拥塞、DRC——全是可精确计算的死标量器件有 Maxwell 方程锚、链路有功率预算；但工艺角是假设值、封装测试无锚、无统一语义交换标准
AI 渗透已全链渗透（AlphaChip / Synopsys DSO.ai / Cadence Cerebrus）只能进前半段，断在工艺角与封测

AI 设计芯片走通了，不是因为 AI 变强了，是因为电子链的判决锚成熟。瓶颈是判决锚，不是算力。

方法论分歧：Ricursive 是「AI 做设计决策」，LDA 是「AI 出题、物理定律判卷」。电子领域 PPA 可计算 ⇒ Ricursive 的路可行；光子领域没有可计算的 reward ⇒ 只能靠物理定律锚 + 公开实证锚。这正是 LDA 在光子侧的护城河，也是把钱投在真值而非电域的根本原因。

补充事实：Google 是最垂直整合的公司，但 AlphaChip 也只做 floorplanning 中有限的一组 block，Google 与 MediaTek 仍由人类工程师承担大部分工作；该成果在 EDA 社区存在公开争议（ISPD 2023 质疑；Google 反驳称对方未训练至收敛且算力仅 1/20）。

可证伪条件（出现任一条，本备忘录结论即须改口）：

  1. 有公司用 AI 端到端做出光子芯片（需求 → GDSII）并流片验证，第三方可复现；
  2. 光子界出现统一的语义交换标准 + 公开可查的工艺统计分布，使「接口」与「工艺角」两格不再空缺。

2.2 客户反驳与成本真相：钱不在电，也不在光，在接缝

客户的反驳（成立）：「电域其实就是 ADC/DAC、Driver/TIA 那一块，不是最复杂的，限在这个领域根本不需要那么多钱；所以整个光电集成的成本应该比单纯电子更容易。」

我必须承认的论证错误：此前用 112G SerDes（授权 $8M–15M）代表整个「电域」，属于用最难的代表整体、偷换范围。光电集成里的电接口是 Driver、TIA、LDD、偏置 DAC、加热器驱动，不是 112G SerDes。

数据支持客户的「电不贵」：

口径电芯片占硅光模块成本
单模硅光收发模块（Yole，IEEE 802.3cz 公开材料）8.6%（含 Driver/TIA/LDD 等）
1.6T 模块（较宽口径，2026）15%–20%，其中 DSP 占电芯片成本 60%–70%（7nm DSP 单颗 $130，博通/Marvell 垄断）⇒ Driver/TIA 只是零头

但客户的推论是反的：光电集成不是更便宜，是更贵。

项单模硅光收发模块成本占比
封装 · 测试 · 组装79.9%
硅光芯片（发射 + 接收）11.4%
电芯片（Driver / TIA / LDD 等）8.6%

为什么封装这么贵：单模光纤模场直径约 10 µm，硅波导亚微米，对准容差 <0.5 µm（CPO 要求亚微米、误差 ≤0.3 µm）。主动对准是串行逐器件的，每个器件占机时、端口越多越慢，无法像晶圆级制造那样并行扩展。

产业实证：德国 ficonTEC 高端全自动耦合设备年产能仅 30–40 台，交期 5–7 个月，定制机型超 9 个月；硅光晶圆测试系统单机价值超 1000 万元；2026 年国内硅光封装市场规模约 170.3 亿元（CPO 封装产值 28.6 亿元，同比 +195.9%）。

⇒ 光电集成的成本大头，既不在光、也不在电，而在二者的「接缝」——封装与耦合对准。这恰恰是 LDA 要占的那一格。

三档投入（回答「到底需要多少钱」）

档做什么需要多少判断
A 光电接口层（客户划定的范围）Driver/TIA/ADC-DAC 行为级模型 + 带参数网表 + 接进 Cadence 流程150–300 万（2–3 人 / 12–18 个月）客户说得对，不贵；1000 万绰绰有余
B 真值 + 接口（LDA 该做的）A + 3–4 轮 MPW + 封测 + 测试能力700–1200 万1000 万刚好够，略紧
C 光电一体化平台（含封装测试工程能力）B + 封装设计 + 测试产线 + 可靠性6000 万 – 1.5 亿1000 万远远不够

🔑 结论：1000 万不是不够，是「够做正确的事，不够做客户想象的事」。

🔴 B 档新发现：封装测试占近八成 ⇒ 跑完 MPW 之后封测才是花钱大头。建议先委托测试、后自建（自建耦合/测试能力需几百万至上千万）。

🔴 战略修正（对我们自己的路线）：「设计侧虚拟制造」不能只做工艺波动（光刻/刻蚀 → CD 偏差 → 工艺角）。既然八成成本在封装与耦合，真正值钱的设计优化是「可封装性」——设计阶段就算清耦合容差、对准失配、封装良率。这正是 S13 设计良率锚 + P-CPO 间距几何下界护栏能做之事，也解释了硅光平台那条 7 工位封装产线值得改造的原因。

对客户的答法

「您说得对，我上次举 112G SerDes 是用最难的代表了整体，范围用错了。数据也支持您——电芯片只占硅光模块成本不到一成，1.6T 宽口径下大头还是 DSP，不是 driver/TIA。 但有个结论我得反过来讲：光电集成不是比纯电子便宜，是更贵。 硅光模块成本里封装、测试、组装占八成——光纤模场十微米、硅波导亚微米，对准容差零点几微米，而主动对准是串行逐器件的，没法像晶圆那样并行扩产；全球最顶尖的耦合设备一年只产三四十台，交期九个月。 所以真正的成本不在光、也不在电，在光与电的接缝上。 我们做的正是那一格——不是想做整个光电一体化，是因为那一格又贵又没人管。 好消息是：您把范围限定在接口这一层，这单我们能接，两三百万、一年半就够。 一千万不够的是『自己建封装测试能力』，那要六千万到一个半亿。」

3. 领袖地位从哪里来

  • Synopsys 的领袖地位来自它定义了格式与流程，不是因为它做得多。光电一体化不会让我们成为领袖，只会让我们成为一家功能齐全但没人用的公司。
  • 我们手上唯一有领袖相的资产：L0 IR / DesignPackage JSON。电子有 OpenAccess、有 IBIS-AMI，光子界至今没有统一的语义交换标准——这个位今天空着。
  • 🔴 但占标准位的前提是有人用。当前 users = 1。⇒ 标准不是写出来的，是被采用出来的。
  • LDA 定位原文：护城河 = 标准 + 生态 + PDK 供给——三件都不靠「功能齐全」。

三年后的成果不是「光电一体化 EDA」，而是：一个有实测背书、有标杆客户、定义了光子语义交换格式的光设计入口。

5. 反向提议：先给我 100 万，不要 1000 万

现在不是钱不够，是「不知道钱该往哪打」——这个问题只能靠小步实测回答，不能靠一次性投入回答。

100 万 + 12 个月，做三件可证伪的事：

  1. 跑 2 轮 MPW，拿到本团队自己的实测数据
  2. 把至少 5 个自证桩换成真锚
  3. 拿下 1 个付费客户
  • 做到了 ⇒ 剩下 900 万投进来的胜率与估值完全不同
  • 做不到 ⇒ 1000 万投进去也是打水漂，而且是在我们最不确定的时候把钱烧掉

6. 什么时候可以做电域：三个触发条件

#条件钱能买到吗
1有可对齐的电域实测真值🟠 部分可以（买 IP 授权做对标、买 test chip）
2有电域 PDK 的工艺统计模型❌ 买不到（取决于与 foundry 的关系与合规）
3有客户签字说「你做了我就换」❌ 买不到（取决于信任）

⇒ 钱能买到的部分，恰好是不够的那部分。 今天三个条件一个都不满足。

补充：即便三条满足，优先做的也应是光电接口层（便宜、可证伪、客户会用），而非自研电域求解器。

8. 待杜先生定的事

  1. 是否接受「不投电域、先投真值」这个方向？
  2. 是否接受「先 100 万 / 12 个月验证，再决定剩下 900 万」这个节奏？
  3. 这 1000 万的性质：自有资金 / 意向投资 / 政府项目配套？——性质不同，可承受的失败率和退出条件完全不同。
  4. 是否授权启动 MPW 询价？（IMEC / Cornerstone / AIM / 国内平台）——这一步零成本，但要先知道真实价格才能做预算。
  5. 接受 A 档（150–300 万光电接口层）作为首个可接订单吗？——客户已把范围划小，这是当下最可能落地的一单。
  6. 虚拟制造的优先级要不要调整？（从「只做工艺波动」扩展到「纳入耦合/封装容差」——因为八成成本在那里）
