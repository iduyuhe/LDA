# LDA 电子计算征程 · E17 设计定稿：时序 / 时钟预算链

> **段位**：E17（D-185 定稿 · D-186 实现 · D-187 验证）· 系统层主线第三段
> **上游定调**：E15（误差预算）→ E16（权重编程）→ **E17（时序 / 时钟预算）** → E18（列侧共享与架构权衡）
> **一句话**：**把 E1–E16 里零散的"时间量"串成一条节拍链**，回答「这颗阵列最快能跑多快」
> （口径 = **每样本耗时**；🔴 **绝不报 TOPS**）。
> **定位**：这是**时间维度上的 E15** —— E15 合成「误差」，E17 合成「时间」。两者**合成律完全不同**。

## 1. 缺口取证（为什么必须做）

### 1.1 全仓检索：时间维度**完全空白**

| 检索词 | `ecore/` 命中 |
|---|---|
| `sample_rate` / `sampling_rate` | **0** |
| `clock` / `t_clk` | **0** |
| `latency` | **0** |
| `timing_budget` | **0** |
| `throughput` | **0** |
| `per_sample` | **0** |
| `settling_time` | **0** |

⇒ 平台**从未把时间当一等公民**。

### 1.2 有"零散时间量"，但从未串成链

| 来源 | 已有量 | 缺陷 |
|---|---|---|
| `parasitic.array_parasitics` | `tau_row_s` / `tau_col_s`（Elmore） | 只是**裸时间常数**，未折算成"建立到 k-bit ½LSB"需要多久 |
| `converter.sample_hold_transient` | `t_to_half_lsb_8bit_s` | 只覆盖**采样保持一级**，未与其他级串联 |
| `converter.sar_convert` | `len(trace) == n_bits`（逐位试判） | **逐次逼近是串行的**，但**从未折算成时间**（无 `t_clk` 概念） |
| `periphery.system_chain` | 全**直流/静态**（增益 · R_oc · 精度） | 🔴 **`PERIPHERY_PROCESS` 里一个时间参数都没有** |
| `weight_prog.WEIGHT_PROG_PROCESS` | `t_read_s`（漂移读取时刻） | 只是**读时刻**，不是节拍 |

### 1.3 🔴 最本质的缺口：**行驱动器是"无限带宽"宏模型**

实测 `PERIPHERY_PROCESS` 的全部键：

```
['a_gain', 'r_out_open_ohm', 'vdd_v', 'vfs_v']       # ← 无一为时间量
```

⇒ E14 的行驱动**能在零时间内把行线充到目标电压**。这在直流精度上无害（E14 关心的是
`v_in·A/(1+A+R_ol/R_L)`），但在**时序上等价于假设带宽无穷** ⇒ **采样率算不出来**。

### 1.4 与 E15/E16 的关系（三段正交）

| 段 | 维度 | 主导项 | 规模指向 |
|---|---|---|---|
| E15 | **精度**（误差预算） | IR drop | **∝ N²（越大规模越差）** |
| E16 | **写入**（权重编程） | 写入噪声地板 | 与 N 无关（有界项）/ 1/√N（随机项） |
| **E17** | **速度**（时序预算） | **待实测（预期：外围主导）** | **待实测** |

⇒ 三段合起来才能回答「这颗芯片**多大·多准·多快**」。

## 2. 🔴🔴 第一原理：**误差要分类合成，时间要分拓扑相加**

**这是 E17 与 E15 的分野，也是本段最容易写错的地方。**

### 2.1 E15 的合成律（回顾）

误差源的**相关结构**不同 ⇒ 必须分三类：系统性 `Σ` · 随机 `RSS→kσ` · 有界 `Σ→√3`。
`worst = Σsys + kσ + Σbnd` —— **简单相加是错的，全用 RSS 也是错的**。

### 2.2 E17 的合成律：**按拓扑**，不是按类型

时间阶段是**物理串行**的（采样 → 保持 → 逐位试判 → 累加），
所以**串行链必须代数相加**：

```
serial_latency = Σ t_i                  （串行：一条链走完）
```

若采用 **N 级流水线**（阶段重叠），则稳态**每周期 = 最慢级**，而**首样本延迟 = Σ**：

```
pipelined_period      = max t_i          （稳态吞吐周期）
pipelined_latency     = Σ t_i            （首样本延迟，含填充）
```

### 2.3 ⇒ 三条通则

1. 🔴 **对时间用 RSS 是错的**（把 `√Σt²` 当总时间）—— 串行阶段的时间**必然叠加**，
   不满足"独立随机量"的前提。**E15 的合成律不可平移到 E17。**
2. **时间预算有两种口径，必须都给**：`serial`（非流水）与 `pipelined`（稳态周期 / 首样本延迟）。
   只给一个 = 不诚实。
3. 🔴 **流水线的收益 = 「Σ − max」**。若 `max` 已占 `Σ` 的绝大部分 ⇒ **流水线几无收益**，
   提吞吐必须**并行复制瓶颈级**（面积代价）。**这个判据要机器化**（见判据 G1c）。

## 3. 五个闭式 golden（全部可手算 · 方法学独立）

| # | golden | 闭式 | 性质 |
|---|---|---|---|
| **G-1** | 一阶 RC 建立到相对残差 ε | `t_settle = τ · ln(1/ε)` | 精确解（`v=V(1−e^{−t/τ})` 反解） |
| **G-2** | 🔴 **建立到 k-bit 的 ½LSB** | `t = τ · (k+1) · ln2` | 精确闭式（令 `2^{−(k+1)}` 代入 G-1 ⇒ `(k+1)ln2`） |
| **G-3** | Elmore 延迟（R 梯） | `τ = r·c·n(n+1)/2` → 极限 `R_tot·C_tot/2` | E7 已有（`parasitic.elmore_delay`），**复用不复制** |
| **G-4** | SAR 转换周期数 | `n_stages = n_bits + 1`（`n_bits` 次试判 + 1 次采样） | 逐次逼近**串行本质**；与 `converter.sar_convert` 的 `len(trace)==n_bits` 交叉核对 |
| **G-5** | CDAC 底板建立 ⇒ 时钟周期 | `t_clk = settle_half_lsb(τ_cdac, k)`，`τ_cdac = R_on·C_tot`，`C_tot = C_u·Σ2^i` | 物理推导（R_on 复用 `converter.nmos_switch_ron_ohm`） |

**验证锚（实测，见 §5）**：
- G-2 ⟷ E14 实测：`τ=1 ns, k=8` ⇒ 闭式 `1n·9·ln2 = 6.2383 ns` **⟷ E14 `t_to_half_lsb_8bit_s = 6.2383e-9 s`（逐位一致）**
- G-3 极限：`Elmore / (R·C/2) = 1 + 1/n_seg`（n_seg=7 ⇒ 1.125 ✓ 实测 rel 12.5%）

## 4. 五阶段时间模型（全部**复用**已有效量）

| 阶段 | 时间常数来源 | 闭式 | 复用对象 |
|---|---|---|---|
| **① 行线建立** | `τ_row_dist` = E7 Elmore**＋** `τ_drv = R_oc·C_row_total` | `settle_half_lsb(τ_row_dist+τ_drv, k)` | E7 `array_parasitics` + E14 `buffer_closed_loop_rout` |
| **② 列线建立** | `τ_col` = E7 Elmore（TIA 虚地 ⇒ 无 `Rf·C` 项） | `settle_half_lsb(τ_col, k)` | E7 |
| **③ 采样保持** | `τ_s = rs_ohm·cs_f` | `settle_half_lsb(τ_s, k)` | E14 `CONV_PROCESS` |
| **④ SAR 转换** | `t_clk`（G-5 推导或显式覆盖） | `(n_bits+1)·t_clk` | E14 `nmos_switch_ron_ohm` + `c_unit_f` |
| **⑤ DAC 建立** | `τ_dac = r_unit·c_node` | `settle_half_lsb(τ_dac, k)` | E14 `r_unit_ohm`（`c_node` 为**新增显式占位**） |

🔴 **关键设计**：**行线建立 = 分布式 Elmore + 驱动源阻抗**（串联）。
`R_oc = 0` 时退化为**纯 Elmore** ⇒ **退化判据**（G3b）。**泛化必须退化为特例。**

## 5. 预期新结论（定稿时**已実测锚定**，见下）

### 5.1 实测基线（本机默认几何 ‖ 默认工艺）

| N | `τ_row` (E7 Elmore) | `τ_col` | `R_row_tot` | `C_row_tot` |
|---|---|---|---|---|
| 8 | **3.1187e-15 s**（3.12 fs） | 2.0791e-15 | 3.528 Ω | 1.547 fF |
| 32 | 5.5245e-14 | 3.6830e-14 | 15.624 Ω | 6.851 fF |
| 128 | 9.0531e-13 | 6.0354e-13 | 64.008 Ω | 28.066 fF |
| 256 | 3.6355e-12（3.64 ps） | 2.424e-12 | 127.5 Ω | 55.9 fF |

**五阶段实测（8×8 / 8 bit · 门禁 A1/B19 逐值守着）**：

| 阶段 | 时间 | 占比 | `τ` |
|---|---|---|---|
| 行线（Elmore 3.119 fs **+** 驱动 1.545 fs） | **0.000029 ns** | ~0 | 4.664 fs |
| 列线 | **0.000013 ns** | ~0 | 2.079 fs |
| 采样保持 | **6.238325 ns** | 4.81% | 1 ns |
| **SAR**（`t_clk` 10.237 ns × 9 拍） | **92.135256 ns** | **71.11%** | — |
| DAC（R-2R 节点电容 **占位**） | **31.191620 ns** | 24.07% | 5 ns |
| **合计（串行）** | **129.565246 ns** | 100% | ⇒ **7.7181 MSa/s** |
| 流水线稳态 | 92.135256 ns | — | 收益 **0.28889** |

**规模 × 时间（B12 守着）**：N 8→1024 ⇒ `τ_row` 跨 **12556.5×**，每样本耗时跨 **1.00469×**。
**交叉点（B13 守着）**：τ=1 ps ⇒ N≈135 · 100 ps ⇒ N≈1341 · **1 ns ⇒ N≈4238（解析 4245.8 ⟷ 二分 4238 · rel 0.184%）**。
**位数交叉（B11 守着）**：4/6 bit ⇒ **DAC 建立**主导（76.8% / 56.4%）；8/10/12 bit ⇒ **SAR** 主导（71.1% / 92.3% / 98.3%）。
**时钟预算（B14 守着）**：固定开销 **37.430 ns**；目标 160 ns ⇒ `t_clk_max` **13.619 ns**（代回残差 **0.00e+00**）；
CDAC 物理推导 `t_clk` = **10.237 ns**。

**Elmore ∝ N²** 已证：`τ/N²` = 4.873e-17 → 5.5473e-17（**收敛**），
逐档比 **4.286 → 4.016**（→ 4 = 2²）✓。

其它锚：`r_row_seg=0.5040 Ω` · `c_row_seg=0.221 fF` · `R_oc(1kΩ, A=1e3)=0.999 Ω` ·
`len(SAR trace) == n_bits` ✓ · `t_to_half_lsb_8bit = 6.2383e-9 s` ✓。

### 5.2 🔴🔴 实测核心结论：**这套架构是"精度墙"，不是"速度墙"**

- **阵列侧**：τ ∝ N²，但**基数极小** —— N=8 是 **fs**，N=256 也才 **ps**。
- **外围侧**：采样保持 **6.24 ns**；SAR `(8+1)·t_clk`，`t_clk` 由 CDAC 建立推导（**ns 量级**）。
- ⇒ **两侧差 3–6 个数量级 ⇒ 时间预算几乎 100% 由外围电路（SAR / 采样 / DAC）决定。**

**解析交叉点**（阵列 RC 何时与 ns 级外围可比）：解 `τ_row(N) = 1 ns`
⇒ `N ≈ √(1e-9 / 5.5473e-17) ≈ 4246`（**实测解析 4245.8 · 二分 4238**）。

🔴 **但 N≈4246 时 IR drop 早已爆掉**（E15：5% 预算 ⇒ **N≤12**）
⇒ **在可达规模内，阵列 RC 对时间的贡献 < 0.001%，永远不是瓶颈。**

### 5.3 ⇒ 可讲的一句话（**单看任何一段都得不出**）

> **误差随规模恶化（IR drop ∝ N²，5% 预算只到 N≤12）；
> 时间不随规模恶化（阵列 RC 在 fs~ps，被 ns 级外围彻底淹没 —— **实测 N 8→1024 每样本只跨 1.00469×**）。**
> ⇒ **规模墙是「精度墙」，不是「速度墙」** —— 加行列**不拖慢采样率**，但**会毁掉有效位数**。

### 5.4 架构指令（第二句）

> **流水线对本架构几无收益** —— 最慢级独占预算，`pipelined_period ≈ serial_latency`。
> ⇒ 要提吞吐，必须**并行复制瓶颈级（SAR / 采样）**，代价是**面积**（接 E18 的架构权衡）。
> ⇒ 要提精度，必须回 E15/E16（降 IR drop / 降写入噪声），**不是**加时钟。

## 8. 突变探针（6 条 · 每条**先证能变红** + **还原重跑**）

| # | 注入 | 必红判据 |
|---|---|---|
| **C1** | 时间合成律改成 **RSS**（`√Σt²`，照搬 E15 的误差律） | B4（`serial == Σ` 被破坏） |
| **C2** | `settle_half_lsb` 漏 `ln2` 或写成 `τ·k·ln2`（漏 +1） | B1 / B2 |
| **C3** | `elmore_delay` 改成 `r·c·n²/2`（漏 `(n+1)/n` 修正） | B6（`τ/N²` 不再收敛到常数 → 需选对判据） |
| **C4** | `sar_period` 改成 `n_bits·t_clk`（漏采样那一拍） | B8 |
| **C5** | 行线时间**丢掉驱动源阻抗项**（`R_oc·C_row_tot`）—— 只留 Elmore | B7（退化判据要求 `R_oc=0` 时才相等；非零时丢项 ⇒ 不等） |
| **C6** | 披露里注入「已报 TOPS」 | B18 |

🔴 **探针纪律**（E8/E14/E15/E16 通则）：
① 每条探针必须**只对被测机制敏感** —— 若参照系里混着别的机制，判据不特异；
② **退化判据要选「非恒等」样本** —— B7 要求 `R_oc > 0` 时**必须不等**（否则丢项判不出来）；
③ **C3 的判据要选对**：`r·c·n²/2` 与 `r·c·n(n+1)/2` 之比 = `n/(n+1)` ⇒
**`τ/N²` 在两种写法下都"近似常数"** ⇒ 单看收敛**不特异** ⇒ 必须**逐值对拍**
