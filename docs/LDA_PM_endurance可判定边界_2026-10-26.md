## 2. ① 任何「N 次循环」的宣称，等价于一个 δ 上界的承诺

现有系统预算（`pm_m4.system_link_budget`，三段独立误差**方差**合成）：

```
ε_tot² = ε_write² + ε_read² + ν_T²·ln²(t/t₀)
ε_bud  = 0.071078        （由 BER ≤ 1e-12 反解）
ε_write = 0.029412   ε_read = 3.09e-5   ν_T = 3.8001e-4（上界锚）
```

把循环损伤按两种口径各加一项，反解即得 δ 的上界：

| 累加口径 | 约束 | δ 上界公式 | 「10⁶ 次 · 保持 10⁴ s」隐含值 |
|---|---|---|---|
| 独立累积 | `N·δ² ≤ rest` | `√rest/√N` | **6.4613e-5** |
| 最坏累积 | `N·δ ≤ √rest` | `√rest/N` | **6.4613e-8** |

🔴 **两口径差 `√N`** —— N = 10⁶ 时是 **1000×**。

> ### 这才是「不可判」的真正原因
>
> 不是缺一个数据点，而是**缺失效机制**。数据能定 δ 的**数值**，但**定不了该用哪个累加口径**，
> 而口径差 3 个数量级。⇒ 本版**并报两个界、不选一个**（「口径不定必须并报」的一贯做法）。
>
> 换句话说：**「10⁶ 次」不是一个可以被"知道"的事实，它是一个 1000 倍宽的承诺区间。**

⚠️ 量纲提醒（第一版就错在这里）：`rest` 是 **ε²** 量。最坏累积的界是 `√rest/N`，
不是 `rest/N`（后者是 ε²/N）。判据 ③ 的比值会立刻从 1000 变成 15477。

## 3. ② 新层在 δ=0 处必须逐位退化（两条独立路线）

```
ln t_max = ln t₀ + √(ε_bud² − ε_write² − ε_read²)/ν_T = 170.280035764     ← 本层闭式
pm_m4.system_link_budget()["max_t_hold_s_for_target"]  = 170.280035764     ← BER 几何二分
                                                        log 空间 |Δ| = 5.7e-14
```

两条路线**互不依赖**（一条闭式，一条对 `BER(ε)` 做几何二分）⇒ 加这一层**没有改旧结论**，
只是把它参数化。判据 V2 就在门禁里做这件事，**不转调模块自检**。

另一个自检 ⑫ 是它的反向探针：把闭式误写成 `rest/ν`（漏 `√`），log 差 **159.3** ⇒ V2 必红。

## 4. ③ 「10⁶ 循环无失效」需要几台器件

0 失效情形的二项精确式：

```
n = ⌈ ln(1 − C) / ln(R) ⌉        夹逼：R^n ≤ 1−C < R^(n−1)
```

| C / R | 90 / 90 | 95 / 90 | 90 / 50 |
|---|---|---|---|
| 器件数 | **22** | **29** | **4** |

⇒ 「10⁶ 次无失效 @90/90」= **22 个器件各跑 10⁶ 次**（10⁶ × 22 = 2.2e7 次写入）。
这条与「有没有模型」**无关**，是统计事实，可以直接拿去写实验计划。

⚠️ 第一版把夹逼写成 `(1−R)^n` —— 那是「至少失败一次」的概率，是**另一个量**（量级差 10^21）。
由自检 ⑥ 抓出。

## 5. ④ 纠正卡上一处隐含论证

「不引用电学 PCM 的 10⁶–10⁹」这个**结论是对的**。但常被引用的理由
「**光子相变体积大 10³–10⁴ 倍**」**单独推不出循环数比**：

> 若每循环注入的缺陷数 ∝ V，且失效所需的临界缺陷数也 ∝ V
> ⇒ `N_crit = N_c / (n_d per cycle)` 中 V **约掉** ⇒ **N 与 V 无关**。

实测尺度比 **2360×**（光子 0.1180 µm³ vs 电学接触区 5e-5 µm³），但
`n_ratio_from_volume_alone = 1.0` —— 判据 V9 把这个「不成立」写成**显式断言**，
防它再被当理由引用。

⇒ 真正成立的理由只有两条：

1. **判据不同**：电学看**阻值窗口**（通常 10×/100× 分离），光子看**透射/相移窗口**；
2. **失效机制未定**：`δ` 的界跨 `√N`。

而 ② 恰好是「没有实测锚」的直接后果 —— **两者是同一件事，不是两条借口**。

```python
e_bud  = 0.071078                          # 由 BER ≤ 1e-12 反解

d_quad = sqrt(rest)/sqrt(N)                # 独立累积
d_lin  = sqrt(rest)/N                      # 最坏累积（🔴 不是 rest/N）
ratio  = d_quad/d_lin == sqrt(N)           # N=1e6 ⇒ 1000
n_dev  = ceil(log(1-C)/log(R))             # 0 失效样本量
```

## 8. 诚实边界

- 本层**不提供任何 δ 的数值、不提供任何循环数预测**；`endurance_verdict()` 恒为 `not_modeled`
  （判据 V8 锁死判词，并要求对拍行 `gap_id` 指向**现存**缺口号）。
- 「独立累积 / 线性累积」只是**两个极端**；真实机制可能介于两者之间，或与 N 非线性
  ⇒ 给的是**区间**，不是点值。
- 电学 PCM 接触区取工程典型 `50×50×20 nm`（**假设**），光子 GST 厚度取 `20 nm`
  （与 `pm_matlib.gamma_invariance` 默认同源），均**非本项目实测**。
- `ε_cyc` 两种加法与现有三段的「方差合成」保持一致；若将来改三段口径，
  本层的四个反解式须同步重推（门禁 V2 会在那一刻先红）。
- 未做：失效判据的实测定义、器件级循环数的分布形式（Weibull 斜率）、温度/占空比加速因子。
  这些都要实测，属 `PM-G10b`。
