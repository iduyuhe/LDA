## 1. 这张表要治什么病

**病**：量子赛道六层（J1 QEC → J2 Transmon → J3 测控 → J4 传感系统 → J5 量子网络，外加 QS-M* 器件档）之间存在**横向复用**——下游档直接 `import` 上游档的常量或闭式律。

```
qs_m0.D_ZFS_HZ  ──import──▶  qs_m5.zero_field_splitting_hz()      （QS-M0 → QS-M5）
qs_m3c.cooperativity_from_g ─▶ qnet_transducer.cooperativity()    （QS-M3c → J5）
qs_m2.cpmg_filter ──────────▶ qnet_classical                      （QS-M2 → J5）
```

**风险**：上游档改了常量值、改了函数参数名、改了默认值或挪了位置 ⇒ **下游静默漂移**（不报错、不崩溃，只是数变了），而黄金锚只覆盖各自档位，**跨档漂移没有任何判据看守**。

**治法**：把「谁复用了谁的什么」连同**接口指纹**一并落成**受跟踪台账**，再用常驻门禁把「上游一动 ⇒ 表不重生成就红」机器化。

🔴 **C 组必须独立实现**：若门禁直接调用生成器的 `build()`，就是**同源自证**（生成器算错 ⇒ 门禁跟着错）。故门禁内自带一份**独立 AST 扫描器**（只取三元组集合，不做指纹）。

🔴 **E 组的价值**：4 道探针**先证判据能变红**，再谈全绿 —— 否则「恒绿空转」无法排除。

## 7. 诚实边界

1. 表只覆盖**量子赛道 45 模块**的**静态 `import` 关系** —— 不含动态 `importlib`、`getattr(mod, name)` 字符串间接引用 ⇒ 是**下限**而非全集。
2. `const` 为 dict / 自定义对象者以 **`repr` 快照**（非逐字段 diff）；`pulse_library.DEFAULT_PULSE` 即此类（dict）。
3. 指纹是**接口形态**，不是**行为等价**：签名不变而函数体改了，本表**拦不住**（那归各档 golden 与门禁管）。
4. 表**不新增任何物理断言**，不改变任何既有 golden 与独立率。

## 8. 什么时候必须重生成

```bash
# 1) 任一量子赛道模块的「跨模块 import」有增删改（含只改行号）
# 2) 任一被复用的 const 改了值
# 3) 任一被复用的 function/class 改了签名或默认值
python scripts/k3_cross_stage.py --write
python lda/run_k3_cross_stage_smoke.py     # 22 判据必须全绿
```

**忘记重生成会怎样**：门禁 B1（逐字节）与 C1/C5/C6 **当场红** —— 这正是本表存在的意义：

> **上游改档不再「静默漂移」，而是「闹钟响」。**
