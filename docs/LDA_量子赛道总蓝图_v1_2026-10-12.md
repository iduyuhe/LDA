## 0. 复利原则（本蓝图的排序法则）

量子赛道按**复利**依次推进：每一档征程必须 ① **向后复用**既有求解器/锚/基础设施（不重造轮子）、② **向前沉淀**可被后续征程复用的资产、③ **单调增长**可验证锚资产池。排序 = 按"复用厚度 × 杠杆 × 缺口闭环"综合最大化，而非按单一热度。

三条硬约束（继承 LDA 铁律）：

- **主权求解器**：新物理链必须闭式 golden ⇄ 方法学独立数值候选，纯 C 级（numpy/scipy），不借 GPL/Meep/Tidy3D。
- **LLM 不进判决路径**：全部死标量比对。
- **绝对 tol 按量级标定**：跨量级锚必按各自物理量纲定 tol（血案 B487/B492/B495）。

### 3.1 旅程明细（复利账：复用 → 建造 → 候选锚 → 沉淀）

#### 🥇 J1 量子纠错（QEC）— 逻辑比特层 · **建议首发**

- **向后复用**：Q 门库（幺正/通用）+ `surface_code.py` + `yield_fault_tolerance`（C12）+ transmon 基础（QS-M6/M7）+ `qeda_topology` 退相干预算。
- **建造**：① 阈值（逻辑错误率 vs 物理错误率 × 码距）② 解码器（MWPM / Union-Find，正确性 + 复杂度）③ 综合征提取（稳定子测量、flag qubit）④ 容错逻辑门（transversal / lattice surgery）⑤ 端到端逻辑错误率标度。
- **候选锚**（编号接 B497+，立项定）：逻辑错误率码距标度（独立误差近似闭式 ⇄ 蒙特卡洛解码）· MWPM 在已知最小权完美匹配上的闭式 ⇄ 数值 blossom · 稳定子本征值闭式 ⇄ 数值投影 · 容错门预算链。
- **向前沉淀**：容错拓扑 + 解码器架构 + 逻辑比特抽象 ⇒ 喂 J2 物理层校核、J5 网络。
- **闭环缺口**：G_Q9 + G-QEC*。
- **为何首发**：量子计算实用化唯一卡口；LDA 已有地基最厚；杠杆最高（逻辑层是其余一切的服务对象）。

#### 🥈 J2 超导量子处理器（Transmon QPU）— 物理比特层

- **向后复用**：QS-M6/M7 Josephson/transmon 物理 + J1 物理错误模型 + E 模拟读出。
- **建造**：transmon 能级（E_J/E_C/非谐性 α）· 耦合器（电容/电感/ gatemon）· 读取谐振器 · 串扰谱 · 比特布局与可布线性。
- **候选锚**：transmon 能级闭式（Matthiessen/CPB 极限）⇄ 数值对角化 · 耦合强度 · 色散位移 χ · 读出 SNR · 串扰系数。
- **向前沉淀**：物理比特参数库 + 布局 + 读出链 ⇒ 回喂 J1 真实物理层、喂 J3 测控。
- **与 J1 关系**：J1 用理想物理层起步；J2 提供真实物理层 ⇒ **J1↔J2 复利闭环**（可部分并行）。

#### 🥉 J3 量子测控与读出（Control & Readout）— 闭环可用性

- **向后复用**：J2 transmon + 色散读出 + E 模拟 + QS-M5 闭环标定思路。
- **建造**：Rabi / DRAG 脉冲（泄漏抑制）· 随机基准测试 RB（门保真衰减）· 色散读出链（χ/κ/SNP/Purcell 滤波器）· cryo-CMOS · 实时解调。
- **候选锚**：Rabi 闭式 ⇔ 数值 ODE · DRAG 泄漏抑制比 · RB 衰减拟合保真 · 色散 χ=−g²/Δ。
- **向前沉淀**：测控脉冲库 + 读出链模型 ⇒ 喂系统级（J4/J5）。

#### J4 量子传感系统集成（QS 二期）— 器件 → 系统

- **向后复用**：QS 三腿 + M4 阵列 + M5 标定 + M3c 腔 QED。
- **建造**：① 多参数 NV（磁场/温度/电场/压力一体化解耦）② 芯片级微型 OPM（MEMS 气室 + VCSEL + 光电二极管）③ NV 阵列 + 微波 + 光路 + 读出单芯片 ④ 低温布线/封装。
- **候选锚**：多参数串扰解耦矩阵 · 微型气室填充/缓冲气体 · 集成串扰 · 封装热负载。
- **向前沉淀**：传感系统封装 + 产品化；多参数 NV ⇒ 喂 J5 网络节点。

#### J5 量子网络与接口（远期）— 连接量子节点

- **向后复用**：NV 自旋 + 腔 QED + 光子 PDA + J1 逻辑比特。
- **建造**：纠缠分发 · 量子中继 · 微波-光换能器 · 量子-经典接口。
- **候选锚**：纠缠保真度 · 中继增益 · 换能效率。
- **定位**：远期（依赖 J1/J2/J4 成熟），先列路径不急于立项。

## 4. 推荐起步与推进机制

**推荐首发 = J1 量子纠错（QEC）**。理由：① 战略卡口（物理比特→逻辑比特的唯一路径）；② LDA 已有地基最厚（门库/表面码/容错映射/transmon 基础），启动成本最低；③ 物理律锚最丰富（阈值定理、解码器正确性、逻辑/物理错误率标度）；④ 直接闭环量子计算遗留缺口 G_Q9；⑤ 与已 done 的 Q 征程拼成"理想门 → 容错实现"完整叙事。

**推进机制（继承 QS 征程验证过的范式）**：

1. **先立项评审**：用户确认旅程 + 范围后，出该征程《可行性评估/架构定义》+ 蓝图补丁。
2. **每档吃狗粮**：用 LDA 从零设计该域一枚真实芯片，物理链逐量「闭式 ⇄ 方法学独立候选」。
3. **锚纪律**：净增锚同登五处 + tol 按量级标定 + 反自证桩 + 突变探针「先证能变红」。
4. **三同步 + 全量 CI**：每版 bump 跑 `run_count_consistency` + 冻结快照全量 CI 干净记录后再发布。
5. **诚实边界**：设计示例量级标"非实测"；SOTA 未达如实标注对照比；不报 fabricated 能效。
