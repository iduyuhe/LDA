## 2. 架构选型（以及为什么）

### 2.1 DAC = **R-2R 梯形网络**（无源 + NMOS 开关 + 缓冲）

```
b_{N-1} ──R──┬──R──┬── … ──┬──R──┬── V_out（经缓冲）
             │     │        │     │
            2R     2R       2R    2R      b_k = 1 接 V_ref / 0 接地（NMOS 开关）
             │     │        │     │
            b_{N-1} …             b_0
```
- **为什么 R-2R 而不是二进制加权电阻**：R-2R 只需**两种阻值**（R / 2R），匹配要求低；
  二进制加权需要 2^N 倍跨度（8 bit = 256:1），在几何上不可实现。
- **golden**：理想分压闭式 **`V_out(code) = V_ref · code / 2^N`**（教科书写法）。
- **次生 golden（网络装配自证）**：由末级向输入端**逐节点递推**的戴维南等效 —— 用来证明
  **是网络本身（而非 golden 公式）** 给出了正确值（同 E7「R=0 网络 ≡ 解析 golden」的纪律）。

### 2.2 ADC = **SAR + CDAC（电荷重分配）**

```
V_in ──[采样开关 M_s]──┬── C_{N-1} ──[开关 → V_ref / 0]──┐
                      ├── C_{N-2} ──[开关 → V_ref / 0]──┤  顶板
      采样电容 C_s ────┤   …                            ├──▶ 比较器 ▶ SAR 逻辑
                      └── C_0     ──[开关 → V_ref / 0]──┘        （逐次逼近）
```
- **为什么 SAR/CDAC**：核心物理是**电荷守恒**（`Σ Q_i` 在开关翻转前后守恒）⇒
  **golden 干净**（`V_top = V_ref · Σ b_i C_i / C_total`），且 CDAC 的**瞬态充放电可用 `solve_transient` 真跑**。
- **比较器实现（关键取舍 · 必须披露）**：MNA 无非线性饱和器件 ⇒
  比较器建模为「**有限增益 + 输入失调 + 噪声**」的**判决器**：
  模拟域用 MNA 解出差分电压 → 判决取符号。**这是混合信号仿真的标准做法，但它是抽象，不是晶体管级比较器** ⇒ 写进披露与 GAP。
- **采样保持**：`C_s` + NMOS 开关（**真瞬态**，可测**建立误差 `v(t)=V_in(1−e^{−t/RC})`** 与 **电荷注入/时钟馈通**）。
- **次生 golden**：SAR 第 k 步后**剩余不确定区间 = `V_ref / 2^k`**（逐次逼近闭式）⇒ 收敛性自证。

### 2.3 行驱动 = **有限增益缓冲 + 输出电阻**（两级）

- (a) **有限增益单位增益缓冲**：`VCVS(gain=A)` + 输出电阻 `R_out`
  ⇒ **golden**：`V_load = V_in · A/(1+A) · R_load/(R_out + R_load)`（**两次分压闭式**）。
- (b) 🔴 **与 IR drop 耦合（本段最有价值的系统级结论）**：把 `R_out` 串进 **E9 的一维三对角网络**
  ⇒ **重算可及规模上界**。E9 的结论是「理想源驱动下 5% 预算 → N≤18」；
  加上真实驱动阻抗后 `R_out` 与行线电阻**串联累加** ⇒ **可及规模必然进一步收缩**。
  这把「器件级参数」第一次**反馈到规模律**上。

### 2.4 系统链 = **端到端对照**

`DAC → 行驱动(+R_out) → 阵列(E2 + E7 寄生 R) → TIA → ADC(SAR)` 全链，
与 **E3 的理想通路**逐项对照 ⇒ 给出三个代价：**精度（ENOB 损失）/ 面积 / 速度**。

## 4. 判据设计（拟 20 条 · name-first）

**A 模块自检**
- ① DAC 静态：8 bit 全码扫描，MNA 解 ⟷ `V_ref·code/2^N`（max |Δ| < ½LSB 目标 / 实测容差）
- ② DAC 单调性：码增 ⇒ 输出**严格不减**（DNL ≥ −1 的条件）
- ③ R-2R 网络装配自证：逐节点戴维南递推 ≡ 闭式（末位级）
- ④ ADC SAR 收敛：8 bit 逐次逼近，输出码 ⟷ 理想量化（≤1 LSB）
- ⑤ CDAC 电荷守恒：每次开关翻转前后 `ΣQ` 守恒（相对误差 < 1e-9）
- ⑥ 采样保持瞬态：`solve_transient` ⟷ 一阶 RC 闭式
- ⑦ 行驱动负载调整：`R_out` 增大 ⇒ 负载电压下降（且 ⟷ 两次分压闭式）
- ⑧ 系统链端到端：`DAC→驱动→阵列→TIA→ADC` ⟷ E3 理想通路（误差有界 + 随位数下降）

**B 物理/架构判据**
- ⑨ **ENOB 损失**：真外围 ENOB < 理想通路 ENOB，且差距随外围精度提升而缩小
- ⑩ R_out 单调性：`R_out↑ ⇒ 可及规模上界 N_max↓`（**核心系统结论**）
- ⑪ 采样时间单调性：`t_sample↑ ⇒ 建立误差↓`（一阶 RC 收敛）
- ⑫ DAC 位数趋势：bits↑ ⇒ 静态误差↓

**C 反向可证伪（6 探针）**
- C1 破坏 DAC 参考权重（某支路 R 改 ×2）⇒ ① 必红
- C2 比较器判决反向 ⇒ ④ 必红
- C3 删掉 CDAC 某电容 ⇒ ⑤ 电荷守恒必红
- C4 把 `R_out` 强制归零 ⇒ ⑩ 必红（"理想源"假设被证伪）
- C5 采样电容归零（无采样保持）⇒ ⑥ 必红
- C6 系统链 golden 被替换 ⇒ ⑧ 必红

**D 保护性约束（红线内）**
- 🔴 **`NmosParams` 默认值逐位不变**（E1–E13 全部已上线数字建立其上）
- 🔴 **E3 的 `quantize_uniform` / `MvmDatapath` 行为级通路不改**（真转换器是**并行第二通路**，不替换）
- 🔴 零商业 SPICE/EDA；golden = 闭式物理律；LLM 不进判决路径

## 5. 诚实边界（本段自带）

- **比较器是判决器抽象**（有限增益 + 失调 + 噪声），**非晶体管级比较器** —— MNA 无非线性饱和器件，
  且 E2 已证明朴素 NMOS 差分对无法闭合高增益环路。
- **DAC/ADC 均为低位（拟 ≤8 bit）**：高位会带来规模与收敛成本；真实芯片的电容/电阻阵列匹配问题
  只以 E8 的 Pelgrom/MC 口径**旁引**，不做专用匹配网络（**无专用校准 DAC/修调网络**）。
- **开关为非理想但简化**：`R_on` 用平方律三极管区闭式；**电荷注入/时钟馈通只做量级估算**，不建完整模型。
- **R-2R 用"理想 R 与 2R"** ⇒ 不建电阻失配（失配沿用 E8 的 MC 口径作旁引）。
- 参数为公开典型量级占位（**非 PDK**）；**不做流片**；不报 TOPS / TOPS-W / fJ/op。
- **本段不新增器件级 PDE 能力**（器件级已在 E11–E13 闭环）⇒ 新能力面是**电路级/架构级外围**。
