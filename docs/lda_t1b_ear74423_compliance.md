> 文档性质：T1 内核对外演示 / 交付 / 文档前的**强制合规声明**（研发规划 §1.1 / §5 / T1-B-W3）。
> 本件与 `lda/lda_solver/drift_diffusion_1d.py` 的红线声明、`guard_t1_not_oracle()` 守卫、
> 以及 CI 门禁（缺声明 / 离线构建证据即红）配套生效。

## 1. 用途声明（成熟节点 / 非先进用途）

🔴 **LDA T1 电学/TCAD 数值内核（含自研 1D 漂移-扩散+连续性求解、以及后续可选的 DEVSIM Apache-2.0
fork 内核）仅用于**：

- **成熟节点**（典型 ≥ 28nm 平面 / 成熟特种工艺）半导体器件的设计阶段载流子分布仿真；
- **非先进用途集成电路**（非 EAR 744.23(a)(2)(iii) 定义的"先进节点集成电路"）的接缝设计入口；
- 行为仿真与候选生成，**不流片、不抢制造**（研发规划 §1.1 铁律 4）。

**禁止用途**：明知用于中国先进制程芯片（先进节点集成电路）设计，或任何受 EAR 744.23 最终用途
管制约束的先进节点场景。一旦触及该边界，立即停止对外演示 / 交付并上报。

## 2. EAR 744.23 管制要点（诚实提醒 · 不可省）

- **EAR 744.23(a)(2)(iii)**（2024-12-02 新规）按「**用途（先进节点集成电路）**」管制 ECAD / TCAD，
  **非按代码许可**。开源 TCAD 在**技术主权 / 代码层面**不受美系商业绑定（DEVSIM Apache-2.0 可合法
  fork 到 Gitee/GitCode 主权副本），但**若明知用于中国先进制程芯片设计仍可能触线**。
- 「**开源 ≠ 完全不受 IP 影响**」：本提醒为红线组成部分，每次 T1 内核对外演示 / 交付 / 写入文档前
  **必复核用途声明**（研发规划 §1.5 铁律）。
- 与美系 A 级商业求解器（Sentaurus / Lumerical DEVICE / COMSOL 半导体）**零 import、零依赖**，
  不构成对美系商业 ECAD/TCAD 的规避使用。

## 4. T1 输出不作 ORACLE 纪律（红线）

- 自研 / DEVSIM 内核解出的 N(x)/P(x)/φ(x) 仅为**候选（candidate）**，`is_oracle=False`。
- 死标量判决仍由**物理定律锚 / 教科书闭式 golden（Sze 耗尽近似）/ foundry 实测 / 公开文献**定。
- `guard_t1_not_oracle()` 反向测试守卫：若判决回路误用 T1 数值解为 ORACLE ⇒ 必 raise（破红线）。
- 真值标定来源 = T2 期 MPW 实测回流（T1 给行为预测，T2 给真值标定，互补不替代）。
