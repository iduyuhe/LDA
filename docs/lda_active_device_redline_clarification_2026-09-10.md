# LDA 有源器件边界梳理（红线澄清 · 2026-09-10）

> 目的：杜先生提出"时间长了记不清当时为什么控制有源"，要求先梳理红线边界与根因，再决定是否动手。
> 本文**只梳理、不实现**。所有结论均来自仓库既有权威文件，注明出处。

---

## 零、一句话结论（先给答案）

1. 仓库里**没有"禁止做有源器件"这条独立红线**。有源之所以"被控"，是**三条既有红线的下游连锁后果**，不是单独禁令。
2. 杜先生记忆的"控制边界以免太早贪多"**方向正确**，但根因更具体：有源真物理会同时撞上
   - **三不做之「电域求解器」「Foundry TCAD」**（真激光/SOA 必须的电-光耦合求解，属禁区）
   - **主权「A 级永不借」**（Lumerical DEVICE / Sentaurus 这类真器件求解器属美系 A 级，不能 import）
   - **验证纪律「LLM 不进判决路径 + 判决须落非 AI ground」**（真有源验证需要 foundry 实测 ORACLE，我们无主权）
   - **战略定位「做 PDK 兼容的设计入口，不抢制造/流片」**
3. **条件是否成熟——要分两档看，不能一概而论：**
   - **A 档（闭式/行为层，物理定律锚）**：✅ 现在就成熟，且**不破任何红线**，可立即扩。
   - **B 档（真器件物理：激光 L-I / 增益 / 载流子动力学 / 探测器带宽真求解）**：❌ **不是"条件未成熟"，是被红线结构性封死**——这是战略边界，不是能力缺口，不会因我们变强而自动解锁。

## 一、红线到底是什么（权威出处逐条）

### 1.1 三条不可逾越的红线（CONTRIBUTING.md:9-13 · 对外口径）
| # | 红线 | 原文要点 |
|---|---|---|
| ① | **主权求解器** | 核心数值内核（FDTD/FDFD/Mie/TMM/严格对角化）不依赖 GPL/Meep/Tidy3D，必须可独立运行、可逐位验证 |
| ② | **LLM 不进判决路径** | 大模型只写代码/提方案，绝不参与数值正确性判决；判分由确定性 ORACLE（物理定律锚+实测语料锚）完成 |
| ③ | **可验证优先** | 任何新求解器/器件模型必须带可复现自测（golden 物理定律锚+开放对抗题），否则不进主线 |

### 1.2 三不做（MEMORY.md:7 · 内部铁律）
> 三不做：**电域求解器 / Foundry TCAD / 封测实体产线**

### 1.3 主权三级（MEMORY.md:7 + build_pitch_deck.js:225-229 + whitepaper 4.2）
- **A 级永不借**：Lumerical / Ansys / Synopsys / Cadence 等美系商业求解器，直接不采用。
- **B 级借今踢后**：gdsfactory / Meep / KLayout / SAX 等开源组件，fork+镜像冷备，离线可构建。
- **C 级自主**：核心算法自研。

### 1.4 验证红线（MEMORY.md:6）
> 判决落非 AI ground（物理定律锚 + 实证大数据锚）；LLM 不进判决路径，PASS/FAIL 由死标量定。

### 1.5 战略定位（design_alliance_resource_planning_report.md:6 · 诚实边界）
> LDA 是开源、Agent 原生、物理定律锚的 EDA；**不抢制造、不抢流片，做 PDK 兼容的设计入口**。
> 诚实边界：属**等效验证**（对标公开 datasheet/标准/文献），非本团队流片。

## 二、当时为什么要控有源——四重根因（不是单一"不贪多"）

代码库里**从未出现"active device = forbidden"字样的规则**。有源被控是以下四条约束的**交集后果**：

| 根因 | 出处 | 对有源意味着什么 |
|---|---|---|
| **① 三不做·电域求解器** | MEMORY.md:7 | 真半导体激光器/SOA/EAM 需要**电-光耦合求解**（漂移-扩散 Poisson + 连续性方程求载流子分布，再喂给光学增益）。这属于"电域求解器"，在禁区。 |
| **② 三不做·Foundry TCAD** | MEMORY.md:7 | 真实器件还需工艺建模（掺杂/刻蚀/应力），属 foundry 专有工艺模型，我们无法主权复现，只能消费 PDK。 |
| **③ 主权·A 级永不借** | MEMORY.md:7 · pitch deck | 唯一能"真正算"有源的商业工具（Lumerical DEVICE 电-光、Sentaurus TCAD）属美系 A 级，**不能 import**——等于真有源物理在主权内核里无解。 |
| **④ 验证纪律 + 战略定位** | CONTRIBUTING.md:12 · design_alliance:6 | 判决须落非 AI ground。真有源验证需要 **foundry 流片实测 ORACLE**（L-I 曲线/增益谱/带宽），我们没有主权、也不流片 → 无 ORACLE → 无法按铁律验货。且定位是"设计入口"不是"器件物理所"。 |
| **⑤「不贪多」纪律（杜先生记忆的来源）** | roadmap §零(12-22) | 接线线已触顶（可接上限 24/48，仅剩 4 道空间），主线已**从"加锚数量"转向"可验货性"**。此时开"真有源物理"是大坑，会稀释已建立的验证可信度立身之本。 |

**结论**：杜先生记忆的"控制边界以免太早贪多"= 上表第⑤条，是真实的、但只是**五条里的一条**。真正的硬约束是 ①②③④（红线 + 主权 + 验证纪律 + 定位），它们让"真有源"在当前架构下**物理上无解**，而非"我们暂时不做"。

## 三、"有源"在代码库里的真实现状（已查实，非印象）

器件库 `lda_l2/device_library.py` 注册**全是 passive**：DirectionalCoupler / Waveguide / RingResonator / BraggMirror / MMI / GratingCoupler。

但 **52 锚里已有 3 道"有源相关" + 一个行为模型模块**，只是**最薄的一层**：

| 已落地 | 物理内核 | 性质 | 在 52 锚内？ |
|---|---|---|---|
| **B28** MZM 调制器 Vπ | Pockels 电光 `Vπ=λd/(2n³rΓL)`，解析闭式（LiNbO₃） | 闭式物理定律 | ✅ 已入（注：其沿程积分候选被判据 D 证伪为假独立，见 IRONLAWS 判据 D） |
| **B29** 热光相移效率 | 1D 散热鳍 PDE 闭式 + FDM 交叉 | 闭式物理定律（热扩散） | ✅ 已入 |
| **B30** 读出保真度 | erfc 读出链（Krantz 2019） | 量子侧，非光子有源器件 | ✅ 已入 |
| `active_models.py` | 热光相移 / MZI 透射 / 探测器响应度 `R=ηqλ/hc` | 闭式 + 黑箱行为 | 模块已存在 |

**关键判读**：这三道 + `active_models.py` **全是"参数/行为"层——零载流子、零增益、零速率方程**。Si 自由载流子效应 `Δn_eff=-k_n·N` 只写在 `active_models.py` 注释里，**没有载流子求解器**。即：有源"外壳"已有，"内核"一件没做。

## 四、现在条件是否成熟——诚实分两档

| 档位 | 内容 | 是否破红线 | 成熟度 | 说明 |
|---|---|---|---|---|
| **A 档·行为/参数层**（复用 B28/B29 范式） | Si 载流子色散 Vπ（闭式 `Δn_eff=-k_n·N` 驱动 MZM）· EAM-QCSE 位移闭式 · 探测器带宽 `τ=RC` 闭式 · 激光器腔体 FSR/布拉格/线宽闭式 · 探测器响应度 `R=ηqλ/hc`（已有） | ✅ **不破**（仍是闭式物理定律 + PDK 标定行为） | **成熟，可立即扩** | 与 B28/B29 同一性质：物理定律锚 + 独立交叉验证，落入 VMM 即合法。把"有源"从 3 锚扩到 ~8 锚，凑齐调制/探测/热调行为闭环 |
| **B 档·真器件物理** | 激光器阈值/L-I 曲线 · SOA 增益谱 · 载流子动力学（速率方程真求解）· 探测器带宽真求解（RC/渡越/暗电流/APD 倍增） | ❌ **直接撞「电域求解器 + Foundry TCAD + A 级永不借」三条** | **不成熟，且非能力问题** | 这些必须有电-光耦合求解器 + foundry 工艺 ORACLE，均在红线/主权禁区。要动手 = 必须先由杜先生拍板**放宽"三不做"红线**，或明确定位"真物理交由 Foundry TCAD、LDA 只管闭式入口与验收" |

**对"条件应该成熟了"的回应**：杜先生的直觉对 **A 档**完全成立——A 档本就不需要任何新能力，只是之前没排进优先级（主线在"可验货性"）。但 **B 档不是"条件成熟就能做"**，它卡在红线/主权/定位这类**战略边界**，不会因我们光子侧变强而自动解锁。这正是最初"控有源"的本质：**不是能力不够，是边界外**。

## 七、终审裁定（2026-09-10 杜先生确认）

经本节梳理，杜先生拍板两点，作为有源器件边界的**终审记录**（防反复审议）：

1. **A 档（闭式/行为层有源）授权启动**：Si 载流子色散相移（Soref-Bennett）/ EAM-QCSE 位移 / 探测器带宽 τ=RC / 激光器腔体 FSR·布拉格 等闭式锚，**授权扩展**，复用 B28/B29 已验证范式。载体密度由耗尽近似闭式给出、**不求解漂移-扩散方程** → 不破电域求解器红线。执行节奏：先出锚题契约评审，再写码。
2. **B 档（真器件物理）维持三不做、真有源永久不做**：激光 L-I / 增益谱 / 载流子动力学 / 探测器带宽真求解，需电域求解器 + Foundry TCAD + A 级工具，全在禁区。LDA 只管闭式入口与验收，真物理交由 Foundry TCAD。**此边界终审锁定，勿反复审议。**
3. **缘起澄清**：原"控有源"非独立禁令，是「三不做 + 主权 A 级 + 验证纪律 + 战略定位 + 不贪多」五重约束的下游后果；杜先生直觉"不贪多"为五条之一，方向正确但非全貌。
