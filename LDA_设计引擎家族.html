CPO 硅光 I/O 共封装

lda_design.cpo_engines.cpo_optical_io_metrics
  • 每通道插入损耗 = GP-* 已锚定基元 dB 级联（S1 同构）
  • 海岸线带宽密度 = lane_rate / pitch（纯几何算术）
  • 链路功率余量 = P_tx − IL − 探测器灵敏度（S1 同式）
  • 🔴 护栏① D-67 能量守恒下界（分束≤3.0103dB/级）
  • 🔴 护栏② P-CPO 间距几何下界（ITU-T G.652 125/10.3µm）
  • ⚠ 不判决能效 pJ/bit（电域，无锚）；EIC 黑箱

QKD 安全密钥率

lda_design.qkd_engines.decoy_bb84_skr

  • 🔴 Q-D67 护栏① 密钥率≤单光子贡献上界
  • 🔴 Q-D67 护栏② 等效探测效率 η≤1
  • 对标公开 datasheet / 论文量级（等效验证，非本团队流片）

闭环机制： 每个引擎两阶段——① 搜索用物理定律 ORACLE（slab 闭式 / TMM / Koch / FSR）在参数网格上瞬时逼近目标；② 验证仅对 top-K 候选跑真实求解器（FDTD/TMM/对角化）双重验证，返回的"最优设计"是被求解器验证过的。
红线： LLM 不进判决路径，passed 由死标量比对决定；loss 类引擎首次把实证语料（E1–E7）引入引擎级判决（D-66/D-67 同量纲纪律）。
