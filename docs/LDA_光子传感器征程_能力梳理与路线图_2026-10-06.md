# LDA 光子设计能力梳理 · 国际版图对照 · 光子传感器征程路线图

> 文档日期：2026-10-06
> 目的：在启动"光子传感器（Photonic Sensor, 代号 PS）"新征程前，先摸清 LDA 平台现有的光子设计家底、国际光子设计领域版图与先进水平基准，再以"自己先吃狗粮"的方式设计一款光传感器，用设计倒逼平台能力补齐，分步逼近国际水平。
> 纪律遵循：C 级自主（纯 numpy/scipy，不借 GPL/Meep/Tidy3D 当作判据）、闭式物理律作 golden、LLM 不进判决路径、方法学独立验证 + 反向探针。

## 1. 执行摘要

- **平台家底（光子）**：LDA 已具备一套相当完整的"通用硅光 PIC 设计基座"——模式求解（全矢量/半矢量，含 vendored 库）、FDTD（1D/2D/3D，numba/torch 后端、CPML、S 参数、伴随法）、定向耦合器（D-01 闭环验收）、微环（FSR 解析↔洛伦兹谱，D-11）、MZI 几何与干涉传输、热光/电光调制（Vπ、热相移效率）、探测器（Ge PD 响应度/带宽、APD）。版图链路 placement→routes→GDS 导出→DRC→LVS 闭环成熟，已有光子计算 M1–M5、光联接 OI M0–M5、光子存储 PM M0–M6b 三档征程资产可复用。
- **平台缺口（传感器纵向）**：传感器特有的"敏感层建模 → 折射率转导(dλ/dn) → 灵敏度/优值/探测极限(LOD)指标 → 传感窗口开窗工艺 → 微流控 → 报告与 WebUI"这一整条链路**为零**。具体缺 6 项（见 §3）。
- **国际基准（传感器）**：SOI 纳米线 *bulk* 灵敏度约 100–500 nm/RIU，slot/suspended 可达 10³⁺ nm/RIU；MZI 与环同物理 S，长臂 MZI 因作用长度可放大（特定器件报告 2870 nm/RIU，非固定值）；级联环 Vernier 的 4.6×10⁵ 是**读出分辨率放大后的表观灵敏度**，非真实 S；表面/分子灵敏度（蛋白）最高 2306 nm/RIU（*surface* 量，不可与 bulk 直接比）。探测极限(LOD)分两档：理想(线宽受限) 10⁻³–10⁻⁴ 量级，实测优良 10⁻⁶–10⁻⁷ RIU（需 Q~10⁵–10⁶ + 低噪读出）；2025 自参考等离子 MZI 实测 LOD 2.6×10⁻⁶ RIU。Q 值 10⁴–10⁵（环）/ 10⁵–10⁶（光子晶体腔）。🔴 四类灵敏度口径不同，**禁止混比**（详见 §5.5）。
- **征程策略（吃狗粮）**：以 PS-M0（裸硅环/MZI 折射率传感器，先用现有模式求解器算 dneff/dn_clad 得到体灵敏度）→ 逐级补"传感窗口开窗几何、传感器指标求解器与报告、高灵敏度架构、生化功能化、微流控阵列、WebUI 向导"，每一步都**先自己设计、跑通、发现缺口、机器验证补齐**，再进入下一档。最终逼近"片上 POC 诊断/环境监测集成芯片"的国际集成水平。

## 3. 平台能力缺口（针对"设计光传感器"用户）

| # | 缺口 | 说明 | 国际对标所需 |
|---|---|---|---|
| ① | 生物/化学敏感层模型 | 无 cladding 锚定/功能化、无表面结合动力学、无"包层折射率变化→有效折射率变化"的传感转导封装 | 表面灵敏度、分子 LOD |
| ② | 传感器专用 PDK 器件 | 无 slot waveguide、suspended ring、传感窗口开口环/MZI 臂；IR `KNOWN_KINDS` 与 `primitives` 无 sensor kind | 高灵敏度架构 |
| ③ | 传感器指标求解与报告（最关键） | 经全仓检索，无 `dλ/dn`、`S`、`FOM=S·Q`、`LOD`、`NERI`、标定曲线；现有"sensitivity"全是探测器链路灵敏度/伴随法 ε 梯度/相位漂移灵敏度，**均非折射率传感转导指标** | 一切传感器性能量化 |
| ④ | 传感窗口工艺层 | 层栈仅 SI/CLAD/METAL/PCM/HEATER，无"开窗刻蚀 cladding"工艺层与对应 DRC 特例；微环传感需局部去包层，当前 DRC 会判违规 | 传感窗口合规 |
| ⑤ | 微流控 / Lab-on-chip | 无流体通道、进样口版图与流体-温度-光学多物理场耦合 | 实用化传感器 |
| ⑥ | WebUI 传感器面板 | 无 `/api/sensor_demo` 或传感设计向导 | 客户自助设计 |

**起点洞察（重要）**：缺口③并非"完全不能算"。折射率传感的核心是 **dneff/dn_clad = 模态在包层中的功率占比**（弱扰动微扰论，闭式物理律），而 LDA 现有全矢量模式求解器已能给出模态场分布。因此 **v0 可直接用现有模式求解器算出 dneff/dn_clad，进而得到体灵敏度 S = (λ/n_g)·(dneff/dn_clad)**——这意味着平台"基座够用"，真正缺的是"封装成传感器指标与报告"以及后续的高灵敏度架构与功能化。这正是吃狗粮要补的方向。

> 🔴 **口径前置声明**：本报告统一以 §5.5 的闭式定义对标。关键红线——**bulk 灵敏度、surface 灵敏度、Vernier 表观灵敏度、MZI 长臂灵敏度 四者不可直接互比**；LOD 必须区分「理想(线宽受限)」与「实测(含噪)」；FOM=S·Q 与 LOD_intrinsic=λ/(S·Q) 互逆，NERI 与 LOD_intrinsic 同义（不另列）。PS-M0 已交付的是 **S_bulk + LOD_intrinsic 基线**，不是实测 LOD。

## 5. 差距基准（Gap-to-International，量化）

> 🔴 **指标口径先校准（详见 §5.5）**：bulk 灵敏度、surface 灵敏度、Vernier 放大、MZI 灵敏度 四者量纲/物理意义不同，**禁止混比**。LOD 分「理想(线宽受限)」与「实测(含噪)」两档；FOM=S·Q 与 LOD_intrinsic=λ/(S·Q) 互逆；NERI 与 LOD_intrinsic 同义（不另列）。

| 指标 | 国际先进（可公开对标） | LDA 现状（PS-M0 后） | 差距 | 补缺口里程碑 |
|---|---|---|---|---|
| 体灵敏度 S_bulk (nm/RIU) | SOI 纳米线（薄线/开窗）100–500；slot/suspended 10³⁺ | v0 已算：exposed-top 30.3 / whole-clad 86.5（SOI 500×220 粗线，偏保守） | 缺高灵敏几何 | PS-M3a(薄线)/M3b(slot) |
| 表面灵敏度 S_surf (nm/RIU 或 pg/mm²) | 蛋白最高 2306 nm/RIU（表面量，≠bulk） | 无功能化/吸附层模型 | 完全缺失 | PS-M4 |
| LOD_intrinsic (RIU) | 线宽受限 ≈ λ/(S·Q)；优值 10⁻⁴ 量级 | v0 已算 5.1×10⁻³（Q=1e4，S=30） | 随 Q↑ 可降 ~10×（Q→1e5） | PS-M2(噪声)+M3(Q↑) |
| LOD_real (RIU) | 实测优良 10⁻⁶–10⁻⁷（需 Q~1e5–1e6 + 低噪读出） | 无噪声模型 | 完全缺失 | PS-M2 |
| FOM = S·Q (nm/RIU) | 文献常用优值（LOD_intrinsic=λ/FOM） | v0 已算 3.0×10⁵ | 随 Q/S↑ 提升 | PS-M2/M3 |
| 高灵敏度几何 | slot/suspended/薄线/非对称臂 | 无对应 PDK 器件 | 完全缺失 | PS-M3 |
| 传感窗口开窗 | foundry 有 oxide window | 无工艺层/DRC 特例 | 完全缺失 | PS-M1 |
| 微流控集成 | lab-on-chip 主流 | 无 | 完全缺失 | PS-M5 |
| 客户自助设计 | GDSFactory+agent、IPKISS | 无 WebUI 面板 | 完全缺失 | PS-M7 |

## 5.5 指标口径定义（golden 闭式 · 必须先统一再对标）

| 符号 | 定义 | 公式 | 来源/备注 |
|---|---|---|---|
| S_bulk | 体转导灵敏度 | S = (λ/n_g)·(∂n_eff/∂n_clad)，由模式求解器闭式微扰（中心差商 + 向前差商互验）求得 | 同物理适用于环与 MZI；v0 已实现 |
| S_surf | 表面/分子灵敏度 | 薄吸附层（t≪衰减长度）引起的等效 S，单位 nm/RIU(表面) 或质量灵敏度 pg/mm² | 与 bulk 不同量纲意义，**禁止与 S_bulk 直接比** |
| FOM | 谐振腔优值 | FOM = S·Q | LOD_intrinsic = λ/FOM |
| LOD_intrinsic | 理想探测极限（线宽受限最优界） | LOD_i = λ/(S·Q) = λ/FOM | 真实 LOD ≥ 此；Q↑ 线性改善 |
| LOD_real | 实测探测极限 | LOD = δλ_min/S，δλ_min = FWHM/SNR（含热/散粒/探测器/激光噪） | 需噪声模型（PS-M2）；Q 与噪声共同决定 |
| Vernier 放大 | 读出分辨率放大（非灵敏度） | 因子 ≈ FSR₁/\|FSR₁−FSR₂\|（典型 10–100×） | 改善有效 δλ_min 与 LOD，但 **不改变 S 或 Q**；"4.6×10⁵"为表观读出灵敏度，非真实 S |
| MZI 灵敏度 | 与环同物理 S；长臂 MZI 因作用长度 L 可放大 | S 同式；长臂器件报告 2870 nm/RIU 是特定 L 值，非固定 | 随 L 增长，不可与环固定 S 直接比 |

🔴 **对标纪律**：任何"逼近国际水平"的声明必须同时给出 S_bulk/S_surf 口径、Q 值、LOD 档（intrinsic vs real）；禁止把 Vernier 表观灵敏度或 MZI 长臂值当作 bulk S 直接 pk。

## 6. 光子传感器征程路线图（PS，吃狗粮驱动）

> 总原则：每档先"自己用平台设计出来→跑通→发现缺口→机器验证补齐→再升级"，绝不先对客户开放未自检的能力。
> 🔴 **量化门（新增）**：每档必须给出"国际基准目标值 + 本档实测值"，实测未超过基线即视为"该几何改动未带来真提升"，禁止假宣传（与 LDA 红线一致）。
> 🔴 **依赖序（修订）**：PS-M1（开窗工艺）是 PS-M3 高灵敏几何物理实现的**先决条件**（暴露传感需去上包层）；PS-M2（指标框架，几何无关）应尽早建好，否则无法量化 M1/M3 是否真提升。

- **PS-M0｜基线可设计版 — ✅ 已完成（2026-10-06）**
  - 复用 `RingResonator`(Q/FSR)，用全矢量模式求解器算 **S_bulk = (λ/n_g)·(∂n_eff/∂n_clad)**（闭式中心差商 + 向前差商互验）→ 微环 Δλ 与 **LOD_intrinsic**；跑通 几何→GDS→DRC/LVS。
  - 实测（SOI 500×220 @1550）：TE n_eff=2.4508、n_g=4.18；**S_top=30.3 / S_whole=86.5 nm/RIU**；R=10µm Q=1e4 → **LOD_intrinsic=5.1×10⁻³ RIU**、FOM=3.0×10⁵。8 项守卫含反向探针全绿（见 `outputs/ps_m0/`）。
  - 登记缺口：G1/G2/G3(部分)/G4/G5/G6。

- **PS-M2｜传感器指标框架（几何无关，建议紧随 M0）**
  - 把 S/LOD_intrinsic/FOM=S·Q 形式化为标准报告；补 **LOD_real 噪声模型**（热噪/散粒噪/探测器/激光 RIN）；标定曲线（Δλ vs Δn）。**先做这档**，才能量化后续几何提升。
  - 量化门：LOD_real 模型在文献参数下应落在实测值 2× 以内。
  - ✅ **v1 已交付（2026-10-06）**：`lda/lda_l2/ps_m2.py` + `run_ps_m2_smoke.py`，7 项守卫全绿。复现文献 10⁻⁶–10⁻⁷ 带（cited 场景 LOD_real=9.3×10⁻⁷）、退化场景明显变差（1.9×10⁻⁵）、零功率/零 S 红标、LOD_temp 与 S 解耦、`LOD_intrinsic` 与 PS-M0 单一真源一致。关键洞察：**当前平台 v0 的 LOD_real≈1.9×10⁻⁶ 已落在文献带，但由温度漂移主导（非传感器几何）→ 凸显 PS-M6 referencing/温控的必要性**。

- **PS-M1｜传感窗口开窗 + 几何封装（M3 先决条件）**
  - 新增 sensor IR Kind（`SensingRing`/`SensingMZI`）；传感臂/环局部去上包层开窗几何；**传感窗口工艺层 + DRC 特例**（让去包层合规）；端口锚定。
  - 量化门：开窗后 S 应 > 裸环（暴露体积↑）。
