## 0. 一句话结论

M0–M3 交付的是**「单元 → 阵列」的光学侧**（能不能写、装几个电平、热与保持窗口、能不能排布并签核）。
M4 交付的是**「阵列 → 系统」的电学侧**：把光信号**读出来**、把电平**写进去**、把三段误差**合成一个系统 BER**、
并给出**可装配的 2.5D 立面与真 GDS**。此前 PM 征程的读出/写驱动**只存在于文字里**，本档把它落成**可算、可判、可点**的模块。

本轮三个结论，按重要性排序：

1. 🔴 **系统 BER 的瓶颈不在电域，而在光学域介质 drift** —— 等效误差占比 **drift 99.99% / 写量化 1.42% / 读出 1.5e-5%**。
   16 电平（4 bit/单元）的**保持窗口仅 1.7 秒**。⇒ 缺口 **PM-G7 从「派生缺口」升级为系统级阻塞项**。
   **该结论如实登记为开放缺口，不粉饰。**
2. **存储读出与 oi 高速链是两套口径** —— oi 为带宽牺牲 R_f；存储读出**低频高灵敏**，
   热噪声项 `4k_BTB/R_f` 主导时 **SNR ∝ √R_f** ⇒ 带宽上界内取最大 R_f 换灵敏度。
   实测读出灵敏度 **P_min = −39.78 dBm**、余量 **≈ 9495×** ⇒ **读出电路不是瓶颈**（电学侧全面让位给光学侧）。
3. **2.5D 的密度瓶颈在电域** —— EIC 通道 pitch（50 µm · 设计假设）> PIC 单元 pitch（18.05 µm · M3 实算）
   ⇒ 想提密度，**先压 EIC 通道 pitch**，压 PIC pitch 无收益。

另外一个**方法论产出**（与数字无关但更值钱）：本轮自查抓出**上轮门禁里的一条假绿** —— 见 §6。

## 1. 读出链（行为级）`readout_chain`

每级显式、全部由上游/常量**算出**，无字面量回填：

```
P_out,j = P_in · T_j                          （T_j 读 M1.level_design · 同源）
I_pd,j  = R_pd · P_out,j                      （R_pd = PD 响应度 · 规格锚区间 0.8–1.0 A/W，取下界 0.8）
V_j     = |Z(f_read)| · I_pd,j                （|Z| 复用 eic_behavioral 单极点 TIA 模型）
σ_I     = √( 2q·I_pd·B + 4k_B·T·B/R_f )       （散粒 + 热噪声；行为级取 B = f_read）
σ_V     = |Z| · σ_I
SNR_j   = (V_{j+1} − V_j) / (2·σ_V)           （相邻电平判决 · 取最坏对）
BER_j   = 0.5·erfc(SNR_j/√2)                  （与 M1 同一 BER 模型）
```

**本档（GST · 16 电平）实测**：

| 量 | 值 | 说明 |
|---|---|---|
| 读出频率 `f_read` | **1.0e5 Hz** | 设计选择（存储读出是低频高灵敏场景） |
| PD 响应度 `R_pd` | **0.8 A/W** | 规格锚**下界**（区间 0.8–1.0 ⇒ 保守取小） |
| 入射读光功率 `P_in` | 1.0e-3 W | 设计假设 |
| 电平数 `n_levels` | **16**（4 bit/单元） | 上游 M1 |
| TIA 反馈电阻 `R_f` | **2.0e4 Ω** | 设计点 = `min(缺省 20 kΩ, 带宽上界)` |
| TIA 跨阻 `|Z(f_read)|` | **19999.9994 Ω** | 低频近似 ⇒ `|Z| ≈ R_f`（差 3.2e-5 相对量） |
| TIA 3 dB 带宽 `f_3dB` | **397887357.7 Hz** | `1/(2π·R_f·C_f)`，`C_f = 20 fF` |
| R_f 带宽上界 | **7.9577e7 Ω** | `1/(2π·f_read·C_f)`（**反函数算出来的**，非硬编码） |
| 最坏 SNR | **32382.6** | 相邻电平对 |
| 最坏 BER | **0.0**（< 1e-308 下溢） | ≤ 目标 1e-12 ⇒ 自检 `all_ok = true` |
| 噪声主导项 | **散粒噪声主导** | `shot_dominant = true`（`i_shot ≥ i_therm`） |
| 口径来源 | ACS Photonics 2025 / arXiv 2512.23559 | 与 M1 同源（椭偏 · Cody-Lorentz · 30 nm 膜） |

## 2. 读出灵敏度与 R_f 权衡 —— **与 oi 高速链的本质区别**

`rf_tradeoff` 在 `R_f ∈ (0, 带宽上界]` 上扫 24 点：

| 量 | 值 |
|---|---|
| 扫描点数 | 24 |
| 设计点 `R_f` | **2.0e4 Ω** |
| 最优点 `R_f` | **7.9577e7 Ω**（= 带宽上界） |
| 设计点最坏 SNR | 32382.6 |
| 最优点最坏 SNR | **37021.3**（↑ 14.3%） |
| SNR 随 R_f 单调不减（判据） | **成立** |

> 🔴 **为什么这是「存储读出」而不是「oi 高速链」**：
> oi 链要 GHz 带宽 ⇒ `R_f ≤ 1/(2π·f·C_f)` 把 `R_f` **压到很小**（带宽是硬约束，灵敏度只能让步）。
> 存储读出的 `f_read` 低 ⇒ 同一个带宽上界**大 3–4 个量级** ⇒ 可以**把 R_f 往大的方向开**。
> 但本档实测 `shot_dominant = true` —— 说明在 `R_f = 20 kΩ` 已经**越过**「热噪声主导」区，
> `R_f` 的收益进入**递减段**（2 个量级 → 仅 +14.3% SNR），所以工程上不必一路开到上界，
> **20 kΩ 已足够**（24 点扫描把这个折点显式暴露出来，而不是靠拍脑袋）。

**读出灵敏度逆解**（二分求使 `worst_ber ≤ 1e-12` 的**最小** `P_in`）：

| 量 | 值 |
|---|---|
| `P_min` | **1.0531e-7 W** |
| `P_min` | **−39.775 dBm** |
| 设计 `P_in` / `P_min` 余量 | **9495.5 ×** |

⇒ **读出电路余量接近 4 个数量级 ⇒ 它不可能是系统瓶颈**（这一点在 §4 被系统预算独立确认）。

## 3. 写驱动 `write_driver`

加热线电阻**由 M3 几何 × 方阻锚算出**（不是查表填数）：

```
R_h = R_sheet · (L_h / w_h)      L_h = pm_m3.cell_length_um（M3 上游）  w_h = primitives.PCM_CELL_DEFAULTS["heat_w"] = 0.60 µm
P   = V_drv² / R_h
E   = P · t_pulse
```

| 量 | 值 |
|---|---|
| 驱动电压 `V_drv` | 3.3 V（设计假设） |
| 写 DAC 位深 | **8 bit** |
| 脉冲宽度 `t_pulse` | **5.0e-8 s** |
| 加热线电阻 `R_lo`（方阻锚下界 10 Ω/sq） | **183.577 Ω** |
| 加热线电阻 `R_hi`（方阻锚上界 50 Ω/sq） | **917.884 Ω** |
| 驱动功率 `P_lo` / `P_hi` | **0.011864 W** / **0.059321 W** |
| 单脉冲能量 `E_lo` / `E_hi` | **5.932e-10 J** / **2.966e-9 J** |
| 脉冲阶梯动态比 `P_hi/P_lo` | **4.6749** |
| 与 M1 脉冲阶梯对齐自检 | **PASS** |
| 写量化等效电平误差 `ε_write` | **0.0294118**（= `1/(2·16)` · 半 LSB 均匀量化） |

> 🔴 **诚实边界**：`E` 是**行为级**（`P·t`），**不含**器件级焦耳热/热-光动力学 —— 后者属 **T1 PDE / T2 电路级锁死区**。
> 方阻 10–50 Ω/sq 是**典型区间**（`heater_sheet_rho_is_typical_range = true`），非 foundry 真值。

## 4. 系统误码预算（瓶颈识别）`system_link_budget`

三段**等效电平误差**合成（不同物理域，量纲统一为「电平份额误差」）：

| 分量 | 公式 | 值 | 占比 |
|---|---|---|---|
| 写量化 `ε_write` | `q·(L−1)/2`（半 LSB） | **0.0294118** | **1.419 %** |
| 介质 drift `ε_drift` | `ν_max·ln(t_hold/t₀)` —— **算自 M2 的 ν 锚** | **2.07209** | **99.990 %** |
| 读出电路 `ε_read` | `1/SNR_read` | **3.088e-5** | 1.49e-5 % |
| **合计** | `ε_tot = √Σε_i²` | **2.07230** | — |
| 系统 SNR | `1/(2·ε_tot)` | **0.24128** | — |
| **系统 BER** @ `t_hold = 3.156e7 s`（1 年） | `0.5·erfc(SNR_tot/√2)` | **0.40467** | — |
| **瓶颈** | `argmax ε_i` | **`drift`** | — |
| 预算自检 | `BER ≤ 1e-12` | **不达标**（`all_ok = false` · **如实登记**） | — |

**保持时间扫描**（`t_hold` ↑ ⇒ drift 侵蚀 ↑ ⇒ 瓶颈切换）：

| `t_hold` (s) | `ε_drift` | `ε_tot` | 系统 BER | 瓶颈 |
|---|---|---|---|---|
| 1.0 | 0.0 | 0.029412 | 4.107e-65 | **write** |
| 60.0 | 0.49132 | 0.49220 | 0.15485 | drift |
| 3600.0 | 0.98264 | 0.98308 | 0.30551 | drift |
| 86400.0 | 1.36401 | 1.36433 | 0.35700 | drift |
| 3.156e7 | 2.07209 | 2.07230 | 0.40467 | drift |

**逆解**：使 `worst_ber ≤ 1e-12` 的**最大**保持时间
`t_max = 1.7147 s`（**约 1.7 秒**）—— 判据 ⑯ 用「`t_max` 处 ≤ 目标 ∧ `2·t_max` 处 > 目标」双边守住。

> 🔴🔴 **跨域代理的诚实标注**（`drift_proxy.is_cross_domain_proxy = true`）：
> 本段的 `ν` 取自 **M2 的电学域 drift 锚**（`ν_min = 0.07` / `ν_max = 0.12` / 上界 `0.18`），
> 而**光学域 drift 至今无直接定量锚**（PM-G7 未闭合）⇒ 本段只回答「**若两域同阶**，系统级后果是什么」，
> **不是**光学域寿命结论。逐点侵蚀时间：
> `ν = 0.07` ⇒ **2.356 s**；`ν = 0.12` ⇒ **1.649 s**。
>
> ⇒ **这是本档最重要的工程含义**：即使读出链余量 9495×、写驱动阶梯干净，
> **系统仍被光学域 drift 按在「秒级保持」上** —— 储能不是问题、**保持**才是问题。
> 该结论**直接升级 PM-G7 为系统级阻塞项**，并把「光学域 drift 锚」列为下一档第一优先。

## 5. 2.5D 装配签核 `system_2p5d`

PIC 阵列 die（**复用 M3 阵列元素**，不重造几何）+ EIC 通道 die + interposer + M1 引出线 ⇒ **真 GDS**。

**尺寸链全部由上游算出**：

| 量 | 值 | 来源 |
|---|---|---|
| 通道数 `n_channels` | **8** | `n_devices − 2·n_buses`（扣除每总线 2 个光栅耦合器） |
| PIC die | **[197.33, 6.2] µm** | M3 `layout_signoff().gds_stats.bbox_um`（**算出来的**） |
| PIC 单元 pitch | **18.0450 µm** | M3（热串扰 binding） |
| EIC 通道 pitch | **50.0 µm** | **设计假设**（`eic_pitch_is_design_assumption = true`） |
| EIC die | **[400.0, 6.2] µm** | `n_channels × eic_pitch` |
| interposer | **[408.0, 24.4] µm** | 每边外扩 `2×min_pad`（**相对量**，非写死绝对尺寸） |
| **密度瓶颈** | **`eic`** | `argmax(pitch)`：EIC 50.0 > PIC 18.0450 |
| 电层 DRC | **PASS**（6 项判据全绿） | 见下 |
| 网络 LVS | **ACCEPT**（0 违规） | 通道条数 == 走线数 == `n_ch` |
| GDS 字节 | **4852 B** | 与 PIC 阵列 GDS **不同**（6224 B）⇒ 真装配，非原样复用 |
| GDS sha256 | `4191e8b8255e98078add7886c35b982e7b5bb8bc6c2880db618b84fa12955bdf` | — |

**独立解码复核**（**复用** `pm_m3.independent_gds_scan` —— 自写最小 GDSII 记录流解析器，**刻意不复用**导出器解码路径）：

| 层 | 元素数 | 含义 |
|---|---|---|
| 1 | 10 | PIC 的 Si（波导 + 光栅） |
| 5 | 8 | PCM 单元（= 单元数） |
| 6 | 48 | HEATER（= 6 × 单元数） |
| 64 | 2 | interposer（外框 + PIC footprint 内框） |
| 65 | 16 | M1：通道条 8 + 引出线 8 = `2 × n_ch` |
| 66 | 1 | EIC die（ASIC） |

**电层 DRC（6 项 · 全部由几何算出，无恒真式）**：
`channel_width_ok` · `channel_space_ok` · `eic_pic_clearance_ok` · `interposer_covers_pic` ·
`interposer_covers_eic` · `lead_within_channel_width`。

**网络 LVS 的关键纪律**：通道/走线计数**从独立解码器读**（`scan["layers"][65] == 2·n_ch`），
**不读生成端的 `len(structs[...])`** —— 否则判据读到**同源派生量**就成了假判据。

> 🔴 **诚实边界**：片外 fiber **不落版图**（与 G-OI2 同口径）；interposer 电学真值属 **T2 锁死区**；
> 本档只做**几何 + 拓扑**签核（DRC/LVS），**不含**封装级热-机械真值（缺口 **PM-G9**）。

## 6. 🔴 方法论产出：本轮抓出**上轮门禁里的一条假绿**

`run_webui_pm_render_path_smoke`（PM-M3 建立）里有一条 `W4c 反向完备（[] 项目块）`。
本轮为 M4 增加项目块时**按同族思路先验一次**，发现：

```python
def _block_keys(card, prefix):        # 原实现
    cur = card
    for seg in prefix:                # ← prefix 是字符串 "scale_tiers[]" ⇒ 逐**字符**迭代
        if isinstance(cur, dict) and seg in cur:
            ...
        else:
            return set()              # 首字符 's' 不在根字典 ⇒ 立刻返回空集
```

⇒ `_block_keys(card, "scale_tiers[]") ≡ set()` ⇒ `W4c` 的「字段全覆盖」半边**恒真**。
**实证**：`scale_tiers` 项目块有 **17** 个字段，前端只渲染了 **10** 个，
而 `n_buses` / `n_cells_per_bus` / `drc_pass` / `expected_pcm` / `got_pcm` / `width_um` / `height_um`
**从来没有在 UI 上出现过**，门禁却一直全绿。

**修法（三层）**：

1. **修判据**：`_block_keys` 归一化为「段列表 + 可选 `[]` 后缀」，字符串前缀按 `.` 切分（表 A ↔ 表 B 两侧同源）。
2. **补反向探针**：新增 `W6-P6`（向 `scale_tiers[0]` / `t_hold_table[0]` 注入字段 ⇒ 必红）
   与 `W6-P6b`（**逐字复刻**修复前的实现，断言它**恒返回空集** ⇒ 这就是被修掉的假绿本身）。
3. **补前端**：把这 7 个字段真正渲染出来（规模档表加「宽×高」「总线结构」「独立解码 期望/实测」「DRC」）。

**验证**（端到端突变，非单元级）：
突变「删掉 `t.n_buses` 映射」⇒ `W4c FAIL（缺 n_buses, n_cells_per_bus）`；
突变「抹掉前端 `ASM.density_bottleneck` 引用」⇒ `W3 FAIL（坏路径）+ W4b FAIL（2.5D 块缺 density_bottleneck）`；
还原后 **22 PASS / 0 FAIL**。

> 同族于既有铁律「**判据读到的值必须是算出来的**」：本次是它的**镜像** —— 判据**读到的键集是空的**，
> 于是「覆盖完备」退化成「空集 ⊆ 任何集合」。**门禁只管看得见的集合 ⇒ 新成员静默进盲区。**
