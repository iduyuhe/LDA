## 2. 物理链（三条新锚）

### ① 磁通聚焦变压器有效面积（链① · B488）

**washer 自感闭式**（超导 washer 环，孔径 d）：

```
L ≅ 1.25·µ0·d
```

**磁通聚焦变压器有效面积**（拾取环 → 输入线圈，通过互感 M 把拾取磁通耦合到 SQUID 环路）：

```
A_eff = γ_A · A_p · M / (L_i + L_p)
```

- A_p = 拾取环面积；L_i = 输入线圈自感；L_p = 拾取环自感；M = 互感；γ_A = 聚焦因子。
- **阻抗匹配 L_i = L_p 时 M/(L_i+L_p) 最大** ⇒ A_eff 最优。
- 默认档：裸拾取环几何面积 100 µm² → 有效面积 **1.5e-07 m²（15× 放大）**。

**独立候选** `transformer_effective_area_numeric`：**离散 Neumann 互感双和**（两个物理圆环，`n_seg=2048`）+ Richardson 外推 ⇒ **真 O(1/n_seg) 截断残差**。闭式 ⇔ 数值 **rel 1.644e-03**。

🔴🔴 **本档最重血案（反自证桩关键坑）**：变压器的**首次**数值候选用了三类**在线性方程上一步精确收敛**的方法 —— ① 不动点迭代（线性方程一步收敛）；② 2×2 线性方程组（`[[L_p+M,−M],[−M,L_i+M]]`）；③ 线性核中点积分（对线性核精确）—— 三者闭式 ⇔ 数值残差**恰为 0**（**代数恒等**）⇒ 会被照妖镜判**自证桩**。逐项排除后改用**离散 Neumann 互感双和**（积分离散化 ⇒ ∝1/n_seg 截断误差）方得真残差 rel 1.64e-3。守卫 A3/E5 以「粗网格（n_seg=32）⇒ 残差放大到 0.105」「极粗网格（n_seg=16）⇒ 2.105e-01（64×/128× 放大）」反向钉死。**

### ② 亚微米结噪声约束（链② · B489）

**Johnson–Nyquist 分流电阻热噪声**：

```
S_I = 4·k_B·T / R_n
```

**亚微米结 R_n 抬升**（面积比 ρ = A_bare/A_sub，饱和增益 max_gain）：

```
R_n,opt = R_n,bare · [1 + (max_gain − 1)·(1 − 1/ρ)]
```

- 默认档 ρ=8、max_gain=8.0 ⇒ 增益 **7.125×** ⇒ **R_n: 20 Ω → 142.5 Ω**（抬高 R_n ⇒ 压低 Johnson 噪声）。
- **Ambegaokar–Baratoff**：`I_c·R_n = πΔ/(2e)`（结临界电流-正常态电阻乘积由能隙 Δ 锁定）。

**噪声磁通**：

```
S_Φ,opt = S_I,opt / (∂I/∂Φ)²          （Wb²/Hz）
```

**独立候选** `submicron_junction_noise_psd_numeric`：**蒙特卡洛噪声传播**（`n_mc=4e6`, seed=20261020）。闭式 ⇔ 数值 **rel 9.149e-04**。

🔴 **与 QS-M6 口径连续**：当 `R_n,opt = R_n,bare`（ρ→1 或 max_gain=1）时，B489 **精确退化**为 QS-M6 的 S_Φ（同式同参）⇒ 本档登记的是「R_n 抬升**后**的优化量」，**非重复计数**。

### ③ 优化后磁场灵敏度（链③ · B490）

```
B_N,opt = √(S_Φ,opt) / A_eff             （T/√Hz）
```

- 默认档：**基线 79.25 → 1.73 fT/√Hz**（**45.81× 优化增益**），`sota_ratio = 0.577` ⇒ **进入蓝图 §3 集成 SOTA 带 1–5 fT/√Hz**。
- 磁通聚焦（放大 A_eff）+ 亚微米结（抬高 R_n、压低 Johnson 噪声）+ 温降 三重叠加。

**独立候选** `optimized_field_sensitivity_numeric`：**MC + 数值互感联合**（同时替换噪声链与面积链）⇒ **rel 2.105e-03**。

## 3. 三道新锚（v0.9.224 净增）

| 锚 | 物理量 | golden（闭式） | candidate（方法学独立） | 实测 rel | tol | 判级 |
|---|---|---|---|---|---|---|
| **B488** | 磁通聚焦变压器有效面积 A_eff | `γ_A·A_p·M/(L_i+L_p)` | **离散 Neumann 互感双和**（n_seg=2048 + Richardson） | 1.644e-03 | 2e-2 | 严格独立 |
| **B489** | 亚微米结噪声约束磁通噪声谱密度 S_Φ,opt | `4k_BT/R_n,opt/(∂I/∂Φ)²` | **MC Johnson 噪声传播**（n_mc=4e6） | 9.149e-04 | 1e-2 | 严格独立 |
| **B490** | 优化后磁场灵敏度 B_N,opt | 闭式逐级 `√S_Φ,opt/A_eff` | **MC + 数值互感** | 2.105e-03 | 2e-2 | 严格独立 |

- 🔴 **tol 标定（按各锚物理量级）**：B488 `2e-2` · B489 `1e-2` · B490 `2e-2`；含噪候选（B489）按**跨 20 种子最坏 rel 1.18e-3** 判（非单次 seed），余量 ≥ 8.5×。
- 🔴 **残差性质**：三锚均为**真数值残差**（非代数恒等）—— B488 粗网格（n_seg=32/16）残差放大 64×/128×（0.105 / 0.2105），实证残差真存在。
- 🔴🔴 **反自证桩通法（承本档血案 + QS-M6 三血案）**：
  1. 线性系统上的**不动点迭代 / 直接线性解 / 线性核积分** ⇒ 残差恒 0 ⇒ **必用真截断数值法**（离散化/级数截断）；
  2. 「响应/残差/变化量」类**绝对阈**必与物理量纲同尺度（`thresh` **或** `Δ/|base|>thresh_rel`，**不可用 max()**）；
  3. **tol 必与各锚物理量级同尺度**（跨 23 个数量级时绝不共用 O(1) 相对量）；
  4. 新接线锚**必跑一次全量照妖镜**（真执行 candidate + 真判 d/tol），并配**跨量纲**反向探针。
