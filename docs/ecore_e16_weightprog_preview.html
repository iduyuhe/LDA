① 核心结论：写入噪声有一个由「单脉冲噪声」决定的硬地板

g ← g + α(g*−g) + η，η ~ N(0, σ_p²) ⇒ Var(e_∞) = σ_p²·Σ_{j≥0}(1−α)^{2j} = σ_p²/(α(2−α)) ⇒ σ_∞ = σ_p/√(α(2−α))（无穷级数精确解）。

闭式 0.700140% ⟷ 4000-trial MC 0.699222%（rel 0.13%，方法学独立）。 ⇒ tol_rel < σ_∞ 时期望意义上不可达 —— 越校验越白校验。

设计指令：要把编程精度做上去，必须降单脉冲噪声 σ_p（脉冲整形 / 电流限制）， 不是加脉冲数。写-校验最多把地板抬升 1/√(α(2−α)) = 1.400 倍 （σ_∞ ∈ [σ_p, σ_p/√(α(2−α))] = [0.5000%, 0.7001%]）。

② 电平量化：误差是「绝对量」，界要用平均电导而不是最小电导

电平在窗口内等间距 ⇒ 每个单元的量化误差绝对值同为半步长（与 g 无关）⇒ 输出相对误差界 = half_step·Σ|x| / |Σ g_i x_i| = half_step / g_mean。 低电导单元的「大相对误差」在求和里并不放大。

本段血案：初版取 max_i(half_step/g_i) ⇒ 界被放大 ~3× （1.0672% → 3.1744%），把预算结论整个带偏。探针 C6 专守此线。

⑥ 良率与卡位：只影响尾部，不影响均值

良率 (1−p)^N：N=64 单元 · p=1e-3 ⇒ 0.9380。 端到端实测（600 trials，`stuck_p=0` 隔离两机制）：σ 实测 ⟷ 矩阵感知严格式 rel 0.31%。

卡位（p=1e-3）只影响尾部：max 1.07% → 22.83%、mean 0.47% → 1.53%、良率 95.31% ⇒ 卡位是良率问题，不是均值精度问题 ⇒ 预算默认不含卡位（另设 include_stuck）。

⑦ 保护性约束与诚实边界

🔴 保护性约束：budget.collect_terms 新增的 include_programming 默认 False ⇒ E15 已发布数字逐位不变（8×8 worst 4.06012% / bits 4.6223 / 5% 上界 N≤12）。 门禁 B12 守住默认不变；探针 C5 专模拟「有人把默认改成 ON」⇒ 必红。 同族纪律见 NmosParams / mna.vcvs。
  • 参数（α / σ_p / tol / ν / p_stuck）为公开典型量级占位 · 非 PDK · 无实测锚 ⇒ 结论随参数变。
  • 器件模型为行为级（比例修正 + 加性噪声），不含细丝动力学 / 脉冲宽度依赖 / 温度加速。
  • 无 endurance / retention 联合退化；只覆盖静态（不含编程时间与能耗）。
  • 共模漂移可被单次校准消除 ⇒ 不进预算（一个能被单次校准消掉的项不是精度上限）。
  • 不报 TOPS / TOPS-W / fJ/op。
