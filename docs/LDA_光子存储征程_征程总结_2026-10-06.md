## 三、本征程三条方法论沉淀（ irreversible 的部分）

1. **「材料（比值）定能力，几何（Γ/L/膜厚）只分配窗口」** —— 三档同族哲学：`IL_π`（Γ、L 同约掉）、`r=k_a/(k_c−k_a)`、相位域 `FOM` 都是与几何无关的**能力判据**；Γ 标定只改几何绝对值。**能约掉 Γ 的结论才是稳的**（现算互等 rel ~2e-16，机器验证）。
2. **「假设更小」≠「更保守」**（G2 结算抓出的跨档断口）：`L ∝ 1/Γ` ⇒ 长度/面积偏大对面积保守，但**可行窗同步缩** ⇒ 按假设 Γ=0.05 出的设计点 11.015 µm 在标定口径窗 [3.559, 9.553] µm 下**越界 +15.3% ⇒ 读出饿死**。口径错一处 ⇒ 余量判断反向（同族 v0.9.177 `TARGET_BER_KP4` 血案）。处置 = 两口径并报 + 登记 G11，重标定属独立批次。
3. **吃狗粮抓框架级真缺陷**：M3 阵列案例暴露 `placement._port_abs_comp_cache` 以 `id()` 为键 ⇒ 对象 GC 后 id 复用 ⇒ 4×8 版图 51 处 LVS 假红。修法（缓存持对象引用 + `is` 身份 + 版本校验 + 缺失改 **raise**）反哺框架全体用户。

**v0.9.199 新增（同族专项）**：受跟踪报告若内嵌 wall-clock 于**字符串内部**（detail/patch 文本），`canon` 键剔除够不着 ⇒ 须写边界 `scrub`（哨兵保留 schema）；**计时类报告（perf_*）本质非确定**，字节级确定性口径不成立，强套 = 假绿 —— 如实钉住 + schema 存活判据 + 由生成器自身漂移预警承担防漂移。
