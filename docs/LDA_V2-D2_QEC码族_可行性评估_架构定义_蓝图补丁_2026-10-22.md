## 1. 为什么 D2 当初被评为「B 平台级」

规划阶段给的判据是三条红线：① 阈值**无闭式**（靠 MC + 有限尺寸标定 ⇒ 仿真值不能当 golden）；② 码参数 `n/k/d` 是**整数** ⇒ 「CF 码族整数不可锚」同型病理；③ 解码器重且禁第三方 QEC SDK。

本档先做**可锚性体检**（不是先写代码），用实测决定哪一块能落锚 —— 结论是：**只有一块能锚**。

## 3. 可锚性三问（**本档的核心贡献**）

### 3.1 精确组合量 ⇒ **不可锚**（resid ≡ 0，触零残差红线）

| 量 | 精确值 |
|---|---|
| Steane `[[7,1,3]]` 量子 Hamming 界 slack = `2^(n−k) / Σ_{j≤t} C(n,j)3^j` | `64/22 = 32/11 = 2.909090…` |
| Toric code 基态简并 `4^g`（g=1） | `4` |
| 稳定子群阶 `2^(n−k)` / 逻辑算子类数 `2^(2k)` | `64` / `4` |

🔴 **任何"独立"算法都给出同一个有理数或整数** ⇒ `resid ≡ 0` ⇒ 直接触 BL 的「零残差」红线（`n_zero_resid` 只许 =0）。
⇒ 这类量**不是"难锚"，是原理上不可锚**（不存在能产生截断误差的数值路径）。

### 3.2 用闭式直接求值当候选 ⇒ **不可锚**（跨平台脆弱）

`I_c(p)` 的闭式 `1 − H₂(p) − p·log₂3`（p=0.1 ⇒ `0.3725081563386031`）若让候选也直接算 log：
`ulp(|g|) = 8.27e-17`，而 BL-M2c 要求 `resid ≥ 1e4·ulp = 8.27e-13`。
两条路径都是同一批 libm 调用 ⇒ resid 只会在 0~几个 ulp 间摆动 ⇒ 平台间不可复现。

### 3.3 ✅ 唯一可锚：**退极化信道 hashing 界**（对数积分表示 + 复合 Simpson）

**被测标量**：退极化信道（错误率 `p`）上量子纠错的**渐近可达速率界**（hashing / coherent-information bound）

```
I_c(p) = 1 − H₂(p) − p·log₂3 ,     H₂(p) = −p·log₂p − (1−p)·log₂(1−p)
```

**golden**：上式闭式（精确数学闭式，非截断）。
**candidate**：用 `−log x` 的积分表示 `−log₂x = (1/ln2)·∫ₓ¹ dt/t` 改写

```
H₂(p) = (1/ln2)·[ p·∫_p^1 dt/t + (1−p)·∫_{1−p}^1 dt/t ]
```

再对两个积分做**复合 Simpson**（被积函数 `1/t` 光滑、解析）⇒ 残差是**真截断 O(h⁴)**。

**实测收敛链（p = 0.10）**：

| n | 64 | 128 | 256 | 512 | **1024** | 2048 |
|---|---|---|---|---|---|---|
| resid | 1.799e-06 | 1.162e-07 | 7.324e-09 | 4.588e-10 | **2.869e-11** | 1.794e-12 |
| 相邻比 | — | 15.48 | 15.86 | 15.96 | **15.99** | **16.00** |

⇒ 比趋近 **16 = 2⁴**（O(h⁴) 真截断，非代数恒等）；`resid/ulp = 3.5e5 ≫ 1e4`（非跨平台脆弱）。

**标定（按 BL-M5b 口径 `tol = |golden|/12`）**：
`golden = 0.3725081563386031` · `tol = 0.031` · `|g|/tol = 12.016` · 余量（n=1024）**1.08e9×**。

**端点语义（自检当场纠正）**：`I_c(0)=1`（无噪）、`I_c(p*)=0`（`p*≈0.1893` 穿零）、`I_c(3/4)=−1`
（完全退极化 ⇒ 强负值 ⇒ 判死）。**不要**把 3/4 当成 0。

## 7. 诚实边界

1. hashing 界是**渐近可达速率的上界**（Shor–Preskill），**不是**某具体码在有限 `d` 下的性能；本锚只证明「闭式 ⇄ 对数积分求积」数值一致 + 该界的物理语义自洽。
2. 候选与 golden **共用同一闭式的数学结构**（只是把 `log` 换成积分表示再求积）⇒ 检验「求积实现 + 闭式推导」的一致性，不检验信息论结论本身。
3. 退极化信道是**理想化单参数噪声模型**（无关联噪声、无泄漏、无测量误差）。
4. **不宣称**「支持 LDPC/色码/拓扑码的阈值预测」—— 那三类在本档被**明确判为不可锚**（§3.1/§3.2 有机器化理由）。
5. 不报能效 / TOPS / fJ-op；**LLM 不进判决路径**；零商业依赖（纯 `math`）。
