## 0. 目的与边界

- **真机 ORACLE** = T2 工艺真值 / 流片实测 / foundry 产线实测数据，是三类 ORACLE 中最贵、最硬的一档，按红线 **T2 永久锁死**。
- 本清单只做两件事：**① 把接口契约和治理闸门先写好（空壳也行）**；**② 把现在能零成本跑的两档（物理定律 + 实证）跑满**。
- **不破的红线**：封测实体产线锁死、A 级永不借、LLM 不进判决路径、T1-B 输出不作真值 ORACLE。
- **启动扳机**：资金到位（T2 档）+ foundry 合作或 MPW 流片机会 + 成熟节点用途声明通过 EAR 744.23 自审。

|------|------|----------|----------|
| **A. 消费 Foundry PDK 接口** | 只读调用 foundry 已测好的参数/实测接口，不反向泄露 | 不破封测锁死（只消费接口） | 接口占位，未激活 |

## 2. 预留契约（Contract）—— 5 类

**C1 · 数据格式契约**
真机实测数据进入 LDA 的标准 schema：测量文件（IV/CV/近远场）→ 锚点对标格式（golden 字段 + 误差带 + 单位）。先定义空 schema，不含真实数据。

**C2 · 接口消费契约（只读 / 不泄露）**
PDK 接口调用方式：只读拉取、本地缓存脱敏、禁止将 foundry IP 回写训练集或外传。违反即触发 G2 主权闸门。

**C3 · 锚点对标契约**
明确哪些锚（主要为 B 档真求解类：载流子动力学、探测器带宽真求解）对接哪个真机 ORACLE；T1 电学内核算出的 N(x) 在此被标定，但**不反向当真值**。

**C4 · 标定方向契约（防破戒核心）**
单向：真机 ORACLE → 标定 T1-B 输出。反向禁止：T1-B 任何输出**不得进入 golden / ORACLE 集合**。这是"输出不作真值"的硬写入。

**C5 · 来源 provenance 契约**
每条真机 ORACLE 必须带 provenance：哪次流片 / 哪个 foundry / 哪份实测报告 / 日期 / 节点声明。无 provenance 的数据拒绝入库。

## 3. 预留闸门（Gate）—— 6 道（进 CI 门禁）

| 闸门 | 作用 | 触发动作 |
|------|------|----------|
| **G1 ORACLE 守卫** | T1-B 输出不得进 golden/ORACLE 集合 | 拒绝合并，报红 |
| **G2 主权扫描** | DEVSIM fork / 自研 T1 内核必须 Apache-2.0；A 级永不借 | 许可证扫描失败即卡 |
| **G3 EAR 744.23 合规** | 成熟节点用途声明 + 离线构建证据 + CI 门禁 | 声明缺失即卡 |
| **G4 真值单向** | 真机数据只进 ORACLE，不出（不回流训练/不泄 IP） | 出域检测即卡 |
| **G5 死标量判决** | 验证仍走死标量 PASS/FAIL，LLM 不进判决路径 | 判决路径含 LLM 即卡 |
| **G6 升级路径** | 自证桩→独立锚，必经真机 ORACLE 或外部实证背书 | 无背书升级即卡 |

## 4. 现在就能做的启动前准备（零成本）

- **框架骨架**：空接口 + 占位契约 C1–C5 落地为代码桩/配置文件，不含真实数据。
- **两档跑满**：物理定律锚（麦克斯韦/Sze 闭式解）+ 实证锚（论文曲线/公开良率表）覆盖当前 53 锚底座，让 LDA 现在即可自我验证。
- **闸门先行**：G1–G6 写入 CI 门禁（即使真机 ORACLE 为空，闸门也常驻），防止以后破戒。
