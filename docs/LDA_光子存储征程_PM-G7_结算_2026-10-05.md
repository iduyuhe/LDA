## 1. 缺口原貌（为什么它是阻塞项）

M4 的系统误码预算把 16 电平存储的失效分解为三段等效电平误差：

```
ε_write（驱动时序量化）= q·(L−1)/2 = 0.0294
ε_read （读出电路噪声）= 1/SNR_read = 3.09e-5
ε_drift（保持期漂移）  = ν·ln(t_hold/t₀)
```

M4 当时的 drift 段只有**电学域** ν 锚（电阻漂移，ν_max = 0.12，≥3 文献源），光学域（透射率/
n·k 随时间）**没有任何定量锚** ⇒ 只能做「跨域代理」：若两域同阶，ε_drift = 2.072 ≫ 其余两段
（占比 99.99%）⇒ 系统 BER 0.4047、16 电平保持仅 **1.7 秒**。该结论**如实登记为缺口
PM-G7 并升级为系统级阻塞项**：锚不闭合 ⇒ 任何寿命结论都不可给。

## 2. 结算证据链（三条 DOI 级实测事实）

| # | 来源 | 实测事实 | 锚语义 |
|---|---|---|---|
| ① | **Cheng et al., "In-memory computing on a photonic platform", Sci. Adv. 5, eaau5759 (2019) · doi:10.1126/sciadv.aau5759** | 2 µm GST 波导存储胞、13 个透射电平、probe 0.1 mW ON 下连续 **10⁴ s（8.8 h）测量无可测漂移**（原文 do not find measurable drift for up to 10⁴ s）；电平编程 SD 0.35% | **主账锚（上界）** |
| ② | **Kalb, Spaepen, Leervad Pedersen & Wuttig, J. Appl. Phys. 94, 4908 (2003) · doi:10.1063/1.1610775** | 溅射 a-GST 薄膜（光学存储介质本身）室温剪切粘度随时间**线性增长**（双分子结构弛豫动力学）；等构型激活能 1.76±0.05 eV | 机制层锚 |
| ③ | **Ríos et al., "Integrated all-photonic non-volatile multi-level memory", Nat. Photon. 9, 725 (2015) · doi:10.1038/nphoton.2015.182** | 集成氮化硅波导 + 5 µm GST：8 电平写入/读出、双态读出对比 21%；作者声明保持「数十年」 | 定性锚 |

**显式排除项**：Cheng 2019 中 probe OFF→ON 后 ~9% 的漂移**不并入**——原文归因探针加热平衡
被撤的热-光弛豫（thermo-optical），且 0.05 mW 下 ON/OFF 均可忽略 ⇒ 非结构老化 drift。

## 3. 上界锚的纯算术推导（非仿真、非臆造）

漂移函数形式（模型假设，与电学域 drift 同族的结构弛豫律）：

```
ΔT/T ≈ ν_T · ln(t/t₀)
```

Cheng 2019 的实测事实「10⁴ s 内无可测漂移」+ 检测下限假设（取其编程电平 SD 0.35%）⇒

```
ν_T ≤ 0.0035 / ln(10⁴ / 1) = 3.800e-4      （上界；ν_T 越小保持越长 ⇒ 取上界是保守侧）
```

**诚实边界（三连披露）**：
1. ν_T 是**上界**（检测下限假设支配），不是直接测得的点值 ⇒ 一切保持时间结论是**下界**语义；
2. ln(t) 函数形式本身仍是模型假设——锚只钉住**速率上界**；
3. 推导是纯算术（第②层实测事实 + 确定性换算），**不是**仿真值（第③层⛔永不作 golden）。

## 4. 主账口径翻转（本档的核心数字）

`pm_m4.system_link_budget` 的 drift 段改算自光学域上界锚（`M2.nu_optical_bound`）：

| 量 | 旧主账（电学代理 ν=0.12） | **新主账（光学上界 ν_T ≤ 3.80e-4）** |
|---|---|---|
| ε_drift @1 年 | 2.0721 | **0.006562** |
| ε 占比 | drift 99.990% | **write 97.6%** |
| 系统 BER @1 年 | 0.40467（all_ok=false） | **3.98e-62（all_ok=true）** |
| 瓶颈 | **drift** | **write** |

**两域 ν 相差 315.8×。** 旧口径**并报不删**（`drift_proxy` 字段保留 is_main_account=False、
瓶颈=drift、BER 0.4047、逐点侵蚀表）——跨域代理会把光学域判决带偏 316 倍，这正是缺口必须
逐条结算的实证；口径并存时必须并报，不选择性披露（VπL 断口结算同款纪律）。

## 6. 方法论产出（可复用）

1. **「无锚缺口」的结算模板**：检索 DOI 级实测事实 → 落锚表（逐条带 source + 实测事实 +
   排除机制）→ 推导只做纯算术并显式披露假设 → 主账重接 + 旧口径并报 → 机器判定 + 重算守卫 +
   pre-fix 行为复现探针。仿真/模型值**永不**冒充锚（第③层纪律）。
2. **上界锚 ⇒ 下界结论**：保守侧取值（ν 取上界）⇒ 保持时间是下界——结论的语义方向必须在
   数据结构里显式标注（`is_upper_bound_semantics` / `retention_semantics`），不能靠文案。
3. **跨域代理的定性纪律**：代理口径给出的是「若两域同阶」的**后果**，不是结论；它有资格
   把缺口抬成阻塞项（M4 做对了），但**没有资格**在结算前给出寿命数字——本档结算后旧口径
   仍并报，供口径对照与历史回溯。

## 7. 残余边界（如实登记）

- ν_T 上界受**检测下限假设**（0.35% SD）支配：若真实检测下限更差（如 1%），ν_T 上界放宽 ~3×，
  t_max 下界相应缩短 ~e^{2·ln3/0.0035}…——量级仍然天文；但「小时级以下漂移」类失效模式
  （如快弛豫分量）不在 Cheng 2019 的 10⁴ s 窗口分辨力内被排除，**须靠后续实测钉死**。
- 保持下界 ~10^74 s 是「锚上界 + ln 模型」的数学外推，**物理上受其他失效模式支配**
  （如热激活晶化、氧化）——那些由 M2 保持窗口 / T1 锁死区另行覆盖，本档不重复记账。
- n·k 的**波长分辨**漂移谱（@1550 nm 点上的 d n/dt、d k/dt）仍无直接实测 ⇒ 相位域口径
  （PM-G6）闭合时需重访。
