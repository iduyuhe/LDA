## 1. 开工前的两处自我修正（必须先说清）

规划依据是第二轮审计，但**开工前的代码勘察推翻了我自己的两条判断**。先纠正，避免按错误定性施工：

### 1.1 🔴 F-8「B18 是裸锚」——**定性错了，撤回**

- **审计原文**：B18 是"宽口径下唯一裸锚，`self_certified` 且 `l2_count=0`，无任何门禁看守"。
- **实测**：B18 的 `provenance = self_authored_closed_form`、`upgrade_path = 本就不升：regime 越界（terminal Tier-1）`。这正是 **`run_self_certified_lock_smoke` ③**（"每桩带四类锁之一"）要求的形式——它**有**防护。
- **真实性质**：这不是"无门禁看守"，是 **K4 的 L2 逐锚统计看不见"全局纪律门禁"**（该门禁是全局断言，不点名任何锚号）。
- **修法因此改变**：不是"补一条判据"（`lda-anchor-wiring` 已把 B18 列入**判定不可接·勿重试**：默认参数 `g=0.1 / κ=0.005 GHz` 落在强耦合区，而 `F_P=4g²/(κγ)` 是坏腔失谐极限公式 ⇒ 候选一仿真就 regime 越界），而是**让 K4 能表达"被全局纪律门禁覆盖"这一类**。降入 M4，严重度 中 → 低。

### 1.2 F-9 的耗时问题比审计写的更具体

- `run_splitter_readout_smoke` 只有 **38 行**，202 秒全部来自 `lda_agent.splitter_readout.design_splitter_readout` 内部（每次调用跑一次真实 FDTD 分束），而该门禁**调它 5 次**。
- 所以优化方向不是"降网格"，而是 **同参数结果缓存 + 检查 5 次调用里哪些参数其实相同**。降入 M4。

### 1.3 对 M1 方案的直接影响

审计建议 A-1 原文是"把 `transmon_cell` 的地平面几何改成共面 CPW 地"。勘察后发现**不能直接改默认路径**：

- 当前 `Transmon` 几何 **9 个元素**：2 pad + 1 JJ + 2 馈线 path + 4 地平面矩形；馈线在 `x∈[-9,-3]`，左地在 `x≤-10` ⇒ 间隙是**端面间隙**，不是共面侧间隙。
- 改默认几何会重定 **S1–S5 全部基线**（DRC 的 `qubit→地间隙` 判据、LVS 的 bbox 网表、以及 5 道案例卡门禁的几何指纹）。
- ⇒ **采用"新增模式、默认不变"**：`geometry_desc("Transmon", params, cpw_ground="coplanar")` 可选开关，默认仍走现几何。**既有 8 道门禁判据逐位不变**，新能力走新路径、新判据。

这符合项目既有纪律（v0.9.272 的"只改报告值、几何逐位不变"；v0.9.269 的"会牵动 S1–S5 ⇒ 本版不动"）。

### 2.3 几何设计（定案）

```
共面地条（cpw_ground="coplanar" 时追加，左右馈线各两条，共 4 个 boundary）
  off        = cpw_w/2 + ground_gap          # 0.25 + 1.0 = 1.25
  x_in       = pad_w + ground_gap            # 3 + 1 = 4      （离开 pad 一个间隙）
  x_out      = gi                            # pad_w + arm_len + ground_gap = 10
  上地条 bbox：x∈[-10, -4], y∈[1.25, 3.0]     （顶端接触上地平面 y=3 ⇒ 电学连通）
  下地条 bbox：x∈[-10, -4], y∈[-3.0, -1.25]
  右侧对称（flux 线侧）
```

**DRC 预期**：地条与 pad 的 `dx=1.0 = ground_gap ≥ min_ground_gap 0.5` ⇒ ACCEPT；地条最薄边 1.75 ≥ min_width 0.2 ⇒ ACCEPT。
**LVS 预期**：地条 `net="ground"`（零悬空）；与 qubit bbox 不重叠（feed line 是 `path`、不进 `qubit_boxes`）⇒ ACCEPT。

🔴 **诚实登记**：地条顶端与外围地平面**几何接触**即视作连通，**不做**电学连通性仿真（无 EM 求解器）；这是"几何连通"而非"电学连通"，`caveat` 里必须写明。
