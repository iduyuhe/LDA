## 二、对照「对标 EDA」的缺口清单

| 能力维度 | 商业 EDA（Lumerical/Ansys/Synopsys Photonic） | LDA 现状 | 缺口 |
|---|---|---|---|
| 器件仿真纵深 | 参数化扫描 / 自动化 sweep | S7/S8 蒙特卡洛（统计锚雏形） | 🟡 有雏形，无专项参数化一致性锚 |
| **良率预估（DFM/DFY）** | yield 分析 / 工艺角分布→良率 | **无**（只有分布均值/下界，无「容差内概率」） | 🔴 **最大缺口** |
| 调制器 | MZM 半波电压 Vπ / 调制效率 | **无任何调制器锚** | 🔴 高频器件缺锚 |
| 量子两比特门 | 门保真度含退相干 | 只有单比特 B10 | 🟡 两比特缺 |
| 读出链路 | 读出 SNR / 保真度 | D-46/D-47 复用+保真度预算（已验证） | 🟡 SNR 物理锚缺 |
| 统计设计 | 蒙特卡洛 + 良率 + 灵敏度 | S7/S8 蒙特卡洛 | 🟡 灵敏度缺 |

**结论：三大真实缺口 = 良率预估（系统级）、调制器 Vπ（器件级）、两比特门保真度（量子侧）。**

## 三、候选钉子清单（含红线合规 / 价值 / 工作量）

### 钉子 A：S13 设计良率锚（DFY）—— ⭐⭐⭐ 首选推荐

| 维度 | 说明 |
|---|---|
| **缺口** | 商业 EDA 的 yield/DFM 分析能力；LDA 只有「分布均值/下界」，缺产品级「良率」指标 |
| **方案** | 工艺角参数分布（如波导宽度 σ=±2% 高斯）→ 蒙特卡洛 N 次 → 关键指标（插损/FSR/串扰）落在规格容差内比例 = 仿真良率 → **与解析良率公式（高斯容差 → erfc 解析解）交叉验证**（同一物理定律两种算法互证，死标量比对） |
| **红线合规** | ✅ 高斯容差积分的解析解是确定性物理定律；判决 = 死标量（良率 ≥ 阈值 → PASS）；LLM 不进路径 |
| **价值** | 直接对标 EDA 的 yield 分析；S7 统计锚的纵深（分布均值 → 容差内概率）；可支撑货架「良率预估」卖点 |
| **工作量** | 中（新锚 + 解析解实现 + MC 实现 + smoke） |

### 钉子 B：B28 调制器半波电压 Vπ 锚（电光效应）—— ⭐⭐⭐ 推荐

| 维度 | 说明 |
|---|---|
| **缺口** | MZM 调制器（IM-MZI-MOD 货架核心、相干发射链路）零物理定律锚 |
| **方案** | Vπ = λ·d / (2·Γ·n³·r₃₃·L)（电光张量物理定律）；材料参数公开可溯源（LiNbO₃ r₃₃=30.8 pm/V、Si 载流子效应等）；加入 46 锚 → B28（光子 B 14→15） |
| **红线合规** | ✅ 标准解析物理定律；材料参数来自公开文献（可溯源，与实证锚 E 系列同精神） |
| **价值** | 补齐 MZM——相干/直调发射核心器件；为 IM-MZI-MOD 货架提供锚支撑（货架 composition 可用） |
| **工作量** | 小-中 |

### 钉子 C：B29 两比特门保真度锚（T1/T2 退相干限制）—— ⭐⭐

| 维度 | 说明 |
|---|---|
| **缺口** | 只有单比特 B10；两比特门（iSWAP/CNOT）保真度是量子侧高频需求（用户点名「量子侧深化」） |
| **方案** | 两比特门保真度 F ≈ f(T1, T2, t_gate) 标准退相干解析模型；与 D-46/D-47 量子保真度预算框架衔接（S4 同构） |
| **红线合规** | ✅ 标准量子退相干物理模型（公开推导可溯源） |
| **价值** | 量子侧深化；支撑量子货架（QCTRL 系列）的锚完整性 |
| **工作量** | 中 |

### 钉子 D：S14 参数化扫描一致性锚 —— ⭐⭐

| 维度 | 说明 |
|---|---|
| **缺口** | 设计参数网格扫描是 EDA 基础操作，LDA 无专项锚（用户点名「仿真纵深/参数化扫描」） |
| **方案** | 对已验证器件（如环形谐振器）在参数网格（半径×间隙）上，解析锚 vs 数值验证（FDFD）逐点一致 → 死标量 |
| **红线合规** | ✅ 已锚定器件的参数化外推，零新物理 |
| **价值** | 仿真纵深可信度；可复用现有 FDFD 验证管线 |
| **工作量** | 中（依赖钉子 A 或独立做） |

### 钉子 E：读出 SNR 物理锚（量子侧）—— ⭐

| 维度 | 说明 |
|---|---|
| **缺口** | D-46/D-47 覆盖复用+保真度预算，缺读出信噪比物理锚（标准 QND 色散读出 SNR 模型） |
| **价值** | 量子读出链锚完整性；支撑 QKD/读出货架 |
| **工作量** | 中-大（模型较复杂） |

## 四、推荐路线（决策点）

**建议组合：A + B 先做（一个系统级纵深 + 一个器件级补齐），C 次之，D/E 后置。**

| 优先级 | 钉子 | 理由 | 预估锚数变化 |
|---|---|---|---|
| P0 | **A：S13 设计良率锚** | 最大缺口（良率预估），对标 EDA 卖点最硬 | 46 → 47（S13） |
| P0 | **B：B28 调制器 Vπ 锚** | 高频器件缺锚，工作量小收益直接 | 46 → 47（B28） |
| P1 | **C：B29 两比特门保真度** | 量子侧深化（用户点名） | 46 → 47（B29） |
| P2 | D：S14 参数化扫描 / E：读出 SNR | 纵深锦上添花 | 后续 |

**决策点（请杜先生拍板）**：
1. 是否接受 A+B 组合先做？（推荐接受）
2. A 的良率指标定义：首批对标哪类系统？（建议用现有 S1 功率预算链路做载体——良率 = 预算余量 ≥ 0 的概率）
3. B 的材料体系：LNOI（铌酸锂薄膜）还是 SOI 载流子效应？—— LNOI 的 r₃₃ 参数公开性最好，建议 LNOI

## 五、一句话总结

**46 锚的下一步最硬钉子 = S13 设计良率锚（把「分布统计」升级为「容差内概率」——商业 EDA 的 yield 能力）+ B28 调制器 Vπ 锚（补齐 MZM 这个高频器件）**。两者都严格落在物理定律锚红线上（解析良率公式 / 电光张量定律），无新物理、无 LLM 进路径，且直接支撑货架卖点（良率预估 / MZM 调制核）。
