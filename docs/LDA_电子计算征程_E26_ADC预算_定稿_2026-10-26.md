# LDA 电子计算征程 · E26 定稿：ADC 四项预算与可校核性（2026-10-26）

> 版本 **v0.9.322** · 决策号 **D-201** · 净增锚 **0** · 账本 541 / strict 519 / 独立率 95.93% / CI core **357**
> 模块 `lda_l2/ecore/adc_budget.py`（ecore 第 29 条能力）· 门禁 `run_ecore_e26_smoke.py`（19 判据）

---

## 0. 一句话结论

**E25 建议「补建模，模型 ⟷ 实测误差 <20% 才算可信」。本段把这件事做完了，
结论是那条建议的前提不成立：四项物理模型只能解释实测 ADC 能耗的 18%~89%（跨设计 4.90×），
校核自由度 dof = −3 ⇒「从头算」路线的上限已经封顶。**

⇒ ADC 能耗从此**只能报区间**（14.9 ~ 66.2 fJ/op），并且必须与**覆盖率 + dof** 同屏报出。

---

## 1. 为什么这件事必须先做

E24 说「两步式 ADC 比 SAR 好 8.5×」，E25 用实测反推发现「CDAC 只占 ADC 总能耗 0.6~3.6%」
⇒ 那 8.5× 只作用在 ~2% 上。E25 因此把 CDAC 项换成实测锚，得到单点地板 33.7 fJ/op。

**但 33.7 是"用实测锚顶替"出来的，不是平台的预测能力。** 一个不能预测的模型，
不能用来做架构决策。所以 E26 的任务是：**把 ADC 的主体建成能算的东西，看看能算到什么程度。**

答案：**能算出结构，算不出数值。**

## 2. 四项物理模型（闭式齐全 · 已落地）

| 项 | 闭式 | 可从公开参数独立确定？ |
|---|---|---|
| CDAC 开关 | `E_units(b, arch) · C0 · V²`（E24 精确单位） | ✅ **是** —— 但它只占 **0.5~4.8%** |
| 比较器 | `b · (C_latch·V² + I_pre·V·t_regen)` | ⚠️ `C_latch` / `I_pre` 是**架构量** |
| 时钟树 | `C_clk_net · V²` | ❌ **依赖目标 f_s**（高速需多级缓冲/大扇出） |
| 数字逻辑 | `α · n_gate · C_gate · (b+1) · V²` | ⚠️ `n_gate` 是**设计选择** |

能量守恒 `Σ四项 ≡ E_explained`（判据 ① 机核，相对差 < 1e-15）。

### 金标（"本应恰好为 X"）

| 金标 | 实测 |
|---|---|
| 标准 SAR：`E(12b)/E(8b) ≡ 4095/255 = 16.0588`（**不是 16** —— 和式比值） | 16.058824 |
| 单调开关 ≡ 标准 SAR 的**精确**一半 | 0.500000000 |
| 四项和 ≡ 已解释能量 | 781.155 vs 781.155 fJ |
| `s_i` 代回 ≡ 实测 `E_conv`（代数恒等） | 残差 **0.000e+00** |
| `E_conv(f_s) = E_dyn + P_static/f_s` 逐点恒等 | 0.000e+00 |

## 3. 覆盖率：18.2% / 21.9% / 89.0%（跨设计 4.90×）

| 实测锚 | E_conv（实测） | CDAC | 比较器 | 时钟 | 逻辑 | 解释合计 | **覆盖率** |
|---|---|---|---|---|---|---|---|
| 28nm 8b 500MS/s | 4300.8 fJ | 20.7 | 137.1 | 405.0 | 218.7 | 781.2 | **18.2%** |
| 40nm 12b 1MS/s | 8478.7 fJ | 371.6 | 408.9 | 605.0 | 471.9 | 1857.4 | **21.9%** |
| 65nm 8b 1MS/s | 1909.7 fJ | 91.8 | 499.3 | 720.0 | 388.8 | 1699.8 | **89.0%** |

🔴 **这不是"模型精度不够"，是"模型没有跨设计的一致性"。** 18% 与 89% 差 4.9× ——
一个真模型不会对三个同类电路差这么多。

## 4. 可标定性：`s_i` 离散 4.98×，但偏离**不是均匀的**

`E_cdac` 是精确可算的，缺口全在 `E_rest`。令电路假设整体乘一个尺度 `s`（代表"设计者的偏置/占空比策略"）：

```
s_i = (E_conv_i − E_cdac_i) / E_rest_i
```

| 锚 | `s_i` | 说明 |
|---|---|---|
| 28nm 8b 500MS/s | **5.63** | 常规档 |
| 40nm 12b 1MS/s | **5.46** | 常规档，**只差 3.2%** |
| 65nm 8b 1MS/s（1.9 µW） | **1.13** | **偏离 4.83×** |

### 两个结论必须分开说

1. **常规档有一个约 5.46× 的系统性缺口**。它在技术上可以用单一 scale 描述 ——
   **这个缺口就是那 80% 不可建模的设计策略**。
2. **超低功耗档不能用同一标定**（亚阈值 / 低偏置把功耗压到 µW 级，`s` 小 5×）。

### 但整体仍不可标定

任何标定都必须引用锚本身 ⇒ **循环自证**。所以 `calibratable = False`。

🔴 **更深一层**：`C_clk_net` **本身是 f_s 的函数**（高速需要多级缓冲/大扇出）
⇒ 可标定性问题不来自"参数没调好"，来自"**参数不是常数**"。
这比"模型不准"是更强的陈述：**再调也调不好。**

## 5. 校核自由度：`dof = 3 − 4 − 2 = −3`

| 项 | 数 | 说明 |
|---|---|---|
| 待定参数 `k` | **4** | `C_latch` / `I_pre` / `C_clk_net` / `n_gate` 等效 |
| 独立实测约束 `m` | **3** | 三条实测 FOM 锚 |
| 工艺缩放参数 `q` | **2** | 三锚分属三个工艺 ⇒ 至少 C_ox 与 t_regen 的缩放指数 |
| 同工艺锚对 | **0** | **交叉验证的前提，一条都没有** |
| ⇒ `dof = m − k − q` | **−3** | |

⇒ **任何「模型 ⟷ 实测 误差 <20%」都只能靠反解参数再正算 = 循环自证。**
本模块**不宣称任何精度**。

### 要可校核，缺什么

🔴 **缺的不是模型结构，是数据**：**同工艺 ≥ `k+1` = 5 个不同配置（位数 / 速度 / 单位电容）的实测 FOM 锚。**

在此之前，**ADC 能耗只能报区间，且必须与覆盖率、dof 同屏** —— 三者缺一，读者无法判断可信度。

## 6. 地板改报区间：14.9 ~ 66.2 fJ/op（4.44×）

`E_op = E_conv/(2·n·K)`（每列一个 ADC ⇒ 每转换 `n/K` 个 ADC）：

| 锚 | `E_op` |
|---|---|
| 65nm 8b 1MS/s | **14.9 fJ/op** |
| **28nm 8b 500MS/s（E25 用的那个）** | **33.6 fJ/op** |
| 40nm 12b 1MS/s | **66.2 fJ/op** |

⇒ 对 Mythic 8.3 fJ/op 的差距是 **1.80× ~ 7.98×**。

🔴 **E25 的「33.7 fJ/op ⇒ 差 4.1×」作为单点结论不成立** ——
它落在区间内，但那是"恰好选中了三个锚里中间那个"。**区间才是诚实的报法。**

## 7. 一条可被实测证伪的结构性预言（及它暴露的口径接缝）

```
E_conv(f_s) = E_dyn + P_static / f_s
```

- `f_s → ∞` ⇒ `E_conv → E_dyn`，FOM 趋近动态地板
- `f_s → 0` ⇒ 静态项主导，FOM 变差
- ⇒ **FOM 存在最优点**

判据 ⑩⑪ 机核恒等（<1e-15）与单调性。

### 🔴 它暴露了 E25 未披露的口径假设

| | `f_s` |
|---|---|
| 28nm 8b 实测锚 | **500 MHz** |
| 平台 E17 自己的 8b 时序 | **10.85 MHz**（`T_conv = 92.14 ns`） |
| 差 | **46×** |

E25 的 `E_op = E_conv/(2nK)` 把 500 MHz 下的"单次转换能量"分摊到 `2n²` 个 op 上。
这在物理上成立（ADC 确实只占 MVM 周期一小段），**但它隐含"ADC 能在 2 ns 内完成转换"**。

🔴 **诚实边界**：真实设计在低速端会**降偏置 / 占空比化**，不会保持 `P_static` 不变。
所以本条是"**同偏置假设下**"的预言，**不可直接当预测**。

## 8. 我自己在开发中踩的坑（记录防再犯）

第一版取 `t_cmp = T_conv/(2b)`。低速锚（1 MS/s · 12b）得到 **41.7 µs** 的通电时间
⇒ 预放大项被算成 **27.6 pJ** ⇒ **覆盖率 343%（40nm）/ 1640%（65nm）** —— 能耗被算爆 16 倍。

正解 = **工艺再生时间**（28nm 200 ps / 40nm 400 ps / 65nm 800 ps），**与 f_s 无关**。

⇒ 立判据 **④/B2：覆盖率 >100% 必须判红**（**不是"越高越好"**）；探针 C1 守此不回退。

> 与血案一致：**"静态功耗 × 转换周期"这个模型在低速下必然爆炸**，
> 因为设计者会让偏置占空比化。**占空比是设计选择，不是物理量。**

## 9. 未解释项构成（8 条，6 条不可建模 = 75%）

| 项 | 可否建模 |
|---|---|
| CDAC 开关能量 | ✅ 可（闭式） |
| 比较器锁存动态能量 | ⚠️ 半可（`C_out` 是架构量） |
| 参考缓冲静态偏置（维持低输出阻抗） | ❌ 由"允许纹波/建立时间"反解，是设计目标 |
| 时钟树去偏斜 + 扇出缓冲 | ❌ 由版图与时序收敛决定 |
| 前台/背景校准数字电路 | ❌ 算法与位宽是设计选择 |
| 自降压 / 亚阈值偏置 | ❌ 电压不在规格里 |
| 异步控制与占空比化 | ❌ 偏置通电占空比是策略 |
| 版图寄生（走线/过孔/衬底） | ❌ 需实际版图提取 |

⇒ **那 80% 缺口的来源，全是设计策略，不是物理规格。**

| E24：两步式比 SAR 好 8.5× ⇒ 能改善能效 | ❌ E25 已否（只作用在 2%） |

## 11. 对下一段的硬指令

🔴 **不要再试图"把 ADC 算准"。** 缺的不是模型，是同工艺实测锚（≥5 个）。

三条可选方向（按价值排序）：

1. **转向"可控量"**：`duty_read` / `c_unit_fF` / `c_logic_fF_per_cell` 都已证明不再是主导项，
   真正未探的是**阵列规模 N 与列共享 K 的联合优化**（E23 只扫了 K）。
2. **把"不可建模"变成"可设计"**：既然参考缓冲静态偏置是最大未知项，就**反解**它 ——
   给定目标 FOM，反推允许的 `I_ref`（这是设计规格，不是拟合）。
3. **接受负结果收口**：端侧 CIM 的能效区间已经足够支撑"做什么/不做什么"的判断，
   继续深挖 ADC 的边际收益趋零。

## 12. 诚实边界（对外必须同屏）

- 工艺参数（V_DD / C_ox / `t_regen`）是**公开典型值占位，非 PDK**，**未在 LDA 上验证**；
- 电路假设（`C_latch`=10 fF / `I_pre`=50 µA / `C_clk_net`=500 fF / `n_gate`=300）**全部是占位**；
- 三条实测锚是**公开文献照录**，未逐篇复核 ENOB 口径；
- **dof = −3 ⇒ 不宣称任何精度**；
- 输出恒 `MODEL_ESTIMATE`，`MEASURED` 档**永久空置**（无硅）；
- **净增 0 锚**。
