## 3. 设计口径（五项逐条）

### 3.1 ① 多通道均衡（CTLE · 形态映射）

**物理（闭式）**：单极点 CTLE 频响

    H_ctle(f) = (1 + (f/f_z)²)^½ / (1 + (f/f_p)²)^½ ,  f_p > f_z（高频提升 = boost）

**噪声 penalty（golden，有精确闭式）**：均衡把信号抬起来的同时放大噪声 ⇒

    NBW ≡ ∫₀^F |H_ctle·H_ch|² df / |H_ctle(F)·H_ch(F)|²        （F = 奈奎斯特）
    ∫₀^F (1+f²/c²)/(1+f²/a²) df = (a²/c²)[F + (c²−a²)·atan(F/a)/a]

  即 **闭式可积** ⇒ `ctle_noise_penalty_db()` 直接解析求值，**数值积分（trapz）作第二独立通道对拍**。

**「多通道」的落点**：8 条 lane 因路径长度/器件差异有**不同频率倾斜（tilt）**，单一 CTLE 无法同时平坦 ⇒
**逐 lane 抽头优化**（Wiener/最小二乘），判据是均衡后各 lane 所需 SNR 的**极差**（max−min）受限 ⇒
正是「IL/倾斜/**眼高平坦化**」的定义。

**形态映射（本轮题眼）**：

    equalizer_for_form("lpo")      → {"ctle": True,  "ffe": False}   # 无 DSP ⇒ 只能模拟
    equalizer_for_form("retimed")  → {"ctle": True,  "ffe": True}    # 有 DSP ⇒ 可数字均衡

🔴 判据必须是**窗口/反向**而非「同源码相等」：断言 `lpo` 的 ffe 为 False 且 `ctle` 为 True，
并要求 `equalizer_for_form` 的返回值**逐键**被门禁消费（§6 探针 P3 让 lpo 拿到 ffe ⇒ 必红）。

### 3.2 ② 热调 Pπ 进链路

- 复用 `tunable_wdm.tune_slope` 闭式 `S = λ·(dn/dT)·R_th/n_eff` [nm/mW]（Si 典型 dn/dT = 1.86e−4/K，
  R_th 默认 1.0 K/mW，P_max 50 mW —— 均与既有模块**同源不复制**，直接 import；
  🔴 **不重抄常量**（M2 血案 #3：跨档抄常量同源不同步））。
- 环需调谐到信道波长 ⇒ 剩余失谐 ⇒ 调谐功耗 `P_tune = Pπ · |Δλ/FSR|`（mW/lane）。
- 加热器寄生损耗：金属/掺杂吸收闭式占位（A 档行为级，显式标注**非 PDK**）。
- 输出登记：**调谐功耗 mW/lane + 模块总调谐功耗 mW**（**功耗口径，非能效口径**）。

### 3.3 ③ 热串扰 Γ 矩阵（版图绑定）

物理（二维薄片稳态热场 ⇒ **对数衰减**）：

    ΔT_ij = Θ_ij · P_j ,  Θ_ij = R_th0 · ln(d_ref / d_ij)          （d_ij = 版图距离，d_ij ≤ d_ref）
    Γ_ij  = S_i · Θ_ij                                              [nm/mW]

- **版图绑定**：Γ 的 d_ij **必须**取自 `lda_layout.oi_transceiver_pnr` 的实际 placement 坐标
  （Tx 调制器阵列 / Rx 环阵列 / 探测器阵列），**不得**写死坐标或常量矩阵。
- **三条闭式物理律判据**（都是 golden，非同源码相等）：
  1. **对称性** `Γ_ij = Γ_ji`（热传导是互易的 —— 非对称布局下仍须成立）；
  2. **单调性** Γ_ij 随 d_ij **严格递减**（≥3 组不同距离对）；
  3. **对角最大** `Γ_ii ≥ Γ_ij (i≠j)`（自身加热最强）。
- **第二独立通道**：另建**集总热网络**（分段 R 的网络矩阵，numpy solve）算 Θ，与解析对数解对拍。
- 与 M2 的互锁：Γ 用到的 `S`（调谐斜率）与 `R_th` 必须与 `tunable_wdm` / 本模块常量**同源**
  ⇒ 复制常量必红（同血案 #3）。

### 3.4 ④ 工艺偏差 → 良率 MC

物理链：波导宽度偏差 δw ⇒ n_eff 偏差 ⇒ 环谐振偏移 Δλ₀（闭式 dλ₀/d n_eff）⇒ 信道串扰。
信道间隔 4.5 nm（M2 栅）⇒ 判定窗 |Δλ₀| < λ_tol 则通过。

    Δλ₀ ~ N(0, σ_λ)  ⇒  yield = P(|Δλ₀| < λ_tol) = 2·Φ(λ_tol/σ_λ) − 1      【闭式 golden】

- **MC 采样 N = 20000（固定 seed，可复现）** ⇒ 频率统计 `n_pass/N` ⇒ 与闭式 **逐位对拍**（容差 2e−3）。
- 🔴 纪律：**MC 统计不是 golden**（它是采样近似），golden 是闭式 Q/Φ；MC 只作**第二通道**。
- 退化/边界判据各 ≥2 同类成员：σ=0 ⇒ yield=1.0；λ_tol=0 ⇒ yield=0（两个探针）。

### 3.5 ⑤ 封装容差（对准 + 温度）

GC（光栅耦合器）耦合效率，高斯模场口径（w = 1/e² 半径）：

    η_dx = exp(−2·dx²/(w₁²+w₂²))                   横向失配（闭式）
    η_m  = (2·w₁·w₂/(w₁²+w₂²))²                    模场失配（闭式）
    η_θ  = exp(−2·(θ·L_eff)²/(w₁²+w₂²))            角度失配（等效横向，闭式）
    η_dz                                            纵向/耦合长度失配（闭式）
    η    = η_dx·η_m·η_θ·η_dz                        总耦合效率

**对准容差预算**：给定 IL_max（dB）⇒ 反解 dx_max（闭式反解，逐项）⇒ 与数值积分对拍。
**温度窗口**：λ_c(T) 随 T 漂移（dn/dT + 热膨胀）⇒ 窗口内 η 漂移 ⇒ 温度容差预算。

## 4. golden 选取（「外部对标四层」）

| 项 | golden（闭式物理律） | 第二/独立通道 |
|---|---|---|
| CTLE 噪声 penalty | 解析积分闭式 `ctle_noise_penalty_db` | trapz 数值积分 |
| 逐 lane 均衡 | Wiener 最小二乘解 + ISI residual 闭式 | 时域眼高（复用 M1/M2 时域引擎） |
| Γ 矩阵 | 对数场闭式 + **三条物理律判据**（对称/单调/对角最大） | 集总热网络 numpy solve |
| 良率 | 闭式 Φ（Q 函数） | MC N=20000 频率统计 |
| 封装 | 高斯重叠**解析**闭式 | 数值积分对拍 |

🔴 全部**不**用「同源相等」当判据（A≡B 同口径必绿的假判据纪律）。

## 5. 规格锚（外部标准 = 限值口径 · 第 ④ 层，可用）

新增锚位（逐条**带窗口**，防 M1 血案重演：值本身错 100× 时原判据全绿）：

- **A6 工艺偏差 σ**：σ_λ 的声明窗口（默认 σ_w = 0.5 nm 宽偏差 ⇒ σ_λ 由闭式 dλ/dw 映射）；
- **A7 对准容差**：GC 对准 IL 预算窗（默认 1.0 dB ⇒ dx_max 反解）；
- **A8 温度窗口**：−5…70 °C（商用光模块典型工作温区）⇒ GC 中心波长漂移闭式。

🔴 σ/T 窗口是**设计者声明**，**不是 foundry 真值**（T2 锁死区），不得宣称「实测工艺能力」或「流片良率」。

## 6. 突变探针（先证「能变红」再信判据；§3.1–3.5 逐项）

| 探针 | 破坏 | 期望变红 |
|---|---|---|
| **P1** | CTLE 频率提升关掉（f_z = f_p，退化成flat）⇒ noise penalty 必 0 dB | 「CTLE 有效」类判据 |
| **P2** | 把 CTLE 噪声 penalty 的积分上限从 F 改成 0（空区间）⇒ 恒绿陷阱 | 积分判据 |
| **P3** | 让 `equalizer_for_form("lpo")` 也返回 ffe=True（**LPO 拿数字 DSP**，自相矛盾） | 形态映射反向判据 |
| **P4** | Γ 的距离改曼哈顿距离 / 常量矩阵（丢对称性或单调性）⇒ 三条物理律判据之一红 | Γ 对称性/单调性 |
| **P5** | 良率 σ=0（退化 ⇒ yield 恒 1）与 λ_tol=0（⇒ 恒 0）**各测一次** | 退化/边界各 ≥2 同类 |
| **P6** | MC 换成不固定 seed（不可复现）⇒ 可复现判据红 | 可复现性 |
| **P7** | GC 对准 IL 预算阈值改 0 dB ⇒ 反解容差判据红 | 封装容差判据 |
| **P8** | 把热调消耗/调谐功耗写成「能效比」（触碰红线禁词面） | 禁词/红线判据 |
| **R** | 探针还原后**基线门禁必须重新全绿** | 探针不污染真判据 |

🔴 探针落点必须打在**被门禁真正消费的那份引用**上（本项目反复踩的坑）。
