## 2. 三个候选新域（现状证据**现算**）

> 证据方法：在**限定的量子模块**里对**专指关键词**去注释计数。命中 0 ⇒ 该域在现有代码中无对应实现（干净缺口）；命中 >0 ⇒ 部分概念已存在，须逐项核可区分性。

### 2.1 V2-D1 · 光-量异质集成

**主张**：把微波-光换能（J5 M3 已建 **B522**，η = `1.125146902042377e-02`）推进到**系统级异质集成**。

**种子**：`lda_l2/qnet_transducer.py` · B522 · `qnet_channel.py`

**缺口（4 条）**：
1. 多模换能阵列（单模 → N 模）
2. 与低温 CMOS 的共集成热/电接口
3. 封装级光耦合（光纤阵列对准容差）
4. 异质材料界面损耗模型

**入口锚提示**：多模换能总效率 · 光纤阵列耦合容差预算 · 界面吸收损耗

**探针证据**：扫描 `qnet_transducer.py` + `qnet_channel.py` 的 `多模/阵列/封装/CMOS/共集成/heterogeneous` ⇒ **1 命中**（仅「多模」一次）⇒ 概念几乎零。

🔴 **风险**：跨域（光 + 微波 + 封装），单锚难以自洽 ⇒ 建议**先做单指标再扩系统**。

---

### 2.2 V2-D2 · QEC 码族扩展

**主张**：J1 只做**表面码**（阈值/解码/综合征/容错门，9 锚）。扩到 LDPC / 色码 / 拓扑码，并比较**同一物理错误率下的资源-阈值折衷**。

**种子**：J1 九锚（B497–B505）· `decoder.py`（MWPM ↔ 自主 Union-Find 位级对拍）

**缺口（4 条）**：
1. 量子 LDPC 解码（BP + OSD）
2. 色码解码与阈值
3. 码族间资源-阈值折衷（同 p 下比较）
4. 逻辑门集合的可比性度量

**入口锚提示**：LDPC 阈值（BP+OSD）· 色码阈值 · 同 p 下资源比

**探针证据**：`decoder.py` + `logical_error_rate.py` + `qec_noise.py` 的 `LDPC/色码/拓扑码/bivariate/hypergraph` ⇒ **0 命中** ⇒ **干净缺口**。

🔴 **风险**：BP+OSD 是迭代求解器，实现重；**红线禁止借第三方 QEC SDK** ⇒ 必须自研（主权 A 档）。

---

### 2.3 V2-D3 · 容错编译（QEC ↔ QPU 联合）

**主张**：在 J1（逻辑层）与 J2（物理层）之间补**编译层** —— 逻辑门 → 物理脉冲序列的映射、调度与错误预算分摊。

**种子**：J1 容错门（B502/B503）+ J2 门错误（B506/B507）—— 两层**已有量化输入**，但**无编译中间层**。

**缺口（4 条）**：
1. 逻辑→物理映射与调度（含测量轮次）
2. 错误预算在编译期的分摊策略
3. 门序优化对保真的净收益模型
4. 编译期资源估计（T 态/魔术态）

**入口锚提示**：编译后总保真（闭式 vs 模拟）· 调度深度下界 · 魔术态消耗率

**探针证据**：限定 `logical_error_rate.py` / `decoder.py` / `fault_tolerant_gates.py` / `qnet_system.py` / `qnet_distribution.py` 的 `magic_state/魔术态/logical_to_physical/transpile/测量轮次/logical_schedul` ⇒ **0 命中** ⇒ **干净缺口**。

> 🔴 **本探针修正过一次**：首版用 `compil/schedul/routing` 扫全 `lda_qeda` + `lda_l2`，得 **205 命中** —— 逐条核后全是**光子版图的布线/调度**（假阳性）。**通则：跨域探针必须限定量子模块 + 专指词**，否则「有命中」也可能毫无关系。

🔴 **风险**：属**软件/算法层**，与现有「物理律锚」范式不同 ⇒ **须先定「golden 是什么」**（物理闭式 / 规格锚 / 模拟基线）。

## 4. 需要你定调的四件事（**本档不自行决定**）

1. **选哪个候选域作为 v2 首档**（或另提新域）？
   - 建议排序依据：① 有无**闭式 golden**（决定能否沿用判据范式）② 是否**跨域**（D1 跨三域风险最高）③ 实现成本（D2 的 BP+OSD 最重）。
2. **V2-D3 容错编译的 golden 是什么？** —— 若答不出「物理闭式」，则该域须先在方法学上另立范式，不能直接立项。
3. **是否允许引入 BP+OSD 类迭代解码**（自研 vs 借用的主权分层归属）？—— 若外购/借开源，按三档分层须登记为 B 档并给「借今踢后」路径。
4. **补盲 415 锚 与 新域扩张 的优先级**？—— 棘轮只升不降 ⇒ 新域落地会**同时抬 L2 下限**，两条战线并行会互相挤压。
