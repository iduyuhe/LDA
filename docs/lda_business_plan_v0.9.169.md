## 1. 执行摘要

**LDA（Lightwave Design Automation）** 是开源、Agent 原生的光子集成电路（PIC）、量子芯片（QEDA）与**电子模拟计算核（ecore）** 三栈设计自动化平台，对标传统电子 EDA 在光/量/模拟计算时代的等价物。

我们的差异化不是"求解器更快"，而是行业结构性空白——**验证可证伪、主权自主、Agent 原生**：

- **验证可证伪**：判决落物理定律锚 + 实证大数据锚，LLM 不进判决路径，PASS/FAIL 由死标量比对定（账本 476 / 独立率 95.59% / CI core 259）。
- **主权自主**：A 级能力永不外借；B 级借今踢后；C 级第一天自主（Meep 已隔离、Tidy3D 仅外部 ORACLE）。
- **Agent 原生**：设计→仿真→版图→DRC/LVS→工艺角→几何寄生全链路可由 Agent 编排。

**为什么是现在**：AI 数据中心把光互连推到刚性需求，硅光子市场 2024→2030 以 29.5% CAGR 爆发；2025 年 5 月美国对华 EDA 出口管制为国产替代创造结构性窗口；云原生 + 开源正重构 EDA 付费模式。

**本轮诉求**：LDA 处于早期开源项目阶段，技术栈已完整（三栈闭环 + 主权 GDS 实证），正从技术验证走向首个商业试点与生态播种。本轮拟引入战略与财务投资人，加速 PDK 生态合作、流片验证与获客。

> **🔴 诚实前置（投资人必读）**：LDA 当前**尚无任何真实付费客户**，生产站点深度使用几乎全部来自 AI 自身与创始人本人；在线支付从未实现（闭环终点为人工询价）。技术账本是真实硬货，但**商业闭环尚未被真实市场需求验证**——本 BP 的财务与获客部分均为策略与假设，非承诺。

## 3. 问题与机会

### 3.1 行业痛点
1. **验证不可证伪**：传统光子/量子设计工具把"仿真结果是否可信"留给用户主观判断，失真可在全绿下溜过（LDA 自身体验过：v0.9.10 漏算 3.0103dB 在 84 项全绿下通过）。
2. **主权依赖**：商业求解器（Lumerical / Tidy3D）掌握在美系巨头手中；2025 年 5 月美国对华 EDA 出口禁令使依赖风险显性化。
3. **工具昂贵、门槛高**：永久许可 $15万–$50万，中小团队与学术机构被挡在门外。
4. **光/量/模拟计算三栈割裂**：光子、量子、模拟计算 EDA 由不同厂商、不同范式割裂提供，缺少统一 Agent 原生闭环。

### 3.2 结构性机会
- 硅光子市场 2024 年 21.6 亿美元 → 2030 年 96.5 亿美元（CAGR 29.5%）[MarketsandMarkets]。
- 光子 EDA 软件市场 2025 年约 18 亿美元，2026–2034 CAGR 13.5%，其中量子应用子段 22.4% 最快、云部署 18.7% 最快 [Dataintelo 2026]。
- 量子光子段获全球政府承诺投资 > $4.1B（截至 2026 初）[Dataintelo 2026]。
- **DAC 2026 共识**：「自主性来自验证器的质量，而非模型的质量」——LDA 的 476 道物理锚 + 判据 D + provenance 验证纪律，是这个时代最稀缺的资产。
- **L6 空白**：「算法 → 光/模拟硬件映射」的计算架构编译层，全球无标准工具——谁先立谁定义标准（LDA 战略切入点）。

## 4. 解决方案：LDA 是什么

LDA 提供光（PDA）+ 量（QEDA）+ 电子模拟计算（ecore）三栈、Agent 原生的设计闭环：

**设计 → 仿真 → 版图 → DRC/LVS → 工艺角 → 几何寄生**（电子侧另含 误差预算 → 权重编程 → 时序 → 面积 → 动态代价）

当前核心账本（v0.9.169 运行源码实测）：

| 指标 | 数值 |
|------|------|
| 验证锚 | **476**（B1–B458）· strict 455 / 降级 3 / 自证桩 18 · **独立率 95.59%** |
| CI core 冒烟 | **259 条全绿**（0 SKIP / 0 FAIL） |
| 电子 ecore | **24 模块 · E1–E19 全闭环**（模拟 MVM 交叉阵列，对标 Mythic 类存算） |
| 量子双栈 | LOQC（D-113..D-132）+ 超导 transmon（D-133..D-145） |
| 光子 PDA | 主权全链路 GDS + DRC/LVS 双闸（9 例 5 拓扑实证；MESH4/MESH8 光子计算核） |
| 规模基线 | 1M 元素 35.98s/0.85GB；10M 实测 428.42s/30.5GB（O(n^1.08)）；层次化 99.96% 降元 |

**验证红线（护城河核心）**：判定落非 AI ground（物理定律锚 + 实证大数据锚）；LLM 不进判决路径；PASS/FAIL 由死标量比对定；**ecore 不报 TOPS/TOPS-W/fJ/op**。

## 7. 战略方向：GPU / PLC / MCU 命题改写（2026-10 评估）

外部常问「能否用 LDA 设计 GPU、PLC、MCU」。经评估（详见战略总纲 §8），结论为**改写命题**而非直接照做——因为 LDA 能力域是光子 PDA + 量子 QEDA + 电子**模拟**计算核，没有数字 RTL 综合、标准单元库或任何 foundry PDK：

| 原命题 | 改写后（LDA 能力域内） | 必要性 | 重要性 | 可行性 |
|--------|----------------------|--------|--------|--------|
| 设计 GPU | **「光子 GPU」= 光子/模拟 AI 加速器**（光学张量核 MESH + 模拟存算交叉阵列） | 高 | 高（AI 数据中心光互连主线） | 高（能力已具备） |
| 设计 PLC | **平面光波导电路（Planar Lightwave Circuit）**——PDA 本命领域；同时评估工业可编程逻辑控制器芯片（= MCU 变体，做其模拟/混合信号子系统） | 高（本命快赢） | 高（硅光/二氧化硅 PLC 市场） | 高（PDA 核心） |
| 设计 MCU | **「边缘 AI MCU」= 混合信号 MCU 子系统**（传感接口 + 数据转换 + 存算，延伸 ecore E14/E17/E8） | 中 | 中高（边缘 AI 大市场） | 高（模拟侧） |

**统一战略定位**：LDA 应定位为「**模拟 / 光子 / 混合信号计算硅设计平台**」，而非「通用数字 SoC EDA」。全数字 GPU/MCU、真实 foundry 流片——错 domain、无 PDK、无数字 P&R，且稀释清晰定位，明确不做。

| **Mythic / Tetra Mem / Lightmatter / Lightelligence** | 模拟/光子 AI 计算芯片 | — | **LDA ecore/光子计算的对标与生态位** |
| **LDA（本平台）** | **验证可证伪 + 主权自主 + Agent 原生 + L6 计算架构编译** | **开源 + 三档 + 企业订阅** | **维度差异，非精度超越** |

**关键立场（诚实）**：LDA 在对比中列第 1，是「验证独立 + 主权自主 + Agent 原生 + L6 切入」的维度差异，不是求解精度已超越 Lumerical / Qiskit（成熟度仍低于商业标杆、尚未流片）。这是结构性空白，而非精度叙事。

**护城河来源**：现有巨头与初创都把"可信验证"交给用户主观判断或黑盒；LDA 把判决锚定到物理定律与实证大数据，且主权模块自主——这是别人短期难抄的架构选择。

## 9. 技术护城河

1. **验证方法论红线**：物理定律锚（解析解/守恒量）+ 实证大数据锚（真实测量/同行结果），判据 D 防自证桩失真；CI core 259 条门禁；独立率 95.59%。
2. **主权分级纪律**：A 级永不借 · B 级借今踢后（gdsfactory/KLayout/SAX；Tidy3D 仅外部 ORACLE）· C 级第一天自主。Meep=GPL v2+ 已隔离（subprocess 只回标量）。
3. **Agent 原生闭环**：设计→仿真→版图→DRC/LVS→工艺角→几何寄生可由 Agent 编排；用户侧智能体客服解答+留资，但不进验证判决路径。
4. **规模能力**：1M 元素 35.98s、10M 实测 428.42s（O(n^1.08)）、层次化 99.96% 降元、已去 GPU 依赖（5 器件 live 5/5）。
5. **L6 切入**：率先把「算法 → 光/模拟硬件映射」作为可验证架构编译层，全球无标准工具。
