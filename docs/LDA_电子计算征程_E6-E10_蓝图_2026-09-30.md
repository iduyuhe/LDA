## 三、五段规划

### E6（D-156）· 版图与签核链 —— ✅ 已完成（2026-09-30）

**目标**：让电子计算芯片**第一次能出真 GDS**，并走完「几何 → DRC → LVS → 签核」闭环。
与光子（M1–M5）/超导（S1–S5）征程收尾同构。

- **交付物**：
  1. `lda/lda_l2/ecore/elayers.py` —— 电子版图层栈（DIFF/POLY/CONT/M1/VIA1/M2）+ 层语义
     （同层可短 / 异层隔离 / CONT·VIA 唯一合法跨层桥）+ 设计规则表（单一真源）。
  2. `lda/lda_l2/ecore/layout.py` —— 交叉阵列版图生成（1T 交叉点单元 + 行线/列线/权重线 P&R）·
     几何 DRC · 段感知 LVS（几何→网表 + W/L 几何回提）· GDS 导出（含 AREF 层次化）· SVG 预览 · 自检。
  3. `lda/run_ecore_e6_smoke.py` —— 常驻门禁（判据 + ≥3 突变探针 + 还原完整性）。
- **golden（闭式）**：阵列版图 bbox = 节距闭式；AREF 层次化**展开后元素数 ≡ flat**；
  晶体管 **W/L 几何回提 ≡ 声明值**；LVS 连通性（每单元恰好 1 行线 1 列线、行列互不短、零悬空）。
- **逼出的平台接缝**：平台**无电子工艺层栈语义**（`layers.py` 只有光子/超导栈）⇒ 新增电子栈；
  平台已有 `gds_library` / `parse_gds_polygons(expand_refs)` / `Geom` 约定 / 层次化 AREF ⇒ **直接复用**。

### E7（D-157）· 寄生提取与后仿 —— ✅ 已完成（2026-09-30）
从 E6 版图**提取导线 RC**（行/列线电阻 + 线间电容，几何闭式：`R=ρL/(Wt)` · `C=ε₀ε_r·W/d`），
把 RC 注入 MNA 交叉阵列 → **带寄生重仿**，量化 **IR drop** 与 **sneak path** 对输出误差的贡献（对比理想互连）。
- 判据：RC 提取闭式 ↔ 数值积分；后仿误差 ≥ 理想误差（寄生必然劣化）+ 单调性。
- **实测**：`R□`=0.084 Ω/□ · `R_row_seg`=0.504 Ω · `R_row_total`(8×8)=3.53 Ω · `τ_row`=3.1 fs；
  **IR drop 相对误差** N=4 0.42% → N=16 8.06% → N=32 **27.0%**（超线性）；**sneak 比例** N=4 1.29× → N=16 7.26×；
  `R=0` 网络 ≡ 解析 golden `I_j=Σg_ij·V_i`（max|Δ|=1.08e-19）。门禁 `run_ecore_e7_smoke` **34 判据 + 4 探针**。

### E8（D-158）· 非理想、失配与噪声 —— ✅ 已完成（2026-09-30）
器件失配（ΔVth / Δβ 正态，**Pelgrom** `σ=A/√(W·L)`）→ **Monte Carlo** 扫出输出误差分布（σ）；
热噪声 / 闪烁噪声表征；温度对 Vth 的一阶影响。产出**校准方案**并量化校准后残差下降。
- 判据：σ 随失配幅度单调；校准后误差严格下降；MC 收敛（样本数 ↑ ⇒ σ 稳定）。
- **实测**：`σ_ΔVth`=**5.00 mV** · `σ_Δβ/β`=1.67% · Vth 25→85 °C **−60 mV** · `µ(85)/µ(25)`=0.760 ·
  热噪声 `i_n²`=1.098e-23 A²/Hz · MC σ_rel(8×8) = **0.654%**（无偏）· **`σ_rel ∝ 1/√N`**（σ·√N≈0.0186 恒定）·
  **校准层级 L0 1.696% → L1 0.212% → L2 0.0743%**。门禁 `run_ecore_e8_smoke` **36 判据 + 4 探针**。

### E9（D-159）· 规模压力与诚实对标 —— ✅ 已完成（2026-09-30）
把 E6 版图推到**千级阵列**（层次化 AREF 压缩），报告面积 / 节距 / 线长 / 寄生量级；
与公开模拟 CIM landmark **同族维度**对标（架构族 / 精度 class），**不做数值超越比较**。
- 判据：面积 ∝ N² 闭式；层次化压缩比；诚实护栏（无 TOPS/TOPS-W/fJ/op，注入造假必红）。
- **实测**：换上 **O(N) 算法**（层次化出图 + **一维三对角 IR-drop**，对拍 E7 的 2D MNA rel ≤1.7e-13）⇒
  1024² 仅 **86.6 KB** / 压缩比 **3571×**；三重规模律 IR drop **3.75%→95.6%**（超线性）· 面积 ∝N² · 失配 σ ∝1/√N；
  **可及规模上界**：10%→N≤26 · 5%→N≤18 · 1%→N≤8 ⇒ **被动单端行线驱动的 IR-drop 是硬天花板**。
  门禁 `run_ecore_e9_smoke` **34 判据 + 4 探针**。

## 四、每段固定五步（沿用 E1–E5 纪律）

1. **勘查接缝** —— 找平台缺口 / 复用点（本次 E6 勘查已完成）。
2. **设计定稿** —— 模块划分 / 门禁 / 探针 / CI 接线方案。
3. **实现** —— 落盘 `.py`（Write），纯标准库 + numpy。
4. **独立验证 + 护栏自证** —— 闭式 golden + **突变探针「先证能变红」** + 还原完整性。
5. **接线收官** —— `CORE_SMOKES` + `_BUILTIN_TIMEOUT_OVERRIDE` + 基线 json + 三道门禁 + 能力清单 + 记忆。

## 五、诚实边界（对外口径）

- LDA 是**设计 & 验证工具链**，**不是流片芯片** ⇒ 不报 TOPS / TOPS-W / fJ/op 等只有实测芯片才有的指标。
- 版图层与设计规则为**公开工艺近似**（**非 Foundry PDK**）；DRC/LVS 为**几何签核**（非签核级 deck）。
- 电路级验证引擎**非签核级 SPICE**（无温度/噪声/稀疏矩阵；E8 补温度与噪声通道）。
- 参数为公开典型量级占位 ⇒ 不宣称器件性能；一切对标只在**同族维度**（架构族 / 精度 class）。
