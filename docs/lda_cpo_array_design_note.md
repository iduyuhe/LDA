# CPO 共封装光引擎阵列 · 十万级真实器件样例设计说明（v0.9.2 · 阶段2）

> 目标：把 v0.8.45（LVS 短路检测 O(n²) 治理）与 v0.8.46（GDS 导出 O(n²)
> 治理）打通的十万器件级全链能力，落到**真实器件样例**上。
> 此前的规模锚是「N 个 Waveguide 串成一条链」——能证明**规模**，不能证明
> **真实度**。本样例两件事都要。

---

## 一、为什么是 CPO

共封装光学（Co-Packaged Optics）是 AI 数据中心互连的确定性方向：交换
ASIC 周边环绕多个光引擎（OE），每个 OE 承载数十个波长通道，每通道跑
WDM 多波长。它的版图天然是**层次化规则阵列**——这既是真实的产业形态，
也是十万级器件唯一可工程化验证的组织方式。

选它的三个理由：

1. **器件构成真实**：微环调制器、WDM 解复用环、功率监测抽头、光栅耦合器、
   互连波导段——类型多样，不再是单一 `Waveguide` 刷量；
2. **参数可反解**：波长、折射率、谐振级数都是物理量，器件参数不该是拍脑袋
   常数，而应由谐振条件算出来；
3. **规模真实**：32 引擎 × 34 通道 × 8 波长是 51.2T 级交换芯片的量级，
   十万器件不是"为了凑数"，是拓扑自然长出来的。

## 二、架构层次

```
Array   n_oe  = 32   光引擎（Optical Engine，交换 ASIC 周边环绕）
 └─ Engine   n_ch  = 34   波长通道（每通道 = 1 路双向光纤端口）
     └─ Channel  n_lane = 8   波长 lane（LAN-WDM 8 波）
         ├─ Tx 链（58 器件）：ELS 馈入 → 级联微环调制 → 输出光栅 → 光纤
         └─ Rx 链（34 器件）：输入光栅 → 级联 add-drop 解复用 → 探测器馈线
```

**每通道 92 器件，共 1,088 通道 → 100,096 器件 / 2,176 条独立光路。**

Tx 链（级联微环调制发射机）：

| # | 角色 | 器件 | 物理作用 |
|---|---|---|---|
| 1 | `wg_trunk` | Waveguide 18 µm | 外部激光源（ELS）主干馈线 |
| 2–8 | `wg_feed` / `tap_in` / `wg_pre` / **`mrm`** / `wg_post` / `mon` / `wg_bus` | 波导 + 环 | 每波长一组：馈线 → 输入功率监测 → **微环调制器** → 输出监测/波长锁定 → 总线段 |
| 9 | `gc_tx` | GratingCoupler | 输出光纤耦合 |

Rx 链（级联 add-drop 解复用接收机）：

| # | 角色 | 器件 | 物理作用 |
|---|---|---|---|
| 1 | `gc_rx` | GratingCoupler | 输入光纤耦合 |
| 2 | `wg_trunk` | Waveguide 18 µm | 接收主干 |
| 3–6 | **`demux`** / `wg_drop` / `tap_rx` / `wg_pd` | 环 + 波导 | 每波长一组：**解复用环**（drop 本波长、其余直通）→ drop 段 → 接收监测 → 探测器馈线 |

器件构成实测：`Waveguide × 54,400` · `RingResonator × 26,112` ·
`RingAddDrop × 17,408` · `GratingCoupler × 2,176`。

## 三、物理参数反解（非拟合常数）

### 3.1 微环半径

谐振条件是硬约束：`m · λ = 2π · n_eff · R`

- 波长栅格：LAN-WDM 8 波，O 波段 1273.54 – 1304.42 nm（约 4.5 nm 间隔）
- `n_eff = 2.45`（SOI 220 nm × 450 nm 条形波导，公开文献近似）
- **`m = 91`** —— 谐振级数**必须是整数**，这是物理约束不是自由参数

反解结果：

| λ (nm) | 1273.54 | 1277.89 | 1282.26 | 1286.66 | 1291.10 | 1295.50 | 1299.92 | 1304.42 |
|---|---|---|---|---|---|---|---|---|
| R (µm) | 7.5285 | 7.5542 | 7.5800 | 7.6061 | 7.6323 | 7.6583 | 7.6844 | 7.7110 |

半径差仅 **0.18 µm** —— 这正是真实 WDM 微环的量级。波长选择靠热调谐
trimming 把环微调到 ITU 栅格，版图差异本就极小；这里由公式直接给死，
**不注入虚假精度**，也不做「每波长半径差几微米」的伪真实。

全部 ≥ DRC `min_bend_R` 5.0 µm ✓

### 3.2 光栅耦合器周期

布拉格条件：`λ_c = Λ · (n_eff,gr − sin θ)`

- 浅刻蚀光栅平均有效折射率 `n_eff,gr ≈ 2.4`
- 光纤耦合角 `θ = 15°`（真实典型窗口 8–25° 内）
- 目标 `λ_c = 1.310 µm`（O 波段中心）

→ `Λ = 1.310 / (2.4 − sin15°) = 0.612 µm`，取 `duty = 0.60`：

- 齿宽 = 0.612 × 0.60 = **0.367 µm** ≥ DRC `min_width` 0.35 ✓
- 齿隙 = 0.612 × 0.40 = **0.245 µm** ≥ DRC `min_space` 0.20 ✓

**线宽/间距双约束同时满足**——不是"先给参数再碰运气过 DRC"，而是
从工艺规则反推物理上可行的齿形。

## 四、几何策略：端口线对齐 + 零跳线

十万器件最怕两件事：**布线慢**和**同层短路**。本样例用几何一次性解决。

### 4.1 端口线对齐

LDA 的端口锚点里，`Waveguide` 的 in/out 恒在 y=0，`Ring*` 的 in/out
恒在 y = −off —— **同一器件的进出端口永远同 y**。据此在放置时做补偿：

```
链首器件：y_place = row · pitch_y − out_dy
其余器件：y_place = row · pitch_y − in_dy
```

（链首用 out 是因为它的连接从 out 出发；`GratingCoupler` 的光路侧是
`wg` 端口而非 `in`/`out`，按实际使用端口取值。）

结果：**同一行所有参与连接的端口落在同一条水平线上** → 行内连接退化为
纯水平段，没有垂直段，也就没有跨行垂落。

### 4.2 零跳线

`pitch_x` 取两个下界的最大值：

```
pitch_x = max( 2·max_hw + margin,                  ← 器件 body 不重叠
               max(out_dx) − min(in_dx) + 6 )      ← 连线长度恒正、不回折
```

第二条是关键：若 `pitch_x` 不够大，「前一级 out → 后一级 in」会变成
**向左回折**的段，回折段必然穿越前级 body 并与相邻段共线——这是同层
短路的温床。把下界写进公式，回折在几何上被排除。

再让通道宽度（92 器件）整除行宽（`92 × ch_per_row`），通道就**不会跨行**，
于是**不需要任何跨行跳线**。

### 4.3 结论

全部布线为同层 M1 水平段：同行各段的 x 区间互不重叠（每段恰好连接相邻
器件的 body 边缘），异行 y 不同。

> **同层短路数 = 0 由几何保证，而不是靠 LVS 兜底。**
> LVS 在这里的角色是**验证**几何结论，不是**发现**短路后返工。

实测：97,920 条布线中，非水平段 **0 条**（smoke 逐条断言）。

## 六、与链式规模锚的分工

| | 链式规模锚（S11） | CPO 阵列样例（本文） |
|---|---|---|
| 回答的问题 | 能跑多**大** | 跑的**真实度**如何 |
| 器件构成 | 单一 Waveguide | 4 类器件、13 种角色 |
| 参数来源 | 常数 | 物理反解（谐振 / 布拉格条件） |
| 拓扑 | 一条长链 | 2,176 条独立并行光路 |
| 布线 | M1 + 跨行 M2 跳线（多层语义） | M1 纯水平（零跳线，几何无短路） |
| 规模 | 128k 默认 / 256k 纵深 | 100k 实测 |

两者互补：S11 守护**多层 + 极限规模**，CPO 样例守护**真实器件构成 +
参数物理自洽**。CPO 样例未使用多层 —— 不为了"用上多层"而引入几何风险，
多层能力由 S11 独立验证。

## 七、诚实边界（不可省略）

- **只建模无源光子层**。有源器件（激光器 / 探测器 / 驱动 IC / TIA）按
  **黑箱**处理（LDA 负面清单：有源器件不做物理级建模）。探测器馈线以
  `Waveguide` 表达并标记 `external_io`，不代表真实探测器几何。
- 工艺为**公开文献近似**（SOI 220 nm 典型规则），非真实 foundry PDK。
- 本样例只做**版图闭环**（构建→放置→布线→GDS→DRC→LVS），
  **未做光学仿真验证**——插损、串扰、FSR、调制效率属另一条链路。
- **未流片，无实测回流**。
- 布线是**规则阵列（regular fabric）**策略：真实 CPO/PIC 阵列化版图确实
  用预留通道 + 规则拓扑，但它不是拥塞感知的全局布线器。
