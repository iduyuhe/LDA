## 1. 为什么是"复利"而不是"堆功能"

量子芯片设计的难点不在单点公式，而在**层与层之间的接口**：纠错的物理错误率来自处理器的门保真度，处理器的保真度来自测控脉冲与读出链，测控的稳定性来自低温电子学，而长程量子通信又依赖上述所有指标。

**复利结构**（下层锚是上层锚的输入）：

```
Layer 0  QS-M*   器件几何/相位/协同度（24 锚）
   │  提供 g, κ, γ, Q, V_eff
   ▼
Layer 1  J1      QEC：阈值标度 / 解码器 / 综合征 / 容错门（9 锚）
   │  提供 p_th, p_L(d)
   ▼
Layer 2  J2      Transmon 处理器：CR 门 / ZZ / 多音串扰 / 耦合图（4 锚）
   │  提供 ε_gate, λ₂
   ▼
Layer 3  J3      测控与读出：Rabi / DRAG / 纯度 / Purcell / 噪声链（5 锚）
   │  提供 P₁(t), n_add
   ▼
Layer 4  J4      传感系统：多参数解耦 / 旁瓣 / 串扰 / 热负载（2 锚）
   │  提供 τ̂, Q_thermal
   ▼
Layer 5  J5      量子网络：分发保真 / HOM / 中继 / 换能（4 锚）
```

**复利的证据**：J5 的换能效率锚（B522）直接复用 QS-M3c 的协同度闭式（`C_g/C_qv = 2n·γ₁/γ_rad`，比值 **8983.807**），这条跨档复用关系已被 K3 的机器表登记并加锁 —— **上游改一个常量，下游会闹钟响**。

## 2. 六层逐层交代

### Layer 0 · QS-M* 器件与相位（**24 锚** · B473–B496）

超导/自旋器件的几何-相位-协同度基座：NV 磁力计灵敏度谱密度、磁偶极近场串扰、梯度计共模抑制、腔 QED 协同度与两口径结算、柱高一致性、最优刻蚀深度等。

**关键金级**：`B494`（协同度两口径断口结算，闭式残差 ~6e-16）、`B487`（绝对阈尺度盲的判据教训，已成全项目通则）。

### Layer 1 · 量子纠错 J1（**9 锚** · B497–B505）

| 锚 | 物理量 | 核心方法 |
|---|---|---|
| B497 | 表面码逻辑错误阈值距离 d\* | 闭式反解 golden ⇄ 数值扫参 |
| B498 | 解码器综合征概率场总权重 | 闭式 erf golden ⇄ MWPM |
| B499 | 匹配代价二阶矩 | 闭式 L²/3 ⇄ Union-Find |
| B500 | 旗比特钩错检测概率 | erfc 闭式 ⇄ 枚举 |
| B501 | 相邻稳定子综合征关联 | 双重积分闭式 ⇄ 数值 |
| B502 | transversal CNOT 保真预算链 | exp(−∫率) 闭式 ⇄ 分步积分 |
| B503 | lattice surgery 合并保真 | exp(−c·p·∫(2x²−1)dx) |
| B504 | 端到端累计逻辑失效 | 1−exp(−∫率) |

**门禁**：`run_j1_qec_smoke` **19 判据**（含 **MWPM ↔ 自主 Union-Find 位级对拍**）· `run_webui_j1_render_path_smoke` **21 判据**。

### Layer 2 · 超导 Transmon 处理器 J2（**4 锚** · B506–B509）

两比特 CR 门退相干错误率、残余 ZZ 诱导门错误、FDM 多音读出相邻通道串扰比、QPU 耦合图代数连通度（Fiedler 值 λ₂）。
**门禁**：`run_j2_qpu_smoke` **37 判据**。

### Layer 3 · 量子测控与读出 J3（**5 锚** · B510–B514）

广义 Rabi 时域布居、三能级驱动泄漏、去极化信道纯度衰减、Purcell 抑制比、分布式放大链附加噪声。
**门禁**：`run_j3_ctrl_smoke` **44 判据**。

### Layer 4 · 量子传感系统 J4（**2 锚** · B515 / B518）

多参数 NV 传感交叉灵敏度解耦（Cramér 闭式 ⇄ 最小二乘）、低温布线束热负载（Wiedemann–Franz）。

**门禁**：`run_j4_multiparam_smoke` **25 判据**。

## 3. 工程纪律：这套东西为什么可信

### 3.1 三档主权分层

| 档 | 含义 | 数量（全项目） |
|---|---|---|
| **A** 自主 | 纯 numpy/scipy 自研，永不借 | — |
| **B** 借用 | 借今踢后，只回标量 | 516 严格独立 |
| **C** 降级 | 有序数降级 | 3 |

**红线**：不借 GPL / Meep / Tidy3D；**LLM 不进判决路径**；不报 TOPS / fJ-op / 能效。

### 3.2 golden 的四种合法来源

1. **科学闭式** → golden ✅（本白皮书 48 锚全属此类）
2. **实测事实** → golden ✅
3. **第三方仿真值** → **⛔ 非 golden**（只可作对照，不可作判决）
4. **标准/规范** → 规格锚 ✅

### 3.3 判据机器化的四个层次（本战役 K0–K4 的成果）

| 档 | 成果 | 关键机制 |
|---|---|---|
| **K0** | 未结项台账（8 条） | 生成器 + 28→**29** 判据门禁 · 快照≡现算 |
| **K1** | 协同度两口径**结算** | 闭式 `C_g/C_qv = 2n·γ₁/γ_rad` = 8983.807 · 主账 + **并报** |
| **K2** | B516/B517 终态 + J1 面板 | **真 grep 同源体检** ⇒ `reserved_null`（不硬凑） |
| **K3** | 跨档复用常量表 | 47 站点 / 20 跨档 · const 存值 + function 存签名 |
| **K4** | 门禁×锚覆盖矩阵 | L1 538 / L2 123 / L3 65 / **盲区 415 如实登记** · 棘轮只升不降 |

### 3.4 一条贯穿始终的通则

> **关闭一个缺口，既要查「旧判据是否被打反」，也要查「有没有判据在看守该缺口」。**

本战役 4 次实践：K1 翻转 E2 · K2 翻转 B7/E4 · K3 翻转 E5 · **K4 发现 G-K-6 从未有判据**（更隐蔽）。

## 5. 诚实边界（必读）

1. **设计期签核，非流片实测**：全部锚为闭式物理律与数值解的一致性签核，**不含任何硅/超导工艺实测数据**。
2. **参数为设计示例量级**：器件参数取典型设计值（如 n_r=3.4、Q、V_eff），**非某一具体 PDK 的认证值**。
3. **规模数字是"版图容量"**：涉及比特数/通道数的表述均指设计可承载规模，**不是已制造规模**。
4. **不报性能宣称**：不做 TOPS / fJ-op / 能效比 / 良率承诺。
5. **盲区如实存在**：量子赛道 48 锚 **100% 有专属门禁**，但全账本 538 锚中仍有 **415 锚**仅有统一判决（K4 已机器登记，不粉饰）。
6. **不替代代工厂签核**：本白皮书不构成任何工艺设计规则（DRC/LVS）的替代，亦不构成流片放行依据。
