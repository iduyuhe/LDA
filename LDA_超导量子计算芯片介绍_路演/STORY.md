# STORY.md · LDA 超导量子计算芯片介绍（对外路演）

## ① 用户意图对齐

- **目标受众**：对外宣传与合作场景——产业伙伴、投资机构、技术评估方（含潜在客户与生态合作方）；场次为路演 / 合作洽谈 / 技术尽调前置沟通。
- **核心目标**：讲完后让受众相信三件事——**① 这是「设计工具链的能力证明」，不是又一颗量子芯片**；**② 能力是可验证的（真 GDS + 机器可判门禁 + 可复现）**；**③ 它有清晰边界（设计期签核，非流片实测），值得在明确边界内合作**。希望受众记住「同一条链路，换一种物理，还站得住」，并采取行动：访问 UI 案例卡 / 申请技术评审。
- **PPT 长度**：13 页（3 章），Hero 页配额 3 页（P01 封面 / P11 版图 / P13 结语）。
- **视觉调性**：权威克制 · 数据驱动 · 工程实证 · 零夸张 · 左对齐纪律（商务咨询风）。
- **内容边界**：
  - **必讲**：S1–S5 五段征程与 200 条门禁判据；四大技术结果（双验证 / 规模自洽 / 频率避撞 / 拓扑统一）；先进性定位（不同台比较）；UI 获取路径；诚实边界。
  - **不讲**：不宣称量子优势、不宣称门保真度/相干时间优越、不宣称「已制备 1024 比特芯片」。
  - **禁碰**：金色 / 正红 / 紫粉黄、衬线字、3D、雷达图、把「版图容量」写成都市传说式的「比特数领先」。
