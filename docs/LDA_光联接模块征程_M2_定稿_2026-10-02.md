# LDA 光联接模块征程 · M2（1.6T）设计定稿

> D-200 · 2026-10-02 · 上游 M1（v0.9.177 · HEAD `ddab16b`）· 定位：吃狗粮第三段
> （M0 定「能设计」→ M1 定「带宽/色散预算」→ **M2 定「规模 × 形态 × 物理落地」**）

---

## 0. 一句话结论

M0 跑通 2 通道链路预算、M1 把整套推进到 8×100G PAM4 800G 并补上**频域 + 时域**两维；
**M2 把规模翻到 8×200G PAM4 1.6T**，同时补上另外两个此前完全空白的维度：

- **形态维**：**LPO（Linear Pluggable Optics）—— 模块内无 DSP** ⇒ 不是免责声明，而是**设计约束**
  （丢失级联 FEC 的模块内内码 ⇒ pre-FEC 门限收紧、所需 SNR 上升 **2.744 dB**）；
- **物理落地维**：**G-OI2 该收发器拓扑专用真 GDS builder** ⇒ 从「链路预算图纸」变成
  「可签核的真实版图」（单 LinkModel + 单次主权 DRC/LVS + 确定性 GDS 字节）。

诚实边界（沿用 M0/M1/M5 纪律）：一切仍为 **`DESIGN_BUDGET`** 级（闭式 + 行为 + 几何近似），
**非实测、非流片、不报 fabricated 能效 / TOPS / pJ/bit**。

---

## 1. 里程碑定义

- **M2 = 1.6T**：**8 通道 LWDM**，每通道 **200G = 106.25 GBd PAM4**
  （线速率 **212.5 Gb/s**，FEC 后净 **200 Gb/s**；8 通道聚合净 **1.6 Tb/s**）。
- 与 M1 的**物理差异**（这是「性能升级」而非「规模升级」的真含义）：
  | 量 | M1（100G/lane） | M2（200G/lane） | 后果 |
  |---|---|---|---|
  | 符号率 | 53.125 GBd | **106.25 GBd** | 奈奎斯特 **26.56 → 53.13 GHz** |
  | EO 带宽压力 | f_3dB(EO)=32.94 GHz **>** Nyquist ⇒ 带宽富余 6.38 GHz | 需 f_3dB(EO) **≥ 53.13 GHz** | 旧调制器/TIA 参数**不再够用** ⇒ 真「吃狗粮」 |
  | FEC 门限 | KP4 RS-only 2.4e-4 | **级联 4.8e-3** / RS-only 2.4e-4 | 见 §5 规格锚 |
  | 色散（同跨度） | σ ∝ 数据率 | 代价随速率上升 | O-band 主设计点的动因 |
- 层次推进：M0 = 功率预算；M1 = 频域 + 时域；**M2 = 规模（速率）× 形态（LPO 无 DSP）× 物理落地（真 GDS）**。

| 缺口 | M1 现状 | M2 闭合手段 | 层 / 红线 |

## 3. 红线影响评估 + 本轮定调

**合法（A 档闭式 / 行为级，不破红线）**：
- 106.25 GBd PAM4 眼/Q/BER：**光通道预算级**闭式（golden = 闭式 Q 函数 `0.375·erfc(Q/√2)`）
  —— 与 M1 同层，与 `eic_behavioral.EIC_DISCLOSURE`（排除 **EIC 电路级** BER）**显式分层**。
- LPO 无 DSP 口径：**强化**诚实边界，不新增越界（把「不含 DSP」从免责声明变成设计约束）。
- TIA 噪声闭式（热 / 散粒）：A 档闭式；**不碰**「电-光耦合增益当功能真值」（T2 锁）。
- 真 GDS 版图：**设计期签核**（D4 同口径），**非流片**；层规为公开工艺近似，非 Foundry PDK 标定值。

**本轮定调（用户 2026-10-02 裁定 · 4 项）**：

| # | 议题 | 裁定 | 含义 |
|---|---|---|---|
| 1 | 1.6T 的 per-lane 拆法 | **8×200G PAM4**（106.25 GBd） | 与国际 802.3dj/OIF 1.6T 主流一致；对齐既有对标锚 `GC-CPO-OIO-8CH`（8×200G=1.6T）同族 |
| 2 | M2「吃狗粮」范围 | **核心四件** | 1.6T 规模 + LPO 形态 + G-OI2 真 GDS + TIA/驱动 co-sim 深化；**热调/串扰/良率/封装容差 与 多通道均衡 后置为 M2b**（不在本轮判据内） |
| 3 | LPO / 可插拔形态深度 | **无 DSP 线性口径** | LPO = 模块内无 DSP/重定时；链路预算须在**无均衡**下闭合 |
| 4 | G-OI2 真 GDS builder 范围 | **完整收发器** | Tx + Rx 双侧全建，单 LinkModel + 单次主权 DRC/LVS，接 D4 交付域 |

> 定调 1 的实现默认：主设计点取 **1.6T-FR8 同族（8×200G PAM4 LWDM，O-band 1311 nm 起，2 km）**，
> 对照点取 **C-band 2 km**（复现 M1 已得结论「长距应改 O-band」，并把色散差异量化）。
> 🔴 波长栅为**设计近似**（800 GHz 间隔），**非**标准 LAN-WDM 栅；对齐的是**架构族**
> （8×200G PAM4 单模 2 km），不宣称栅位符合某具体 MS​A 规范。

## 5. Golden 闭式锚（门禁用 · 物理律）与 **规格锚**（外部标准逐条核对）

### 5.1 闭式物理律（golden）
1. 一阶低通 `|H(f_3dB)| = 1/√2`（复用 M1）。
2. 色散展宽闭式 `σ₁² = σ₀² + (β₂L)²/(4σ₀²)`（复用 M1，时域 ⟷ 闭式对拍）。
3. PAM4 眼电平：3 眼、等间距、满幅/3（复用 M1）。
4. `BER = 0.375·erfc(Q/√2)`（PAM4 Gray 闭式）⟷ MC 计数（复用 M1）。
5. **TIA 输入参考噪声闭式**：`i_n² = 4kT/R_f + 2qI_ph`（热 + 散粒）→
   `SNR = I_sig²/(i_n²·BW)`。与 M1 的「SNR 假设」**并存对照**（方法学独立）。
6. 无源无增益 B19（`|T| ≤ 1`，延续）。
7. GDS 确定性：同参数 ⇒ 同 sha256；异参数 ⇒ 异 sha256（D4 同口径）。

### 5.2 🔴 规格锚（外部对标四层 · 第 ④ 层「标准 = 限值」逐条核对）

> **来源四源独立一致**：Signal Integrity Journal《200 Gbps Ethernet FEC Analysis》（DesignCon 2024
> 最佳论文，ADI）· Netnod《To Infinity and Beyond!》（802.3df/3dj 提案）· Vitex《1.6T Optical
> Transceivers 2026 技术指南》· Ethernet Alliance（IEEE P802.3dj 主席 John D'Ambrosio 撰文）。

| # | 常量 | 取值 | 门禁锚（Plausible 窗口） | 含义 |
|---|---|---|---|---|
| A1 | 200G/lane 符号率 | **106.25 GBd** | ∈ [106.0, 106.5] GBd | DR8/2×DR4 变体；DR8+ 为 113.4375 GBd（不取） |
| A2 | RS-only pre-FEC BER 门限 | **2.4e-4** | ∈ [2.0e-4, 2.8e-4] | 外码 KP4 `RS(544,514)` 单独能力（= M1 同值） |
| A3 | 级联 pre-FEC BER 门限 | **4.8e-3**（4.85e-3） | ∈ [4.5e-3, 5.2e-3] | KP4 ⊗ 内码 **Hamming/BCH(128,120)** + 卷积交织 |
| A4 | 由 A2/A3 推导的 SNR 差 | **2.744 dB** | ∈ [2.4, 3.1] dB | = 内码增益；**LPO（无模块 DSP）丢失量** |
| A5 | 1.6T 聚合 | 8 × 200G | == 1.6 Tb/s（净） | 架构族对齐（非 LDA 成就） |

🔴 **纪律（M1 血案 v0.9.177 的延续）**：A1–A5 **每一条**都要有①「落公开合理窗口」的规格锚判据、
②配**改回错值必红**的探针（P7）；A4 还要与门禁独立算的闭式 Q 差**逐位对拍**。
**绝不**把 100G/lane 的 `2.4e-4` 直接当 200G/lane 的门限（那正是 M1 曾犯的「口径差 100×」同类错误）。

## 6. 突变探针（**先证能变红**）

| 探针 | 突变 | 应红判据 |
|---|---|---|
| P1 | 抹平 EO S21（去滚降） | 带宽 / 眼门禁 |
| P2 | 去色散（`D = 0`） | 色散代价门禁（C-band 变体） |
| P3 | 倍增接收噪声 | BER / 眼门禁 |
| P4 | 打乱 PAM4 电平间距 | 眼 / 电平门禁 |
| P5 | 撤 CORE 登记 | 覆盖门禁 |
| P6 | `TARGET_BER_KP4` 改回错值 2.4e-2 | C13 规格锚（M1 遗留探针，保留） |
| **P7（新）** | **200G/lane FEC 门限改错**（级联 4.8e-3 → 1e-4） | **A3 规格锚必红** |
| **P8（新 · G-OI2）** | **收发器拓扑退化**（拿酉网格顶替收发器 / 去掉探测器阵列） | **LVS / 网表一致性必红** |
| **P9（新 · LPO）** | **给链路注入「DSP 增益」**（假装有均衡/内码） | **LPO 无 DSP 口径门禁必红** |
