| J1–J5 六层 | v0.9.230 → 242 | 13 | 24 | **1.85** | J2-M0/M1、J4-M2/M3、J5-M4 净增 0 |
| 蓝图 v2（D1/D2/D3） | v0.9.259/260/261/265/266/267 | 6 | **3** | **0.50** | D1-M1/M2、D2-M1 净增 0；**D3 整域判死** |

**边际锚产出 2.00 → 0.50，跌 4 倍**，且最近 6 版里 3 版净增 0 + 1 域被判死。这不是"最近运气差"，是**结构性枯竭**：量子域已把"物理层闭式量"扫完，剩下的三类都不可锚——

> **零净增版本计数口径**（可复现）：CHANGELOG 标题级含「净增 0 锚 / 零净增」且属量子域的版本 = **9 个**（v0.9.220 / 225 / 230 / 234 / 242 / 243 / 245 / 250 / 261）；另 v0.9.266（D2-M1「净增 **0** 锚」）与 v0.9.267（D3「零锚」）措辞不同、实为同类 ⇒ **合计 11 个整版零净增**。

| 剩余类别 | 为什么不可锚 | 实例 |
|---|---|---|
| 精确组合量 | 与任何闭式比对都是代数恒等（resid ≡ 0） | 码族参数 `8·n_color−3·n_toric ≡ 2` |
| 阈值 / MC 标定量 | 无闭式 golden，只有拟合曲线 | 阈值 p\*、简并度、伪阈值 |
| 算法 / 编译层 | 无物理闭式，golden 来源不合法 | 编译后总保真（两条实现只差 3–53 ulp） |

**战略含义**：D3 短评估那句「**物理律闭式锚的射程 = 物理层；越往编译/算法/调度层走，可锚量趋近 0**」，现在被三次独立复现（D2-M1、D3、CF-M0）证明是**域级定律，不是个案**。

### 6.2 投入产出：量子域强在"判别力"，弱在"签核力"

| 维度 | 评级 | 依据 |
|---|---|---|
| 锚密度 | **高** | 56/541 锚、80% 的 L3 多重覆盖、0 盲区 |
| 判据密度 | **高** | 1,438 判据点 / 58 门禁 / 24 探针 |
| 代码密度 | 中 | 24,134 行支撑 56 锚 ⇒ **431 行/锚** |
| **可签核性** | **低** | 无 deck、无实测、无 EM 反提 ⇒ 判决只能是 `DESIGN_SIGNOFF` / `DESIGN_BUDGET`，**不能当流片放行依据** |
| 对外可讲性 | 中高 | 11 面板 + 12 端点可演示"设计能力"，但**每个数字都必须带"设计期"限定** |

### 6.3 两条量子路线：已收敛到"框架统一、物理分裂"

- **已统一**：D-145 把方阵与 heavy-hex 收进 `sc_topology_core`（度上限由拓扑自声明），DRC/LVS/物理走同一引擎。
- **仍分裂**：光量子（DV 被动 LOQC / Fock + permanent）与超导（CV 微波 / transmon + CR）**器件模型、观测量、损耗口径完全不通用**；共用的是"几何可制造性"层，不是"物理正确性"层。
- **判断**：**不需要强行统一器件层**（物理本就不同），但**应统一"签核报告 schema"**（verdict / disclosure / 容量口径），否则对外叙事会出现两套口径。

### 6.4 三条建议（分层，可直接排期）

**A 级（战略级 · 决定"能不能签核"）**

1. **补 deck 接口，不补 deck 数据**：把光子侧 `FoundryDeck` schema 接到量子 DRC/LVS（`run_quantum_drc` 增加 `deck` 可选参数），**净增 0 锚**，但让"自建规则"与"工艺厂规则"在同一接口下可切换。这一步不需要 NDA。
2. **补"版图→参数反提"的最小闭环**：超导侧至少做 **CPW 传输线准静态场解**（保角映射/矩量法，纯 numpy），把 `sc_layout` 的几何反提成 L/C ⇒ **版图与 T1/f01 之间第一次有双向校验**。净增 0–1 锚。
3. **编译层降级立项**：不做"锚域"，做**能力层 + 硬判据**（逻辑→物理映射的**合法性断言**：门集闭包、拓扑邻接、测量轮次计数恒等式）。判据可以是整数恒等式，不必是浮点 golden。

**B 级（平台级）**

4. **修 F-1**：给 `schip_case` 建专属门禁（照 `run_qchip_case_smoke` 体例），把 12 条自检接进 CI core（+1 门禁）。
5. **统一判据数口径（F-5）**：58 道门禁全部以末行 `N/N PASS` 声明判据数，注释与声明对拍。

**C 级（对外级）**

6. **停止加锚的量子新域**（理由见 §6.1/§6.5），把预算转到 1–3 项；对外物料统一口径："**设计期签核 · 版图容量 · 判别力**"，不写流片、不写量子优势。

### 6.5 明确"不该做什么"（防返工）

| 不该做 | 理由 |
|---|---|
| 再开一个"量子新域"去凑锚 | 边际 **0.50 锚/版**，且 D1 已证明"跨域缺口多半被既有锚占满"（全作用域复核：光子侧 776 命中、3/4 缺口被占） |
| 把 LDPC / 色码解码当锚域 | 迭代求解器无闭式 golden；红线禁第三方 QEC SDK |
| 把时间复用当"通用又省损" | 参数计数硬约束：通用 D ≥ N，损耗必然更贵（D-121/D-122/D-123 三次复现） |
| 用"酉保真度"做规模验收 | 实测 F 对 N 几乎不变（σ/2 极限）⇒ 会漏掉全部真墙（损耗墙/签核墙/基准墙） |
| 宣称"已达国际水平" | 无实测、无 deck；与 IBM/Xanadu 只可"不同台比规模" |

## 7. 对外口径与红线（沿用，不动摇）

1. **设计期签核，非流片实测**；规模数字一律标「**版图容量**」（≠ 已制备器件数）。
2. **不宣称量子优势**、不做跨厂商数值同台比较、不报 TOPS/fJ-op/能效。
