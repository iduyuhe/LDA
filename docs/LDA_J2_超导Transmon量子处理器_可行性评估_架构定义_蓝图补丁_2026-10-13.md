## 0. 立项依据

用户 2026-10-13 明确「J2 Transmon 征程立项（蓝图 v1 的 J1→J2 复利闭环）」，即确认 J2 为量子赛道第二征程（物理比特层 · L2）。

J1（QEC）已于 v0.9.228（M0+M1）+ v0.9.229（M2+M3+M4）全档收官：B497–B505、自主 Union-Find 解码器、`run_j1_qec_smoke` 19 判据、G_Q9 闭环。J1 用**理想去极化噪声**起步，其逻辑错误率曲线是"裸标度界"——**缺少真实物理层标定**。

J2 意图：把 L0/L1 本金里已有的**超导 transmon 物理（transmon_solver / cross_resonance / qubit_resonator_solver / IR B9·B12·B13）+ S1–S5 芯片设计分支（D-133…D-145，真 GDS · N=1024）**&#x4ECE;「点式地基」升级为一条**可吃狗粮的 Transmon QPU 征程**——物理比特层（L2），闭环缺口 **G-QPU***，并**与 J1 做复利闭环**（J2 真实物理错误率 ⇄ J1 逻辑错误预算）。

🔴 **与既有 S1–S5 芯片分支的关系（必须先对齐）**：S1–S5 已把 transmon 芯片**版图/DRC/LVS/路由/频率避撞/可调耦合/读出 mux/控制/封装损耗**做成真 GDS 闭环（200 判据 · 18 突变探针）。J2 **不复刻芯片布局**，而是在 S-branch 之上新&#x589E;**「物理错误率模型 + QPU 误差预算 + 拓扑↔QEC 对接」**&#x8FD9;一层，使其与 J1 形成可验证的复利闭环。两条线共用同一组红线与同一套死标量验收。

### 1.3 红线 / 主权可行性（LDA 铁律逐条对账）

- **主权求解器（C 级纯 numpy/scipy，不借 GPL/Meep/Tidy3D/QuTiP）**：Lindblad 主方程 ODE-RK4 已在 **B446–B452** 占道（可复用）；色散读出严格对角化已 D-88；误差预算闭式（退相干极限）已有数学基础。门错误率数值候选可纯 numpy 实现。✅ 可行。
- **LLM 不进判决路径**：全部死标量比对（f01 对易、门保真、读出 SNR、拓扑度、逻辑/物理错误率标度）。✅ 可行。
- **绝对 tol 按量级标定（B487 血案）**：错误率 ~~1e-2~~1e-3、频率 ~1e0 GHz、保真度 ~1e-3、SNR ~1e0——**四类判据必须分别按各自量级定 tol，且用「绝对 ∨ 相对」并列**（不可用 `max(绝对,相对)`，否则尺度盲）。✅ 已立项为锚纪律。
- **golden 分级（③仿真值⛔永不作 golden）**：门/读出仿真与蒙特卡洛是③，只作证据/标度关系，不作 golden；golden 锁定为①闭式物理律（退相干极限、Koch、Blais、χ=g²α/(Δ(Δ+α))）与②已知事实（QEC 阈值≈1%、ZZ 极点 Δ=−α）。✅ 口径已对齐。
- **复用 S-branch 铁律**：涉频率检查须用限带默认 f01∈[5.0,6.2] GHz（铁律①）；可调耦合器工作区须 `f_coupler` 全程低于 `f_qubit` 且留失谐余量（铁律②）；heavy-hex 用两子格几何、拓扑度上限由拓扑自声明（铁律③）。J2 新增门禁**复用**这些守护，不重造。✅ 可行。

## 3. 蓝图补丁（里程碑 · 复利吃狗粮）

> 每档用 LDA 亲手设计一枚真实 transmon 单元/阵列补丁，物理链逐量「闭式 ⇄ 方法学独立候选」。

### M0 物理错误模型 + J1 闭环校准（核心复利闭环）

- 建造：transmon 物理参数 → 每门/每比特错误率映射；把 J2 真实物理层注入 J1 `qec_noise` → 重跑 `logical_error_rate` → 校准 J1 逻辑错误曲线（从「理想」变「物理标定」）。

## 4. 复利账（复用 → 建造 → 沉淀）

- **向后复用**：`transmon_solver`(D-35) · `cross_resonance`(D-74) · `qubit_resonator_solver`(D-88) · IR `B9/B12/B13` · **S1–S5 芯片分支**(D-133…D-145) · QS-M6/M7 Josephson · **J1 QEC**(`surface_code`/`decoder`/`qec_noise`/`logical_error_rate`) · E 模拟读出。
- **向前沉淀**：物理错误率模型 + QPU 误差预算 + 拓扑-QEC 桥 ⇒ **回喂 J1 真实物理层**（J1↔J2 复利闭环）· 喂 **J3 测控**（门保真/读出驱动脉冲设计）· 喂 J4/J5。
- **J1↔J2 复利闭环机制（用户强调的核心）**：
  1. **J2 → J1（物理标定）**：J1 用理想去极化噪声起步；J2 提供真实物理错误率（每门/每比特）→ 注入 J1 `qec_noise` → 重跑 `logical_error_rate` → J1 逻辑错误曲线从「裸标度界」变为「物理标定曲线」。
  2. **J1 → J2（设计硬指标）**：J1 阈值定理 p_th≈1% + 解码器给出「逻辑错误率随物理错误率下降」的预算 ⇒ 成为 J2 比特/门设计的**保真度硬指标**；J2 设计参数须使门错误率落于阈值下**两数量级**（才触发子阈值指数抑制）。
  3. **设计⇄验证反馈环**：J2 参数（E_J/E_C/耦合/布局）→ 物理错误率 → J1 逻辑预算检查 → 未达则 J2 收紧参数，循环至闭环。

## 5. 红线合规声明

- 主权求解器：误差模型/Lindblad/门保真/读出全部纯 numpy/scipy，不借 QuTiP/外部图算法。
- LLM 不进判决路径：全部死标量。
- 绝对 tol 按量级标定（跨量级四档：错误率/频率/保真度/SNR）+ 绝对∨相对并列 + 突变探针「先证能变红」。
- golden 分级：①闭式物理律 + ②已知事实(阈值≈1% / ZZ 极点 Δ=−α) 作 golden；③数值仿真/蒙特卡洛只作证据/标度关系，不作 golden。
- 复用 S-branch 三条铁律（频率限带 / 耦合器工作区 / 两子格几何）作门禁守护，不重造。

- **B514（QPU 总错误率 ≤ 阈值余量）⇒ 完全占用**：①「总错误率预算」= ∏/Σ **算术级联** ⇒ 与既有 **S4**（`part1.py` ∏fᵢ 乘法级联保真预算 `s4_fidelity_budget`）同源；②若走「∫率 dt ⇒ 累计错误」数值路线 ⇒ 与 J1 锚 **B502/B503**（`F=exp(−∫率)`）+ **B504/B505**（`1−exp(−∫率)` / `∫(1−e^{−kx})dx`）同原子族 ⇒ 否。

### 10.2 取代靶 = B509（QPU 耦合图代数连通度 λ₂ · Fiedler 值）

- golden = 方阵耦合图（= Cartesian 积 `P_rows □ P_cols`）Laplacian `L=D−A` 次小本征值闭式 `λ₂=2−2·cos(π/max(rows,cols))`（**Kronecker 和谱定理，精确解析解、非截断近似**；与稠密 `eigvalsh` 差 ≤ 3.84e-15）。
- candidate = **嵌套 Krylov 子空间 Rayleigh–Ritz 最小值**（`K_m=span{v₀,Lv₀,…,L^{m−1}v₀}`，`v₀⊂1⊥`，**全重正交**；min-max ⇒ 单调非增上界）。
- 与 **B10/B506/B507**（门错误率 ⇄ Lindblad/矩阵 RK4）在被测标量 / 物理构型 / 数值格式**三者均异** ⇒ 计新锚（承 B452↔B33 先例）；实 grep 核验 `fiedler|algebraic_connect|laplacian|krylov|eigsh|谱隙|...` 在**锚定义**内零占用。
- 默认档（方阵 10×10, N=100）golden=**9.788696740969e-02**；残差链 m=4→**4.626e-01** → 8→**9.999e-02** → 16→**1.082e-02** → **32→1.122e-10**；比值 **4.63/9.25/9.64e7×**；余量 **891.4×**（tol 1e-7）。
- 🔴 **退化防护**：Krylov 维 **m=32 ≪ N=100**（m→N 时重正交残差把常数向量泄漏 ⇒ 最小 Ritz 滑向 λ₁=0；首轮探针 m=N 残差 → −3.82e-01 已实证）；数值核对 `m>N` 显式抛 ValueError。
