# LDA 电子计算征程 · E13 设计定稿：2D 漂移扩散输运（补 I–V / 亚阈值摆幅）

**日期**：2026-10-01 · **段位**：E13（D-170…D-172）· **上游**：E12（2D MOS 静电求解器，D-166…D-168）

---

## 1. 为什么做（上游缺口）

E12 交付了 **2D MOS 自洽泊松**（四端栅/源/漏/衬底 + 分段 BC + 电子准费米势分裂），
短沟道 roll-off / DIBL 已由 2D 数值解自然涌现。但 E12 的诚实边界（G-K）明确登记：

> **本段是准平衡静电求解、不含漂移扩散输运 ⇒ 不产 I-V**；V_th 用「界面最低表面势达 +φ_F」
> 判据（**非恒定电流法**——那需要 I-V）。

`device_2d.short_channel_capability_report()` 的 `still_not_available` 第一条即
**I–V 特性 / 亚阈值摆幅（从电流）⇒ E13 候选**。

**E13 就是把这一格补上**：解稳态漂移扩散 ⇒ 产出 `I_d(V_g, V_d)` 曲线、
**亚阈值摆幅 SS**、`I_on/I_off`、**恒定电流法 V_th**。

## 2. 接缝勘查结论（两侧各有一半，E13 = 焊接）

| | `lda_solver/drift_diffusion_2d.py`（现有） | `lda_solver/mos_2d.py`（E12） |
|---|---|---|
| **有** | **输运全套**：`_bernoulli`（SG 核心）· `_solve_continuity_sg`（稳态连续性）· `_solve_poisson_drift_diffusion`（非线性泊松）· `_terminal_current_sg`（终端电流）· Gummel 主循环 | **MOS 几何全套**：幂律非均匀网格 · 变系数 FV 泊松 · **分段四端 BC** · 电子准费米势分裂 · 接触优先序 |
| **没有** | MOS 几何（均匀网格 + 矩形 p-n 结 + **两端欧姆标量 BC** + y 诺伊曼） | 输运（`majority` 截断 / `boltzmann` 仅 V_d=0；**无连续性方程 ⇒ 无电流**） |

**三个本质缺口**（E13 必须解决）：

1. **连续性 BC 是两端标量**（`bc_left/bc_right`）⇒ MOS 需要**节点集 mask 式**（源/漏整列 + 衬底整行 + 栅跨度无载流子）。
2. **氧化层内无载流子**：连续性方程必须**只在 Si 节点上解**（氧化层节点逐出未知量集），
   Si↔SiO₂ 界面取**无通量（Neumann）** —— 否则解出伪载流子、电流从栅漏走。
3. **接触准费米势 BC**：接触处钉 `φ_n = φ_p = V_接触`（无限复合中心 ⇒ n·p = n_i²），
   于是 `n_k = n_i·e^{(ψ_k − V_c)/V_T}`、`p_k = n_i·e^{(V_c − ψ_k)/V_T}` —— 这个统一式
   **自动**给出 n⁺ 区 n=N_SD、p 区 p=N_A（因为 ψ_k 由掺杂决定），无需分支。

**关键数值资产（好消息）**：`mos_2d` 的 y 网格在 Si 表面用 **s^1.8 幂律加密**，
首格 ≈ **0.15 nm** ⇒ **反型层（~几 nm）可解析**。这正是 MOS 输运最难的数值点，**已经具备**。

## 4. 物理与数值（定稿）

### 4.1 方程组（稳态漂移扩散，Gummel 解耦）

```
∇·(ε∇ψ) = −q(p − n + N_D − N_A)                  泊松（非线性，φ_n/φ_p 固定）
∇·J_n = 0,  J_n = q·μ_n·n·E + q·D_n·∇n           电子连续性（SG 离散）
∇·J_p = 0,  J_p = q·μ_p·p·E − q·D_p·∇p           空穴连续性（SG 离散）
n = n_i·e^{(ψ−φ_n)/V_T},  p = n_i·e^{(φ_p−ψ)/V_T} 玻尔兹曼（准费米势）
```

Gummel 每轮：`n/p` → 反推 `φ_n/φ_p` → 解泊松 → 用新 `ψ` 解连续性 → 阻尼松弛 → 收敛判据 `max|Δψ|`。

### 4.2 SG（Scharfetter–Gummel）离散（复用既有形式 1）

边 `k→m`（间距 `h`）：`η = ψ/V_T`，
`J_km = (q·μ·V_T/h)·[c_k·B(η_k−η_m) − c_m·B(η_m−η_k)]`，`B(x)=x/(e^x−1)`（Bernoulli）。
无条件稳定（对 `exp(ψ/V_T)` 任意量级），这是克服偏压下简单 FD 系数跨 10^13 致矩阵奇异的关键。

### 4.3 边界条件

| 位置 | 泊松（ψ） | 连续性（n/p） |
|---|---|---|
| 源接触（x=0 整列） | `ψ = ψ_n + V_s` | 钉 `n_k = n_i·e^{(ψ_k−V_s)/V_T}`、`p_k = n_i·e^{(V_s−ψ_k)/V_T}` |
| 漏接触（x=Lx 整列） | `ψ = ψ_n + V_d` | 同上，`V_c = V_d` |
| 衬底（y=Ty 整行） | `ψ = ψ_bulk + V_b` | 同上，`V_c = V_b` |
| 栅（y=0 栅跨度） | `ψ = ψ_bulk + V_g − V_FB` | **无载流子（逐出）** |
| Si↔SiO₂ 界面（栅外同样） | — | **Neumann（无通量）** |
| 侧壁 y 两端非接触段 | Neumann | Neumann |
| 氧化层全部节点 | 变系数 ε（FV 精确） | **不在未知量集内** |

### 4.4 终端电流

`I_d = Σ_j J_n,xx|_(nx−2→nx−1),j · dy + Σ_j J_p,xx|_(…),j · dy`（漏接触前最后一条 Si 内边沿 y 积分）。
`∇·J = 0` ⇒ 全 x 守恒 ⇒ **源端电流 ≡ 漏端电流**（作为自洽判据）。

### 4.5 关键量提取

- **SS**：`SS = dV_g / d(log10 I_d)`，在亚阈值区（`I_d ∈ [I_lo, I_hi]`，取 `1e-12…1e-8 A`）用最小二乘线性拟合；两点法作交叉校验。
- **恒定电流法 V_th**：`I_d = I_REF` 处的 `V_g`，`I_REF = 100 nA × (L_y / L_g)`（**教科书恒流法惯例口径**，非标定）。
- **I_on / I_off**：`V_g = V_dd` / `V_g = 0` 处的 `I_d`（`V_dd = 1.0 V` 公开惯例）。

## 5. golden 判据（方法学 · 为什么算数）

| # | 判据 | 性质 | 理由 |
|---|---|---|---|
| **G1** | **SS ≥ 60 mV/dec**（室温热极限） | 🔴 **物理定律锚** | 玻尔兹曼尾 + `kT/q ln10` 的**硬下限**（扩散机制）。任何数值解低于它 ⇒ **必是数值假象**（伪负电容）⇒ 强反向判据 |
| **G2** | **长沟道 L↑ ⇒ SS → 60 mV/dec 单调** | 渐近极限 | 长沟道静电理想 ⇒ 逼近热极限（与 E12 的 roll-off 收敛**同向**） |
| **G3** | **短沟道 SS > 60 且 L↓ ⇒ SS↑** | 与 E12 交叉 | 与 E12 的 DIBL / roll-off **同物理**（静电控制退化）⇒ 两条独立路径同向 |
| **G4** | **电流守恒** 源端 ≡ 漏端（rel < 1e-3） | 自洽 | `∇·J=0` 的直接推论；不守恒 ⇒ Gummel 未收敛或 BC 装配错 |
| **G5** | **I_d 随 V_d 单调**（低 V_d 线性 → 高 V_d 饱和） | 定性物理 | MOS 输出特性 |
| **G6** | **V_th 双法一致**：恒流法 ⟷ E12 表面势法（同量级） | 交叉验证 | 两个**独立**判据给出同一器件参数 |

🔴 **golden 归属**：G1 是**物理定律**（科学原理层公共品，可作 golden）；
G2/G3 是**渐近/单调趋势**（定性 golden）；G4/G5 是**自洽/定性**；
G6 是**内部交叉**（E12 表面势法 ⟷ E13 恒流法，两法均 `is_oracle=False`，**互不充当 ORACLE**）。
**本段数值输出一律 `is_oracle=False`**（T1 红线）。

## 6. 诚实边界（本段最重要 · 一次性写清）

- 🔴 **仍是漂移扩散（DD）框架** ⇒ **不含**：量子修正（反型层电荷重心 / 体量子化）· 速度饱和 ·
  带间/栅隧穿（GIDL、直接隧穿）· 弹道输运。⇒ 薄氧化层 / 强场下会偏离；**深亚阈值 SS 不受影响**
  （那里电流由玻尔兹曼尾决定），但 **I_on 会偏高、I_off 会偏低**（无隧穿漏电）。
- 🔴 **迁移率为常数**（`μ_n/μ_p` 取文献常数，无场依赖退化 / 无表面散射 / 无库仑散射）
  ⇒ `I_on` 绝对值**不可当器件性能**，只作**相对趋势**与 SS/亚阈值判据。
- **无 LDD / halo / 应变 / 栅重叠**；结构为教科书突变结 + 2 nm tanh 平滑。
- 参数（`N_A / N_SD / t_ox / x_j / V_FB / μ / τ`）为**公开典型量级占位 · 非 PDK**；无实测锚。
- **2D 仿真 = 每单位宽度电流**（A/m），不是绝对安培；`V_dd` / `I_REF` 为公开惯例口径。
- **无温度扫描**（本段固定 300 K）；**无 AC / 瞬态**（只做 DC）。
- 不报 TOPS / TOPS-W / fJ/op；不宣称器件性能。
- **EAR 744.23**：声明仅用于成熟节点 / 非先进用途半导体器件设计仿真。
- 依赖 scipy ⇒ `device_transport.py` 用**函数内惰性导入**（无 scipy 环境仍可 import 包）。
