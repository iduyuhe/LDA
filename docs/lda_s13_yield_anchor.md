# S13 设计良率锚（DFY）· 设计说明与验证证据

> 版本：v0.9.1（2026-08-30）· 模块：`lda/lda_harness/yield_anchor.py`
> 定位：LDA 第 47 道锚（S13），把「分布统计」升级为「容差内概率」——对标商业 EDA 的 yield / DFM 分析能力
> 红线：判决为死标量比对，LLM 不进判决路径

---

## 一、它回答什么问题

商业 EDA 卖 yield 分析，本质是回答一句话：

> **「这个设计，在给定的工艺容差下，有多大比例能命中规格？」**

LDA 原有的 S7/S8 统计锚只能给出「分布均值 / 最坏下界」——能说"典型值多少""最坏多少"，但说不出**"多少比例合格"**。而后者才是产品决策语言：97% 和 99.5% 对量产是天壤之别。

S13 补上的正是这个标量。

---

## 二、物理模型

**载体：环形谐振器 FSR**（复用 B4 已验证定律，**零新物理**）

```
FSR = λ² / (n_g · L)
```

- `L`（环周长）服从高斯工艺分布：`L ~ N(L0, σ_rel · L0)`，σ_rel 为光刻 CD 容差
- 规格窗口（双侧）：`FSR ∈ [FSR_nom·(1−δ), FSR_nom·(1+δ)]`
- 良率定义：`Y = P(FSR 命中窗口)`

默认参数（公开文献典型量级）：λ=1550nm、n_g=4.2、FSR_nom=17.5nm → **L0 = 32.69 µm**，δ=2%、σ_rel=1%。

---

## 三、为什么这是「非 AI ground」：双算法互证

S13 的判决不是"用一种方法算出来就信"，而是**同一物理定律的两种独立算法互相对账**：

| | 算法 | 性质 |
|---|---|---|
| ① | **解析解**：FSR = c/L 在区间上严格单调 → 规格窗口可**逆变换**为 L 区间 → `Y = Φ((L_hi−L0)/σ_L) − Φ((L_lo−L0)/σ_L)` | 高斯容差积分的**精确闭式**，确定性数学 |
| ② | **蒙特卡洛**：固定种子采样 L → 逐样本算 FSR → 命中窗口计数 / N | 数值采样，N=20000 |

两者若一致（|Δ| ≤ 1 个百分点），说明数值采样与解析积分在同一物理定律上收敛。任何一方出错都会被对方抓出来——**这是可证伪的，不是自证**。

### 关键设计：解析解用精确闭式，不用一阶近似

一阶线性化（FSR 相对偏差 ≈ −L 相对偏差）会给出：

```
Y ≈ 2Φ(δ/σ_rel) − 1 = 2Φ(2) − 1 = 0.954500
```

而精确闭式给出：

```
Y = 0.954413
```

差异虽小（0.000087），**性质却完全不同**：一阶近似忽略了 1/L 的非线性。如果用近似解去"验证"蒙特卡洛，就是**两个近似互相印证**，不构成硬 ground。用精确闭式，才是真互证。

> 这也意味着：蒙特卡洛如果实现有偏（比如采样分布写错），会被解析解直接抓出来——锚具备**可证伪性**。

## 四、实测数据

### 默认场景（δ=2%、σ_rel=1%、N=20000、seed=1313）

| 量 | 值 |
|---|---|
| 解析良率 | **0.954413** |
| 蒙特卡洛良率 | **0.954750** |
| 交叉偏差 | **0.000337**（0.034 个百分点） |
| 容差 tol | 0.01（1 个百分点） |
| 样本 FSR 均值 | 17.5017 nm（名义 17.5） |

交叉偏差仅为容差的 **1/30**。

### 工艺容差扫描（DFY 设计空间）

| 光刻容差 σ_rel | 解析良率 | 蒙特卡洛良率 | 交叉偏差 |
|---|---|---|---|
| 0.5% | 0.999934 | 1.000000 | 0.000066 |
| 1.0%（默认） | 0.954413 | 0.954750 | 0.000337 |
| 2.0% | 0.682786 | 0.682850 | 0.000064 |
| 4.0% | 0.383048 | 0.383850 | 0.000802 |

良率随容差**单调下降**——这是 DFY 的物理正确性判据（容差越松良率越低，不能反着来）。扫描的每个点解析与 MC 都吻合，不是只在默认点碰巧对上。

### 规格窗口 trade-off

| 规格窗口 δ | 解析良率 |
|---|---|
| ±1% | 0.682714 |
| ±2%（默认） | 0.954413 |
| ±3% | 0.997217 |

## 五、怎么用

```python
from lda_harness.yield_anchor import (
    yield_analytic,            # 解析良率（精确闭式）
    monte_carlo_yield,         # 蒙特卡洛良率
    s13_design_yield_anchor,   # S13 golden（固定种子可复现）
    yield_report,              # 完整报告（含交叉验证 + 扫描）
    yield_vs_tolerance_scan,   # 容差 → 良率扫描（DFY 设计空间）
)

# 默认场景
rep = yield_report()
rep["yield_analytic"]      # 0.954413
rep["yield_monte_carlo"]   # 0.95475
rep["cross_check_ok"]      # True

# 客户会问的问题：「容差收紧到多少，良率能到 99%？」
scan = yield_vs_tolerance_scan(sigmas=(0.002, 0.005, 0.008, 0.01))
# σ=0.2% → 100.00%；σ=0.5% → 99.99%；σ=0.8% → 98.75%；σ=1% → 95.44%
# → 结论：要稳过 99%，光刻容差须收紧到 0.5% 以内
```

## 七、诚实边界

1. **工艺模型是输入，不是产出**：σ_rel（光刻容差）与 δ（规格窗口）目前取**公开文献典型量级**，非具体 foundry 的 PDK 实测分布。真实 PDK 校准属发动期（C 期）工作。
2. **载体单一**：当前只实现环形 FSR 这一个指标。插损 / 串扰 / 保真度的良率锚可复用同一套框架（解析闭式 + MC 互证），但尚未实现。
3. **只扰动 L**：为保持解析解精确，默认只扰动环周长（单变量，逆变换精确）。若同时扰动 n_g 与 L，FSR 分布为两独立高斯之积，解析解不再闭式——届时需改用数值积分作为 ground，互证强度会下降（诚实标注）。
4. **蒙特卡洛有采样噪声**：N=20000 时标准误约 0.15 个百分点，tol 取 1 个百分点即约 6.8σ，稳健。
