## 1. B31（C1）· Si 载流子色散相移（Soref-Bennett 闭式）

- **物理对象**：PN 结耗尽型 Si 相位调制器，反偏电压 V → 耗尽层载流子浓度变化 → 折射率变化 → 相移 → 等价 Vπ。
- **golden（design_rule_anchor · 物理定律锚）**：Soref & Bennett 1987 (IEEE J. Quantum Electron. 23, 123) 唯象闭式
  `Δn_eff = c1·ΔN_e + c2·(ΔN_e)² + c3·ΔP_h + c4·(ΔP_h)²`
  - c1~c4 为 Si 材料常数（@1550nm，ΔN/ΔP 单位 cm⁻³）。**写码时从原表逐项核对取文献公认值，严禁拟合回算**（IRONLAWS 二/27）。常用量级：c1 ≈ −8.8×10⁻²² cm³（电子线性项，文献级典型值，须以原表为准）。
- **独立候选（independent_cross_check）**：Drude 自由电子气模型
  `Δn_eff = −q²·ΔN_e / (2·ε0·n_eff·m*_e·ω²)`
  - 与 Soref-Bennett **方法学不同源**（经典微观等离子体 vs 宏观唯象多项式，含 many-body 二次项）；Drude 仅给线性自由电子项，结构差异保证非代数恒等 → 判据 D 不撞。
- **载流子（红线）**：ΔN(V)/ΔP(V) 用**一维耗尽近似闭式**（泊松方程耗尽解，零电场点 x_n/x_p 解析），**绝不求解漂移-扩散** → 不破「电域求解器」红线。
- **评审风险与处置**：① c1~c4 文献取值（已锁）；② ΔN 上限（耗尽近似失效区，~10¹⁸ cm⁻³ 量级）须标 honest_tier=「depletion-approx」；③ 相移→Vπ 由 `Δφ=2π·Δn_eff·L/λ` 换算，与 B28 电光 Vπ 范式同源不同材料（Si 载流子 vs LiNbO3 Pockels），各自独立。
- **裁决：GO。** 写码顺序 W3（见 §6）。

> **⚠️ ERRATA（2026-09-12 · W3 写码时修正）**：§1 初稿 golden 公式误写为二次近似 `Δn_eff = c1·ΔN_e + c2·(ΔN_e)² + c3·ΔP_h + c4·(ΔP_h)²`。**实际落地的代码采用 Soref & Bennett 1987 原论文幂律形式**（@1550nm，Optica OE-18-24 / math-physics.net 双重佐证）：
> `Δn_e = c1·ΔN_e + c2·(ΔN_h)^0.8`，其中 c1 = −8.8×10⁻²² cm³、c2 = −8.5×10⁻¹⁸ cm^2.4（电子线性项系数 c1 与初稿一致，已锁）。
> 原论文显式适用域 10¹⁷–10²⁰ cm⁻³；耗尽近似失效阈值 ~10¹⁸ cm⁻³ 已标 honest_tier=「depletion-approx」。独立候选 Drude（仅电子线性项）与 SB 幂律故意非代数恒等，ratio≈1.96（同号、0.2–3.0）证明捕捉同一等离子体色散物理——判据 D 不撞，与初稿评审结论一致。

## 2. B32（C2）· EAM-QCSE 吸收边位移

- **物理对象**：电吸收调制器（EAM），外电场 F → 带边位移 → 消光比。
- **golden（design_rule_anchor）**：Franz-Keldysh 效应（体材料）Kane 1956 位移
  `ΔE_g = (ℏ·e·F)² / (2·m_r*·E_g)`（m_r* 约化质量 =(1/m_e*+1/m_h*)⁻¹）。
- **独立候选（independent_cross_check）**：严格 2-band k·p 模型数值积分吸收谱，扫 F 定带边位移，与 Kane 闭式交叉。
- **关键评审风险（须在写码前消除）**：QCSE（多量子阱 MQW）与 FK（体材料）公式**不同**。golden 选错 = 锚判错。
  - **裁决前置条件**：写码前锁定目标器件是**体材料 FK** 还是 **MQW QCSE**，二者 golden 公式分叉：
    - 体材料 → Kane 1956 FK 闭式；
    - MQW → QCSE 吸收边位移闭式（阶跃场下 ΔE_g ≈ 一阶 QCSE 公式，须引对应文献）。
- **红线自检**：纯电磁/能带闭式 + 数值带结构，无载流子动力学 → 不破。
- **🔒 写码前锁定裁决（2026-09-12 · W4 写码时落定）**：**器件类型锁定 = MQW-QCSE（多量子阱 · 量子限制 Stark 效应）**。
  - 理由：① 锚名即 "EAM-**QCSE**"，物理对象明确为量子限制 Stark；② 体材料 FK（Kane）在 Si 光子平台 @1550nm 因 Si 间接带隙（E_g≈1.1eV ≫ 0.8eV 光子能）吸收边位移可忽略，非实用 Si EAM——若锁 FK 则锚判错（与物理现实脱节）；③ QCSE 是 Ge/SiGe MQW on Si 的实际 EAM 机制（Handwiki/Stanford 均载 Ge/SiGe QW 实验）。
  - golden 公式锁定：`ΔE ≈ -24·(2/3π)⁶·e²·F²·(m_e*·Le⁴ + m_h*·Lh⁴)/ℏ²`，const=24·(2/3π)⁶≈2.1924e-3（与专利 C1=-2.19e-3 一致，WebSearch 双重佐证）。
  - MQW 外延（生长）属 foundry T2 工艺真值——本锚仅消费 L / 有效质量（文献/PDK），**不求解**生长/带结构第一性原理 → 红线安全（行为层 A 档，同 B28/B29/B31 范式）。honest_tier=qcse-closed-form。
  - **裁决：GO（已锁）。** 写码见 `b32_qcse_anchor.py`（W4）。

## 3. B33（C3）· 探测器带宽 τ=RC + APD 倍增闭式扩展

- **B33 现状**：已落地（v0.9.67，严格独立 27→28，CI 全绿）。golden=`f_3dB=1/(2π·R·C)`，candidate=RC 暂态梯形积分拟合 τ。纯电路闭式，无光子有源物理。
- **研发规划 C3 要求「扩到 APD 倍增闭式」——边界裁定（重要）**：
  - **A 档合法**：APD **闭式倍增因子** `M = 1/(1−(V/V_br)^n)`（Miller 经验式，n≈3–6，V_br 与 n 取文献公认值，给定电压即算）。倍增使等效带宽下降，确定性闭式扩展：
    `f_3dB(APD) = f_3dB(PIN) / (M·k_excess)`，k_excess 为过剩噪声引起的确定性带宽折减因子（文献闭式）。
    → 属 A 档「闭式行为层」，**不破红线**。
  - **B 档锁死**：APD **雪崩载流子输运真求解**（碰撞电离率积分、载流子倍增瞬态、过剩噪声系数真算）属 T1-B 内核可做项，但**本轮 A 档不碰**；留待 Sprint 2 第3阶段 W5/W6（经 T1-B）。
  - **honest_tier**：标「RC-limited + APD-gain-closed-form（雪崩动力学留 B 档）」。
- **裁决：GO·扩展**（W1，作为 B33 的 APD 闭式子项，不新建独立锚，不虚报计数）。

## 4. C4 激光器腔体：FSR 与布拉格波长

### 4a. B34（激光器 FSR）不单列新锚 · 并入 B3 器件扩展
- **物理对象**：FP/DBR 激光腔纵模间距 `FSR = c/(2·n_g·L)`。
- **评审风险（2026-09-10 已识别）**：该式与现有 **B3（环形谐振腔 FSR = c/(n_g·L_ring)）同源方法学**（频域周期取值 / 腔长倒数）。若新增为独立锚，判据 D 视为「同性质复刻」→ **虚报独立候选数**（标签≠行为纪律缺口）。
- **终审裁决**：**不单列 B34**。改为在 **B3 候选里加 laser-cavity 工况**，物理对象差异由「有源腔 n_g 含增益介质色散（给定 n_g 即可，不求解增益）」证成。即 C4a = B3 器件扩展，零新增锚。
- 红线：n_g 由给定（或闭式群折射率）提供，不求解有源增益 → 不破。

### 4b. B35（布拉格波长 λ_B=2·n_eff·Λ）复用 B15
- **物理对象**：DBR/DFB 光栅布拉格条件 `λ_B = 2·n_eff·Λ`。
- **现状**：B15 独立候选 `bragg_solver.py`（Bloch 反周期广义本征值问题）**已实现**，与 golden 闭式交叉，判据 D 标定完成（v0.9.19）。C4b 其实现成。
- **裁决：GO·复用 B15**（不新建、不重复投入）。如需 DBR/DFB 专用入口，仅在 B15 上加 laser-grating 工况别名，零新锚。

## 5. （边界项）激光器线宽 Schawlow-Townes · 本轮不纳入

- `Δν = hν·n_sp·(1+α²) / (4π·P·τ_p²)`，含自发辐射因子 n_sp（依赖有源区载流子浓度）。
- **边界模糊**：n_sp 牵连有源区载流子 → 与「A 档零载流子求解」纪律冲突面模糊。
- **终审裁决**：**本轮不纳入 A 档**。归 B 档待杜先生拍板：
  - 若裁定「给定 n_sp 即纯闭式算 A 档」→ 可加（标 honest_tier，n_sp 作为外部给定量，不求解）；
  - 否则归 B 档（涉有源载流子）。**先搁置以守红线，不急于求成。**
