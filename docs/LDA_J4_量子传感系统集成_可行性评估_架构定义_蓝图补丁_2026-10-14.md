## 0. 立项依据

### 0.1 为什么此刻做 J4（而不是继续堆器件）

QS 征程（M0–M9 + M3c）已把**器件级**三腿全部落地：**腿 A NV 色心**（B473–B481）· **腿 B 超导 SQUID**（B485–B490）· **腿 C 光泵原子 OPM**（B491–B493）· 外加**腔 QED 物理链**（B494–B496）与**阵列/标定**（B478–B484）。这 24 道锚全部钉在「**单器件 / 单通道 / 单物理量**」这一层。

**但 QS 征程留下了一整块空白**：`docs/LDA_量子传感器芯片征程_总蓝图_v1_2026-10-10.md` §4 的收官判据只要求「设计征程功能闭环」，**从未交付「器件 → 系统」这一跃迁**。具体地说：

- **单参数 → 多参数**：现有 NV 链只回答「B 场多少」，而真实 NV 传感必须同时处理 **B / T / E / σ 四场串扰**（零场劈裂 D 同时被温度、电场、应力调制）——**全仓零实现**；
- **台式 → 芯片级**：OPM（B491–B493）的物理链是**气室/线圈的台式量级**（2 cm 气室、亥姆霍兹线圈），距「MEMS 气室 + VCSEL + 光电二极管单片集成」**只建了物理、未建集成**；
- **单通道 → 单芯片**：NV 阵列有**几何与串扰**（B478–B481），但「**NV 阵列 + 微波天线 + 光路 + 读出**如何落在同一颗芯片上、彼此的寄生耦合怎么算」——**零实现**；
- **室温/器件 → 低温/封装**：SQUID 腿（B485–B490）有器件噪声，但**低温布线热负载与封装寄生**这一「系统级成本项」——**零实现**。

这正是蓝图 §2 缺口矩阵里的 **G-QSYS*（传感系统级：多参数 / 微型化 / 单芯片 / 封装）**，也是蓝图 Layer 4 的**唯一职责**。

### 0.2 与 J1/J2/J3 及 QS 的关系（必须先对齐，避免重造轮子）

| 层                                    | 谁负责                       | J4 做什么                         |
| ------------------------------------ | ------------------------- | ------------------------------ |
| QS 器件物理（D/γ/NV 柱/腔 QED/RCSJ/气室热力学）   | QS-M0…M9 + M3c（B473–B496） | **只读复用**（不改公式、不重做）             |
| QS 阵列几何/串扰/梯度计/标定/动态范围               | QS-M4/M5（B478–B484）       | **只读复用**其**输出量**作 J4 的系统输入     |
| 逻辑/物理比特/测控闭环（QEC → Transmon → 脉冲/读出） | J1/J2/J3（B497–B514）       | **只读复用**（同属 QEDA，但 J4 不碰量子计算链） |
| **多参数解耦 + 芯片级集成 + 封装热负载 + 系统签核**     | **J4（本征程）**               | ✅ **新增**（既有锚/模块均未覆盖，见 §1.2）    |

四条线共用同一组红线（纯 numpy/scipy · 零量子 SDK · LLM 不进判决路径 · 设计预算口径非实测）。

🔴 **与 S 分支（超导版图）的分工**：J4 的「单芯片集成」是**传感系统的功能集成预算**（微波-光-读出三路的寄生耦合与净灵敏度劣化），**不是** P\&R 版图几何（那是 S5 `sc_layout`/`sc_topology_core` 的职责）——J4 只读复用其几何结果，不重做 DRC/LVS。

### 1.3 红线 / 主权可行性（LDA 铁律逐条对账）

- **主权求解器（C 级纯 numpy/scipy，不借 GEM/COMSOL/ANSYS/Qiskit 作判据）**：  
  · 多参数灵敏度矩阵 —— 4×4 线性代数（求逆/条件数/伪逆），纯 numpy；  
  · 压致展宽 —— 闭式 Lorentzian 碰撞展宽 ⇄ **Voigt/卷积数值积分**（纯 numpy）；  
  · 集成寄生耦合 —— 集总/分布电路 S 参数代数 + 数值谱积分；  
  · 低温热负载 —— 1D 稳态热传导（三对角）或 Wiedemann–Franz 电子热导闭式；  
  ⇒ ✅ **全部可行，无外部依赖**。
- **LLM 不进判决路径**：全部死标量（交叉灵敏度系数、解耦残差、条件数、线宽、隔离度、热负载 W）。✅
- **绝对 tol 按量级标定（B487 血案）**：J4 涉及 **5 类量纲** ⇒ **分别**标定 + 「**绝对 ∨ 相对并列**」（不可用 `max`，否则尺度盲）：  
  · 无量纲矩阵元/解耦残差 ~**1e−2…1e0**（条件数可至 1e3）  
  · 线宽/频率 ~**1e6…1e9 Hz**  
  · 隔离度/抑制比 ~**1e−3…1e2**（dB 型无量纲）  
  · 热负载 ~**1e−6…1e0 W**  
  · 灵敏度（对照） ~**1e−16…1e−9 T/√Hz**
- **golden 分级（③仿真值⛔永不作 golden）**：golden 锁定为 ①**闭式物理律**（NV 哈密顿闭式对角化、Lorentzian 碰撞展宽 `Δν=p·k`、Fourier 热导、Zeeman/Stark 一阶微扰位移）与 ②**已知事实**（`dD/dT` 符号、对称性选择定则）；③数值对角化/谱拟合/热传导 FD **只作候选与证据**，**永不作 golden**。✅
- **复用 S/J2/J3 铁律**：频率限带 `f01∈[5.0,6.2] GHz` · 耦合器工作区 · 拓扑度自声明 · J2「同源体检必做 / 口径订正用新增+标注 / 下界≠可达」三条工程纪律**全继承**。✅

## 3. 蓝图补丁（里程碑 · 复利吃狗粮）

> 每档用 LDA 亲手设计一段真实**传感系统补丁**，物理链逐量「**闭式 golden ⇄ 方法学独立候选**」。  
> 🔴 候选锚编号 **B515–B518** 为提案；**每档实现前必须逐锚做同源体检**，判同源即改靶（先例：J2 M0 净增 0 / J2 M3·M4 各否 2 / J3 M3 否 1）。

### M0 多参数 NV：四场灵敏度链 + 交叉灵敏度解耦（缺口 G-QSYS-1）

- **建造**：把 QS-M0 的「单参数磁力计」升级为**四参数传感**——① 磁（Zeeman `γ_e`，复用 QS-M0 哈密顿）② 温度（零场劈裂温度系数 `dD/dT`）③ 电场（Stark 移位 `dD/dE_⊥`）④ 应力（`dD/dσ`）。构造 **4×4 灵敏度矩阵** `S = ∂f_i/∂x_j`（f=ODMR 频率读数，x=B/T/E/σ），做**解耦**（`x = S⁻¹·Δf`，或**伪逆**）+ **条件数** + **解耦残差**。
- **候选锚**：**B515 多参数交叉灵敏度解耦残差**（闭式 4×4 线性解耦 `x̂=S⁻¹Δf` ⇄ **数值最小二乘 / SVD 伪逆 / 迭代 Tikhonov 正则化**，判据 D 扫正则化强度或迭代步数 ⇒ 残差单调收敛）。
- ✅ **体检预判（实测支持）**：`温度/应力/压力灵敏度` **0 命中** · `解耦\|decoupl\|多参数` **0 命中** ⇒ **多参数族零锚占用（本族首锚）**；与 **B473**（单参数 Zeeman 灵敏度）**三方分歧**：①被测标量（**交叉灵敏度矩阵/解耦残差** vs 标量 η）②物理构型（**四场线性反演** vs 单场 Ramsey）③数值格式（**矩阵求逆/伪逆/正则化迭代** vs 标量误差传播链）。
- ⚠️ **M0 备选锚（若 B515 被判同源）**：**NV 电场（Stark）灵敏度** `dD/dE_⊥`（闭式一阶 Stark 微扰 ⇄ 数值精确对角化含 E 项）；须对 **part1 EAM-MQW 量子限制 Stark** 证三方分歧（**被测标量**：NV 零场劈裂位移 vs 半导体吸收边位移；**物理构型**：金刚石色心 vs MQW 调制器；**数值格式**：微扰闭式 vs 传输矩阵）。
- **闭环**：**G-QSYS-1**（多参数解耦可用性）。

### M1 芯片级微型 OPM：MEMS 气室 + 缓冲气体压致展宽（缺口 G-QSYS-2）

- **建造**：把 QS-M9 的**台式** OPM 物理链缩到**芯片级**——MEMS 气室几何（mm 级）+ VCSEL 泵浦 + 光电二极管读出；核心新增量 = **缓冲气体压致展宽线宽** `Δν_L = p · k_broadening`（碰撞展宽，闭式）+ 微型化后的抽运均匀性/信噪比与灵敏度劣化。
- **候选锚**：**B516 缓冲气体压致展宽线宽（Voigt 半宽）**（闭式碰撞展宽 + Doppler 高斯宽度 ⇄ **数值 Voigt 卷积/谱拟合**；判据 D 扫频率网格 ⇒ 拟合残差单调）。
- 🔴 **体检预判（三重避让已做）**：气室**数密度**被 **B492** 占 ⇒ 否；**光路透过率**被 **B493** 占 ⇒ 否；**自由进动**被 **B491** 占 ⇒ 否。⇒ 本档唯一候选 = **压致展宽线宽**，须对 **B492/B493** 证三方分歧（**被测标量**：谱线半宽 Δν vs 数密度/透过率；**构型**：碰撞展宽谱 vs 热力学/光吸收；**数值格式**：Voigt 卷积数值拟合 vs 梯形积分/RK4）。另须避 **part5 B4xx 洛伦兹脉冲展宽**（光学色散展宽 `Δt=|β2|LΔω`，非气室碰撞展宽）。**若判同源 ⇒ 本档净增 0，如实登记**（不硬凑）。

### M2 单芯片集成：微波-光-读出寄生耦合 + 净灵敏度劣化（缺口 G-QSYS-3）

- **建造**：把「NV 阵列 + 微波天线 + 光路 + 读出」落到**同一芯片**的**功能集成预算**——微波驱动对光路的**寄生调制/隔离度**、光路对读出的**杂散光耦合**、读出链对微波的**反向泄漏**；多源合成 ⇒ **净灵敏度劣化倍率**与**集成签核**。
- **候选锚**：**B517 片上微波-光寄生耦合隔离度**（闭式定向耦合/隔离比 `I=1/|S21|²` ⇄ **数值 S 参数谱积分 / 耦合模 ODE 积分**）。
- 🔴 **体检预判（蓝图原提案否决）**：蓝图原提案「**集成串扰**」**已被 B478/B479 占用**（磁偶极近场串扰系数 + 灵敏度恶化倍率）⇒ 否。⇒ 改靶到**不同物理机制**的**微波-光寄生耦合**（不是磁偶极近场）：须对 **B478** 证三方分歧（被测标量：光学隔离度 vs 磁串扰系数；构型：**微波-光跨域寄生** vs 同域磁偶极；数值格式：S 参数谱积分 vs 点偶极场数值积分）。**若证否 ⇒ 本档净增 0 或并入 M3**（不硬凑）。

### M3 低温布线 / 封装热负载 + 系统签核（缺口 G-QSYS-4）

- **建造**：SQUID 腿（4K）的**低温布线热负载**（自 300K 经线束漏入 4K 级的热量 W）+ 封装寄生（电容/电感/介质损耗）+ 温漂对 `D` 的传递；与 M0–M2 总装成**系统级签核**。
- **候选锚**：**B518 低温布线束热负载**（Wiedemann–Franz 电子热导 + 1D 稳态传导闭式 `Q=(k·A/L)ΔT` ⇄ **数值三对角 1D 热传导 / 分段解析**）。
- 🔴 **体检预判（蓝图原提案否决）**：蓝图原提案「**封装热负载**」若写成**圆柱壁面热阻**或**阵列热串扰**即与 **B465/B466 同源** ⇒ 否。⇒ 改靶到 **B518 低温布线束**（**被测标量**：热负载 W vs 热阻 K/W / 温度比；**构型**：多线束跨温区 vs 单圆柱壳/相邻通道；**数值格式**：三对角稳态 vs FD-BVP）。**若判同源 ⇒ 本档净增 0，如实登记**。
- **闭环**：**G-QSYS*** 全部闭合 + **QS 器件三条腿 → J4 系统**贯通；三同步 + 冻结快照全量 CI 干净记录 → bump 发布。

### M4 WebUI + 收官

- **建造**：`qs_j4_system.py` 系统报告 + WebUI 面板 `/api/j4_qs_system`（多参数矩阵热图 / 解耦对照 / 微型气室 / 集成隔离度 / 热负载 / 签核）+ 三入口面 + `CASE_PANELS_MIN` 13→14 + 常驻 render-path 门禁。
- **候选锚**：M4 一般**不新增锚**（纯对外窗口 + 总装），除非 M0–M3 有净增 0 需在此补靶。
- **闭环**：**G-QSYS*** 收官 + QEDA「计算 + 传感」双支柱的**系统级**对外叙事。

> **建议首发粒度**：**M0 先做**（多参数解耦族实测**零占用 = 最高置信度**净增锚），验证「系统层能否出锚」，全绿后再扩 M1–M4。

## 5. 红线合规声明

- **主权求解器**：多参数矩阵 / 气室线宽 / 集成寄生 / 热传导全部纯 numpy + 标准库（scipy 仅作**第三方 oracle** 交叉核对，非唯一实现），不借 GEM/COMSOL/ANSYS/量子 SDK。
- **LLM 不进判决路径**：全部死标量比对。
- **绝对 tol 按量级标定**：5 类量纲分档（无量纲矩阵元 / 频率线宽 / 隔离度 / 热负载 / 灵敏度）+ **绝对 ∨ 相对并列** + 突变探针「先证能变红」+ 跨量纲反向探针。
- **golden 分级**：①闭式物理律（NV 哈密顿对角化、碰撞展宽、Fourier 热导、Stark 一阶微扰）+ ②已知事实 = golden；③数值对角化/谱拟合/FD 热传导 = 候选与证据，**永不作 golden**。
- **复用 S/J2/J3 铁律**：频率限带 / 耦合器工作区 / 拓扑度自声明 + J2 三条工程纪律（同源体检、新增+标注、下界≠可达）。
- **诚实边界**：示例量级标注「**非实测 PDK / 非流片**」；SOTA（真实商用 OPM/SQUID 灵敏度、集成传感器芯片）**未达如实标注对照比**；**不报** fabricated 能效 / TOPS / fJ-op；不冒充实测。
