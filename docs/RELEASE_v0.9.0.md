## 一、里程碑概述

```
看懂（特点/用途/国际对标）→ 对比（站内同类）→ 反馈（评价/提意见）
   ↓
转化：直接购买（50 开放货架）或 定制需求（6 方向导流，先看现成）
   ↓
交付：兑换码下载（限次防滥用）或 定制开发（4 状态机多文件交付）
   ↓
服务：我的模块（许可证资产/进度/改密）+ 管理员五 tab 后台
```

## 二、功能亮点

### 2.1 货架商品化三批（58/58 全覆盖）

- **ShelfItem 新增商品化四字段**：特点（features）/ 用途（applications）/ 关键规格（specs）/ 国际对标（peers）
- **58 个货架全部填充**（50 开放 + 8 量子咨询制），国际对标**全部带可溯源来源**：
  - IEEE 802.3 系列标准（PSM4/FR4/DR4/LR4/FR8）
  - ITU-T G.671 / G.9804 / G.9807.1（PLC 插损 / 50G-PON / XGS-PON）
  - 产业路线（CWDM4 MSA / LPO / NVIDIA GB300 / TSMC COUPE / Broadcom TH5-Bailly）
  - 期刊公开实验（imec OE 2020 / npj QI 2017 / OLT 2026 PSR / OE 2026 FMCW）
  - 市场报告（Cignal AI / Dell'Oro / LightCounting / IDTechEx 等，多口径并存如实标注）
- **诚实边界铁律**：全部标注「仿真预期 · 前瞻预研 · 未流片」，与流片实测性质区分

### 2.2 商务闭环四要素全通

| 要素 | 能力 |
|---|---|
| **能收钱** | 个人微信收款码 + 企业对公转账（五要素统一配置，admin 可改全站生效）；身份三档折扣（学术 6 折 / 机构 8.5 折）；对公申请免登录 + **转账凭证截图上传**（magic bytes 校验 / 3MB 上限 / 路径穿越防护） |
| **能交付** | 50 开放货架兑换码下载（**限次原子化**，并发超额防护）；定制需求 4 状态机（待接单→开发中→已交付→已验收）+ 多文件交付物 + 客户验收 |
| **能服务** | 「我的」模块（消费概览 / 许可证资产+剩余次数 / 定制进度 / 资料编辑 / 改密令牌轮换）；管理员五 tab 后台（订单 / 对公申请 / 收款配置 / 账号重置 / 意见需求） |
| **能收集** | 货架评价/提意见（免登录 + 管理员聚合含联系方式）→ 需求信号；定制需求 6 方向枚举 → 精准对接 |

### 2.3 全站体验修复

- **一键登录**：nav.js 内置全局登录弹窗，任何页面点登录直接弹窗（此前非 store 页要先跳转再点一次）
- **定制需求导流**：6 方向 chips → 该方向开放货架实时推荐 → 「直接购买」跳转（想定制先看现成）
- **站内同类对比**：货架卡勾选 2~4 个 → 7 维度对比表（含国际对标来源）

## 三、安全与质量

### 3.1 安全审计（登录注册 8 项 + 授权加固）

| 项 | 修复 |
|---|---|
| 暴力破解 | 账号 + IP 双维度失败限流（5 次锁 10 分钟，账号锁跨 IP 生效） |
| 用户枚举 | 统一「邮箱或密码不正确」+ 等价 pbkdf2 消除时序侧信道 |
| 计算型 DoS | 密码上限 200 字符（10 万字符实测可注册的漏洞） |
| 会话 | 令牌 30 天 TTL + 恒定时间比较；改密自动轮换（旧设备登出） |
| 找回密码 | 管理员重置闭环：临时密码（去易混字符）+ 强制改密 + 应急解锁 |
| 授权 | 兑换码消耗原子化（TOCTOU 修复，max_uses 真实生效） |
| 鉴权 | 🔴 修复 `dict(self.headers)` 丢 token 根因（21 处全改） |

### 3.2 数据可靠性

- JSON 原子写（tmp + fsync + replace）+ 损坏文件自动备份（不静默清空）
- 读改写全程互斥（RLock，并发丢写修复）

### 3.3 工程化

- **商务闭环入 CI core（69→70）**：`run_store_flow_smoke.py` 7 测试覆盖注册/下单/审批/下载限次/对公/定制状态机/我的/账号重置/意见，函数级直调 0.7s
- 商品化数据抽审：10 关键货架对照 signal_ref 核查，6 PASS + 4 修正（含 1 处数字错误）
- 计数守护 11/11 通过（版本线 / CI core / 引擎/题数全一致）

## 五、已知限制（诚实标注）

1. token 存 localStorage，XSS 可窃取（根治需 HttpOnly Cookie 架构，未在本次范围）
2. 无邮箱验证 / 无自助找回密码（未接 SMTP；管理员重置为兜底通路）
3. 48 货架商品化数据由 AI 起草，已抽审 10 个（4 修正）；剩余 38 个建议按类型/热点再抽
4. 用户实测发现的两处 bug（dict(headers) 丢 token、admin 缺 .hide CSS）已在本次修复，教训固化进测试矩阵
