## 1. 物理模型（NV 色心磁强计）

### 1.1 自旋哈密顿量与 Zeeman 劈裂

```
H = D·Sz² + γe·B·Sz          （D = 2.87 GHz 零场劈裂 · γe = 28.024 GHz/T）
ms = 0 / ±1 子空间 ⇒ 塞曼劈裂 Δf = 2γeB
```

- **闭式**：`zeeman_split_closed_form(B) = 2·γe·B`。
- **数值**：`spin_hamiltonian(B)` 精确对角化 ⇒ 按 **ms 标签**定位 ±1 本征值（**不是**取首末特征值——初版按排序取曾致 rel_err=51205 的血案，见 §5.1）。
- 双验：B=1 µT ⇒ 闭式 56048.0 Hz ↔ 数值 56048.0 Hz，**rel_err = 0.0**。

### 1.2 Ramsey 序列

- 相位积累 `φ = 2πγeBτ`。
- 对比度包络 `C(τ) = C₀·e^(−(τ/T2*)²)`，最优进动时间 `τ_opt = T2*/√2`（包络斜率最大化点）。
- 本档 @T2*=1 µs：τ_opt = 7.07e-7 s · φ = 0.1245 rad · C(τ_opt) = 0.0182。

### 1.3 灵敏度（口径锁定）

```
η = δB·√T*   （白噪声功率谱密度，单位 T/√Hz）
散粒噪声极限闭式：η = ħ/(gμB)·√(1+a²)·√2/(C·√(n_ph·T2*))
```

🔴 **口径纪律**：一律用 `η = δB·√T`，**禁止**与线宽受限 LOD（`T/Hz` 量纲不同）混比 —— 这是 PS 征程血案的教训，本档**前置**写入。
> 注：`qs_m0_report.json` 输出的 **846.59 pT/√Hz** 即 = 0.8466 nT/√Hz（同一数字的两单位表述，非两个值）。

## 4. 锚 B473（严格独立 · 本档唯一净增锚）

- **被测标量**：NV 磁强计灵敏度谱密度 η（T/√Hz）。
- **golden**（闭式 · 代数整理）：`η = ħ/(gμB)·√(1+a²)·√2/(C·√(n_ph·T2*))`。
- **candidate**（方法学独立 · 逐步数值合成）：`b473_nv_eta_error_propagation_cand`
  ① 相位噪声率 `ρ_φ=√(1+a²)/(C√n_ph)` → ② 最优时间 `τ_opt=T2*/√2` → ③ 用**双能级量子时间演化核**（复指数）对 B 做**数值中心差商**求磁场-相位斜率（独立于闭式的 γe 解析代入）→ ④ 谱密度归一 `η=√2·ρ_φ·τ_opt/(|dφ/dB|·√T2*)`。
- **判据**：|Δ| = **2.058e-14**（rel = **2.431e-05**）· tol = 1e-3 ⇒ **41.1× 余量** PASS。
- **同源体检**：`magnetomet|磁力计|NV|nitrogen.vacancy|金刚石|Ramsey|ODMR` 在 `BENCHMARK_DEFS` 内 **0 命中** ⇒ 量子传感器族**零锚占用（本族首锚）**。

## 5. 🔴🔴 本档吃狗粮抓到的平台真缺陷（核心产出）

### 5.1 血案 A：Zeeman 数值路径「按排序取特征值」错

初版 `zeeman_split_numeric` 取排序后首末特征值 `[0, D−γB, D+γB]` ⇒ 劈裂算成 `D+γB` 而非 `2γB`，**rel_err = 51205（5 万倍）**。
**根因**：本征值排序不携带物理标签。
**修法**：`spin_hamiltonian` 用 **ms 标签**（好量子数）定位 ±1 子空间再取劈裂。
**通则**：**对角化取物理量必须按量子数标签定位，不能按数值排序**。

### 5.2 血案 B（本档最重要）：反自证桩护栏的**盲区**

**现象**：B473 初版被 `run_benchmark_falsifiability_smoke` **误判为自证桩**（该 smoke 实测「严格独立=468、自证桩=20/491」，而 `run_three_class_consistency_smoke` / `run_maturity_baseline_smoke` 却报 strict=469、桩=19 —— **两条独立推导路径打架**）。

**根因（双因叠加，缺一不可成灾）**：
1. **锚未携带可扰动参数**：B473 初版 `default_params={}`（T2*/C/n_ph 写死在函数体内）⇒ `candidate_responds` 的**行为判据** `for key,val in params.items()` 空循环 ⇒ **恒返回 False**；
2. **桩判据用绝对残差阈值**：判据为 `|cand−golden| < 1e-12 AND not responds ⇒ 桩`。而 η 本身是**极小物理量**（≈8.5e-10 T/√Hz），候选与 golden 的**绝对**残差 = 2.06e-14 **< 1e-12** ⇒ 第一条件成立 ⇒ 误判。

> 注意：B473 的**相对**一致性 2.43e-05 是**真独立方法吻合**（tol 的 41× 余量）。误判纯粹由「绝对残差阈值 + 无参可扰」造成。

**与既有血案的关系**：B10（v0.9.24）是「残差**物理上不可标定**、恰落 1e-12 内」被误判 —— 与之**同族、方向相反**（B10 是残差小但确有响应；B473 是残差小且无参可扰）。这说明**桩判据对「小量物理量」系统性偏严**。

**修法（通法，已落地）**：**锚必须携带可扰动的物理参数**。
- `_batch_b39_numeric.B473_DEFAULT_PARAMS` = 四个物理设计量 `{T2star_s, n_ph_per_s, contrast, dark_ratio}`；
- `golden_b473(**params)` 与 `cand_b473(**params)` 接收之；adapter 从 `spec.params` **thread** 传入；
- 实测：`candidate_responds=True` ⇒ 正确判**严格独立**；且 golden/candidate 数值**逐位不变**。

**验证**：全量 falsifiability smoke 复跑（见 §6）。

### 5.3 血案 C：灵敏度量纲（1000×）

初版候选链误用「每循环光子数 N=n_ph·τ_opt（N≪1）」+ `δB·√τ_opt` 归一 ⇒ 与 golden 差 **1000×（=1/√T2*）**。
**根因**：标准 NV 灵敏度用**单位时间相位噪声率** `ρ_φ=1/(C√n_ph)`（rad/√s），**不是**每循环总光子数的 1/√N。
**通则**：谱密度归一必须用「单位时间噪声率」，循环计数归一错 ⇒ 量纲级偏差。
