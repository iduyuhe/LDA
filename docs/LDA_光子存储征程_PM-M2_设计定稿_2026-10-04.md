## 0. 一句话结论

M0/M1 只回答「**能不能写、能装几个电平**」；M2 补上两块**刻意排除在外的物理**：
**① reset 淬火快不快**（PM-G3）与 **② 态能不能保持住**（PM-G5）。
两块都**闭合**，但同时**派生并如实公开两个新缺口**（PM-G6 相位域口径 / PM-G7 光学域 drift 锚）——
**本轮最有价值的产出不是「数字漂亮」，而是「光学域保持性证据不足」这一条被机器判定并公开。**

## 1. PM-G3 瞬态热（缺口闭合）

### 1.1 缺的是什么

`reset`（写非晶）要求把 GST 熔体**淬火**到玻璃转变温度以下；淬火太慢 ⇒ 部分晶化 ⇒ 写不进非晶态。
M0/M1 完全没有膜厚维度，也没有热学时标 ⇒ 无法回答「膜能做多厚」「写周期下限是多少」。

### 1.2 补的锚（逐条带来源）

| 类 | 数量 | 值 | 代表来源 |
|---|---|---|---|
| 非晶相热扩散率输入 `{ρ, cp, k_a}` | **2 源**（+1 源**字段级排除**） | `k_a = 0.17 / 0.2 W/m·K`，`ρcp = 1.252×10⁶ J/m³K` | Opt. Express 23(23):29353；Front. Mater. 8:798398 |
| 晶化/玻璃转变温度 | **3 源** | 130 / 150 / 160 °C | J. Phys. Conf. Ser. 214:012102；Optica AOP 18(2):285；arXiv:1809.08907 |
| 熔点 | **2 源** | 873 / 893 K | arXiv:1809.08907；Microsyst. Nanoeng. 8:101 |
| 界面热阻 TBR（GST/SiO₂） | **3 源** | 5.0 / 5.8 / 7.5 ×10⁻⁸ m²K/W | Front. Mater.；arXiv:1809.08907；JSTS（汇总） |
| 界面热阻 TBR（GST/金属） | **2 源** | 2.0 / 2.6 ×10⁻⁸ m²K/W | JSTS；Front. Mater.（GST–TiN） |
| 临界冷却速率 | **1 源（数量级锚）** | **~10⁹ K/s** | Adv. Mater.（2024）DOI:10.1002/adma.202414031 |

> 🔴 **数量级锚纪律**：文献只给「order of 10⁹ °C/s」⇒ 全程标注 `is_order_of_magnitude=True`，**不当精确值用**。
> 🔴 **字段级消费审计**：`arXiv:1809.08907` 自述 `k`「temperature/phase dependent」但未给数值 ⇒ **排除出扩散率消费**，该源只贡献熔点锚（这正是「缺锚不发明」的机器体现）。
> 🔴 **防漂移判据 `thermal_table_consistency()`**：同来源在 `THERMAL_ANCHORS`（服务写能量预算）与 `TRANSIENT_THERMAL_ANCHORS`（服务瞬态热）两表并存时，**ρ/cp 必须逐位相等**——消费语义分离 ≠ 数据可以不一致。

### 1.3 核心律：可非晶化最大膜厚（**双口径并报**）

- **扩散口径**（乐观上界）：`L_max = π·√(D·ΔT/R_crit)`
- **集总 RC 口径**（保守，含界面热阻）：`(ρcp/k_a)·L² + TBR·ρcp·L − ΔT/R_crit = 0`

**实测（GST，ΔT = 440–490 K）**：

| 口径 | L_max | 与文献经验上限（~150 nm） |
|---|---|---|
| 扩散 | **768 – 879 nm** | 5.1–5.9× ⇒ 同数量级 |
| 集总 RC | **240 – 272 nm** | 1.6–1.8× ⇒ 同数量级（**更贴近**） |

> 🔴 **判据是双边的**（`0.1 < L_max/150nm < 10`）。原实现只查「不过大」⇒ `L_max` 塌缩时不报警 ⇒ **单边判据是假判据**；该缺陷由本轮探针 **P1 抓出**并修正。
> 模型忽略相变前沿动力学与温度依赖 `k` ⇒ 只作**可行性上界**，不作精确厚度选择依据。

### 1.4 冷却时间与写周期下限

**闭式（串联 界面 TBR + 体 的集总 RC）**：`τ_cool = (TBR + L/k_a)·(ρ·cp·L)` —— 对膜厚 **二阶**（界面项 ∝L、体项 ∝L²）。

**写周期下限 = 脉冲宽 + τ_cool**（切换时间的定义，Adv. Mater. 2024）。

**实测（10 nm 膜）**：

- `τ_cool = 1.25 – 1.68 ns`（跨 TBR 源与热扩散率源）
- `t_cycle_min = 501.25 ns`（**由 500 ns 脉冲主导**），`f_max ≈ 2.0 MHz`
- ⇒ **结论：冷却不是瓶颈，脉冲宽才是。** 薄膜器件的热时标在 ns 量级，写速度受脉冲宽（reset 典型 几百 ns – µs）约束。

## 2. PM-G5 非晶 drift（缺口闭合 + 新缺口派生）

### 2.1 物理与锚

非晶相处于亚稳 ⇒ **结构弛豫** ⇒ 电阻随时间漂移：**`R(t) = R₀·(t/t₀)^ν`**（power law）。

| 锚 | 值 | 来源 |
|---|---|---|
| ν（暗态，300 K） | 0.11 | arXiv:1912.04480 |
| ν（暗态，125 K） | 0.07 | arXiv:1912.04480 |
| ν ± σ_ν | **0.12 ± 0.029**（300 K） | arXiv:2002.12487 |
| ν 上界（可接受） | < 0.18（专利另给优选 < 0.058） | US7701749B2（引 Pirovano, IEEE TED 51(5):714） |

**幂律两路互证**：路径 A（幂式直接）⟷ 路径 B（「激活能随 `ln t` 线性增长」+ Arrhenius 导出幂律，Boniardi & Ielmini, APL 98:243506 (2011)）⇒ dev **1.59e-15** ⇒ 锁定 `ν ≡ 激活能对数增长速率` 的物理语义。

### 2.2 正面结论：对数域不变性

drift 是**统一因子**：`R_j(t)/R_k(t) = R_j(0)/R_k(0)`（与 t 无关）
⇒ **对数域电平间距对 drift 严格不变**；只有**线性域**读出才被侵蚀。

> 🔴 本式是**代数恒等** ⇒ 门禁只作**事实陈述**；其判别力由**反向探针**证明（令各电平带不同 ν ⇒ 比值漂移 **36.9%** ⇒ 律可被证伪，非恒真）。

### 2.3 保持窗口（**电学域可算**）

真问题不是「统一漂移」而是 **`ν` 的单元间分散**：展宽 = `σ_ν·ln(t/t₀)`，要求 ≤ 间距/σ_mult
⇒ **`t_hold = t₀·exp( ln10·log_range / ((n−1)·σ_mult·σ_ν) )`**。

**实测（16 级 / σ_mult=3 / σ_ν=0.029）**：

| 电阻比 log_range | t_hold |
|---|---|
| 2 decade | **34.1 s** |
| 3 decade | **199.0 s** |
| 4 decade | **1162 s（19.4 min）** |

> ⇒ **电学域多电平保持窗口为分钟级**（4-bit）。🔴 电阻比数量级为**假设**（无逐条文献锚）⇒ 只报**敏感性区间**，不报单点寿命。

### 2.4 🔴 头号诚实结论：光学域 drift **无直接定量锚**

- 检索所得 drift 锚**全部是电学域（电阻）**；**@1550 nm 的 n/k 随时间定量漂移**未获直接锚。
- 实现上：`OPTICAL_DRIFT_ANCHORS = {"GST": []}`（**显式登记为空**）⇒ `optical_drift_status()` **机器可判**为「无直接锚」。
- ⇒ **派生新缺口 PM-G7**。
- **跨域代理**（`retention_window_optical_proxy`）：若光学相对漂移率与电学**同阶** ⇒ 6% 间距被侵蚀仅需 **1.6–2.4 秒**。🔴 **该代理是无据假设**，显式标注「不作光学域寿命结论」。

> **含义**：M1 的光学振幅域多电平设计，其**长期保持性尚无证据支持**（既不能证明能保持，也不能证伪）。
> 这正是「用平台设计芯片、反过来暴露平台短板」的典型产出：**下一步要么补光学域 drift 实测锚，要么在设计上引入参考/差分单元补偿，要么换相位域机制（关联 PM-G6）。**

## 3. 缺口台账纪律升级（本轮结构性修正）

| 项 | 修前 | 修后 |
|---|---|---|
| 闭合判据 | `closed = evidence_ok` 后判 `closed == evidence_ok` ⇒ **同义反复、恒真** | `GAP_SPECS` 加**人工声明 `declared_closed`**；判据 = `declared_closed == evidence_ok`（**两不同来源**） |
| `_ev_g3` | `hasattr(ML, "THERMAL_TRANSIENT_ANCHOR")`（存在性字面量） | 读锚表 + 跑 `diffusivity_table` / `max_quench_thickness`（**算出来的**） |
| `_ev_g5` | `hasattr(ML, "DRIFT_ANCHOR")` | ν 锚 ≥3 源 ∧ 两路互证 ∧ **光学域判定为无锚**（算出来的） |
| 缺口集 | G1–G5 | **G1–G7**（新增 G6 相位域口径 / G7 光学域 drift 锚） |
| M0 探针 P4 | 查 `closed==evidence_ok`（与升级后判据**脱钩**） | 直击判据表达式 `declared_closed == evidence_ok` |

**终态**：`gaps_total=7 / gaps_closed=4` —— 闭合 **G1（材料锚库）/ G3（瞬态热）/ G4（晶化动力学）/ G5（drift 物理来源+电学域锚+光学域适用性判定）**；

## 5. 与 M0/M1 的接续

| 档 | 回答的问题 | 核心律 | 缺口 |
|---|---|---|---|
| **M0** | 一个单元能不能写 1 bit | `IL_π ≡ (10/ln10)·2πk/Δn`（Γ 与 L 同时约掉） | G1 闭合 |
| **M1** | 同一单元能装几个电平 | 可行 ⇔ `r = k_a/(k_c−k_a) ≤ 0.198`（Γ 与 L 同时约掉） | G4 闭合，G6 派生 |
| **M2** | 淬火快不快 / 态能不能保持 | `L_max = π√(D·ΔT/R_crit)`；`t_hold = exp(ln10·log_range/((n−1)σ_mult σ_ν))` | G3/G5 闭合，G7 派生 |

**三档同一条设计哲学**：*材料（及其比值）决定能力，几何（Γ / L / 膜厚）只分配窗口*。
