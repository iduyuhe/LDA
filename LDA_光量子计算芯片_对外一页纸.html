四条硬结论

① 紧界可达：通用 N 模酉的相邻耦合紧下界 = N，矩形 Clements 网格深度恰 = N，且元件数不增。

② 参数计数会骗人：「可及参数 ≈ ⌊N/2⌋·D」只是上界；实测可达维数显示全最大匹配序列恒为 2N（与深度无关），最优浅电路是交替砖墙。

③ 通用与省损不可兼得：损耗墙本质是深度墙，深度下界 Ω(N)；时间复用省元件但更费损，只有放弃通用性的浅电路才越墙。

④ 约定须精确到块级恒等式：相位臂不一致的「看似只差一个标量」，嵌入 N×N 后变成逐模相位注入，连全局相位都不是。

可信度来自哪里

判决不靠模型：是否通过由死标量比对（闭式物理律 vs 数值）给出，LLM 不进判决路径。

外部真值分层：闭式科学原理与 A 级实测事实可作基准，仿真/计算值永不作基准；对标只比规模架构，不比数值。

机器可判护栏：每个能力配常驻门禁 + 突变探针（探针证明断言真会变红）；本芯片案例的 UI 面板亦有 24 判据把数字对回报告与平台常量，文案漂移即红。

可复现：纯 numpy，零量子 SDK，零 GPU，python examples/lda_qchip_m5.py 秒级复跑。

诚实边界（与本页同步，不可省略）

① 本成果是设计 + 数值正确性证明（数学 + 构造性数值 + 版图签核流程），非流片后实测； ② 损耗 / 效率均为设计预算口径（per_mzi 2.4 dB / per_step 2.6 dB），非实测 PDK； ③ 与 Borealis 只比规模 / 架构 / 参数计数，不比数值（CV GBS vs DV 被动 LOQC，物理模型不同）； ④ 「综合对标分」是平台自定义量，非国际公认指标； ⑤ 最优性证据限于 N ≤ 8 / D ≤ 6 搜索空间（N=4 穷举），不宣称全局最优证明； ⑥ 每模口径不含波导交叉损耗，属下界。
